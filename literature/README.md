# Literature

This directory stores **source and literature links only**. It is deliberately separated from distilled principles, article cards, modern cases, and executable skills.

## Why this separation exists

Praxis Engine distinguishes four layers:

1. **Source** — what the original text actually says.
2. **Extraction** — what problem, mechanism, causal model, and boundary conditions can be reconstructed from it.
3. **Synthesis** — which mechanisms recur across multiple sources and survive comparison.
4. **Application** — whether the synthesized mechanism transfers to a modern problem.

Mixing these layers makes it too easy to project later ideas back into earlier texts. Literature files therefore contain bibliographic metadata, canonical links, edition notes, and reading status, but no derived doctrine.

## Files

- `mao-selected-works.md` — first four volumes and supporting editions/indexes.
- `bayesian-reasoning.md` — primary and canonical Bayesian references.
- `kelly-criterion.md` — Kelly's original paper and later rigorous treatments.
- `compounding.md` — compound-growth and geometric-growth references.

## Source priority

Prefer sources in this order:

1. primary/original publication or authoritative edition;
2. official or institutional archive;
3. reputable scholarly archive;
4. high-quality secondary exposition.

Every link should record what role it plays and, where relevant, edition/version differences.

## Rule

Do not place distilled conclusions in this directory. If a source leads to a methodological claim, cite it from an article card or synthesis document instead.
