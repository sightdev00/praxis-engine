# Method Evolution — V1-005 through V1-013

This note records three methodological controls that became strong enough during V1-005–V1-013 to affect how Praxis Engine should work. They remain testable protocol hypotheses rather than permanent doctrine.

---

## M-01 — Separate epistemic deliberation from action commitment

### Trigger

- V1-005 `关于纠正党内的错误思想`
- background negative case: V1-004 remote directives vs local reality

### Observation

V1-005 places different controls before and after a decision:

```text
Before commitment:
  gather lower-level reality
  allow competing views
  clarify disagreement
  understand meaning and method

After commitment:
  coordinate execution
  transmit decision
  avoid incoherent simultaneous action

Later:
  retain a path to reopen the issue
```

### Praxis control

Do not collapse these into one generic “decision” state.

For research/Agent work distinguish at minimum:

```text
HYPOTHESIS / DELIBERATION
-> COMMITMENT
-> EXECUTION
-> VALIDATION / REOPEN
```

Evidence thresholds and behavior differ by phase.

### Why this matters

A system that demands execution discipline too early suppresses useful uncertainty. A system that remains indefinitely in deliberation after a reversible commitment cannot coordinate or learn from execution.

### Risk

This can become ceremony if every trivial action gets formal states. Apply only where mistaken commitment has material downstream cost.

## M-02 — The investigation/classification ontology is itself a hypothesis

### Trigger

- V1-007 `反对本本主义`
- V1-009 `怎样分析农村阶级`
- counterpressure from V1-004 `井冈山的斗争`

### Observation

V1-007 correctly attacks conclusions formed before investigation, but also prescribes a class-centered investigation schema. V1-009 operationalizes that schema into a consequential classifier. V1-004, however, contains evidence that kinship, native/guest identity, locality and historical conflict can alter behavior across class lines.

Therefore:

```text
investigate reality
!=
assume the categories used to investigate reality are already correct
```

### Praxis control

For every structured investigation/classification, record:

- why these variables/categories were chosen;
- what observations would show that the schema is missing a dimension;
- borderline/unclassified cases;
- whether the schema is descriptive, predictive, or connected to action;
- how it can be revised without losing traceability.

### Consequence gradient

The closer a classifier sits to consequential action, the stronger the audit requirement:

```text
analysis label
< recommendation
< resource allocation
< irreversible write/action
```

### Risk

Infinite ontology doubt can block useful analysis. Require a concrete anomaly, unexplained residual, costly error mode, or decision consequence before expanding the schema.

## M-03 — Action-as-learning requires a reversibility / failure-cost gate

### Trigger

- V1-013 `中国革命战争的战略问题`
- explicit source model: plan execution is another process of knowing the situation; revise plan if reality diverges

### Observation

V1-013 offers a powerful loop:

```text
evidence
-> synthesis
-> judgment
-> plan
-> execution
-> new evidence
-> re-judgment
-> plan revision
```

For Agent/modern systems this cannot be copied without qualification. Some actions generate information only by imposing unacceptable irreversible cost.

### Praxis control

Before using action primarily to learn, classify:

```text
1. reversible / sandboxed
2. recoverable with bounded cost
3. partially irreversible
4. catastrophic / rights-affecting / destructive
```

Prefer experiments, simulations, read-only probes, shadow evaluation or limited pilots when the action class is 3–4.

### Conflict-specific extension (tested at V2-034)

When the action responds to an adversarial or disputed event, reversibility alone is insufficient. Record:

```text
trigger evidence
-> attribution confidence
-> authorized objective
-> minimum necessary response
-> third-party / rights impact
-> escalation ceiling
-> stop / ceasefire condition
-> monitoring
-> re-entry condition
```

V2-034 supplies a partial lifecycle—defensive trigger, readiness/selectivity, and a stop/reset rule—but not neutral fact finding, proportionality, third-party protection or an appeal path. Those are modern safety additions and must not be attributed to the source.

### Decision rule

“Practice is evidence” does not imply “all uncertainty should be resolved by real-world trial.”

The stronger formulation is:

> use the lowest-cost observation or intervention that can discriminate the live hypotheses while keeping failure consequences acceptable.

### Relation to future Bayes/Kelly synthesis

This will later connect naturally to value of information, downside risk and allocation, but Phase 1 must keep those external theories out of the Mao-text attribution layer.

---

# Status

All three controls and the conflict-specific extension are **active working hypotheses for Praxis Engine**, not claims that Mao explicitly formulated them in this modern form.

They should be tested against the remaining corpus and may be narrowed, split or removed.
