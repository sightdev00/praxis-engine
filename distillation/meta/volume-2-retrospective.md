# Meta Retrospective — After Mao Selected Works Volume II

> Scope: what the research system learned while completing V2-001—V2-040.  
> This evaluates the protocol, not the political correctness of the corpus.

## 1. Volume-I controls survived, but needed sharper state distinctions

The six-pass workflow continued to prevent source claim, empirical reality and modern transfer from collapsing. Volume II especially validated:

- source/interpretation separation;
- dual textual/empirical confidence;
- prediction and revision ledgers;
- stage and actor model versioning;
- adversarial reading before abstraction.

The main new need was not another reading pass. It was better typing of objects inside the existing passes.

## 2. Prediction tracking changed the conclusions

Without a prediction ledger, later texts repeatedly claiming prior correctness would have produced survivorship bias. Component scoring exposed:

- strong foreign-policy forecast failures;
- local outcome vs universal mechanism divergence;
- vague horizon and superlative problems;
- a completed event prefix being mistaken for a whole future sequence;
- a public forecast being downgraded weeks later.

Retain the ledger. Add an explicit distinction among `forecast`, `target`, `commitment`, `contingency` and `outcome` so a numeric order or preparation plan is not scored as a neutral expectation.

## 3. Variant audit expanded from wording to document function

Volume II showed that title, date, owner, addressee, signatory, channel and document type can change the reconstructed reasoning role.

V2-031 is decisive: a branch-aware Central decision becomes a compact editorial principle. A selected-only reading loses uncertainty, implementation and authority context.

Protocol effect: source identification must include delivery metadata and role when a variant is methodologically important.

## 4. The conflict safety gate required an extension

V2-034 supplied trigger/readiness/stop structure; V2-038 demonstrated why it is insufficient. Adversarial action now requires:

```text
trigger evidence
attribution confidence
authorized objective
minimum necessary response
third-party / rights impact
escalation ceiling
stop / repair / ceasefire
re-entry condition
```

This change is retained as an active hypothesis. The corpus does not get credit for safeguards added by the research system.

## 5. Contingency and belief are separate control planes

The strongest Agent-level lesson from the volume is V2-038→040:

```text
prepare for branch B
!= believe branch B is certain
```

An Agent record should separately carry:

- branch probability;
- downside severity;
- preparedness level;
- activation trigger;
- preferred-branch shaping actions.

This prevents high-cost but low-probability risks from being ignored without letting them dominate the base model.

## 6. Revision quality needs upstream-cause review

V2-040 correctly identifies that some cadres confused worst-case preparation with the only future. But V2-038's central public statement itself used near-certain nationwide-rupture language.

Meta correction:

> when many executors make the same mistake, inspect instructions, interfaces, incentives and examples before assigning the failure only to executor judgment.

Revision should localize both the belief error and the communication/system condition that propagated it.

## 7. Trust should be permission-tiered

V2-035 and V2-037 initially look inconsistent: zero-suspicion leadership screening vs broad intake despite infiltration risk. The useful model is role-sensitive:

```text
permission / blast radius / reversibility
-> screening threshold
-> monitored access
-> trust update
```

This is a better ontology than a single “trusted/untrusted” field. It remains a candidate until tested outside clandestine/war institutions.

## 8. Article-card scale is becoming a real architecture cost

The current cards are rigorous but often 250–300 lines. That helped complex source reconstruction, yet it makes 159-item comparison expensive and partially duplicates evidence ledgers.

Decision for Volume III:

- do not retroactively compress Volume II;
- preserve full argument maps for genuinely complex texts;
- for short/repetitive texts, keep Pass sections but avoid forced subsection count;
- keep factual/source detail in evidence ledgers;
- use volume and cross-article syntheses as comparison surfaces rather than repeatedly reopening every card.

This is a cost-control refinement, not a relaxation of evidence requirements.

## 9. No generalization upgrade from repetition alone

Volume II contains many closely related united-front documents. Repetition across V2-027–040 often reflects one policy campaign, not independent confirmation.

Accordingly:

- actor-vector, branch-aware planning and formal/operational separation remain `P2`;
- bounded conflict is `P2` with explicit modern safety additions;
- no Volume-II pattern becomes `G3`;
- Volume III must test organization, learning, economy and leadership contexts that are less tied to the same conflict chain.

## 10. AgentRecord boundary remains unchanged

The results strongly overlap AgentRecord concerns—belief control, commitment, validation, workflow and experience retention—but the project has not yet shown that an existing AgentRecord judgment must change. No write-back is made at this checkpoint.

A future write-back would be justified if cross-volume evidence shows, for example, that preparedness routinely contaminates belief state unless stored in separate fields, or that permission-tiered trust materially improves Agent outcomes beyond this historical corpus.

## 11. Active hypotheses carried into Volume III

1. problem representation and observation schema are revisable hypotheses;
2. evidence, interpretation, forecast, commitment and action require separate states;
3. contingency preparation must not overwrite branch probabilities;
4. stage models need entry, residual, maintenance, regression and action boundaries;
5. actor models need issue/time dimensions and behavioral update;
6. formal artifacts require operational/effective-control validation;
7. conflict actions require attribution, proportionality, exit and repair gates;
8. trust/screening should scale with permissions and failure cost;
9. revision must inspect upstream communication as well as executor error;
10. source variants can change the document's function, not only wording.

These remain testable working hypotheses, not final Agent laws.
