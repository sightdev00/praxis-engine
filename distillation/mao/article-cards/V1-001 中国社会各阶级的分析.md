## B. Historical situation

### S — source / editorial context

毛选版编者说明将本文置于第一次国共合作和革命运动发展背景下，并说明写作针对党内两种策略倾向：一类侧重同国民党合作而忽视农民，另一类侧重工人运动而同样忽视农民。

### I — reconstruction

这不是一篇抽象社会学分类文章。它面对的是一个直接的战略资源问题：

```text
自身力量有限
-> 必须寻找盟友并识别敌对力量
-> 但社会群体不能按表面身份粗分
-> 需要用经济位置、利益与现实行为预测政治取向
-> 据此决定团结、领导、争取、防范或对抗
```

因此其核心产物不是“阶级表”，而是一张**行动者—利益—倾向—能力地图**。

---

## C. Problem

### S

文章开头把“谁是我们的敌人、谁是我们的朋友”定义为革命首先必须解决的问题，并认为过去斗争成效不足与不能正确团结朋友、攻击敌人有关。

### I

可重写为一个一般战略问题：

> 在资源有限且参与者立场不完全固定的环境中，如何识别哪些力量可以长期合作、阶段性争取、需要防范，或构成根本性阻碍？

文章选择的主要解释变量是：

1. 经济地位；
2. 所受压迫/收益结构；
3. 是否拥有生产资料和上升机会；
4. 组织集中程度；
5. 革命局势所处阶段及胜利可见度。

---

## D. Observed facts

本文使用的事实类型并不单一。

### S — explicitly used evidence

- 不同群体在所有权、收入、土地、资本和劳动关系上的差异；
- 不同小资产阶级群体存在“有余剩 / 大体自给 / 生活下降”等内部差异；
- 半自耕农、贫农、雇农等承受的经济压力程度不同；
- 产业工人的数量虽少，但集中于铁路、矿山、海运、纺织、造船等产业；
- 海员、铁路、煤矿、沙面以及五卅后的罢工作为工人组织力量的经验材料；
- 五卅运动和农民运动被用于判断不同小资产阶级群体在运动高涨时的行为变化。

### I — evidence pattern

文章实际采用的是一种“结构变量 + 行为证据”的组合：

```text
资源/利益位置
+ 当前生活趋势
+ 组织结构
+ 已发生的集体行动
-> 对未来政治行为的预测
```

这比单纯根据身份标签判断阵营更细。

## E. Competing judgments

### S / editorial context

编者说明列出的两种被反对路线，都表现为只看到部分力量而没有找到更广泛的同盟来源。

### S — within the article

文章还反对把“中间阶级”看成稳定、统一、可以长期独立存在的整体，强调其内部差异和在局势变化中的分化可能。

### I

本文反对的深层错误可概括为：

1. **只看显性组织，不看潜在力量来源**；
2. **按大类标签处理内部高度异质的群体**；
3. **把参与者立场看成静态属性，而不是利益与阶段共同作用的结果**；
4. **只按人数判断力量，忽视集中程度和结构位置。**

---

## F. Contradiction structure

本文没有以后来《矛盾论》的完整术语组织全文，因此不强制给出“主要矛盾/主要方面”的形式化标签。

### I

从决策结构看，至少存在两层关键冲突：

1. 革命力量与其所定义的根本敌对力量之间的冲突；
2. 革命阵营内部“力量不足”与“社会中存在大量潜在可联合力量但未被正确识别/组织”之间的矛盾。

本文重点解决的是第二层的**战略识别问题**。

## G. Actors / forces

| 群体 | 文中主要经济/利益特征 | 文中预测的政治倾向 | 方法论上值得保留的观察 |
|---|---|---|---|
| 地主与买办上层 | 与既有国内外权力/资本结构深度绑定 | 根本敌对 | 深度受益于现状者的转换成本极高 |
| 民族资产阶级/中产阶级 | 受外资和军阀压迫，同时担心更激进的社会变化 | 摇摆、可能分化 | 一个参与者可同时受到相反方向的利益压力 |
| 小资产阶级上层 | 有余剩并期待上升 | 更谨慎/怀疑 | “未来上升预期”会影响风险偏好 |
| 小资产阶级中层 | 大体维持但受压加重 | 中立但不必然反对 | 当前尚可生存并不等于支持现状 |
| 生活下降群体 | 相对过去持续恶化 | 更倾向变化 | **趋势**可能比静态收入水平更能解释行动倾向 |
| 半无产阶级/贫农等 | 资产少、压力高、生活脆弱 | 较强改变现状动机 | 受损程度与行动动机可能相关，但不能脱离组织条件 |
| 产业工人 | 数量不大、集中、处于关键产业、缺少生产资料 | 被判断为领导力量 | 力量不仅是人数，还取决于集中度和结构位置 |
| 游民无产者 | 高度不稳定、组织形式复杂 | 可形成力量，也有破坏性 | 高动员能力与高治理风险可以同时存在 |

## H. Stage judgment

### S

文章明确指出，同一小资产阶级内部各部分在平时态度不同，而在“革命潮流高涨、可以看得见胜利的曙光”时，中间乃至右翼部分的行为可能变化。

### I

这是全文最重要而容易被“静态阶级表”掩盖的机制之一：

```text
参与者属性不是常数
stance = f(material position, trend, perceived success, pressure, organization)
```

因此任何行动者地图都带有时间戳。

## I. Causal model

以下为从全文重构的主要因果命题。

### I1. 经济依赖 -> 利益绑定 -> 政治倾向

```text
生存/发展高度依赖既有权力结构
-> 改变现状会破坏核心利益
-> 更可能维护现状并阻碍相反运动
```

### I2. 双重利益压力 -> 摇摆/分化

```text
既受到现状压迫
+ 又受到替代秩序威胁
-> 对变革同时存在支持与恐惧
-> 随局势发展发生分化
```

### I3. 生活下降趋势 -> 改变现状动机增强

```text
过去较稳定
-> 当前持续下降/债务与压力增加
-> 对现状预期恶化
-> 更愿意支持改变
```

### I4. 集中度 + 结构位置 -> 超过人数本身的行动能力

文章解释产业工人作用时，不只诉诸人数，而强调“集中”以及其在现代生产中的位置。

```text
数量有限
+ 高集中
+ 关键生产位置
+ 强烈共同压力
-> 高组织与集体行动能力
```

### I5. 胜利可见度上升 -> 中间力量参与意愿变化

```text
成功概率看起来很低
-> 中间群体观望

成功概率/势头显著上升
-> 观望成本上升、参与风险下降
-> 更多中间力量加入或附和
```

这是解释“阶段变化导致联盟结构变化”的候选机制，后续必须与其它文章交叉验证。

## J. Strategic objective

### S

正确识别真正的朋友与敌人，从而团结可团结的力量，对抗根本敌对力量，并避免领导方向错误。

### I

更抽象地说，战略目标是：

> 在自身资源不足的条件下，通过正确识别和组织外部力量，扩大有效力量集合，同时避免把不稳定伙伴误判为稳定核心力量。

---

## K. Tactical / operational actions

本文直接给出的行动不是具体战术动作，而是战略前置工作：

1. 对社会群体作细分；
2. 分析其实际经济地位；
3. 判断其在当前阶段的利益方向；
4. 区分稳定盟友、可争取力量、摇摆力量与根本对立力量；
5. 对摇摆力量保持动态判断，而不是一次分类后永久固定。

---

## L. Organization and execution

本文对具体组织流程展开有限，但有两个可观察点：

- 文章认为“领导方向正确”是行动成败的前置条件；
- 对产业工人能力的解释明确包含“集中”这一组织结构变量。

因此本卡暂不从本文单独推出完整组织理论。

## M. Feedback / falsification

### S

文章用此前罢工、五卅运动及农民运动作为对部分判断的经验支持。

### I — possible falsifiers

本文核心模型会被以下事实削弱：

- 相似经济地位的人群长期表现出系统性不同的政治行为，而差异无法由组织、文化、制度等变量解释；
- 生活下降并不增加改变现状倾向，或在某些制度下反而强化保守行为；
- 高度集中并不带来更强行动能力；
- 所谓“中间力量随成功可见度变化而移动”的现象在其它阶段不成立。

后续文章必须专门寻找这些反例，而不是只搜支持证据。

## N. Candidate transferable mechanisms

以下全部为 **G1**，不得直接进入最终 Skill 强制规则。

### G1-01 — Actor mapping should begin from stakes, not labels

广义参与者分析应优先问：

```text
他拥有什么？
依赖什么？
正在失去什么？
希望获得什么？
什么变化会威胁其核心利益？
```

而不是先依据职位、组织名称或公开表态归类。

### G1-02 — Segment internally heterogeneous groups

同一个大类内部，如果资源、趋势和风险暴露不同，其行为可能完全不同。粗粒度分类会直接导致联盟与资源判断错误。

### G1-03 — Track trajectory, not only current state

当前绝对水平之外，还应观察：

```text
improving / stable / deteriorating
```

相对于过去的下降趋势可能显著改变行动动机。

### G1-04 — Power is multidimensional

有效力量不能只用数量衡量，至少还包括：

```text
number
x concentration
x coordination
x structural position
x motivation
```

这里的乘法只是提醒变量之间可能存在互补关系，不是本文给出的数学模型。

### G1-05 — Alliance maps are stage-dependent

参与者的行为方向可能随：

- 环境压力；
- 成功/失败可见度；
- 替代方案可信度；
- 自身利益变化

而改变。因此参与者地图必须定期重算。

### G1-06 — Unstable allies require differentiated treatment

“可以合作”不等于“可以依赖”。对于同时受两种相反利益驱动的力量，需要把合作价值与稳定性风险分开评估。

## O. Non-transferable / high-risk-to-transfer content

以下内容不能直接抽象成现代组织或商业规则：

- 1920 年代中国特定阶级结构本身；
- 文中对具体阶级必然政治立场的历史判断；
- 帝国主义、军阀、国民党派别等具体政治敌友分类；
- 把经济地位视为足以解释政治行为的单一决定因素；
- 革命组织对社会群体采取的具体政治目标。

现代迁移必须重新建模法律、制度、文化、身份、信息网络和技术条件。

## First-pass takeaway

本文暂时最值得追踪的不是一套静态“阶级结论”，而是一种战略建模方式：

```text
先明确要解决的联盟/对抗问题
-> 按实际利益结构细分行动者
-> 加入资源趋势、组织集中度和阶段变量
-> 预测其可能移动方向
-> 据此决定团结、争取、防范与对抗
-> 用实际集体行为继续修正地图
```

这只是第一篇文章产生的假设。下一步必须用《湖南农民运动考察报告》等后续文本检验它是否真的是可重复的方法，而不是我们对单篇文章的过度解释。
