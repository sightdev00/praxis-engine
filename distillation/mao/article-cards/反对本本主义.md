# Pass 1 — Source / argument reconstruction

## 1.1 核心链条

全文可以压缩成：

```text
没有现实与历史调查
-> 不知道问题底里
-> 发言/判断成为瞎说
-> 计划和指导容易错误

调查现状 + 调查历史
-> 找到问题来源和当前结构
-> 形成结论
-> 决定策略和工作方法
```

## 1.2 结论必须位于调查之后

文章直接提出：

> 一切结论产生于调查情况的末尾，而不是在它的先头。

这实际上定义了一个 ordering constraint：

```text
observe/investigate first
-> conclude later
```

而不是先形成答案再搜集支持材料。

## 1.3 权威来源不是正确性的充分条件

正文对上级指示的判断尤其重要：

```text
instruction is not correct merely because it comes from above
```

其正确性依据被写成：

- 是否适合客观和主观情势；
- 是否是现实斗争所需要。

盲目无异议执行反而被认为不是真正执行。

这直接把**来源权威**与**内容有效性**拆开。

## 1.4 理论必须和具体情况结合

文章同样不因为马克思主义来自经典就认为其正确，而诉诸实践验证，并要求理论同中国实际结合。

方法论上：

```text
abstract theory
+ current concrete conditions
-> usable judgment
```

不是：

```text
theory -> direct application
```

## 1.5 “调查”不是收集奇闻，而是面向决策的结构化取样

正文明确批评像“狗肉账”“听新奇故事”“高山顶观察城郭”一样的调查。

文章规定当时社会经济调查的目标：

```text
了解阶级政治经济状况与相互关系
-> 做阶级估量
-> 决定斗争策略
```

因此调查不是信息越多越好，而是要围绕决策所依赖的结构变量。

## 1.6 模型必须随工作环境更新

文章承认过去调查“偏于农村而不注意城市”，导致对城市贫民和商业资产阶级策略模糊，并用非常形象的表述指出：

```text
身体已经下山
思想还在山上
```

这可以重构为：

```text
operating environment changes
but internal problem representation does not
-> old categories no longer cover decision-relevant reality
-> strategy becomes misaligned
```

## 1.7 调查技术被操作化

正文给出七条：

1. 开讨论式调查会；
2. 找真正了解情况的人；
3. 人数根据主持能力决定，至少避免囿于单人见闻；
4. 预先准备调查纲目，并逐级细分；
5. 领导者亲身参与，不能只靠书面报告；
6. 初学者先深入研究一地/一问题，建立调查门路；
7. 自己记录，不完全委托他人。

这让“调查”第一次从原则变成 workflow。

## 1.8 后来的注释对口号本身进行了修正

1931 年补充：

```text
不做调查没有发言权
+
不做正确的调查同样没有发言权
```

这非常关键，因为它修正了一个可能的错误推论：

```text
只要做过调查 -> 就获得认知资格
```

真正的问题变为：

```text
调查质量如何？
```

# Pass 3 — Reasoning reconstruction

## R1 — Source authority and claim validity are separate

书本、上级、经典都不能仅凭来源获得正确性。

## R2 — Evidence acquisition precedes commitment

结论应在调查后形成，而不是先承诺答案。

## R3 — Investigate both state and history

当前状态不够；需要理解问题来源与历史变化。

## R4 — Make investigation decision-relevant

信息收集应围绕最终需要区分的行动结构，而不是积累碎片事实。

## R5 — Use multiple informed perspectives and discussion

调查会通过不同知情者之间的讨论、统计估计和疑义辩论降低单一见闻风险。

## R6 — Update the problem ontology when the environment expands

从农村走向城市后，原有调查范围不足，必须扩大对象。

## R7 — Leaders should preserve direct contact with evidence

书面报告不能完全替代亲身调查；领导者应直接参与提问、讨论和记录。

# Pass 4 — Adversarial reading

## A1 — “调查就是解决问题”表述过强

很多问题即使事实充分，也仍需要：

- 因果模型；
- 价值/目标选择；
- 不确定性处理；
- 实验；
- 技术能力；
- 权衡与资源配置。

因此现代迁移只能保留：

> 决策相关事实缺失时，调查是形成可靠问题表征和候选方案的必要输入。

不能变成“只要调查就自动得到答案”。

## A2 — 调查本身也会错

1931 年的补充事实上承认这一点。

调查可能存在：

- 错样本；
- 错问题；
- 错记录；
- 受访者利益偏差；
- 主持人诱导；
- 预设分类错误；
- 调查者本身干预现场。

## A3 — 文章反本本，却仍预设阶级 ontology

本文要求社会经济调查主要“解剖各种社会阶级”。但 V1-004 已显示：

- 家族；
- 土客籍；
- 地方主义；
- 历史仇怨

会显著影响行为。

因此即使调查是真实的，**调查框架本身也可能因理论预设而漏掉重要变量**。

这是一条非常重要的内部反证。

## A4 — “亲身调查”不能否定高质量间接证据

现代复杂系统中，负责人不可能亲自观察所有数据库、日志、实验或用户。

真正可迁移的不是“必须亲自去现场”，而可能是：

- 对证据产生过程保持理解；
- 对关键原始证据有直接抽查通道；
- 不让摘要层完全隔绝现实。

## A5 — 调查会议并不自动产生正确结论

多人讨论可能造成：

- groupthink；
- 权威效应；
- 从众；
- 共同信息偏差；
- 选择性受访者。

1931 的“正确调查”补充应视为重要修正方向。

## First-pass takeaway

真正值得蒸馏的不是口号“没有调查，没有发言权”，而是一套更严格的认识控制：

```text
不要继承来源权威
-> 在承诺结论之前重建现实和历史
-> 围绕决策需要设计调查结构
-> 让多个知情视角发生可审计讨论
-> 领导者保留直接接触关键证据的通道
-> 环境变化时重审原有调查范围和分类
-> 调查本身也必须接受质量审计
-> 结论、调查纲目和理论框架都不能免于后续修正
```

Praxis Engine 从这篇得到的最重要反思是：**反本本主义如果被固定成一套不可修改的调查模板，它自己就会变成新的本本主义。**
