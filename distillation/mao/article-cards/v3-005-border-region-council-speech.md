# Pass 1 — Source / argument reconstruction

## 1.1 用阶段约束限制终局制度的立即实施

社会主义被称更好，但当前中国没有实行条件；边区实际政策不得超过革命三民主义/新民主主义范围。

```text
preferred end state
but enabling conditions absent
-> choose feasible stage policy
-> prohibit premature objective substitution
```

这是 desired state 与 current feasible state 的明确分离；“条件”具体指标和转移门未给出。

## 1.2 由主要敌人形成广泛纳入边界

主要敌人被放在日本和德意法西斯，国内凡非汉奸者原则上均纳入抗日合作。

```text
dominant external threat
-> broad coalition eligibility
```

这体现 principal priority；但“只有一个目的/不能有别的目的”会抹去治理、生产、权利等支撑目标，后文事实上又保留了这些多目标。

## 1.3 把社会结构映射为政治代表与政策覆盖

中国被描述为两头小、中间大；农民、城市小资产阶级和其他中间阶级构成多数，任何政党若不给他们利益与发言权就无法治理。

```text
population / interest structure
-> representation need
+ policy coverage need
-> governing viability
```

这是从 stakeholder distribution 推导制度设计；具体比例、群体内部异质性和选择机制仍缺数据。

## 1.4 将抽象民权民生拆成可观察资格

人身自由、参与政治、财产保护、说话、衣食、工作和教育被列为政策目标。

```text
abstract ideology
-> rights / capabilities / material outcomes
```

这一 operationalization 比制度标签更可验收；但每项仍需 access、quality、distribution、remedy 指标。

## 1.5 对土地与劳资关系设计双向生存走廊

减租减息让农民生活，同时交租交息使地主生存；帮助工人就业生活，同时发展实业让资本家获利。

```text
weaker-side floor
+ counterparty viability
-> maintain production and coalition
```

这不是平均主义，而是 multi-stakeholder constraint satisfaction。谁承担成本、最低生活线和利润上限未规定。

## 1.6 把党外合作定义为党员义务而非恩赐

共产党员有同党外抗日人士合作的义务、无权排斥；国事不是一党私事。

```text
organizational role
-> duty to include affected outsiders
not discretionary permission
```

这是一项强 governance invariant；其 enforcement 和违规救济取决于实际权力结构。

## 1.7 把完整发言与决策采纳分开

他人说对要欢迎学习；说错也应让其说完，再解释。

```text
right to complete input
!= automatic acceptance

input
-> assess
-> learn or explain
```

这为 epistemic deliberation 提供最小保护：允许错误输入存在，防止权威把异议提前截断。

## 1.8 用外部参与纠正内部组织偏差

关门主义/宗派主义一方面通过党内教育清除，另一方面通过同党外人士民主合作清除，被概括为“内外夹攻”。

```text
internal training
+ external participation / feedback
-> expose and correct organizational blind spots
```

这是比单靠自我反思更强的 correction architecture；但外部意见是否有信息、议程、否决和申诉能力决定其真实强度。

## 1.9 明确接受人民监督

共产党应受人民监督、站在民众之中而非之上。

```text
decision authority
-> answerability to affected public
```

监督仍只有规范承诺，没有独立机构、信息权、制裁和领导更替机制。

## 1.10 公开缺点与自我保证同时存在

讲话承认党有很多毛病、不怕说出并要改；同时又保证绝大多数党员能执行路线、共产党没有私利且真心办好国事。

前者提高 correction openness；后者是组织自我认证，不能替代利益冲突和实际行为审计。

## 1.11 把议会作为实践训练场

共产党参议员应在实际合作中受锻炼、克服宗派主义，不只靠课堂学习。

```text
governance participation
-> encounter external views
-> practice deliberation
-> update organizational behavior
```

这把 V3-002 的学习制度连接到真实任务，但需观察发言是否改变议程、决策和资源。

## 1.12 将合作原则宣布为永恒不变

理由是只要政党存在，党员总是少数、党外总是多数，因此必须合作。

这是 scoped invariant 的候选：代表性组织需要同非成员协作。绝对措辞仍须定义“合作”的底线、对象和冲突例外。

# Pass 3 — Reasoning reconstruction

主要推理操作：

1. **stage-gated objective**：终局偏好受当前条件门限制；
2. **stakeholder-distribution mapping**：社会多数推导代表与政策覆盖；
3. **ideology-to-operational-rights**：把标签拆成权利/能力/生活结果；
4. **two-sided policy corridor**：同时设置弱方底线与交易对方可持续性；
5. **inclusion as duty**：把外部参与变为掌权者义务；
6. **input/acceptance separation**：完整听取不等于照单接受；
7. **internal/external correction**：教育与外部合作共同纠偏；
8. **authority/supervision coupling**：权力连接人民监督；
9. **practice-based learning**：在真实共同治理中训练合作；
10. **scoped invariant claim**：成员少数时必须同非成员合作。

# Pass 4 — Adversarial reading

## 4.1 “只有一个目的”与多目标治理相冲突

抗战可获最高权重，但衣食、工作、教育、权利和经济生产不是可删除目标，恰是抗战的必要条件与独立价值。

## 4.2 阶段条件由谁判定尚不明确

“没有社会主义条件”限制过早跃迁有价值；若没有公开指标，领导者可无限延长或突然宣布阶段转换。

## 4.3 社会“两头小中间大”是粗粒度模型

人口多数不直接等于利益一致；性别、地区、财产、职业和权力差异可能被三个大类遮蔽。

## 4.4 双向走廊可能冻结原有权力不平等

保证双方生存不说明租率、工资、利润与财产起点公正，也不说明最弱方是否有谈判权。

## 4.5 发言权例外可能吞噬普遍权利

先说全国人民有说话机会，后排除汉奸和破坏团结的“顽固派”。若分类者、证据和申诉未独立，批评可被循环定义为破坏团结。

## 4.6 让“错误意见说完”仍是家长式容忍

最终由谁判定错误、解释能否被质疑、意见是否进入决策，决定这是真 deliberation 还是咨询仪式。

## 4.7 组织自称无私利不可审计

任何组织都有生存、扩张、声誉和职位激励。使命宣言不能替代冲突披露、外部检查和制裁。

## 4.8 人民监督缺少 actuator

若监督只能说话却不能获取信息、要求答复、纠正决定或追究责任，它对 effective control 的影响有限。

## 4.9 外部参与可能被组织用作训练资源

党外人士不只为帮助党员改进而存在；他们是权利主体和共同决策者。不能把参与价值只归结为内部学习。

## 4.10 全国扩展是 prototype transfer claim

边区政策“有成绩、获赞成”主要由提案者自述；扩展全国前需比较环境、行政能力、财政、冲突和反例。

# Pass 5 — Article-local candidate mechanisms

## H1-3-05-01 — Gate preferred end states by observable transition conditions

把理想状态与当前可行制度分开，为进入/退出阶段定义指标、授权者和复评时间，防止过早跃迁与无限延期。

- Textual confidence: high
- Empirical confidence: high

## H1-3-05-02 — Convert values into rights, capabilities and outcome tests

制度标签必须下沉为谁能发言、参与、保有财产、获得工作/食物/教育，以及权利受侵后的救济。

- Textual confidence: high
- Empirical confidence: high

## H1-3-05-03 — Design policy corridors around multiple stakeholder viability constraints

同时保护弱方底线与系统交易/生产连续性；公开分配、上限、谈判权和长期权力变化。

- Textual confidence: high for two-sided policy
- Empirical confidence: medium-high

## H1-3-05-04 — Treat external participation as a correction mechanism

内部教育只能修已知错误；受影响的外部成员通过发言、监督和共同决策暴露未知盲点。有效性取决于信息权和 actuator。

- Textual confidence: high
- Empirical confidence: high

## H1-3-05-05 — Protect input completeness separately from decision acceptance

先让观点完整进入记录，再评估内容；拒绝时给可质疑理由，防止“我认为错”成为提前静音权限。

- Textual confidence: high
- Empirical confidence: high

## H1-3-05-06 — High-consequence speech exclusions require independent due process

任何使人失去表达/参与权的 hostile-actor classifier，都需可观察行为、较高证据、独立审查、申诉和定期复评。

- Textual confidence: high that source creates an exception
- Empirical confidence: high for corrective control
