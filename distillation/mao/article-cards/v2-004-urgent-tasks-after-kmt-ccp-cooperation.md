# Pass 0 — Historical frame

The formal second KMT-CCP united front had just been publicly announced in late September 1937.

The article asks a classic post-agreement problem:

```text
coalition declared
-> what makes it operational, durable and capable of delivering the shared objective?
```

This is structurally different from merely negotiating agreement formation.

---

# Pass 1 — Source / argument reconstruction

## 1.1 Coalition formation is reconstructed as a multi-step path, not one event

The article reviews a sequence from 1933 through:

- conditional anti-Japanese agreement proposals;
- broader united-front calls;
- negotiations;
- Xi'an Incident and ceasefire;
- mutual concessions/guarantees;
- Red Army renaming;
- publication of CCP declaration and Chiang's statement.

This creates an implicit process model:

```text
shared threat
-> exploratory offers
-> bargaining/concessions
-> minimal common ground
-> formal recognition
-> coalition declaration
```

## 1.2 A formal coalition is explicitly described as incomplete

The core claim is:

```text
统一战线成立
!=
充实、坚固的统一战线
```

This extends V2-002's stage-transition vs capability-completion distinction into coalition architecture.

## 1.3 Coalition scope must match the stated objective

The article argues that a national anti-Japanese coalition cannot remain only an agreement between two parties.

```text
national objective
but
coalition participation limited to two organizations
-> capability/scope mismatch
```

It therefore calls for broader participation by workers, peasants, soldiers, urban petty bourgeoisie and other patriotic actors.

## 1.4 Structural separation between government, people and army is treated as an execution blocker

The article identifies three disconnects:

```text
government ↔ people
army ↔ people
commanders ↔ soldiers
```

It links these separations to front-line weakness.

This is an organizational architecture claim: nominal top-level unity does not guarantee coupling across operational layers.

## 1.5 Coalition durability requires a common action program

A particularly important source structure is:

```text
broad coalition
+
shared objective
without
common program / rules
-> loose / unstable unity
```

The article calls a common program a form of binding constraint tying participating groups together.

Modern mapping: coalition API/contract/governance layer—not literal source vocabulary.

## 1.6 Old institutional constraints can become incompatible with a new objective

The article says the political/military/public/finance/economic/education system largely remains the old one even though the central external objective has changed.

Its phrase can be reconstructed as:

```text
changed objective/state
+
unchanged operating system
-> mismatch / exposed weaknesses
```

This strongly extends V2-001/V2-002.

## 1.7 Policy change is explicitly justified as stage-conditional rather than ideological abandonment

The article explains suspension of certain earlier policies (e.g. confiscation) as a response to changed domestic class relations after Japanese invasion.

Thus:

```text
principle/long-term issue persists
but
current policy changes because current coalition/stage constraints change
```

This reinforces Volume-I long-horizon vs current-action separation.

## 1.8 The article uses historical coalition success/failure as comparative evidence

1924–27 cooperation is cited as enabling rapid gains; rupture is cited as contributing to failure and external vulnerability.

This is used to support the value of renewed cooperation, though causal attribution is obviously simplified.

# Pass 3 — Reasoning reconstruction

## R1. Formation-vs-consolidation distinction

```text
agreement reached
-> audit scope, rules, institutions, execution coupling
-> determine whether coalition is actually durable/capable
```

## R2. Coalition capability decomposition

```text
formal members
+ mass participation
+ common program
+ institutional reform
+ army/government/people coupling
-> operational coalition
```

## R3. Legacy-system compatibility audit

```text
new strategic objective
-> inspect inherited institutions/policies
-> replace mechanisms incompatible with new objective
```

## R4. Stage-conditioned policy adaptation

```text
external relation changes
-> domestic actor relation changes
-> current policy changes
while
long-term unresolved issues remain
```

## R5. Shared-program governance

The coalition requires more than common rhetoric: a mutually recognized action program provides coordination and constraint.

# Pass 4 — Adversarial reading

1. Historical 1924–27 gains/failures are over-attributed to coalition formation/rupture; many variables changed simultaneously.
2. Broad participation may increase capability but also increase coordination complexity; the article underplays coalition governance cost.
3. A common program can coordinate, but it can also conceal unresolved objective conflicts among members.
4. The article assumes institutional reform toward its preferred political model is necessary for military victory; causal pathways are not fully separated from normative program.
5. `Only road` language is too strong given uncertainty and possible alternative institutional arrangements.
6. Coalition expansion can dilute decision speed or increase defection risk; safeguards and conflict-resolution mechanisms are underdeveloped.
7. Suspension of long-term policies for coalition purposes can create credibility problems with core supporters; the article explains principle continuity but does not fully model that tradeoff.

# Pass 6 — Cross-volume update

## P2 strengthened — declaration/formation vs consolidation

This now appears across:

- peace achieved vs consolidated (V1-016);
- resistance begun vs full capability built (V2-002);
- coalition announced vs operationally solidified (V2-004).

Candidate state model:

```text
proposed
-> negotiated
-> declared
-> operationalized
-> consolidated
-> stress-tested
```

Do not collapse these into a binary `exists / does not exist` status.

## P2 strengthened — objective/operating-system consistency

V2-001—V2-004 repeatedly audit whether institutions and behavior have actually changed to support a new declared objective.

This is becoming one of the strongest early Volume-II patterns.

## New architecture candidate — coalition contract layer

A shared objective is insufficient for a heterogeneous multi-agent system. It may require a common program specifying enough shared constraints to coordinate action while retaining distinct actors.

Future united-front texts should test:

- independence boundaries;
- conflict resolution;
- decision authority;
- defection/commitment validation;
- adaptation when objectives diverge.

# First-pass takeaway

The article's most reusable structure is the distinction:

```text
coalition declared
!=
coalition capable
```

Operationalization requires alignment of scope, participation, common program, institutional mechanisms and execution links with the shared objective.

This is a strong multi-agent/organization pattern, but the historical political program itself is not transferable.
