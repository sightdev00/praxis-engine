# V3-020 评蒋介石在双十节的演说

> 状态：依现行协议完成首轮蒸馏
> 日期：1944-10-11
> 文类：新华社政治评论／公开预警／对手承诺审计

## A. 识别

- 标准文本：[《评蒋介石在双十节的演说》](https://www.marxists.org/chinese/maozedong/marxist.org-chinese-mao-19441011.htm)。
- 作用：公开批评蒋介石 1944 年双十演说，将“不打内战、实行政治改革”等保证与部队部署、既有表述和已许诺的改革相对照。

# Pass 0 — 历史情境

写作于 1944 年军事危机和政治改革要求上升之际。直接压力是：在反共兵力仍被部署的条件下，是否应相信“不打内战”和“自由化”的保证。

# Pass 1 — 原文／论证重构

文章形成四步论证：

```text
未回答的公共问题 + 反复保证
→ 信任危机／政策不足

既有标签 + 当前兵力部署
→ 否认内战不是充分的安全信号

声明的自由化 + 强制性语言或行动
→ 要求观察兑现，而非接受口头承诺
```

它认为演说没有给抗日危机提供政治或军事答案；把“汉奸”称谓解读为可重复利用的内战借口；并要求以实际行为衡量言论自由、宪政过渡和政治解决。

# Pass 2 — 证据审计

见 `../evidence/v3-020/evidence-ledger.md`。原文足以证明其修辞主张和解释路径；数字、秘密接触、动机、七十七万五千兵力说及预警的后续效果，均须由独立材料核验。

# Pass 3 — 推理重构

1. **承诺—行动对照**：比较克制性承诺与兵力部署、执行活动；
2. **先例审计**：用既有标签和运动考察当前模糊表述可能怎样被操作化；
3. **能力优先于修辞**：土地、信心和许诺不能替代政策、人员和执行；
4. **公开预警**：在升级被常态化之前，使其风险可见。

# Pass 4 — 对抗性阅读

这一方法可能滑向对敌对动机的读心。反复保证本身不证明恐惧；部署与意图的联系须有命令、地点、任务和替代解释。秘密谈判与派系财产的主张须有来源链，不能靠修辞累积。后来的内战支持风险预警，却不能证明每一项 1944 年指控，也不能证明一篇演说造成了结果。

# Pass 5 — 本篇候选机制

## H1-3-20-01 — 用可观察承诺审计政治保证

记录保证的原文、兵力调动、法律与行政行为、执行个案、例外和期限。当高成本行动与低成本保证冲突时，升级风险上升。

- 文本置信度：高
- 实证置信度：中

## H1-3-20-02 — 将敌对标签视为操作风险指标

当执政者反复把对手归为“汉奸”或敌人时，检验该标签是否扩大法律或军事权限；在将其视为意图证明之前，保留正当程序和独立复核。

- 文本置信度：高
- 实证置信度：中

# Pass 6 — 跨篇更新

V3-014 已显示公开预警会与私下交涉和降级配合。本篇把规则收紧：预警必须区分已证实的行动、推断的意图和预测的结果；否则便会复制它所批评的不可证伪归因。

## 工作判断

可迁移的贡献不是党派谴责，而是一条核验规则：政治承诺应有可观察的实施证据，以及限时、可独立审计的矛盾日志。本篇最大的弱点是有时把证据检验变成对私人动机的结论。
