# Pass 0 — Historical frame

本文写于 1928 年湘赣边界割据已经经历建立、扩张、八月失败和九月纠正之后。直接决策压力不是抽象解释革命，而是回答边界党内的现实疑问：

```text
四周均为强大敌对政权
+ 自身区域小、军力少、经济困难
-> 这种政权究竟能不能长期存在？
-> 如果能，依靠什么条件？
-> 当前应该采取什么策略维持和发展？
```

文章对象同时包含全国政治结构、地方割据、军事力量、党组织、经济供给和根据地建设。

# Pass 1 — Source / argument reconstruction

## 1.1 文章结构

全文六部分形成一条从宏观环境到局部执行的推理链：

1. 国内政治状况；
2. 红色政权发生和存在的原因；
3. 湘赣边界割据与八月失败；
4. 边界割据在湘鄂赣三省中的作用；
5. 经济问题；
6. 军事根据地问题。

它不是只回答“为什么存在”，还回答“怎样继续存在”。

## 1.2 核心论证

### J1 — 全国统治力量并非统一稳定

文章认为各派军阀之间存在持续矛盾与战争，暂时妥协不等于长期统一。

```text
外部势力分裂
+ 国内军阀利益分裂
-> 全国统治力量存在周期性裂隙
```

### J2 — 红色区域只能在特定历史与社会基础上发生

并非“任何地方都能复制”。文章列出曾经历 1926—1927 年群众运动、具有工会和农会组织基础等历史条件。

### J3 — 局部政权持续存在依赖全国形势方向

若全国革命形势长期停顿，局部区域长期存在会受到根本限制；若全国形势继续发展，则局部区域有继续存在和扩大的空间。

### J4 — 群众基础不足以替代正式军事能力

文章把“相当力量的正式红军”明确称为必要条件；只有地方赤卫队不足以应付正式军队。

### J5 — 组织和政策质量也是持续条件

除了环境、历史基础、趋势和军事力量，还要求共产党组织有力量、政策不错误。

因此文章真正给出的不是一个单因解释，而是一个条件集合：

```text
外部统治力量存在结构性分裂
+ 当地有既往群众运动与组织基础
+ 全国形势不发生长期逆转
+ 存在相当正式军事力量
+ 党组织有力量且政策基本正确
-> 局部政权具有持续和发展的可能
```

注意：这是我们的结构化重写，不是原文数学模型。

## 1.3 八月失败作为反向论证

文章没有只用成功证明策略正确，而是用一次明确失败解释“阶段判断错误 -> 战略错误 -> 失败”：

```text
此前：敌方政治分裂较大
-> 某些主动扩张策略可行

八月：敌方处于暂时稳定
-> 仍采用适用于其分裂时期的分兵冒进
-> 边界与湘南遭受失败

九月：调整政策
-> 局面被挽救
```

这是全文对条件依赖最有操作性的例子。

## 1.4 从战略存在转向运营条件

文章最后两部分把“能否存在”下沉到非常具体的约束：

- 食盐、布匹、药材、现金、军队给养；
- 工事；
- 粮食储备；
- 医院。

因此宏观正确性并不自动保证局部系统能够持续运行。

# Pass 3 — Reasoning reconstruction

## R1. 从“反常现象”开始寻找特定条件

文章首先指出小块政权被强大敌对政权包围却长期存在是反常现象，然后拒绝把它视为普遍可复制事件，而追问其“独特原因”和“相当条件”。

推理操作：

```text
surprising observation
-> reject universal assumption
-> identify context-specific conditions
```

## R2. 多层条件组合，而不是单主因

条件跨越不同层级：

- 国际/全国政治结构；
- 地区历史基础；
- 全国趋势；
- 军事能力；
- 组织和政策质量。

这是一个嵌套层级模型，而不是单一变量模型。

## R3. 区分不能替代的能力条件

“群众很好”不能替代正式红军；地方武装只能应付相应等级的对手。

其推理不是简单“资源越多越好”，而是：

```text
任务/对手强度
-> 要求相匹配的能力层级
```

## R4. 阶段/环境变化要求改变策略

八月失败是最强案例：策略本身不能脱离敌方政治状态评价。

```text
same strategy
+ different environment
-> different result
```

## R5. 成功原因与失败原因同时用于更新

四月至七月的胜利与八月失败被放在同一分析中，用于区分什么条件组合有效、什么错误会破坏有效组合。

## R6. 战略可行性必须下沉到运营约束

经济供给、粮储、医疗、工事不是“后勤细节”，而被列为能否长期维持割据的关键现实问题。

现代分析映射（非原文术语）：战略 feasibility 与 operational sustainability 必须分开检验。

# Pass 4 — Adversarial reading

## A1. 条件集合是否存在事后选择？

因为文章在已有湘赣边界案例之后总结条件，可能存在：

```text
观察到成功案例
-> 从案例特征中挑出若干解释变量
-> 将其描述为存在条件
```

缺少大量“具有这些条件却失败”与“缺少某条件却成功”的系统比较。

## A2. “全国革命形势继续发展”具有高解释弹性

该变量边界不够精确，容易在事后根据结果重新解释“发展/停顿”。若不能定义可观察指标，其预测性有限。

## A3. 局部军事成功不能自动证明宏观政治推断

四月至七月的边界胜利可以支持局部策略有效，但不能单独证明全国革命形势或帝国主义—军阀结构的全部因果链。

## A4. 政策正确可能具有循环解释风险

若成功被归因于“政策正确”，失败又被解释为“政策错误”，必须进一步说明政策的事前判定标准，否则容易成为结果导向标签。

八月失败部分之所以更有价值，是因为文章给出了相对具体的错误：在敌方暂时稳定时采用适用于其分裂时期的分兵冒进策略。

## A5. 后来历史已经修正部分范围判断

第二版注释明确指出，二战及其后发展改变了 1928 年关于帝国主义直接统治殖民地无法长期形成类似根据地的观察。这是项目 revision ledger 应重点保留的真实修正案例。

## A6. 组织/军事/地形/经济条件之间的交互未被识别

文章列出条件，但没有严格回答：

- 哪些是必要条件；
- 哪些是促进条件；
- 哪些可以相互补偿；
- 哪个条件不足会首先导致系统崩溃；
- 条件阈值是多少。

因此不能把“五条”机械变成通用 checklist。

# Pass 5 — Article-local candidate mechanisms

## H1-16 — Explain exceptional outcomes through condition sets before searching for one master cause

**Source basis:** 第二节明确从“独特原因”和“相当条件”解释反常现象，并列出跨层级条件。

- Textual confidence: high
- Empirical confidence: unknown

最低假设：结果确实由多个相互约束的条件共同产生。

失败条件：若单一主因已经有充分识别证据，额外条件表只会制造复杂度。

现代映射：configurational / conjunctural reasoning。

## H1-17 — Capability must match the level of the opposing task

群众基础和地方武装不能替代能够对抗正规军的正式军事能力。

- Textual confidence: high
- Empirical confidence: medium at abstract level

现代迁移必须抽象成“能力—任务匹配”，不能迁移军事手段本身。

## H1-18 — Strategy validity is conditional on environmental state

八月失败显示，同一扩张/分兵策略在不同敌方状态下结果可能相反。

- Textual confidence: high
- Empirical confidence: provisional

## H1-19 — Use failure to identify violated assumptions, not only to score outcomes

文章不是简单记录失败，而是追踪：此前策略依赖什么环境 -> 环境如何改变 -> 哪项策略仍被机械执行。

- Textual confidence: high
- Empirical confidence: unknown beyond corpus

## H1-20 — Strategic feasibility does not remove operational sustainability constraints

宏观环境有利仍不足以持续；供给、医疗、粮储、工事等可以成为现实存续约束。

- Textual confidence: high
- Empirical confidence: medium as broad systems claim

## H1-21 — Historical organizational residue can be a state variable

地区过去经历的群众组织、政治训练和斗争被当作当前可持续能力的重要前置基础。

- Textual confidence: high
- Empirical confidence: unknown

现代映射：path dependence / accumulated organizational capability。

## First-pass takeaway

本文最值得保留的不是“五个条件”本身，而是一个更严格的分析习惯：

```text
遇到反常、脆弱但持续存在的系统
-> 不先假定一个普遍规律
-> 识别跨层级的条件集合
-> 区分能力是否匹配真实对手/任务
-> 用成功与失败同时检查条件依赖
-> 环境状态改变时重新判断策略
-> 最后检查经济、供给、医疗、基础设施等运营约束
```

同时，它第一次明确迫使 Praxis Engine 修正自己的倾向：**不是每个复杂问题都有一个足以支配一切的“主要瓶颈”；有些问题首先表现为多个必要/促进条件的组合。**
