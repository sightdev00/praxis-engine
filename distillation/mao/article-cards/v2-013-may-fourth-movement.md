# Pass 0 — Historical frame

本文为五四运动二十周年纪念文章。它不是单纯纪念，而是把1919放入1840年以来的长历史序列，借此判断当前抗战处于什么阶段、哪些社会力量是关键。

# Pass 1 — Source / argument reconstruction

## 1.1 阶段变化由新力量和关系结构标记

五四被称为“新阶段”，理由不只是时间过去，而是工人、学生、新兴民族资产阶级等新力量进入并扩大了运动阵营。

```text
same long historical problem
+ actor/capability composition changes
-> new stage
```

## 1.2 多个阶段可以共享长期任务但拥有不同局部特征

文章把鸦片战争以来多个事件放进同一民主革命长过程，同时强调各阶段各有特点。

这支持一个层级结构：

```text
long-horizon task continuity
!=
short-horizon strategy sameness
```

## 1.3 先锋、根本力量和领导力量被区分

学生在五四中处于前列，但文章把工农视为根本力量，并把工人阶级视为领导力量。

无论是否接受其阶级判断，这种角色区分本身值得注意：

```text
first mover / visible vanguard
!=
main capacity base
!=
coordination/leadership role
```

## 1.4 判断一个知识群体不以自我声明为最终标准

文章把知识分子是否真正同广大工农民众结合，作为其现实政治位置的重要判据。

其方法结构是：

```text
declared belief
vs
observable relation / behavior
```

后文 V2-014 会把这个标准进一步强化。

# Pass 4 — Adversarial reading

1. 把近百年复杂历史压成单一“民主革命过程”有强理论预设。
2. 对“根本力量/领导阶级”的因果主张并未在本文独立验证。
3. “是否与工农结合”作为知识分子最终分界标准过于单维，可能忽略制度、专业能力、组织形态等变量。
4. “历史必由之路”容易把后见结果写成必然进程。

# Pass 5 — Article-local candidate mechanisms

## H1-13-01 — Stage transitions should be tied to structural composition changes

阶段标签最好对应参与者、能力、约束或关系发生可观察变化，而不只是年代划分。

- Textual confidence: high
- Empirical confidence: medium

## H1-13-02 — Visible vanguard is not necessarily the main capability base

先出现、最显眼或最积极的群体，不自动等于决定长期结果的主要力量。

- Textual confidence: high
- Empirical confidence: medium-high as a general analytical caution

## H1-13-03 — Evaluate declared identity against sustained behavior and relationships

自我标签、口号或理论信仰不能替代实际行为证据。

- Textual confidence: high
- Empirical confidence: high as an audit principle
