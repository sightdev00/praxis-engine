研究对象不是完整报告，而是后来收入选集的第一章。正文后的长说明属于后见性 O7：它概括后续生产运动“巨大成绩”，不能反向成为 1942 年方针的同期证据。

# Pass 0 — Historical frame

本文把“财政缺口”从会计问题改写为系统承载力问题：

```text
population + production + trade + institutional footprint
-> taxable/suppliable surplus
-> fiscal capacity
-> military/government continuity
```

它同时拒绝两个极端：只削必要支出的财政保守主义，以及脱离资源条件的大工业计划；在政府与人民之间，又拒绝只顾即时轻税和无限汲取。结构上是一个多目标约束控制器，而不是单一“增产”口号。

# Pass 1 — Source / argument reconstruction

## 1.1 把财政定义为经济产出的下游

总方针是“发展经济，保障供给”。财政政策会反作用于经济，但财政长期可用资源由人民经济、公营经济和可持续剩余决定。

```text
productive base
-> real goods / tradable surplus
-> tax + self-supply + purchasing capacity
-> fiscal provision
```

这纠正只看名义收支的局部优化，但“经济决定财政”不能省略货币、信用、贸易和价格渠道。

## 1.2 用 1940—1941 的极端困难作为自然实验

停发经费和封锁使衣、油、纸、菜、鞋袜、被盖都短缺；边区依靠人民公粮、公营工业和军队机关生产渡过。文本把这段经历视为“生产保障供给”的历史证明。

这是有力案例，但并非单因素实验：税粮、贸易、货币发行、组织动员和特殊商品收入也参与结果。

## 1.3 明确自给经济是状态依赖型制度

军队和机关学校直接经营农工商业被限定为“特殊条件下的特殊产物”，在其它历史条件下可能不合理。

这是重要边界：

```text
external blockade + idle/available labor + survival constraint
-> temporary vertical integration

normal specialization + market access
-> direct production may become inefficient/conflicted
```

它防止把战时应急制度升级为永久组织原则。

## 1.4 在保守与冒进之间建立双边界

一边反对忘记开源、只削必要开支；另一边拒绝重工业、大盐业和大军工等不适合当时资源的计划。发展必须通过本地需求、资源、技术、周期和机会成本门槛。

## 1.5 把人民负担放入净收益约束

正文列出 1940—1942 年公粮、运盐、盐代金和公债，承认 150 万人口供养大量脱产人员负担不轻。政府取之于民的同时，必须帮助农业、畜牧、手工业、盐业和商业，使人民所得大于所失。

```text
public extraction
<= household surplus + public-return value - resilience reserve
```

“所得大于所失”是正确验收方向，但文本没有户级分布、强制程度、损失口径和申诉机制。

## 1.6 用“大仁政”处理当前负担与长期战争

只顾即时轻负担可能使抗战能力崩溃；只顾军政需求则会竭泽而渔。文本把战时适度加重负担解释为长期公共利益，同时承诺一有办法就减负休养民力。

其合理性取决于四项条件：战争支出真实必要、负担分配不过度回归、公共收益能兑现、减负触发器能执行。

## 1.7 将财政路线分为三个阶段

1937—1939 少取、休养民力；1940—1942 加重负担；1943 年以后若公营经济继续发展且军队能屯田，则两年后减轻人民负担。

这是明确的 conditional forecast，不是无条件保证。关键输入是公营产出、屯田机会、战争压力、人口和物价。

## 1.8 提出公私兼顾和军民兼顾

财政供给不能只发展公营，也不能只靠民营；公家能力、私人生产和军民负担必须共同增长。文本从 actor balance 上修正了单向汲取逻辑。

但“兼顾”仍需具体权重、产权边界、采购价格、税率和纠错渠道。

## 1.9 把韧性判断扩展到其它根据地

文章预言边区不会“塌台”、只会兴盛，华北华中根据地也能继续支持直到胜利。依据是既往渡过更大困难、组织动员和群众支持。

这是 survivorship + capability forecast；“任何困难都能战胜”则过度普遍化，没有失败条件。

## 1.10 用精兵简政闭合生产—财政环

第三次精兵简政要求严格、彻底、普遍，目标是精简、统一、效能、节约和反官僚主义。机制包括减少消费性支出、增加生产收入、减轻人民负担、统一财经指挥、减少浪费和贪污。

这不是单纯裁员，而是组织重构：

```text
smaller footprint + clearer command + redeployed labor
-> lower consumption + higher output + lower extraction
```

缺口是人员安置、功能损失、基层工作负荷和独立监督。

# Pass 2 — Evidence audit

详见：

`../evidence/v3-012/evidence-ledger.md`

正文与后续材料共同支持：生产、精简和贸易确实提高了边区承载力，粮食产量和自给能力上升，非生产人员下降，农民公粮占收获比在 1941—1942 已有所下降。独立材料同时显示，1941—1944 年边币发行和延安物价剧烈上升；学术研究还记录 1942 年后鸦片贸易收入。故“生产自给”是重要机制，但不是完整收入解释，更不能由最终存续识别其净福利效果。

# Pass 3 — Reasoning reconstruction

1. **real-resource accounting**：从名义财政回到商品、劳力和可交易剩余；
2. **shock-based diagnosis**：用外援中断和封锁识别脆弱依赖；
3. **state-dependent institutional design**：战时自给不永久化；
4. **bounded development**：同时反保守和大计划冒进；
5. **net-benefit burden test**：人民所得须大于所失；
6. **intertemporal welfare tradeoff**：当前负担换长期安全，但保留减负承诺；
7. **conditional phase forecast**：用 1943—1944 产出和屯田作为转段条件；
8. **actor balancing**：公私兼顾、军民兼顾；
9. **organizational carrying-capacity control**：精简、统一、效能、节约；
10. **morale/resilience inference**：由既往渡险推断未来存续。

# Pass 4 — Adversarial reading

## 4.1 选集摘录不是完整财经账

第一章总结方针，不提供全报告的行业、贸易、金融和预算细目。研究不能把选集篇幅当作当时全部政策或全部收入来源。

## 4.2 “经济决定财政”不能删除货币财政

边币增发和物价上涨表明，政府还通过货币体系转移资源。只看实物增产会漏记通胀税、汇率损失和不同持币者的负担。

## 4.3 自给成果不能由机构自报单独确认

“解决整个需要的大部分”缺少统一分母、价格口径、劳动机会成本和质量标准。机关生产可能是真实新增，也可能挤占训练、治理或私人生产。

## 4.4 公粮总量不能代表负担公平

九万、二十万、十六万担说明总规模变化，不说明按收入、土地、家庭人口和地区分布的税负，也不说明征收中的强制与腐败。

## 4.5 “人民谅解”需要独立反馈

群众支持不能只从持续缴纳或政权存续推断。需要会议记录、投诉、逃亡/隐匿、消费营养、债务和不同阶层的反应。

## 4.6 大仁政可能成为延期减负的通用理由

如果战争、建设或未来利益始终优先，当前损害可以无限延期。必须预设税负上限、期限、复评和自动减负触发器。

## 4.7 公营经济存在隐性和高风险收入

学术材料记录 1942 年后边区从鸦片贸易取得收入。无论其占比如何，这都改变“人民赋税 + 正常自给生产”的简化来源图，并引入健康、外部化和保密治理成本。

## 4.8 粮食增长不能直接等于净福利增长

产量可因播种面积、天气、统计口径、劳力动员和征收激励变化。还须观察人均可支配粮、营养、市场价格、劳动时长和生态成本。

## 4.9 精兵简政可能把成本下推

中央机构减少不一定等于总系统成本减少；任务可能转给县乡、军队、家庭或无薪群众。应跟踪功能、工作量和成本转移。

## 4.10 “任何困难都能克服”是不可校准的韧性叙事

既往成功提高未来存续概率，但不能证明对任意冲击都有效。需要列出粮食、人口、军事、金融和政治的失效阈值。

# Pass 5 — Article-local candidate mechanisms

## H1-3-12-01 — Diagnose fiscal capacity in real-resource terms

预算表必须连接产量、库存、劳力、贸易、价格和分配；名义平衡不得掩盖通胀或实物短缺。

- Textual confidence: high
- Empirical confidence: high

## H1-3-12-02 — Make emergency vertical integration expire by state

直接生产应绑定封锁、市场缺失和生存约束；恢复专业分工或市场后自动复评退出，防止应急组织永久扩权。

- Textual confidence: high
- Empirical confidence: high

## H1-3-12-03 — Apply a distributional net-benefit test to extraction

不仅比较总所得和总所失，还按家庭、地区和阶层记录负担、公共回报、强制、申诉与恢复能力。

- Textual confidence: high
- Empirical confidence: high for added controls

## H1-3-12-04 — Treat austerity as capability reallocation

区分必要/浪费支出，记录功能、人员去向、下游负荷和总系统成本；精简的目标是能力密度，不是人数本身。

- Textual confidence: high
- Empirical confidence: high

## H1-3-12-05 — Require a full-source fiscal ledger

同时列税粮、自给产出、贸易利润、债务、货币发行、外援和特殊商品，并记录各自外部性；禁止用一个正当来源覆盖完整财源。

- Textual confidence: medium from source omission
- Empirical confidence: high

# Pass 6 — Cross-article update

### Extends V3-009 from organization size to a complete carrying-capacity loop

V3-009 说明“鱼大水小”要缩编；本文把组织规模与生产、税负、贸易、财政和治理统一起来。两篇共同支持能力密度模型，但本篇增加了人民净收益与公私/军民兼顾约束。

### Adds a state-expiry rule for emergency institutions

军队机关自给在封锁下合理、在其它条件下可能不合理，是此前少见的明确制度适用边界。今后所有战时特例必须记录进入和退出条件。

### Adds a hidden-finance audit requirement

正文的生产叙事遗漏货币扩张与特货收入。任何“自力更生”机制都要用全财源表复核，避免合法性叙事筛掉高成本来源。

### Adds four prediction entries

- `PRED-045`: 再生产一年，1943 年公营经济基础会更稳固。
- `PRED-046`: 若 1943—1944 持续发展公营经济并获得屯田机会，两年后人民负担会下降。
- `PRED-047`: 边区不会塌台而会兴盛，其它根据地能坚持到胜利。
- `PRED-048`: 五项精兵简政全面实行将克服财政经济困难。

## Working judgment

本文的核心贡献是把财政问题还原为真实生产能力、组织规模和分配关系，并明确应急自给的状态边界。它也包含一个需要持续警惕的政治经济张力：以长期公共利益证明当前汲取，同时由同一权力判断必要性、净收益和减负时点。可迁移模型应保留生产优先、反冒进、净收益和能力密度四个机制，同时加入完整财源、通胀、分布、独立反馈和自动退出门槛。
