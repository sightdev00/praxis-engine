# Pass 0 — Historical frame

本文写于苏德互不侵犯条约签订后、德国进攻波兰的同一天。欧洲大战的结构正在快速变化，因此这是一篇高价值的**实时预测文本**：许多结论在当时尚未被后果验证。

# Pass 1 — Source / argument reconstruction

## 1.1 国际环境被解释为策略互动，而不是孤立事件

文章把英法政策、德苏关系、德国扩张、日本选择和中国抗战放入同一多方互动模型中。

其论证结构是：

```text
actor interests / prior behavior
+ current agreements
+ constraints
-> likely next moves
-> implications for China
```

## 1.2 一个协议的意义由它改变了谁的可选动作来判断

苏德协定被解释为打破英法推动苏德冲突的计划、降低苏联两线风险并改变日本处境。

无论这一动机解释是否正确，方法上它不是只读协议文字，而是问：

> 协议签订后，各主要参与者的 feasible action set 怎样变化？

## 1.3 文中包含多个强 prospective claims

主要包括：

- 欧洲将从片面战争进入英法与德意直接冲突；
- 美国暂时不会参战，试图在后期争取领导地位；
- 日本灭亡中国的目标不变，但军事大进攻可能减少，政治经济压力增强；
- 中国战略退却结束、战略相持到来；
- 相持不是反攻，而是准备反攻。

这些必须逐项进入 prediction ledger，而不能被后见历史整体打包成“判断正确”。

## 1.4 Actor objective 与 operating method 被区分

作者判断日本“根本目的”不变，但行动方式会因外部条件改变：

```text
objective stable
operating mode changes
```

这是一个有用的分析区分，但“根本目的绝不改变”本身过于绝对，后文必须检验边界。

## 1.5 战略阶段由条件而非单一事件触发

作者把相持阶段到来绑定于：

- 新国际环境；
- 日本困难增加；
- 中国不妥协；
- 敌我力量仍有巨大差距。

同时指出正面相持会伴随敌后压力增加，因此阶段转变不是所有局部变量同步停止。

## 1.6 阶段名称必须翻译成当前任务

“相持”并不意味着停止行动，而被具体化为：

```text
maintain defense
+ support war behind enemy lines
+ political/military/economic reform
+ accumulate counteroffensive capability
```

因此阶段判断只有连接到能力建设和任务变化时才有操作意义。

# Pass 4 — Adversarial reading

## 4.1 动机归因过强

文章多次把英法行为解释为有计划地推动德苏互相消耗，把英国对日政策解释为准备共同瓜分中国。这些解释可能含有真实利益冲突，但正文没有展示足够证据证明单一主观阴谋。

## 4.2 “美国暂不参战”的短期判断不能与长期预测混写

美国随后在1941年参战，因此这条判断若只指“暂时”可能成立；若被理解为整个战争阶段保持中立则错误。必须保留原时间范围。

## 4.3 “日本根本目的决不会变”把 actor model 写得过于刚性

长期目标会受政权、能力、战争失败和外部环境改变。稳定目标应是高置信假设，不应写成永恒属性。

## 4.4 相持阶段判断可能存在定义弹性

如果阶段定义足够宽，许多后续事件都可被吸收，因此要检查它是否真正改变了可观察任务和预测。

# Pass 5 — Article-local candidate mechanisms

## H1-17-01 — Evaluate agreements by how they change participant action spaces

协议的意义不仅在文本，还在于它降低、增加或重定向了哪些参与者的可行动作。

- Textual confidence: high
- Empirical confidence: high as an analytical heuristic

## H1-17-02 — Separate actor objectives from operating modes

同一个长期目标可以在不同约束下采用不同手段；观察手段变化不能自动推断目标变化，反之亦然。

- Textual confidence: high
- Empirical confidence: medium-high
- Boundary: objectives themselves remain revisable hypotheses.

## H1-17-03 — Stage labels are useful only when they change current capability-building tasks

- Textual confidence: high
- Empirical confidence: high as a planning discipline

## H1-17-04 — Forecasts should be decomposed by actor, horizon, condition and observable outcome

这是本文对 Praxis protocol 的反向要求：密集预测文本必须逐条建账，避免事后只保存命中的方向判断。

- Textual confidence: n/a (meta inference)
- Empirical confidence: high as research-control discipline
