# Pass 0 — 历史情境

苏联于8月8日对日作战，日本战败进入最后阶段。声明要求抗日力量全面反攻，同时警告必须制止内战并促成民主联合政府。

# Pass 1 — 原文／论证重构

苏联参战缩短战争 → 全国抗日力量反攻、敌后组织与交通破袭 → 扩大解放区、减租生产、组织政权和武装 → 夺取最后胜利；所有军事动员同时受制于制止内战和建立联合政府的政治目标。

# Pass 2 — 证据审计

见 ../evidence/v3-031/evidence-ledger.md。声明直接证明动员命令和政策组合；反攻规模、群众支持、缴械结果和内战风险需用战报、地方材料及后续事件核验。

# Pass 3 — 推理重构

1. 把外部战略冲击迅速转化为军事窗口；2. 以正规军、武装工作队和地下军形成多层反攻；3. 用减租生产和纪律维持后方承载力；4. 把军事胜利与战后政治安排并列。

# Pass 4 — 对抗性阅读

“千百万群众”是动员目标，不等于已同意；扩大解放区可能与地方安全和资源压力冲突。对日反攻与随后国共冲突存在时间连续性，不能把后者简单归咎于本声明，也不能用日本投降倒证每项组织预测都成功。
