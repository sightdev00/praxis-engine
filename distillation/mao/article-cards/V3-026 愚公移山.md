# Pass 0 — 历史情境

七大已决定路线、通过党章并选出中央委员会，代表即将返回各地和战场。闭幕词要把会议决议转化为长期执行信念。

# Pass 1 — 原文／论证重构

大会路线与组织决定 → 代表回到工作岗位宣传、解释和执行 → 全党全国形成信心 → 下定决心、不怕牺牲、排除万难，争取胜利。

愚公移山寓言被用来说明：目标巨大、过程漫长并不取消行动责任，关键是持续组织、代际接力和共同方向。

# Pass 2 — 证据审计

见 ../evidence/v3-026/evidence-ledger.md。闭幕词直接证明会议决定、宣传要求和寓言式动员；它不是工程计划，不能单独证明胜利时间、牺牲规模或制度结果。

# Pass 3 — 推理重构

1. 将一次会议的决定转化为分布式执行；
2. 用共同叙事维持长期目标；
3. 以自我批评和团结处理组织内部分歧；
4. 将困难视为需要持续投入的约束，而非失败证明。

# Pass 4 — 对抗性阅读

坚定信念可以维持耐力，也可能压低坏消息和退出权。“不怕牺牲”不能替代风险评估、保护和责任追究；代际接力也不能证明目标本身正确。会议称为民主和团结，仍需用代表异议、修改记录和实际权力约束检验。

# Pass 5 — 本篇候选机制

## H1-3-26-01 — 把长期目标拆成阶段性可逆任务

为每阶段设定可观察里程碑、资源上限、复核点和停止条件，避免用信念覆盖不可逆损失。

- 文本置信度：中
- 实证置信度：高

## H1-3-26-02 — 用传播解释连接决议与地方执行

下达目标时同时提供背景、异议渠道、地方适配和反馈记录；宣传不能替代结果审计。

- 文本置信度：高
- 实证置信度：中

## 工作判断

“愚公移山”的可迁移价值是长期任务的阶段化坚持和组织接力；其风险是把坚忍、牺牲和胜利绑定，进而削弱对目标、代价和替代路径的独立审计。
