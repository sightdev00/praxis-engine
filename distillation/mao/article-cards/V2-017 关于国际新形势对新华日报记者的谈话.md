# Pass 0 — Historical frame

国际环境在极短时间内剧烈变化：英法苏谈判失败，苏德签订互不侵犯条约，欧洲战争临近，中国抗战进入武汉失守后的相持判断。

本文同时承担四项任务：

1. 解释苏德协定及英法苏谈判失败；
2. 预测欧洲、美国、日本和苏联的下一步；
3. 判断中国抗战阶段是否变化；
4. 把国际判断转换成国内政治和军事任务。

它尤其适合检验：同一模型可以同时产生方向正确、时间正确、机制错误和 actor model 失真的不同预测分量。

# Pass 1 — Source / argument reconstruction

## 1.1 苏德协定被解释为防御性和平结果

文章把协定归因于苏联力量增长与和平政策，并认为它：

- 打破英法挑动苏德战争的计划；
- 打破德意日对苏包围；
- 巩固苏德和平；
- 增强援华和世界解放条件。

这是一个高度单向的因果/价值解释，没有讨论秘密议定书、苏德各自的领土和安全交易，也没有给德国机会主义动机独立权重。

## 1.2 英法苏谈判失败被完全归因于英法

文章用此前“不干涉”、慕尼黑、对波兰/波罗的海安全与苏军通行的分歧，重建英法缺乏诚意，并说失败“完全由于”英法政府。

```text
past appeasement pattern
+ negotiation positions
-> infer persistent actor objective
-> assign complete causal responsibility
```

这一推理利用了历史行为先验，但把多边谈判失败压成单方原因。

## 1.3 欧洲战争阶段变化被清晰预测

文章判断由一方侵略、英法坐视的“片面性”状态，将转为英法与德意两集团直接冲突的全面战争，并称其迫在眉睫。

这是可观察的阶段转换预测：

```text
appeasement arrangement exhausted
-> conflict externalized back to sponsors
-> direct inter-bloc war
```

## 1.4 国际系统被分为四组行动者

正文区分：

- 德意集团；
- 英法集团；
- 以美国为首、暂时不参战的美洲集团；
- 资本主义世界之外的苏联。

对每组分别预测战争、国内动员、反战运动、迟后介入和世界领导竞争。这个分组提高了情景清晰度，也带有强烈的阵营价值预设。

## 1.5 美国预测被拆成短期等待与长期出场

美国被判断为暂不进入战争，以中立保存力量，未来再出场争取资本主义世界领导地位。

```text
short-run non-entry
-> preserve optionality/capacity
-> later intervention
-> leadership bid
```

这是全文少数明确建模“延迟行动作为战略资产”的地方。

## 1.6 日本被判断为目标稳定、手段转换

文章认为苏德协定增加日本困难，内部存在南进结盟与对英美妥协两派，但“灭亡中国”的根本目标不变；正面大规模进攻可能减少，政治分化、经济掠夺、敌后扫荡和诱降会加强。

```text
environment/capability pressure changes
-> operating method shifts
but
-> actor objective retained
```

## 1.7 国际判断触发中国阶段重判

在日本更加困难、国内不妥协两个条件下，文章宣布战略退却阶段结束、相持阶段到来，并把相持定义为准备反攻。

但它同时指出：

- 正面相持可能伴随敌后斗争加剧；
- 敌我力量仍相差很远；
- 相持不等于风险下降或立即反攻。

## 1.8 阶段判断被转换为组合任务

当前总任务被定为准备反攻，具体包括：

- 支持正面防御；
- 援助敌后战争；
- 反妥协、反分裂、反倒退；
- 在政治、军事、经济、文化等方面改革；
- 聚积力量，等待时机集中反攻。

因此“进入相持”不是等待，而是改变能力状态的建设阶段。

# Pass 3 — Reasoning reconstruction

主要推理操作：

1. **historical-prior actor modeling**：用连续绥靖行为推断英法目标；
2. **causal attribution**：把谈判破裂归因于参与者诚意/安全条件；
3. **bloc/scenario decomposition**：分别预测欧洲两集团、美国、日本、苏联；
4. **stage-transition forecast**：从间接纵容转为直接集团战争；
5. **option-value reasoning**：把美国暂不参战解释为保留未来领导能力；
6. **objective/method separation**：日本目标不变但手段切换；
7. **global-to-local update**：国际变化更新中国抗战阶段和能力建设任务；
8. **prospective operationalization**：把相持定义为可执行的反攻准备期。

# Pass 4 — Adversarial reading

## 4.1 对苏德协定的解释遗漏了决定性变量

秘密议定书和随后对波兰、波罗的海地区的安排表明，协定不只是苏联防御性和平政策。作者可能当时不知道秘密内容，但“全部政治意义”的高置信表述明显超出可用证据。

## 4.2 “完全由于英法”是过强单方归因

英法绥靖和谈判立场是重要证据，但苏联谈判策略、波兰拒绝苏军通行、德国提供的交易以及各方安全困境也影响结果。

## 4.3 对苏德和平的预测很快失败

协定确实短期延后苏德战争，但 1941 年德国入侵苏联，否定了把它当作稳定和平结构的强读法。应拆分“短期争取时间”和“巩固和平”。

## 4.4 价值阵营可能影响相同事实的解释

英法中立被解释为损人利己，苏德中立则解释为和平与解放基础。两者具体结构不同，但文章没有用对称标准审计各方交易和第三方代价。

## 4.5 方向预测正确不能反证全部机制正确

欧洲全面战争确实迅速爆发；这不自动证明英法单方导致谈判破裂、苏德协定全部服务和平或所有集团目的分类都正确。

## 4.6 中国阶段转换条件仍不完整

“日本更加困难 + 中国不妥协”支持相持判断，但战线、资源、国际援助、占领治理和敌后能力也影响阶段；正文虽提部分变量，宣布转换时仍较确定。

# Pass 5 — Article-local candidate mechanisms

## H1-17-01 — Score forecasts by component, not by article

同一分析可在方向、时间、actor、机制和条件上分别正确或错误；一次命中不能给整个模型背书，一次失败也不抹掉其它有效分量。

- Textual confidence: high from the article's multiple explicit forecasts
- Empirical confidence: high as a forecast-audit rule

## H1-17-02 — “Complete significance” claims require an unknown-information allowance

对刚发生的秘密外交、并购或组织事件，若关键协议和动机不可见，就不应宣称掌握“全部意义”；应保留未知变量和多种解释。

- Textual confidence: high that the article closes interpretation
- Empirical confidence: high as an epistemic-control rule

## H1-17-03 — Separate actor objective from operating method, but allow both to update

环境变化可能先改变手段而非目标；然而“目标永不变”也必须有反证条件。

- Textual confidence: high
- Empirical confidence: medium-high

## H1-17-04 — Stage changes should produce a new work program

宣布进入新阶段只有在它改变资源积累、风险重点、组织接口和当前任务时才具有操作意义。

- Textual confidence: high
- Empirical confidence: medium-high

## H1-17-05 — Waiting can preserve option value, but only with an explicit trigger

延迟承诺可保存能力并等待其它参与者消耗；若没有进入条件、机会成本和最大等待期，也可能变成无期限观望。

- Textual confidence: high for the US model
- Empirical confidence: medium
