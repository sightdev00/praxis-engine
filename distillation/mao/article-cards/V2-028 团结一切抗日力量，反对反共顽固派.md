# Pass 0 — Historical frame

这篇讲话是上一份内部指示的公开执行版本。它既要把汪精卫政权与反共磨擦连接起来，又要防止听众从愤怒直接跳到“国民党全部是敌人、抗日无望”。

因此核心任务是：

```text
acknowledge severe harm
-> differentiate actors
-> authorize resistance to one subset
-> preserve cooperation with another subset
-> defend a shared objective
```

# Pass 1 — Source / argument reconstruction

## 1.1 从多地事件构造协调威胁图

文章列举湖南、河南、山西、河北、山东、鄂东、陕甘宁等地的袭击、杀戮、封锁、渗透和舆论活动，把它们解释为日汪分裂国共合作的总体策略在各地的表现。

```text
distributed incidents
-> common beneficial effect for adversary
-> hypothesized coordination / command relation
```

第一步（共同效果）有较强行为基础；第二步（共同指挥/暗藏身份）需要逐案证据，不能由模式相似直接推出。

## 1.2 承认情绪合理，但阻止情绪决定分类

面对“国民党都是坏人、抗日无望”的反应，讲话先认可愤怒，再要求按行为与立场区分不同国民党人。

```text
emotion as severity signal
!=
actor classifier
```

这是一个重要的认识/行动边界：情绪可以提示问题强度，但不能完成 ontology。

## 1.3 对有害行为可按效果响应，不必先证明内心

文章说无论相关人员心里怎样想，其行动实际上帮助日本/汪精卫，因此应抵抗；同时另说其中一些可能是暗藏汉奸。

可分解为：

```text
observable harmful action/effect
-> proportionate defensive response

hidden identity/intent
-> separate higher evidence threshold
```

正文前半有这个分离的萌芽，后半的“暗藏”语言又容易把两层合并。

## 1.4 两条政策共享一个目标

```text
cooperate with committed anti-Japanese actors
+ oppose capitulationist/anti-communist attacks
-> preserve resistance + coalition
```

团结与反对不是互相取消，而是对不同对象/行为采用不同控制。

## 1.5 “统一”按底层机制而非名称判定

讲话把统一分为真实/形式、合理/不合理、实际/口号，并用三个条件评价：抗战、团结、进步。

```text
label: unity
-> inspect who is erased
-> inspect decision rights
-> inspect effect on shared objective
```

“统一”若要求取消盟友的组织与能力，被判为借共同名义实施单方支配。

## 1.6 建立一条依赖链

文章提出：

```text
progress
-> stronger unity
-> sustained resistance
-> real national unity
```

其价值在于指出统一不是静态口号，需要政治/组织条件；弱点是“进步”的定义由讲话者掌握，链条也未用比较证据验证。

## 1.7 用本方组织作为运行样板

正文列举军队抗敌规模、边区廉洁与社会秩序“十无”、低薪等，证明共产党/根据地不应被取消，反应当成为全国样板。

```text
local model case
-> demonstrate feasibility
-> claim broader adoption
```

这是一种 prototype evidence，但所有指标均来自本方公开讲话/后来选集注，缺独立审计、分母和失败项。

## 1.8 以确定性承诺维持动员

结尾/中段断言能够粉碎顽固派、中国必不亡国、解放和进步必然、倒退只是暂时。

这种语言可支持集体行动，却把概率判断转成确定性身份承诺，容易减少 contingency planning。

# Pass 3 — Reasoning reconstruction

主要推理操作：

1. **distributed-pattern aggregation**：把多地事件放入共同威胁模型；
2. **emotion/classification separation**：承认愤怒但阻止整体化 actor 分类；
3. **effect/intent separation**：先按可见危害响应，再另审隐蔽身份；
4. **differentiated coalition policy**：对不同 actor/行为团结或抵抗；
5. **label-to-mechanism audit**：穿透“统一”口号检查权力和效果；
6. **dependency-chain construction**：进步—团结—抗战—统一；
7. **model-case argument**：用根据地/军队样板证明可行性；
8. **certainty mobilization**：用必胜/必进步承诺维持行动。

# Pass 4 — Adversarial reading

## 4.1 共同效果不证明统一指挥

多个事件都削弱抗日合作，可以说明功能趋同；要证明日汪、蒋介石、地方部队和文化批评者构成同一协调链，仍需命令、资金、通信和时间证据。

## 4.2 “按行为区分”容易被秘密身份标签吞掉

正文一度说不论内心、按实际帮助敌人的效果响应，这是可操作原则；但“暗藏汉奸”会把意图重新作为惩罚依据，且难证伪。

## 4.3 “必定还击”缺比例、程序和退出条件

哪些行为触发政治批评、法律追责、组织排除或军事还击，谁调查、怎样避免误报复、何时停止，均未规定。

## 4.4 道德羞辱降低事实分辨率

“丧尽天良”“不要脸”“齑粉”等语言有动员作用，却把程度、动机和可转变性压成道德本质，可能增加升级和内部从众。

## 4.5 根据地“十无”是宣传式完美系统声明

零贪腐、零贫困/乞讨、零派系、零灰色经济等广泛全称高度可疑；缺指标定义、调查覆盖、举报保护和负面事件记录。

## 4.6 军事贡献数字需要分母和口径

“挡住五分之二敌人/17个师团”、后来注释的 64% 日军和 95% 伪军都需说明兵力、时间、接触强度、战役类型和重复计算。后期比例不能验证 1940 当时说法。

## 4.7 自我样板不能由自我描述验收

样板案例应有预注册指标、外部观察、失败案例和迁移条件；否则“我们最进步，所以应领导”形成循环。

## 4.8 确定性乐观可能压缩准备空间

方向信心可支持行动，但“倒退只是暂时”没有最大时长、损失上限或失败触发器。V2-009 更稳的做法是战略轮廓加事实校正。

## 4.9 统一的三个条件可能被同义反复

如果“进步”被定义为接受本方方案，“真正团结”被定义为在本方领导下合作，结论就不会被外部结果纠正。

# Pass 5 — Article-local candidate mechanisms

## H1-28-01 — Emotion can signal severity but should not classify actors

强烈愤怒可提示价值/安全边界受损；actor 分类仍要用行为、证据、范围和可更新规则完成。

- Textual confidence: high
- Empirical confidence: high

## H1-28-02 — Respond to harmful effects without overclaiming hidden intent

可对明确危害采取比例性保护措施，同时把幕后身份、动机和协调链留给更高证据门槛。

- Textual confidence: medium-high
- Empirical confidence: high

## H1-28-03 — Shared labels should be audited through control and outcome

“统一”“合作”“安全”等名词若实际取消一方能力、反馈或代表权，应按控制结构和结果重分类。

- Textual confidence: high
- Empirical confidence: high

## H1-28-04 — Model cases require independent observability and transfer tests

原型可证明可能性，但要推广还需共同指标、外部审计、失败账本和新环境下复现。

- Textual confidence: high that the article uses a model case
- Empirical confidence: high as an added validation rule

# Pass 6 — Cross-article update

### Strengthens P2: actor classification must remain differentiated under stress

V2-015/018/027 与本文都在高冲突情境中拒绝把国民党整体化；但“暗藏汉奸”等标签又不断侵蚀这一原则。应同时追踪 differentiation mechanism 与 collapse pressure。

### Strengthens P2: observable effect and hidden intent must be separate fields

V2-018 已指出 adversary preference 只是证据；本文直接说无论内心、实际行为可帮助敌人。现代映射应规定：防护性响应可依据效果，惩罚性归责需更强因果/意图证据。
