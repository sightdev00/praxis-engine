# Pass 1 — Source / argument reconstruction

## 1.1 灾难后先恢复组织连续性

军委命令迅速任命代军长、副军长、政委、参谋长和政治部主任，并重申整军、内部团结、军民协和、抗战与防袭 mission。

```text
leadership loss / organizational shock
-> appoint interim command
-> restate mission and interfaces
-> preserve organizational identity
-> resume operation
```

这是 incident recovery 的第一步：不能等完整责任调查结束才恢复关键功能。

## 1.2 证据入口被明确为部队来电

命令称依据陈毅、张云逸等电报了解事变经过。这至少标出信息来源，但它仍是冲突一方报告，缺对方命令、现场记录、路线和独立证词。

```text
field report
-> urgent provisional action
!= final causal adjudication
```

## 1.3 从已发生步骤推断完整隐蔽计划

谈话列十五步：前四项已实现，第五开始，六七准备/开始，其余被称积极准备。

```text
observed sequence prefix
-> hypothesized hidden plan
-> forecast remaining sequence
```

把公开电令、宣传、围攻和取消番号放入共同模型是合理的 hypothesis generation；断言所有后续步骤属于同一日汪/国民党总计划，需要命令链、协调证据和逐项结果。

## 1.4 把一次重大事件当作系统转移信号

文章将皖南事变称为全国性突然事变的开端，并判断发令者已决定全面破裂、彻底投降。

```text
high-severity local event
-> system transition alert
```

这与 V2-027/035 先前“局部事件不等于全国转换”的模型发生实质张力，必须用后续两篇和实际事件评分。

## 1.5 高警报同时保留外力改变分支的可能

虽然说改变对方决心甚难，正文仍把全国人民压力与国际外交压力列为可能干预条件，并要求监控后续发展、准备最坏局面。

```text
high-risk forecast
+ intervention levers
+ monitoring / preparation
```

因此不是完全宿命论；但高确定性阴谋叙事会使新证据更难下调警报。

## 1.6 最坏路径与最终方向被分开

文章允许短中期出现黑暗局面和巨大代价，同时断言最终敌对计划必败，理由包括本方组织能力、其他党派/军队可转变、民意、国际变化、世界革命与苏联援助。

这是 resilience argument 与 historical inevitability 的混合：前几项可操作验证，后几项复用已知的 actor/全球趋势过度确定。

## 1.7 十二项要求构成事件修复包

要求覆盖：

1. 停止挑衅；
2. 撤销命令并承认错误；
3. 追责；
4. 释放/恢复领导；
5. 返还人员装备；
6. 抚恤伤亡；
7. 撤退进攻力量；
8. 拆除封锁；
9. 释放政治犯；
10. 制度改革；
11. 重新遵守共同纲领；
12. 对亲日首领司法处理。

```text
cessation
+ acknowledgment
+ accountability
+ restitution/compensation
+ release
+ non-recurrence / force withdrawal
+ structural reform
+ legal process
-> proposed coalition repair
```

这比“恢复团结”口号更可执行，但没有 owner、优先级、时间、验证、协商或部分履行规则。

## 1.8 修复责任被放在伤害方

文章用“杀第一刀/伤痕”比喻，认为造成损害的一方必须主动医治，且让步阶段结束。

```text
harm-causing actor
-> primary repair obligation
```

这保护受害方免于以继续让步购买表面和平；同时完全单方归责若未经共同事实程序，也会阻断谈判。

## 1.9 用对方说法内部矛盾反驳“叛变”标签

重庆方面一边说新四军叛变，一边称其意图进入日占京沪杭建立根据地；谈话用二者的不一致质疑叛变指控。

```text
counterparty claim A
+ counterparty claim B
-> internal consistency test
```

这是比直接动机攻击更强的反驳；但它只能削弱特定叛变叙事，不能单独证明己方所有行动合规。

# Pass 3 — Reasoning reconstruction

主要推理操作：

1. **continuity restoration**：危机后快速恢复领导与 mission；
2. **provisional evidence action**：依据现场报告先保关键功能；
3. **sequence completion inference**：由已发生前缀推隐藏完整计划；
4. **transition alerting**：重大局部事件触发系统级警报；
5. **branch intervention mapping**：压力与外交可能改变高风险路径；
6. **resilience inventory**：列出组织、盟友、民意与外援支撑；
7. **remediation package design**：停止、承认、追责、赔偿、改革组合；
8. **repair-obligation assignment**：伤害方承担主要修复；
9. **internal-consistency attack**：用对方叙述矛盾削弱标签。

# Pass 4 — Adversarial reading

## 4.1 紧急任命与最终事实认定应分离

恢复指挥可依较低、及时证据；把所有责任归于亲日总体计划则需要更高门槛。行动时限不同不应让认识门合并。

## 4.2 已实现前缀会制造叙事吸引力

前四步按顺序发生使十五步看起来可信，但同一事件可产生许多可拟合的后续故事。应预注册每步时间、触发、证据和失败标准。

## 4.3 功能受益不证明统一指挥

日方可能从国共冲突获益，不等于每项国民党行动受日方计划直接控制。common effect、aligned incentive、coordination、command 是不同因果等级。

## 4.4 局部灾难可能导致 base-rate neglect

皖南事变严重性极高，容易使全国全面投降/破裂概率被瞬间推到近一。此前材料中的制约条件仍应重新加权，而非删除。

## 4.5 修复清单混合事件补救与政体重构

返还装备、抚恤与撤军直接对应事件；废止一党专政属于更广制度目标。全部绑定为一次性前置条件可能降低达成局部止损的机会。

## 4.6 追责名单需独立事实和程序

点名惩办/逮捕并要求国法审判比私刑更受约束，但仍应区分调查对象与已定罪者，保留辩护和证据。

## 4.7 “让步阶段结束”需要清晰行动边界

停止单方让步不等于授权任何反制。还需与 V2-034 的 trigger、proportionality、escalation ceiling 和 ceasefire 协议连接。

## 4.8 确定性世界革命与苏联援助理由已被反例削弱

V2-019 的苏联永久一致/援助判断已被 1941 条约与援助变化反驳；将其继续作为必胜基础显示模型更新不足。

## 4.9 侮辱和威胁降低恢复空间

“蠢猪”“茅厕”等语言强化动员和羞辱，却使对方承认错误的政治成本更高，与修复目标冲突。

## 4.10 组织存续不能把巨大损失正常化

称皖南部队为未来道路“代价的一部分”可能支持韧性，也可能稀释对预测、部署和指挥失败的责任追查。

# Pass 5 — Article-local candidate mechanisms

## H1-38-01 — Restore critical function before completing final attribution

事故后可用标明来源与置信度的临时证据恢复关键领导、接口和任务；最终责任认定使用更高证据门并保持可修正。

- Textual confidence: high
- Empirical confidence: high

## H1-38-02 — Sequence models must expose observed and inferred steps

事件链应逐项标 `observed / underway / inferred / predicted`，并为未发生步骤设期限；已发生前缀不能验证整个隐藏计划。

- Textual confidence: high that article mixes statuses
- Empirical confidence: high as corrective control

## H1-38-03 — Incident repair needs a multi-layer package

有效修复通常包含止损、承认、事实调查、责任、返还/赔偿、释放、非复发保证和制度改进；各项需 owner、期限、证据和验收。

- Textual confidence: high
- Empirical confidence: high with controls

## H1-38-04 — Separate immediate remediation from broad political settlement

先完成可降低持续伤害的事件级措施，再对长期制度冲突单独协商，避免“全包或全无”阻塞止损。

- Textual confidence: medium-low; adversarial extension
- Empirical confidence: high

## H1-38-05 — Test adversary claims for internal consistency

同一方的理由若对事实、目标或规则给出互不兼容解释，可降低其主张可信度；但不能因此自动确认自己的完整叙事。

- Textual confidence: high
- Empirical confidence: high

### Tests M-03 conflict extension

### Adds recovery-vs-accountability separation
