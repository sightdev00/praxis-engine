# V3-027 论军队生产自给，兼论整风和生产两大运动的重要性

## A. 识别

# Pass 0 — 历史情境

国家贫困、分裂，军队分散作战，全面由上级供给难以维持。文本把军队生产自给解释为特殊条件下的能力安排，并试图证明它同时改善生活、军民关系和战争耐力。

# Pass 1 — 原文／论证重构

上级供给不足 + 分散长期战争 → 统一领导、分散经营 → 部队部分或全部生产自给 → 改善生活、减轻人民负担、增强纪律与军民关系 → 支持长期战争和根据地扩大。

社论又把整风和生产分别称为精神与物质生活的关键环节，认为两者共同构成革命链条。

# Pass 2 — 证据审计

见 ../evidence/v3-027/evidence-ledger.md。原文直接证明制度主张和组织者的因果解释；自给数字、生活改善、税负变化及对胜利的贡献须与独立统计和失败案例分开验证。

# Pass 3 — 推理重构

1. 在供给约束下把部分生产能力下沉；
2. 用统一目标配合分散经营；
3. 将经济劳动与纪律、关系和组织教育连接；
4. 把整风、生产视为互补能力而非单一运动。

# Pass 4 — 对抗性阅读

“自给”可能把供给责任转移给基层成员和居民；改善生活不能自动证明劳动自愿、分配公平或军事效率提高。整风与生产同时发生，不代表整风造成生产结果。军队扩大、人民负担减轻和消灭侵略者是不同层级的结果，不能由同一组数字一次性证明。

# Pass 5 — 本篇候选机制

## H1-3-27-01 — 在明确边界下分散供给责任

记录上级投入、基层劳动、居民负担、产出、损失和退出权；以净负担而非名义自给率评价制度。

- 文本置信度：高
- 实证置信度：中

## H1-3-27-02 — 将组织教育与物质绩效分开验收

分别测量纪律、批评安全、产出、营养、伤害和军民关系，避免用经济结果为整风或权力分类背书。

- 文本置信度：高
- 实证置信度：高

## 工作判断

可迁移经验是让基层在清晰授权和安全边界内发展供给能力；最大风险是把自力更生转化为隐性强制，并用整风或战争目标掩盖真实成本。
