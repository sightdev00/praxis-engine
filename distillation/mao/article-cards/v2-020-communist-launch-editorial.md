# Pass 0 — Historical frame

文章的直接对象是一种新的内部知识/组织基础设施：《共产党人》党刊。它出现于两个同时发生的变化：

- 外部：投降、分裂、倒退和突然事变风险增加；
- 内部：党员、组织、武装和全国影响迅速扩大，但新组织尚未巩固。

因此问题不是一般性的宣传，而是：

> 当组织规模、任务复杂度和外部压力同步上升时，怎样把十八年分散经验转成可传播、可执行的组织能力？

# Pass 1 — Source / argument reconstruction

## 1.1 专门媒介由特定组织缺口产生

文章先问党刊与一般党报有何不同，回答是：一般党报不能承担建设全国性、群众性、思想政治组织上巩固的党的专门任务。

```text
specific capability gap
-> general communication channel insufficient
-> dedicated internal channel
-> focused experience transmission and organization building
```

媒介不是目的，组织能力才是验收对象。

## 1.2 当前“已经强大”与“仍需建设”可以同时成立

正文承认党在一定程度上已全国化、群众化且核心较巩固；同时指出：

- 新党员形成的新组织还未巩固；
- 新成员经验、理论和政治能力不足；
- 老党员/老组织也需升级；
- 当前环境和任务比过去复杂艰巨。

```text
aggregate organization appears mature
while
component maturity is heterogeneous
```

## 1.3 扩张改变了系统组成，旧能力不会自动复制

第一阶段的历史总结已经出现：组织发展但未巩固，新党员多而教育不足，经验多却未总结，投机/暗害者未清理，活动分子未形成骨干，拥有武装却不能掌握。

第三阶段快速扩张后，同类问题再次出现：新成员、新组织、新干部缺经验，理论与实践未统一，并混入投机和暗害者。

这形成重复结构：

```text
growth
-> composition shift
-> training/selection/control lag
-> renewed capability debt
```

组织过去学会过某事，不代表新组成自动继承。

## 1.4 组织建设被放入环境/任务关系中

文章不把党建设当纯内部纪律，而先用中国的半殖民地半封建、不平衡、土地广阔等条件，解释统一战线和武装斗争为何成为特殊问题。

```text
external institutional/social structure
-> dominant task forms
-> organization capabilities required
-> organization design/learning
```

## 1.5 三个基本问题构成相互依赖系统

全文把统一战线、武装斗争、党的建设表示为：

- 两种对外行动能力；
- 一个掌握和协调这些能力的组织主体。

党建设影响能否正确处理前两者，处理前两者的结果又影响党的发展巩固。

```text
organization quality
-> better control of coalition + force
-> survival/growth/experience
-> organization quality
```

这是反馈关系，也存在“成功即路线正确、路线正确即成功”的循环自证风险。

## 1.6 联盟对象被建模为具有条件性和二重性

文章区分民族资产阶级、大资产阶级不同集团、农民和城市小资产阶级，并强调：

- 某些时期可合作；
- 合作内容会随情境改变；
- 合作者仍可能限制/瓦解组织独立性；
- 既要反关门，也要反取消原则差异。

所以联盟能力不是“加入或拒绝”单开关，而是：

```text
conditional cooperation
+ independent capability
+ ongoing boundary contest
+ prepared transition if coalition breaks
```

## 1.7 主要行动形式需要和其它形式配合

武装斗争被设为主要形式，但正文同时列出工农、青年、妇女、政权、经济、锄奸、思想等战线，要求直接或间接配合。

```text
primary action form
!=
only action form
```

## 1.8 历史阶段被用作能力成熟史

三个阶段不是只按年份分，而按组织能够做什么区分：

- 第一阶段：有动员和增长，但缺经验、教育、总结、筛选、骨干与武装控制；
- 第二阶段：学会依靠农民、建设政权/根据地、治理和战争，但仍发生路线错误；
- 第三阶段：规模和影响扩大，同时扩张再次制造训练、巩固和渗透问题。

能力学习不是线性完成，而会因环境、规模和组成变化重新欠债。

## 1.9 党刊被赋予“把经验传到全党”的任务

结尾要求把理论与中国实践相统一，把十八年和当前新鲜经验传达到全党，使组织避免重复历史错误。

这是明确的组织记忆/学习机制；但正文未规定如何保留异议、失败预测、版本差异和对中央历史解释的反证。

# Pass 3 — Reasoning reconstruction

主要推理操作：

1. **capability-gap/tool matching**：由专门缺口选择专门内部媒介；
2. **aggregate/component separation**：区分整体规模与各组成成熟度；
3. **scale-induced debt diagnosis**：识别扩张造成的训练、筛选、控制滞后；
4. **environment-to-organization mapping**：由外部结构推组织所需能力；
5. **feedback modeling**：组织质量与联盟/武装控制相互影响；
6. **conditional actor modeling**：按时期、集团和利益关系更新联盟策略；
7. **primary/supporting-form composition**：主行动形式与多种支撑形式配合；
8. **stage-by-capability reconstruction**：用可执行能力而非年份描述组织阶段；
9. **organizational memory design**：把历史和新经验传到分布式组织。

# Pass 4 — Adversarial reading

## 4.1 “十八年历史证明正确路线”存在循环自证

成功/增长被用来证明路线正确，路线正确又被用来解释成功/增长。外部条件、对手错误、偶然性和幸存者选择可能被低估。

## 4.2 三个基本问题可能是有用压缩，也可能遗漏独立约束

经济、行政、情报、后勤、合法性、国际援助等被折入三者之中；“正确理解三者就等于正确领导全部革命”是过强完备性主张。

## 4.3 内部刊物既能传播经验，也能集中固化一种历史解释

如果只有中心定性的“正确/错误”进入组织记忆，刊物可能提升执行一致性却降低坏消息上行、异议和模型可修正性。

## 4.4 渗透/投机分类器仍未给出误差控制

扩张和安全双约束在 V2-010 已出现；本文承认实际上混入很多人，但没有提供识别标准、复核、申诉和误杀成本。

## 4.5 把政治路线与组织巩固高度绑定可能惩罚有效异议

组织一致性有助于执行，但若“巩固”被定义为接受既定路线，强组织可能更高效地执行错误模型。

## 4.6 历史阶段总结对失败责任分配高度不对称

失败多归为右/左机会主义或未掌握正确路线，成功则归于正确领导；需要用 prediction/revision ledger 检查当时可用证据和替代解释。

# Pass 5 — Article-local candidate mechanisms

## H1-20-01 — Growth creates recurring capability debt

当新成员、节点或任务快速增加时，过去形成的训练、筛选、经验和控制能力不会自动复制；增长计划必须同步预算能力再生产。

- Textual confidence: high
- Empirical confidence: medium-high

## H1-20-02 — Organizational maturity must be measured by component and stress behavior

总体规模/影响力不能代表所有新旧节点成熟；应分别检查教育、经验、骨干、反馈、压力下保持和执行质量。

- Textual confidence: high
- Empirical confidence: high as a diagnostic rule

## H1-20-03 — Dedicated knowledge infrastructure should be judged by capability change

内部刊物、知识库或培训系统的验收不是“是否发布”，而是是否减少重复错误、缩短新节点成熟时间并改善跨组织判断/行动。

- Textual confidence: high
- Empirical confidence: medium-high

## H1-20-04 — Organizational memory needs falsification channels

把经验集中传播可提升协调，也必须保留失败预测、证据边界、异议、版本和后来修正，否则记忆基础设施会固化胜利者叙事。

- Textual confidence: high that the article proposes transmission; low that it supplies falsification
- Empirical confidence: high as a modern safety boundary

## H1-20-05 — Cooperation capability includes controlled transition out of cooperation

组织必须既能在共同目标下合作，又能在对方改变行为或联盟破裂时保留独立能力和转换方案。

- Textual confidence: high
- Empirical confidence: medium-high

## H1-20-06 — Feedback models must not use outcome labels as their own proof

“正确处理导致成功、成功证明正确处理”需要外部可观察的中间机制和反事实，否则是封闭循环。

- Textual confidence: high that the article uses the feedback claim
- Empirical confidence: high as a causal-audit rule

# Pass 6 — Cross-article update

### Strengthens P2: scale requires quality and stress controls

V1-004 的成员暴涨/压力崩溃、V2-010 的扩张+筛选+培养+检查，在本文变成跨三个阶段重复的组织问题。该模式已跨根据地组织史、干部治理和全国性扩张，可保持 P2，并开始为 G2 的反例/边界工作做准备。

### Strengthens P2: strategy requires a capability-bearing execution layer

V2-010 强调干部生命周期；本文说明经验必须通过组织媒介、训练、骨干和新旧协作在全国节点复制。路线本身不会自动扩散成一致能力。

### Adds a memory-infrastructure boundary

Praxis Engine 自己也是专门知识基础设施。本篇反过来要求我们用可观察标准审计本仓库：

- 是否减少重复方法错误；
- 是否保留被否定预测和版本差异；
- 是否允许后文推翻早期综合；
- 是否只是文档数量增长。

当前不修改协议，但把这一自审问题写入 V2 中段综合。

### Rejects “three keys are complete” as generalization

三个法宝可作为本文的历史压缩，不升级为一般系统完备模型。Praxis Engine 保持先识别 constraint topology，而不是把所有现代问题塞进联盟、强制能力、组织三类。
