# Pass 1 — Source / argument reconstruction

## 1.1 文章先提出一个极强总命题，再用多个事件解释它

核心主张是：

> 苏联自身利益与世界大多数人利益具有一致性。

随后围绕四个争议问题展开：

- 苏德互不侵犯条约是否促成大战；
- 苏联贸易是否等于援德/参战；
- 苏军进入波兰东部性质为何；
- 苏日潜在协议是否会损害中国。

这种论证结构值得警惕：总命题在开头已高度确定，后续事件更像被吸收到既有模型中，而不是竞争模型之间的开放检验。

## 1.2 一个有价值的分析动作：区分 action semantics

文章明确反对把：

```text
trade
=
aid
=
participation in war
```

混为一谈。

它通过苏联同时与德国、日本贸易却在其它层面援助其对手来说明：同一个 actor 的不同关系类型必须分别编码。

这是本文最稳健、最容易脱离政治立场的机制之一。

## 1.3 另一个有价值的动作：拆分复合实体

关于“波兰问题”，文章没有只用“波兰”一个节点，而分成：

- 德国；
- 英法；
- 波兰政府；
- 波兰人民；
- 苏联；
- 波兰境内多个民族。

这表明地理/国家标签可能隐藏利益不同的行动者。

但细分本身并不能保证随后判断正确。

## 1.4 文章对苏联进入波兰作强正当化解释

正文把苏军行动解释为：

- 收回旧领土；
- 解放乌克兰/白俄罗斯民族；
- 防止德国继续东扩；
- 破坏英方推动德国攻苏的计划。

文章并未提及德苏秘密议定书对东欧势力范围和波兰分界的预先安排。

这是本文最大的证据缺口。

## 1.5 后见证据对该模型构成直接挑战

后来可核史料显示：

- 1939-08-23 德苏协定存在秘密议定书，预先划分东欧势力范围，并约定波兰分界；
- 1939-09-17 苏军从东部进入波兰；
- 德苏随后调整分界并共同完成对波兰的占领/分割。

因此，把苏军行动仅解释为临时的防御/民族解放行动，是一个**严重不完整的 causal model**。

注意：这并不要求假设作者在1939-09-28已知秘密议定书；恰恰相反，研究重点是：

> 当关键不可见变量缺失时，一个高度一致的解释可能有多危险。

## 1.6 文章把苏联未来行为写成近乎不可证伪的身份推断

例如：

```text
Soviet state is socialist
-> therefore it will not join unjust war
-> future history will continue to prove this
```

这类推理把 actor identity 当作未来行动保证，弱化了对现实协议、秘密行动和利益变化的独立验证。

## 1.7 对中国外援提出“可靠/部分暂时”分级

文章区分：

- 被认为可靠的外援来源；
- 其它只能部分、暂时利用的外援；
- 自力更生为主。

其方法结构是：

```text
support source
-> reliability / duration / incentive alignment
-> dependence level
```

但对苏联“永久一致”的可靠度判断显然受到强意识形态先验影响。

# Pass 4 — Adversarial reading

## 4.1 Master-thesis confirmation bias

“苏联利益与人类利益一致”作为近乎不可动摇前提，使所有争议事件都被解释为支持材料。这是我们整个项目必须防止的一种推理模式。

## 4.2 波兰解释被后来证据实质削弱

德苏秘密议定书和随后分区事实意味着：源文没有纳入一个会显著改变因果解释的关键变量。此处不能只标“时代局限”，而应明确记为**模型严重不完整**。

## 4.3 对群众欢迎的报道不能证明行动整体性质

局部欢迎、民族构成和波兰政府问题，都不能单独排除大国分区、占领和战略利益等竞争解释。

## 4.4 国家/制度身份不能作为永久行为保证

“社会主义国家所以不会怎样”属于 identity essentialism。可靠 actor model 应基于能力、激励、约束、协议和实际行为持续更新。

## 4.5 Trade / aid / participation 的区分是正确问题，但不能反向证明贸易绝无战略帮助

不同关系类型应分开；同时贸易仍可能产生资源、财政、战争能力等间接作用。语义区分不能替代因果评估。

国家、组织、部门、用户群等标签内部可能存在目标不同的主体；先拆分再建模。

- Textual confidence: high
- Empirical confidence: high

## H1-19-02 — Distinguish relation/action types before inferring alignment

贸易、援助、联盟、参战、信息共享等不是同一边。

- Textual confidence: high
- Empirical confidence: high

## H1-19-03 — Missing hidden variables can make a coherent explanation systematically wrong

如果关键协议、激励或行动不可见，内部逻辑一致并不是模型可靠的证据。

- Textual confidence: derived from source + later external evidence
- Empirical confidence: high

## H1-19-04 — Actor identity must not substitute for behavior-based updating

- Textual confidence: this is an adversarial correction, not source endorsement
- Empirical confidence: high

- Textual confidence: A/G-layer correction

# Pass 6 — Cross-article update

### Strong correction to prior actor-model pattern

前文多次强调“行为 > 声明”。V2-019 反而提供一个负例：当 ideology/identity 的先验过强时，同一研究者可能对盟友使用低审计标准、对对手使用高怀疑标准。

因此 Praxis Engine 后续必须加入：

```text
symmetry check:
Would we accept the same evidence standard
if the actor label were reversed?
```

### New meta-pattern: hidden-variable humility

当关键信息明显可能受保密、战争宣传或组织信息壁垒影响时，结论应显式保留：

```text
unknown hidden agreements / constraints / incentives
```

而不是因为现有证据能组成故事就关闭候选空间。
