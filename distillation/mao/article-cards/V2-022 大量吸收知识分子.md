# Pass 0 — Historical frame

党、军队和根据地在快速扩大，既缺具备文化/专业能力的人，又担心知识分子的阶级背景、忠诚和敌对渗透。过去部分地区和军队曾排斥知识分子；当前又需要把大量新人纳入不同工作系统。

决策问题因此是双重的：

> 怎样扩大专业/知识能力，而不把安全风险当作关门理由；又怎样筛选风险，而不把怀疑变成无证据清洗？

---

# Pass 1 — Source / argument reconstruction

## 1.1 先把知识分子定位为组合能力的一部分

文章把知识分子的作用分别连接到：

- 抗战力量组织；
- 农民群众组织；
- 文化运动；
- 统一战线；
- 党、军队和政府工作。

它不是把“有知识”当抽象身份优势，而是映射到多个具体系统功能。

## 1.2 已有吸收成绩不等于局部执行问题消失

过去两三年已吸收大批知识分子，但军队干部、学校和地方党组织仍存在恐惧、排斥或不敢扩大招生/入党的现象。

```text
central policy progress
!=
uniform local adoption
```

组织平均状态掩盖节点差异。

## 1.3 风险判断随组织吸收能力变化

文章认为过去排斥的一部分原因，是没有认识到组织已经形成中坚骨干、具备掌握/带领知识分子的能力。

```text
incoming-member risk
depends on
host integration/control capacity
```

同一类新人，在弱组织与有骨干/教育能力的组织中风险不同。

## 1.4 大量吸收与严格证据筛选同时成立

政策一方面扩大进入军队、学校、政府和党的渠道；另一方面拒绝敌方派遣者和不忠实者，并处理已混入者。

但正文特别加了两个限制：

- 依靠真凭实据；
- 坚决而有分别地处理，不因风险怀疑较忠实者，也要防止陷害好人。

```text
open intake
+ evidence-based security
+ differentiated response
+ false-accusation guard
```

## 1.5 组织关系不是“入党/拒绝”二元开关

对不能或不愿入党的人，仍可建立共同工作关系；对党外同情者，可保持联系并组织到抗日、民主、文化和统一战线工作中。

这形成分层参与：

```text
membership
co-work
network/contact
issue-specific participation
```

不同信任/责任等级对应不同接口。

## 1.6 招募之后必须完成角色配置和能力转化

吸收不是完成点，后续包括：

- 分配适当工作；
- 教育和带领；
- 在长期工作中磨练；
- 改善与老干部、工农成员的关系；
- 逐渐克服弱点并服务实际任务。

```text
recruit
-> assign
-> educate
-> work-based development
-> relationship integration
-> review for deeper responsibility
```

## 1.7 能力转换是双向的

文章同时要求工农干部提高文化水平、知识分子与工农群众结合。不是把一方单向同化到另一方，而是两类能力共同补齐：

```text
domain/field legitimacy + practical experience
<->
cultural/technical/analytical capability
```

## 1.8 风险控制随环境改变

在国民党统治区和日占区，吸收入党时对忠实程度要求更高；说明准入门槛不是全局固定，而与暴露、渗透和恢复成本相关。

# Pass 3 — Reasoning reconstruction

主要推理操作：

1. **role/capability mapping**：把人群映射到具体系统功能；
2. **aggregate/local separation**：区分总体进展与节点执行差异；
3. **host-capacity risk adjustment**：按组织吸收能力重估新人风险；
4. **dual-constraint policy**：扩大吸收与安全完整性同时控制；
5. **evidence-gated classification**：要求真凭实据和防止陷害；
6. **tiered participation design**：成员、合作、联系等多级接口；
7. **lifecycle integration**：从招募延伸到配置、教育、磨练和关系整合；
8. **reciprocal capability building**：两类成员双向补足能力；
9. **context-sensitive admission**：按地区风险调整信任门槛。

# Pass 4 — Adversarial reading

## 4.1 “没有知识分子就不可能胜利”是必要条件强断言

知识/专业能力显然重要，但本文没有区分哪些任务必须由既有知识分子承担、哪些可由内部培养或其它角色替代。

## 4.2 忠实和吃苦标准缺乏测量定义

它们容易由政治印象、阶层偏见或服从性替代；若靠行为观察，又需说明观察窗口和伪装风险。

## 4.3 “掌握知识分子”可能滑向工具化和压制专业异议

组织需要整合能力，但专业人员的独立判断、坏消息和技术反对意见若只被当作待改造弱点，会损害真实能力。

## 4.4 真凭实据仍需程序

何为证据、谁调查、如何复核、如何申辩和怎样纠正误判未规定。“有分别地洗刷”仍连接高后果 actuator，需要更高门槛。

## 4.5 大量吸收可能再次制造 V2-020 的能力债

本篇给出教育/配置方向，但没有容量、导师比例、成熟时间和质量验收。快速招募可能超过中坚骨干的真实带领能力。

# Pass 5 — Article-local candidate mechanisms

## H1-22-01 — Acquisition value depends on integration capacity

引入人才/模块的收益与风险不只由输入质量决定，也由现有系统的配置、训练、监督、反馈和边界能力决定。

- Textual confidence: high
- Empirical confidence: medium-high

## H1-22-02 — Open intake and integrity are simultaneous constraints

安全不能靠关门“成功”，扩张也不能忽略渗透；分类应基于证据并显式管理误拒、误收和诬陷风险。

- Textual confidence: high
- Empirical confidence: high as a control objective

## H1-22-03 — Participation should be tiered by trust and responsibility

不能承担最高责任或不愿成为正式成员，不等于完全排除；可设计不同授权、可见性、审核和共同工作接口。

- Textual confidence: high
- Empirical confidence: medium-high

## H1-22-04 — Recruitment is incomplete without a conversion lifecycle

```text
recruit -> role fit -> development -> work evidence -> integration -> responsibility update
```

- Textual confidence: high
- Empirical confidence: high as an organizational hypothesis

## H1-22-05 — Cross-group integration should be reciprocal, not one-way assimilation

不同群体各有能力缺口；整合应使双方获得对方的有效能力，同时保留专业异议和现场反馈。

- Textual confidence: high for two-way development
- Empirical confidence: medium-high
