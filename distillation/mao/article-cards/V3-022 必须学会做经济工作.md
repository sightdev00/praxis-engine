# V3-022 必须学会做经济工作

> 文类：劳动英雄与模范工作者大会讲话／战时经济能力政策

## A. 识别

- 原始出处：《毛泽东选集》第三卷，第 1014—1020 页；对陕甘宁边区劳动英雄和模范工作者大会的讲话。

# Pass 0 — 历史情境

直接约束是在外援不确定的条件下维持战争、平民生活和重建。讲话把经济工作从专家的附属事项转为干部、部队和社区共同的责任。

# Pass 1 — 原文／论证重构

```text
外援可能到来但不能依赖
+ 军民创造性努力
→ 自力生产能力

生产 + 节约 + 质量 + 互助 + 模范扩散
→ 改善供给、士气和战争耐力
```

文本要求发展农业、工业和贸易，要求机关与部队生产，节省劳力和材料，同时提高数量与质量，并推广劳动英雄经验。

# Pass 2 — 证据审计

见 `../evidence/v3-022/evidence-ledger.md`。

# Pass 3 — 推理重构

1. 把外部支持视为上行空间，而非唯一计划；
2. 将生产能力与军民韧性连接；
3. 用地方试验和模范劳动者扩散技术；
4. 以产品质量和资源节约约束扩张。

# Pass 4 — 对抗性阅读

产出增长可能来自天气、市场、强制、无偿劳动、配给或外部转移，而不是模范或竞赛。“自力更生”可能遮蔽不均等负担并拒绝必要援助。劳动竞赛必须记录工时、伤害、补偿、分配、同意和反事实生产率，不能只庆祝。

# Pass 5 — 本篇候选机制

## H1-3-22-01 — 规划外援时不形成依赖

维持内部能力基线，同时记录外部支持、其可靠性和失去支持的情景。

- 文本置信度：高
- 实证置信度：中

## H1-3-22-02 — 通过可审计试验扩散模范做法

扩散前测量产出、质量、劳动时间、安全、投入和分配；保留失败案例，禁止强制模仿。

- 文本置信度：高
- 实证置信度：中

# Pass 6 — 跨篇更新

V3-009 和 V3-015 已把组织负荷与生产相连。本篇加入质量、节约和外援不确定性，但仍需要 V3-021 的自愿参与边界，防止动员沦为汲取。

## 工作判断

可迁移规则是依靠可测量的地方能力建立韧性，而不是自给自足的修辞：可以欢迎外援，但计划必须经得起外援消失，并核算人的成本。
