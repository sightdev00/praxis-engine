# V3-025 论联合政府

> 状态：依现行协议完成首轮蒸馏
> 日期：1945-04-24
> 文类：七大政治报告／联合政府纲领／战后国家建设

## A. 识别

- 1945 年原报告资料：https://zh.wikisource.org/wiki/論聯合政府
- 选集对照文本：https://www.marxists.org/chinese/maozedong/marxist.org-chinese-mao-19450424.htm
- 这是毛泽东代表中共中央向七大作的政治报告；1953 年收入《毛选》第三卷时经过较大修改，必须分开审计。

# Pass 0 — 历史情境

日本尚未投降，国共关系和战后政权安排同时处于竞争状态。文本试图把抗战、民主改革、联合政府和新民主主义国家建设组织为一套可供全党动员的纲领。

# Pass 1 — 原文／论证重构

抗战经验与国民党统治批评 → 需要团结、民主和政治改革 → 建立民主的临时联合政府 → 打败侵略者并建设独立、自由、民主、统一、富强的新中国。

报告还把党的领导、根据地经验、军队建设、土地与经济政策、文化教育和城市工作纳入同一国家建设框架。

# Pass 2 — 证据审计

见 ../evidence/v3-025/evidence-ledger.md。1945 年报告本身是纲领和承诺的一手证据；根据地人口、军队、政权绩效和国民党失败等事实主张，仍须与独立材料分开核验。1953 年修订只能作为版本结果，不能直接证明 1945 年文本的决策边界。

# Pass 3 — 推理重构

1. 将战时统一战线转化为战后临时政权方案；
2. 用民主、自由和统一等目标约束组织权力；
3. 以根据地治理经验作为可扩展能力样本；
4. 把政治纲领拆成军队、土地、经济、文化和城市能力；
5. 用联合政府作为联盟谈判和权力过渡的制度接口。

# Pass 4 — 对抗性阅读

“联合”可能是包容性制度，也可能只是由一方定义边界的过渡工具。根据地经验不能自动代表全国；群众动员不等于自由授权；“民主”必须有竞争、少数权利、司法救济和权力交接证据。1945 年后的内战与政权建立能验证部分组织能力，却不能把后见成功倒写成联合政府承诺已经实现。

# Pass 5 — 本篇候选机制

## H1-3-25-01 — 将联盟纲领拆成可执行权利和能力指标

为代表性、军队国家化、土地权利、财政透明、言论自由、司法救济和地方自治分别设定结果账，不用“民主”总标签替代。

- 文本置信度：高
- 实证置信度：中

## H1-3-25-02 — 对战时联盟设置战后授权闸门

明确临时安排的期限、退出与复核方式；战时贡献不能自动变成永久执政授权。

- 文本置信度：中
- 实证置信度：高

# Pass 6 — 跨篇更新

V3-024 提出两种前途，本篇进一步给出联合政府这一制度方案。新的审计边界是：愿景、联盟承诺、组织能力和战后权利兑现必须分别评分。

## 工作判断

本报告的核心价值是把抗战胜利后的制度选择提前制度化；核心风险是把一方的领导资格、群众代表性和民主含义预先合并，导致纲领承诺缺少独立验收。
