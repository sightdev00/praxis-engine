# Pass 0 — Historical frame

本文直接回应“红军前途和时局应如何估量”的争论。前面已经出现两个相反错误：

```text
过度乐观
-> 看大自身、看小对手
-> 盲动冒进

过度悲观
-> 看小自身、看大对手
-> 回避根据地建设与积极发展
```

所以核心任务不是证明“乐观主义”，而是回答：

> 在当前力量很弱、局部屡受打击的情况下，怎样判断长期趋势，并据此决定红军应流动保存还是建设根据地、集中发展？

# Pass 1 — Source / argument reconstruction

## 1.1 从时局估量直接推出行动策略

文章开头明确把两个问题连在一起：

```text
estimate the situation
-> choose action
```

不同的现实估量分别导向：

- 盲动；
- 悲观保存；
- 有根据地、有计划的扩大路线。

## 1.2 反对只看“当前可见规模”判断力量

文章承认 1927 后主观力量很弱，但认为判断不能停在表面数量，而要把自身力量放在**相对力量结构和发展趋势**中考察。

主要论证：

```text
自身弱
but
对方组织也受特定社会政治结构约束而相对脆弱
+
多组社会政治矛盾继续发展
-> 当前弱小力量的增长潜力不能由静态规模推断
```

## 1.3 局部环境不能无条件一般化为全局

文章明确批评：

```text
一次败仗 / 四面被围 / 强敌追击
-> 把一时、特殊、小的环境扩大为全国全局判断
-> 产生悲观结论
```

因此区分：

- local snapshot；
- general situation；
- underlying trend。

后两个是我们的现代标签。

## 1.4 未来判断应基于正在发展的矛盾，而不是简单愿望

文章试图把“高潮快来”建立在多组矛盾发展之上，包括国际力量、国内统治者、税负、土地关系、工业、士兵处境、学生就业等。

其推理结构是：

```text
multiple tensions intensify
-> pressure accumulates across many groups
-> instability / collective resistance more likely
-> current small organized force may enter a faster-growth regime
```

这不是现代概率模型，但明显尝试给预测提供机制链，而不是只喊口号。

## 1.5 集中/分散原则被进一步条件化

正文引用旧信，然后主动修正自己的旧论证：

> 过去所列“不应分兵”的理由都是消极的，“很不够”。

随后增加正面理由：集中兵力才能消灭更大敌人、占领城镇、发动更大范围群众、建立相连政权，从而形成更大的政治影响。

同时又明确：

```text
不是永远集中
```

满足条件时仍可近距离或远距离分兵：

- 环境较好；
- 领导机关较健全；
- 分兵能实现争取群众、土地、政权、扩军目的。

所以原则进一步从：

```text
集中 > 分散
```

变为：

```text
choose concentration/distribution according to purpose + environment + leadership capability
```

## 1.6 明确承认一个预测参数错误

文章说此前提出“一年争取江西”，错误在于**规定一年为期**。

并进一步提出：

> 未来发展只能说大的方向，不应该也不可能机械规定时日。

这是一条极重要的预测修正：

```text
方向判断
!=
精确时间承诺
```

## 1.7 上级判断被现实重新修正

文章记录：中央此前对形势和红军行动的一个悲观估计后来发生变化；一个关于蒋桂战争的估量“不适当”的通告，中央后来另发通告更正。

这继续提供组织层级上的 revision evidence。

# Pass 3 — Reasoning reconstruction

## R1 — Evaluate relative, not absolute, strength

自身弱不等于前景差；需要同时估计对手强度、结构脆弱性和增长速度。

## R2 — Separate snapshot from trajectory

当前规模和一次局部失败不是长期趋势本身。

## R3 — Avoid local-to-global extrapolation

局部、短期、特殊状态不能未经论证扩展成全局判断。

## R4 — Forecast through causal/tension indicators

未来方向通过观察一组正在加剧的矛盾和行为信号来判断。

## R5 — Refine an argument, not only a conclusion

作者明确指出自己此前论证“很不够”，保留结论但补充正面因果理由。

## R6 — Condition tactical rules on purpose and operating context

集中和分兵不是价值判断，而要看目的、环境和领导能力。

## R7 — Separate directional forecast from calendar forecast

允许判断趋势方向，同时拒绝机械规定准确时日。

# Pass 4 — Adversarial reading

## A1 — “表面 vs 实质”容易成为理论优先于反证的工具

如果坏结果被称为“表面”，而理论期望被称为“实质”，那么任何反证都可以被排除。

可靠迁移必须要求：

```text
所谓“实质”必须对应可观察机制和可失败预测
```

而不是凭理论身份自动获胜。

## A2 — 革命高潮“很快”仍然模糊

虽然文章纠正“一年”这一机械期限，但“快要”仍缺少清晰阈值和时间边界，可证伪性有限。

## A3 — 多矛盾发展链可能存在选择性证据

列出大量恶化矛盾可以支持上升趋势，但也需要主动寻找：

- 稳定机制；
- 缓和机制；
- 国家整合能力；
- 对手学习与适应；
- 群众风险厌恶。

## A4 — 对江西一年计划的时间错误被承认，但方向判断继续保持

这是健康修正，也可能是“只修参数、不修模型”的例子。后续必须看方向判断在现实中如何继续接受检验。

## A5 — 反事实和必然性语言较强

“必然”“无疑义”等表述超过了本文提供的现代实证证据强度。我们不能把语言确信度等同于经验可信度。

## First-pass takeaway

本篇真正重要的不是“星星之火”这个比喻，而是一个预测—行动模型：

```text
不要由当前规模直接预测未来
-> 同时估计自身、对手和结构条件
-> 区分局部快照与全局趋势
-> 为趋势判断列出正在变化的驱动因素
-> 根据状态和目标选择集中/分散等策略
-> 允许修改旧论证和预测参数
-> 对未来方向与精确时日采用不同证据标准
```

对 Praxis Engine 最重要的新增约束是：**“看本质”不是跳过证据的许可证。任何被称为本质的东西，都必须继续接受可观察机制和失败条件的审计。**
