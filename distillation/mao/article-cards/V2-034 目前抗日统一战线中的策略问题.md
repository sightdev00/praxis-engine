# Pass 0 — Historical frame

这篇报告把统一战线建模为一个动态 actor system，而不是静态名单。不同力量同时受对日战争、阶级利益、中央—地方矛盾、组织实力和近期胜负影响，因此可合作、可中立、可敌对，并会分化。

```text
actor interests + current pressures + observed power
-> current stance
-> differentiated policy
-> interaction outcome
-> actor stance changes
```

本文最重要的机制不是“发展/争取/反对”三个标签本身，而是试图给竞争性联盟设计一个有启动、目标、停止和重启合作的冲突协议。

# Pass 1 — Source / argument reconstruction

## 1.1 先建立多层形势模型

报告同时判断：日本行动能力与基本目标、英法美苏政策、亲日与欧美派大资产阶级、中间势力、共产党领导的进步力量。

```text
external adversary capability/objective
+ international constraints/support
+ domestic actor interests/behavior
+ own capability
-> branch assessment
```

这是多变量状态图，但多项判断为作者推断或本方自报，例如日军“无力再大规模进攻”、本方抗敌兵力比例、苏联援助稳定性。

## 1.2 联盟策略由三个同时运行的环节组成

```text
develop progressive forces
+ win middle forces
+ oppose die-hard forces
-> expand and consolidate united front
```

三个环节不是按顺序完成的流水线，而是相互作用：本方发展与对顽固派的有效抵抗会降低中间派疑虑；尊重中间派利益会防止其被对手吸收。

## 1.3 斗争被放在目的—手段结构中

文章明确说斗争是团结的手段，团结是斗争的目的，既反对因怕破裂而完全退让，也反对无限使用斗争。

```text
bounded contest
-> preserve capability + alter incentives
-> renewed cooperation / larger coalition
```

这不是冲突最小化，而是把冲突限制在服务共同目标的范围内。

## 1.4 中间力量被进一步分解

中等资产阶级、开明绅士和地方实力派虽然统称中间势力，但可合作范围不同：共同建政、有限参与、善意/勉强中立或暂时中立。

```text
coarse class: middle
-> subtypes
-> issue-specific cooperation envelope
```

这延续 V2-023 的 taxonomy refinement：同一类别不能自动获得同一 policy。

## 1.5 争取中间力量依赖三项条件

文章提出本方需有充足力量、尊重其利益、并能在反对顽固派的斗争中取得逐步胜利。

```text
credible capability
+ interest protection
+ observed execution success
-> middle actor neutrality / cooperation more likely
```

这把说服从话语变成可信度和利益结构问题；但仍假设中间派主要随力量/利益移动，可能低估价值、信息和自主目标。

## 1.6 对顽固派采用双通道策略

文章不把尚抗日的顽固派等同于已经投降者：一方面延长其留在抗日联盟的时间，另一方面抵抗其压制进步力量的行为。

```text
shared objective still active
-> keep cooperation interface

harmful anti-coalition behavior
-> resist / constrain
```

这与 V2-028 的 effect/identity separation 一致，但正文又把反动政策解释为准备将来投降的步骤，意图推断仍强。

## 1.7 “有理”规定启动边界

只在受到攻击后还击，强调防御性。其功能是提供可说明的触发器，避免无故扩大战线。

```text
verified attack
-> defensive response authorized
```

原文没有 `verified`、归因/误判和比例条件，现代重建必须添加，不能把“我方认定受攻”直接当作事实。

## 1.8 “有利”规定选择与准备边界

不进行无计划、无准备、无把握的斗争；利用对方矛盾，不同时打击许多对象，先选最反动者。

```text
objective + readiness + favorable scope
-> selective engagement
```

它控制资源分散与多线升级，但“必胜”可能鼓励人为压低风险估计或只选择弱目标。

## 1.9 “有节”规定停止与重开合作

击退一次进攻后，在没有新攻击时适可而止，主动谈团结、订立和平协定；新攻击出现再进入新一轮斗争。

```text
trigger
-> bounded response
-> stop condition
-> truce / cooperation reset
-> monitor for new trigger
```

这是目前文本中最明确的 conflict lifecycle，防止成功行动因惯性无限延续。

## 1.10 党派整体不能由主导政策代表

报告说国民党成分复杂，虽顽固派支配当前政策，但不等于全部党员都是顽固派，应利用内部差异、分别对待。

```text
organization-level policy
!= every member identity
```

这是防止组织标签吞掉 actor resolution 的重要边界。

## 1.11 同一纲领根据控制权限切换制品类型

国民党共同纲领在其统治区是宣传纲领，在八路军新四军所到地区是行动纲领。

```text
same specification
+ authority/capability context
-> advocacy artifact OR executable policy
```

这说明“知道该做什么”不等于“有权限执行”；Agent 必须把 recommendation 与 action authorization 分开。

# Pass 3 — Reasoning reconstruction

主要推理操作：

1. **multi-layer state modeling**：联合外部、国际、国内和自身能力；
2. **dynamic actor segmentation**：按利益、行为和可合作范围细分 actor；
3. **coupled strategy portfolio**：发展、争取、反对并行；
4. **means-end discipline**：冲突服务联盟而非自我延续；
5. **credibility-through-capability**：力量、利益尊重和成功影响中间选择；
6. **dual-channel engagement**：同一 actor 可同时合作与受约束；
7. **trigger/readiness/exit protocol**：有理、有利、有节；
8. **organization/member separation**：组织政策不吞并所有成员；
9. **specification/authorization separation**：同一纲领按权限成为倡议或行动。

# Pass 4 — Adversarial reading

## 4.1 三分法可能成为自我实现分类器

“进步”由是否接受本方领导定义，“顽固”由是否限制本方定义，中间又被视为待争取对象，可能使所有 actor 都围绕本方利益编码。需要独立行为字段与多方目标。

## 4.2 结构身份仍预先决定行为预期

大地主大资产阶级被设为必然两面/将分化，地方实力派被判断“不久仍反动”。文本虽允许阶段变化，却容易只把符合理论的变化视为真实。

## 4.3 “一切经验证明”没有失败账本

斗争可能导致联盟破裂、误伤中间派或升级内战；退让也可能在某些情境买到时间。没有完整案例集，不能从胜利叙事推出普遍真理。

## 4.4 “人不犯我”需要共同事实裁决

双方都可能认为自己自卫。事件归因、时间顺序、命令链、误击和 proportionality 若由一方决定，防御原则不能阻止升级。

## 4.5 “彻底全部消灭进攻”突破最小必要响应

防御授权不自动允许最大化军事毁伤。现代转译必须加入最小必要、非战斗者保护、可逆性、升级上限和独立复核。

## 4.6 “斗则必胜”诱发选择性风险报告

若只有宣布有把握才能行动，下级可能隐瞒不确定性；同时不行动的机会成本也需评估。应使用概率、损失上限和撤出条件，而非胜利保证。

## 4.7 休战触发器容易被低强度行为规避

对方可能不再公开进攻，却继续封锁、渗透或行政压制。停止协议要覆盖多种 harm channel，并允许分级响应。

## 4.8 争取中间派可能滑向交易式工具化

尊重利益是联盟基础，但若只为孤立对手、而不承认其独立代表和长期权利，合作会随力量变化撤销。

## 4.9 共同纲领的合法性仍由本方解释

“我们实行所以合法、对方反对所以非法”可能形成自证。共同规则需要共同解释、公开事实和争议处理接口。

## 4.10 当前能力判断不能无限外推

“日军无力再大规模进攻”即使短期成立，也不等于资源、战区或战略改变后仍成立。必须绑定时间、规模与触发条件。

# Pass 5 — Article-local candidate mechanisms

## H1-34-01 — Competitive coalitions need dynamic, issue-specific actor models

同一组织/阶层内部可存在不同目标，同一 actor 在不同问题上可合作、中立或对抗；policy 应随行为证据和情境更新。

- Textual confidence: high
- Empirical confidence: high

## H1-34-02 — Conflict should have an explicit lifecycle

高冲突行动至少需要：可验证触发、合法目标、准备/胜算、范围、比例、停止、休战、监控和重新进入条件。

- Textual confidence: high for trigger/readiness/stop skeleton
- Empirical confidence: high with added safety controls

## H1-34-03 — Preserve cooperation interfaces while constraining harmful behavior

actor 在一个目标上仍合作、另一个行为上造成危害时，可分别处理；不必在无条件容忍与整体敌对之间二选一。

- Textual confidence: high
- Empirical confidence: high

## H1-34-04 — Coalition credibility depends on capability and interest protection

声明不足以吸引中间参与者；可观察执行能力、尊重其利益及兑现有限胜利会改变合作预期。

- Textual confidence: high
- Empirical confidence: medium-high

## H1-34-05 — Separate recommendations from authorized actions

同一规范在无权限处只能传播/建议，在有权限处才可执行；跨越 action boundary 需显式授权与风险门。

- Textual confidence: high
- Empirical confidence: high

# Pass 6 — Cross-article update

### Strengthens P2: differentiated engagement under shared objectives

V2-011/015/018/027/028 都拒绝“合作或斗争”二选一；本文给出最完整的 actor 分层与 conflict lifecycle。相近战争/统战语境仍高度相关，暂不升级 G2。

### Extends M-03 from action safety to conflict escalation

现有 reversibility/failure-cost gate 应增加 conflict-specific fields：trigger evidence、attribution confidence、minimum necessary response、third-party harm、escalation ceiling、exit/ceasefire、re-entry condition。原文只提供部分骨架，现代安全门是必要增强。

### Strengthens organization/member and identity/behavior separation

V2-023/028 已区分结构身份、实际行为和隐藏意图；本文明确说支配组织政策的少数不等于全体成员。组织层决策、子群体和个体必须分层记录。

### Prediction ledger update

“日军已无力再作大规模军事进攻”进入 PRED-020，必须绑定 1940 当时、战区和“大规模”定义；后续日军战役尤其 1944 一号作战用于检验，不能用战略相持标签自动吸收。

### Does not validate the actor taxonomy

本文反复使用进步/中间/顽固三分，但这仍是同一作者同一策略链内的重复；后续应检查预测的 actor 迁移是否发生，以及被归为中间者是否真实按条件变化。
