# Pass 0 — Historical frame

文章产生于武汉失守后的抗战相持期和反共压力上升期，面向文化工作者，同时回应：

- 中国应建立什么政权和经济；
- 统一战线的共同纲领是什么；
- 为什么当前不能直接实行社会主义；
- 为什么共产党又不能放弃自己的长期纲领；
- 新文化怎样连接政治、经济和群众。

它把 V2-023 的社会—革命模型扩展成政治、经济、文化三系统的完整蓝图，但定本已被后来的建国与社会主义选择重新编排过，不能直接等同于 1940 年决策时点。

# Pass 1 — Source / argument reconstruction

## 1.1 以实践检验开场，但全文含大量不可直接检验的必然命题

开头反对自以为是，主张实事求是、共同讨论，并说真理由千万人民的实践检验。

```text
claim
-> public discussion
-> mass practice
-> result
-> truth test
```

这是开放认识论姿态；但正文随后多次使用“只有”“唯一”“必然”“决然”等词，又未给出失败条件。两者构成需要审计的内部张力。

## 1.2 文化既被解释为结果，也被设计为干预变量

基本模型是：经济为基础，政治是集中表现，文化反映政治经济，又反过来产生重大影响。

```text
economy
-> politics
-> culture

culture
-> politics/economy
```

这避免纯单向决定论，但“文化为政治经济服务”容易把知识、艺术和批评全部工具化。

## 1.3 先定义当前系统类型，再规定阶段目标

沿用殖民地、半殖民地、半封建定性，将现有政治、经济、文化都视作目标系统；再把变革分成民主与社会主义两个性质不同的阶段。

关键不是只排时间表，而是防止跨阶段 actuator：

```text
current task set
!= future task set

future direction retained
but future policy not executed now
```

本文明确反对把社会主义任务合并进当前阶段，也反对因当前合作而取消未来纲领。

## 1.4 战略目标、当前纲领和理论方法被拆成三层

文章区分：

- 将来的社会主义/共产主义社会制度；
- 当前新民主主义行动纲领；
- 用于研究、训练和处理工作的共产主义立场与方法。

```text
worldview/method
-> informs current program

current program
!= final system
```

这是一种 horizon separation；但长期目标仍可能影响当前伙伴对未来承诺的信任。

## 1.5 用 common/difference matrix 管理联合

在三民主义与共产主义之间，正文分别列出：

- 当前民主革命政纲的共同部分；
- 人民权力、工时、土地纲领等差异；
- 是否有后续社会主义阶段；
- 世界观差异；
- 所谓实践彻底性差异。

```text
shared objective scope
+ explicit non-shared scope
-> conditional coalition
```

不是通过消除差异来维持合作，而是把共同接口与保留域同时公开。

## 1.6 政治设计区分“谁拥有国家权力”和“权力怎样组织”

文本把国体解释为各阶级在国家中的地位，把政体解释为政权机关的组织形式。提出各级人民代表大会、普遍平等选举和由代表大会选举政府，再以民主集中制整合意志与行动。

```text
constituency / power base
!=
institutional form / decision process
```

这是重要的 representation distinction；但“联合专政”中的排除、领导和民主之间的制度冲突没有被解决。

## 1.7 经济方案采用分层所有权组合

定本方案包括：

- 大银行、大工业、大商业：国家所有；
- 不能操纵国民生计的一般私人资本：允许发展；
- 地主土地：分给无地少地农民，成为农民私产；
- 富农经济：允许；
- 合作经济：作为社会主义因素。

```text
strategic/monopoly assets -> public ownership
ordinary private production -> permitted
land concentration -> redistribution
smallholder base -> cooperative option
```

这比单一所有制口号更像 transition portfolio；但“操纵国民生计”“规模过大”“某种必要方法”等执行边界没有量化。

## 1.8 路径选择同时规定“必须做”和“暂不做”

文章两面反驳：

- 反对资本主义共和国作为下一阶段；
- 反对立刻进行社会主义改造。

```text
not endpoint A
not immediate endpoint B
-> bounded transitional system C
```

这种双侧否定能限制误执行；然而把 C 称为“不可移易的必要形式”又过度普遍化到所有殖民地半殖民地。

## 1.9 文化输入被设计为“选择—分解—重组”

对外国文化和古代文化，文章既反对全盘拒绝，也反对生吞活剥：

```text
external/historical material
-> critical decomposition
-> retain usable parts
-> recombine with local practice/form
```

马克思主义本身也被置于此规则之下：普遍理论必须与中国具体实践和民族形式结合。

## 1.10 “民族、科学、大众”是文化验收三轴

- 民族：独立、具体语境、与其它民族互相吸收；
- 科学：实事求是、客观真理、理论实践一致；
- 大众：为多数工农服务，并逐渐成为其自身文化。

同时区分并连接：

```text
cadre depth <-> mass accessibility
raising <-> popularization
```

不过“大众服务”仍可能由代表者代言，正文没有建立群众反馈、选择权和文化生产权的程序。

## 1.11 历史阶段模型用结果反向确认领导资格

文章把五四以后文化/政治进程分四期，以共产党、工农参与和统一战线解释进步，把对手失败解释为路线失败，由此证明无产阶级文化领导。

这形成循环风险：

```text
correct leadership -> historical progress
historical progress -> proves correct leadership
```

需要独立结果指标和竞争解释才能打破。

# Pass 3 — Reasoning reconstruction

主要推理操作：

1. **practice-as-validation claim**：宣称用公共实践检验理论；
2. **base/feedback model**：经济、政治、文化间决定与反作用；
3. **horizon separation**：区分方法、当前纲领和最终目标；
4. **two-sided stage bounding**：同时拒绝跳阶段与取消后续阶段；
5. **common/difference matrix**：用共享域和保留域管理联盟；
6. **power-base/form separation**：区分谁拥有权力与如何组织权力；
7. **mixed transition portfolio**：战略国有、一般私营、土地重分、合作因素并存；
8. **critical assimilation**：外来/传统材料分解后本地重组；
9. **multi-axis cultural acceptance**：民族、科学、大众三维验收；
10. **periodization**：用关键 actor/联盟/文化变化分期；
11. **opponent-motive inference**：从论点推断对方投降/阶级目的；
12. **historical inevitability extrapolation**：由世界趋势推唯一制度路径。

# Pass 4 — Adversarial reading

## 4.1 实践检验需要预先写出可失败条件

如果成功归正确路线、失败归执行不彻底/敌人破坏，实践不能真正反驳理论。开头的开放姿态必须落实到 prediction、counterfactual 和 revision rules。

## 4.2 “文化反映/服务政治经济”可能压扁知识自治

文化也能发现政治经济模型的错误。若所有批评先按阶级服务对象分类，坏消息会被视作敌对文化而不是纠错信号。

## 4.3 普遍选举与“领导/专政”的冲突未制度化

文本同时承诺普遍平等选举、各阶级联合和无产阶级领导，但未解释选举若产生不同领导结果怎么办、谁定义反革命、排除决定如何复核。

## 4.4 经济边界过于依赖解释权

“操纵国民生计”“大企业”“一般私人财产”“某种必要方法”均可宽窄变化。没有稳定规则、赔偿、司法和 transition gate，承诺难以约束未来权力。

## 4.5 当前承诺被后来的定本修改重新着色

建国后增加国营经济的社会主义性质/领导作用、合作经济社会主义因素，并把没收“大地主”改成“地主”。这会让 1940 的联盟承诺显得比原文更接近后来社会主义改造。

## 4.6 三类国家制度的穷尽分类过粗

现实政体存在联邦、混合经济、多党议会、威权发展型、殖民自治等多维组合；按“阶级专政”压成三类会损失制度机制和结果差异。

## 4.7 世界必然性预测后来没有普遍成立

资本主义没有在 1940 年代迅速退出历史，社会主义共和国也没有成为所有工业先进国家的统治形式。中国路径不能验证这一全球全称。

## 4.8 对异议的动机归因替代了论证审计

把“一次革命论”者统一解释为接受日资比例的投降准备，把反共等同汉奸，可能存在真实案例，却不能证明所有提出相似论点者共享同一秘密目的。

## 4.9 “思想比赛”与排除性文化斗争并存

文章一处说各种主义可以比赛，另一处又把部分文化判为必须打倒、不能联合。缺少言论边界、非暴力异议保护和公共证据程序。

## 4.10 “大众文化”仍可能是精英替大众定义需求

接近群众、语言改革和普及很重要，但群众是否能拒绝、改写、生产和评价文化没有明确机制。

## 4.11 领导资格论证存在 outcome attribution 问题

五四、大革命、土地革命和抗战变化受战争、国际环境、国家能力、多党组织和地方社会共同作用；不能由结果单独识别某一思想的决定性领导。

# Pass 5 — Article-local candidate mechanisms

## H1-26-01 — Separate method, current program and terminal objective

同一组织可用较长期的方法/价值指导当前任务，同时不得把未来状态的 actuator 提前执行；每一层需要独立承诺和验收。

- Textual confidence: high
- Empirical confidence: high as a planning architecture

## H1-26-02 — Coalitions need an explicit common/difference matrix

合作应写清共享目标、差异、暂缓冲突、不可让渡边界和退出条件；统一不等于隐藏矛盾。

- Textual confidence: high
- Empirical confidence: high

## H1-26-03 — Transitional systems need a portfolio and stable boundary rules

不同资产/任务可按规模、公共风险、替代性和能力配置不同治理方式，但分类字段与转移程序必须可测量、可申诉。

- Textual confidence: high for portfolio
- Empirical confidence: high for boundary requirement

## H1-26-04 — Import by decomposition and recomposition, not labels

外来理论/技术与历史材料应拆成可检验部件，保留有效部分，再与本地约束、语言和实践重组；来源身份不能决定整体采纳或拒绝。

- Textual confidence: high
- Empirical confidence: high

## H1-26-05 — Representation and decision form are separate design layers

“谁的利益/权力被代表”与“通过什么制度聚合、授权、执行和纠错”必须分别审计；前者的正当标签不能证明后者有效。

- Textual confidence: high
- Empirical confidence: high

## H1-26-06 — Mass accessibility requires feedback and co-production

普及、语言接近和服务多数只是起点；若缺群众的选择、反馈、修改与生产权，仍是单向分发。

- Textual confidence: medium for accessibility
- Empirical confidence: high for added feedback boundary
