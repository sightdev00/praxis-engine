# Pass 0 — 历史情境

日本投降大势已定，苏联参战使战争迅速进入终局。抗日阶段结束后，国共关系、解放区扩展和战后政权安排同时成为核心问题。

# Pass 1 — 原文／论证重构

日本败局与苏联参战 → 中国进入和平与内战危险并存的过渡期 → 共产党既要争取和平、民主、团结，又要准备应对国民党进攻 → 依靠人民、扩大解放区和建立联合政府，争取光明前途。

# Pass 2 — 证据审计

见 ../evidence/v4-001/evidence-ledger.md。讲话直接呈现战略判断、政策方针和组织动员要求；“和平可实现”“国民党必然进攻”“解放区扩大”等是不同强度的预测，必须分开评分。

# Pass 3 — 推理重构

1. 将外部战争终局转成国内政治窗口；2. 和平谈判与军事准备并行；3. 以群众、解放区和民主改革争取谈判筹码；4. 用联合政府作为战后制度出口。

# Pass 4 — 对抗性阅读

“和平”和“内战”并存要求条件化策略，但文章仍把国民党反动性作为高置信度前提。解放区扩大可能增强安全却也加剧冲突；人民支持不能用组织覆盖或动员人数替代真实同意。后续重庆谈判与内战只能分别检验策略分支。

# Pass 5 — 本篇候选机制

## H1-4-01-01 — 谈判与防御准备构成双轨策略

同时记录谈判提议、对手回应、部队部署和地方治理，避免把军事准备误判为拒绝和平，或把谈判承诺误判为安全保证。

- 文本置信度：高
- 实证置信度：中

## H1-4-01-02 — 战后制度承诺必须绑定权利和安全指标

将联合政府、民主改革、军队整编、地方自治和人民安全分别验收，不以最终政权胜负替代承诺审计。

- 文本置信度：高
- 实证置信度：中

# Pass 6 — 跨篇更新

V3-031已把反攻与制止内战并列；本篇进入第四卷后，把“窗口期双轨策略”作为后续重庆谈判和内战篇目的共同基线。新增约束是：每次战略判断都要写出和平分支、冲突分支及各自触发条件。
