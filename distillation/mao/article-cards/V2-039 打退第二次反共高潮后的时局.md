# Pass 0 — Historical frame

V2-038 将皖南事变视为全国性突然事变的开端，并推断十五步全面破裂/投降计划。本文则把同一事变定义为反共高潮最高峰，把三月六日进一步反共言行解释为退兵时的一战，并预测暂时轻微缓和。

```text
Jan 20 model: local catastrophe -> national rupture beginning

new March evidence / incentives
-> reclassify event as peak
-> forecast partial temporary easing
-> retain local-risk vigilance
```

这是 corpus 中少见的短期 actor/stage model 下调，必须作为 revision 而不是术语变化处理。

# Pass 1 — Source / argument reconstruction

## 1.1 用事件序列识别“峰值—退潮”而非继续升级

文章把皓电以来五个月视为一轮高潮，皖南事变和一月十七日命令为峰值，三月六日反共演说/决议虽表面强硬，却判断为退兵时的一战。

```text
event severity
!= direction of change

late hard action
may occur during de-escalation
```

它要求看行为在完整 episode 中的位置，而不是只按最新事件语气判断趋势。

## 1.2 缓和判断采用多约束 actor model

文中列出的抑制继续升级因素包括：国际两大集团竞争、国民党内部多重派系矛盾、国内民意和中共持续抗议。

```text
external strategic constraint
+ internal factional friction
+ public legitimacy pressure
+ opponent response
-> incentive for limited easing
```

这比 V2-038 单一日汪总计划模型保留更多独立约束，但各因素权重仍未量化。

## 1.3 预测语言显著降低确定性

文章使用“可能”“暂时”“某一程度”“轻微”四层限制。

```text
direction: easing
duration: temporary
magnitude: slight / partial
confidence: possible
```

这让局部进攻、宣传压迫继续存在仍与预测兼容，也使未来证据更容易明确更新。

## 1.4 区分形式姿态与政策变化

蒋介石强调国防、弱化党派观念被解释为维持统治的策略；文章又设下可观察边界：若只有形式欺骗、没有政策变化，就不会成功。

```text
public repositioning
-> inspect policy/action change
-> accept or reject substantive update
```

这延续 claim-behavior audit，但“企图维持统治”的内心解释仍是 O6。

## 1.5 把应对过程拆成先退让、后反攻

文章认为高潮初期的有限退让取得公众同情，皖南事变后的猛烈政治反攻也获支持，两者共同符合有理、有利、有节。

```text
early accommodation
-> expose counterpart / preserve legitimacy
trigger threshold crossed
-> bounded counter-pressure
```

这是状态依赖策略而非固定强硬度；但“公众赞助”与“已收成效”主要是本方自我评价，缺独立数据和反事实。

## 1.6 下降警报不等于关闭问题

文章要求在主要争点未解决前继续抗议和扩大十二条宣传，不能因总体缓和而松懈。

```text
system risk decreased
but unresolved harms remain
-> continue bounded remediation pressure
```

阶段改变应调整强度，不自动结束未完成的 repair items。

## 1.7 系统缓和与局部风险并存

国统区压迫与宣传被判不会放松，淮北、皖东、鄂中进攻还会继续；同时反对把它们解释为国共最终/迅速破裂。

```text
local persistent harm
compatible with
system-level non-transition
```

这直接恢复 V2-027/035 的 scale separation，并修正 V2-038 的过度升级。

## 1.8 模型更新没有完全进入因果归责

文章调整了阶段预测，却仍把皖南事变归于国民党内亲日派反共派，并断言国民党压力政策“决不会放松”。

因此 revision 是部分的：系统转换概率下降，hidden-coordination/actor identity 并未同步重审。

# Pass 3 — Reasoning reconstruction

主要推理操作：

1. **episode segmentation**：把事件放入上升、峰值、退潮周期；
2. **severity/direction separation**：强硬事件不自动代表趋势继续上升；
3. **multi-constraint actor update**：国际、派系、民意与对手行动共同改变激励；
4. **calibrated forecast**：方向、幅度、期限和置信度分开；
5. **claim-behavior validation**：形式姿态等待政策结果；
6. **state-dependent response**：退让与反攻按触发状态切换；
7. **unresolved-item persistence**：总体缓和不关闭修复要求；
8. **local/system scale separation**：局部冲突与全国破裂分别预测。

# Pass 4 — Adversarial reading

## 4.1 “退兵时一战”可能是不可证伪的后验标签

若任何后续强硬行为都可解释为退潮余波，缓和模型不会被反驳。应定义事件频率、规模、政策撤销和时间阈值。

## 4.2 多约束解释仍缺权重和新证据

文章列出多种压力，但没有说明哪项在 1 月 20 日后发生了什么可观察变化，或各自如何改变决策。

## 4.3 自称政策“打退高潮”有 self-attribution bias

局势缓和也可能来自国民党自身目标有限、外部战争压力、资源约束或事变后目标已达。没有反事实不能把效果完全归于抗议与十二条。

## 4.4 公众同情/赞助缺测量

报刊、请愿、党派声明和参政会行为可以作为指针，但“广大人民赞助”不能由己方声明验收。

## 4.5 形式/实质标准需要对称使用

要求观察国民党政策变化是合理的；同样应观察本方反攻是否遵守有节、是否伤害中间 actor、是否真实恢复多党权利。

## 4.6 继续所有要求可能与降级不匹配

若系统风险下降，要求包应按止损优先级、实现可能和新证据重新排序，而不是机械维持原清单强度。

## 4.7 “决不会放松”与缓和预测张力

若压迫政策绝不放松，缓和究竟表现在哪些可观察行为？需要拆分军事、政治、宣传、组织和地域维度。

## 4.8 revision 未说明为何先前高估

文章纠正结论，却没有明确回顾 V2-038 哪些证据、推理或置信度有误。没有 error diagnosis，未来仍可能重复 sequence overfit。

# Pass 5 — Article-local candidate mechanisms

## H1-39-01 — Separate event severity from trend direction

高严重度或强硬事件可能发生在上升、峰值或退潮任一阶段；阶段判断需要频率、范围、能力、政策和激励的联合时间序列。

- Textual confidence: high
- Empirical confidence: high

## H1-39-02 — Calibrate forecasts across direction, magnitude, duration and confidence

“可能/暂时/轻微/某种程度”不是含糊装饰，而是可分别被结果检验的预测字段。

- Textual confidence: high
- Empirical confidence: high

## H1-39-03 — Lowered system risk should not erase unresolved local harm

总体转移概率下降时，应降低相应准备等级，但继续跟踪未修复事件、局部攻击和权利问题，避免全开/全关警报。

- Textual confidence: high
- Empirical confidence: high

## H1-39-04 — Every forecast downgrade needs an error diagnosis

记录结论从何变到何、哪些新证据触发、旧模型哪一部分失效、哪些字段保留；否则 revision 只是新判断覆盖旧判断。

- Textual confidence: high that downgrade occurs, low that diagnosis is supplied
- Empirical confidence: high as meta control

## H1-39-05 — Do not infer causal impact from post-action improvement alone

行动后局势好转只说明时间关联；需竞争解释、机制证据和未采取行动的 counterfactual 才能评估贡献。

- Textual confidence: high that article self-attributes effect
- Empirical confidence: high as corrective rule
