# Pass 1 — Source / argument reconstruction

## 1.1 选集文本将三个目标定义为联合必要条件

文章认为抗战、团结、进步三者缺一不可；没有团结和进步，抗战会转向投降或失败。

```text
resistance
AND unity
AND progress
-> durable resistance / possible victory
```

这不是单瓶颈，而是必要条件组合。但“进步”包含民主自由、群众动员、反腐与保护本方组织等多项内容，本身仍是一个复合变量。

## 1.2 每个正面目标都通过反向故障清单落地

正文不是解释抽象定义，而是列出每个目标需要排除的失败模式：

- 抗战：投降、汪伪、阵线内投降活动；
- 团结：分裂、磨擦、袭击进步力量、破坏根据地、否认合法性；
- 进步：取消自由、包办宪政、迫害青年、腐败与豪强横行。

```text
positive objective
-> prohibited failure modes
-> editorial monitoring agenda
```

这使口号具备一定可观察性，但各项仍缺指标、归因标准与处理程序。

## 1.3 用共同公开纲领约束联盟伙伴

正文援引三民主义、《抗战建国纲领》和“唤起民众”等国民党自身承诺，批评实际倒退。

```text
shared / counterpart commitment
-> observable implementation gap
-> accountability claim
```

这与 V2-029 的共同承诺审计一致；但谁有权解释承诺、发生冲突时如何裁决仍未解决。

## 1.4 较早文本先建立竞争分支

长文本明确保留两种结果：时局好转或逆转。它列出阻碍投降/全国反共战争的国内国际条件，同时承认投降倒退危险仍是主要危险。

```text
current state
-> branch A: improvement
-> branch B: reversal

branch probability affected by:
domestic resistance + KMT majority + public resistance
+ Japan's hard objective
+ inter-imperialist conflict
+ Soviet support
+ European-war constraints
```

这种结构比选集短文的必然语气保留了更多可更新空间。

## 1.5 较早文本把预测转为双轨准备

长文本反对因为担心逆转就只消极准备突发事变；其基本任务是扩大进步力量、抵抗倒退、争取好转，同时对局部突发事件保持警觉。

```text
shape preferred branch
+ prepare for adverse branch
```

这延续 V2-027 的 branch-aware risk control，并明确反对把 contingency preparation 变成放弃主动塑造。

## 1.6 十项任务组成能力与行动组合

长文本的任务覆盖宣传、统一战线、宪政、自卫、群众与知识分子、经济减负、根据地政权、军队、文化和党组织。

它是一组耦合系统：

```text
narrative legitimacy
+ coalition capacity
+ democratic interface
+ defensive capacity
+ mass participation
+ material incentives
+ governance base
+ military capacity
+ learning/culture
+ organization
```

但文本多次把每一项表述成没有它就不能胜利，尚未区分真正必要条件、增强项和替代路径。

## 1.7 内部任务与外部口号是两种表示层

长文本最后把复杂任务翻译为十四条公开口号，包括拥护蒋介石、国民政府和国共合作，同时要求开放党禁、自由权利、民主政权等。

```text
internal model / task portfolio
-> public action language
```

公开口号不是完整认知模型；它经过受众、联盟和动员约束的压缩。选集删除整组口号后， contemporaneous support/pressure interface 也被削弱。

## 1.8 选集重新定义了制品类型与时间

较早文本是 2 月 1 日中央决定，选集文本则以 2 月 7 日报纸纪念文章出现，并只保留原决定部分论述。变化涉及：

- author/owner：中央决定 → 毛泽东文章；
- date：2 月 1 日 → 2 月 7 日；
- audience：党内决策执行 → 机关报读者；
- content：分支/条件/任务/口号 → 三目标原则及故障清单。

这证明 document metadata 会改变我们重建的 reasoning role。

# Pass 3 — Reasoning reconstruction

主要推理操作：

1. **joint-necessity modeling**：把抗战、团结、进步视为组合条件；
2. **failure-mode decomposition**：用反面事件展开抽象目标；
3. **commitment audit**：用联盟共同/对方公开承诺检验行动；
4. **branch preservation**：保留好转与逆转两种未来；
5. **condition mapping**：列出影响分支的国内国际变量；
6. **dual-track control**：争取优选路径同时准备局部风险；
7. **portfolio design**：用多领域任务共同改变系统状态；
8. **representation translation**：把内部模型压缩为外部口号。

# Pass 4 — Adversarial reading

## 4.1 三目标可能由同一方循环定义

若“团结”定义为保护本方组织，“进步”定义为接受本方政策，“抗战”又由团结进步来判定，模型就可能自我封闭。需要跨方指标和共同裁决接口。

## 4.2 联合必要性没有反事实证明

文章列出三者不可缺一，却未比较缺少其中一项的历史样本，也未说明最低阈值和补偿关系。它可能是政治程序主张，而非严格因果定律。

## 4.3 负面清单混合不同风险等级

投降、军事袭击、压制出版、腐败、豪强、婚姻数量和财富问题被放入同一修辞链。它提示系统性退化，却不能授权同级响应。

## 4.4 “反共即投降步骤”过度压缩因果与身份

部分反共行动可能客观削弱抗战联盟；这不自动证明所有反共者均准备投降或属于汉奸。效果、协调关系、目的和身份仍需分别审计。

## 4.5 对突发事变的自卫原则缺程序

谁判定“人若犯我”、证据门槛、响应比例、升级上限和退出条件均未规定，容易发生相互归责和升级螺旋。

## 4.6 十项任务缺优先级、依赖与资源约束

任务覆盖面广，但没有 owner、预算、先后顺序、冲突处理和验收。多约束系统若只列清单，执行时仍会被局部资源瓶颈支配。

## 4.7 “完全民选”与排除特定 actor 的边界不清

政权被定义为所有赞成抗日民主者的联合，同时预先排除投降/反共者。若资格由执政方不可申诉地判定，选举范围会受分类器控制。

## 4.8 公开口号隐藏了内部概率与争议

支持特定领导、政府与合作是策略接口；若后来只保存反对清单，历史上的不确定 actor model 和妥协边界会消失。反过来，公开支持也不能当作内部信念完全认同。

## 4.9 长文本本身的出处仍需验证

镜像明确称其不在官方选集/文集，并列出后期参考资料来源。在得到报刊扫描、档案版本或可靠校勘前，只能把它列为高价值 variant witness，不能视为无争议底本。

# Pass 5 — Article-local candidate mechanisms

## H1-31-01 — Critical objectives may form a joint condition set

当某一目标依赖协作、能力和制度环境时，不能只优化名义主目标；应先检验目标之间是必要条件、增强项还是可替代关系。

- Textual confidence: high
- Empirical confidence: medium

## H1-31-02 — Define positive goals through observable failure modes

把“团结/进步”拆成袭击、封锁、权利取消、腐败等事件可提高可审计性，但事件仍需独立证据、严重度和响应映射。

- Textual confidence: high
- Empirical confidence: high with controls

## H1-31-03 — Shape the preferred branch while preparing for adverse branches

不确定环境下，主动改变分支概率和准备损失控制应并行；不能因风险存在而放弃塑造，也不能因争取好转而取消预案。

- Textual confidence: high in earlier document
- Empirical confidence: high

## H1-31-04 — Internal models and public representations require separate audit

面向行动者的口号会压缩条件、不确定性与冲突；研究者必须保留它与内部判断/任务清单的映射，避免把交付文本误作完整模型。

- Textual confidence: high from variant
- Empirical confidence: high as research control

## H1-31-05 — Task portfolios need dependency and resource architecture

耦合问题需要跨领域组合行动；清单只有增加 owner、优先级、依赖、资源、指标和申诉后才能成为执行系统。

- Textual confidence: high that a portfolio is used
- Empirical confidence: high for added implementation controls
