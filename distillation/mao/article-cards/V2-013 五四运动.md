# Pass 0 — Historical frame

文章写于全面抗战接近两周年之际。其直接任务不只是纪念 1919 年，而是回答：

> 五四运动在更长的中国革命过程中处于什么位置，青年和知识分子在当前抗战中应怎样行动？

因此，本文把二十年前的运动作为当前政治动员的历史依据。历史解释与现实号召相连，尤其需要区分：

- 当时可用的历史事实；
- 作者对历史阶段和社会力量的分类；
- 从这种分类推出的规范性组织结论。

# Pass 1 — Source / argument reconstruction

## 1.1 五四被嵌入一个长过程，而非当作孤立事件

文章把鸦片战争以来的多个运动排列为中国民主革命的不同发展阶段。各阶段具有不同特点，但被归入同一总体历史过程。

```text
different episodes and forms
-> shared historical task
-> stage-specific contribution
```

这是一种“连续过程 + 阶段差异”的历史表征。

## 1.2 五四的“新”首先由参与力量的变化定义

文章并不只用观念更新定义五四，而把工人阶级、学生群众和新兴民族资产阶级的生长，以及学生走在运动前列，作为相较辛亥革命的新因素。

因此其阶段划分依据至少包括：

- 参与者构成；
- 领导/先导力量；
- 运动规模；
- 与此前阶段的连续性。

## 1.3 当前任务由阶段性质和社会力量结构共同推出

文章先判断当前仍处在反帝反封建的民主革命过程，再列出工农兵学商的联合力量、工农的根本地位和工人阶级领导，最后推出抗日民族统一战线是当前政策。

```text
historical-stage judgment
+ actor/force model
+ current principal enemy
-> coalition strategy
```

## 1.4 “首先觉悟”不等于“单独完成”

知识分子在辛亥和五四中被描述为较早觉悟、走在前列的成分，但文章随即否定其单独完成任务的能力，要求与工农民众结合。

这里区分了三种角色：

```text
early sensing / articulation
!=
mass capability
!=
final leadership claim
```

它反对把信息上的先行自动转换成独立执行能力。

## 1.5 身份判断被转为行为检验

文章不以口头接受某种主义作为最终分界，而以是否愿意并实际同工农民众结合为标准。

```text
declared identity
-> insufficient

observable alignment + repeated action
-> practical test
```

## 1.6 文章最终落到角色转换

青年和文化人不仅要“认识”革命性质与动力，还要进入工农民众之中，成为宣传者和组织者。

因此结论不是一般性的“青年重要”，而是：

```text
historical understanding
-> locate decisive social forces
-> change one's work relation to them
-> organize present action
```

## 1.7 版本变化改变了部分因果和分类结构

1939 原刊文本把辛亥革命与五四运动的失败直接归因于知识分子未同工农结合；第二版删除了这句明确的单因果判断。第二版同时新增“工人阶级是领导阶级/离开其领导不可能完成”的条件，并把“真正的三民主义与马克思主义者”改为更宽的“真正的革命者”。

因此不能把第二版中的完整结构无条件回投为原刊时已经相同的论证。

# Pass 3 — Reasoning reconstruction

主要推理操作：

1. **process reconstruction**：把分散事件放入一个连续历史过程；
2. **stage differentiation**：在总体连续性中用参与力量和领导关系识别阶段变化；
3. **actor/force analysis**：区分先觉者、根本力量、领导力量和联盟成员；
4. **role-to-capability distinction**：信息/观念先行不等于能单独完成系统任务；
5. **behavioral classification**：用实际结合和组织行动检验政治身份；
6. **history-to-action mapping**：把历史诊断转为当前青年工作的部署。

# Pass 4 — Adversarial reading

## 4.1 连续阶段模型可能压平重大断裂

把性质差异很大的运动统一归入同一民主革命过程，有助于形成战略连续性，但也可能忽略各事件独立的目标、主体和制度后果。

## 4.2 “知识分子不结合工农导致失败”是过强的单因果归因

原刊的明确因果句没有排除组织能力、国家强制、国际环境、联盟结构等变量；第二版将其删除，反而提示原论证需要降级。

## 4.3 行为标准比口号可靠，但标准本身带有政治价值预设

“同工农结合”确实把身份检验推向行动，但它仍是本文政治目标下的规范性分类器，不能直接迁移为一般人才评价法。

## 4.4 从“社会力量重要”到“某一阶级领导”存在额外推理跳跃

第二版明确加入领导阶级判断，但本文本身没有用独立比较证明为什么根本力量、先觉力量和领导力量必须按此配置。

## 4.5 历史解释服务当前动员，可能发生目的性选择

文章的终点是动员青年进入工农群众，因此历史材料的选择和因果强调可能受当前组织目标影响。

# Pass 5 — Article-local candidate mechanisms

## H1-13-01 — A process model should preserve both continuity and stage-changing variables

跨期分析既需要说明什么任务/约束延续，也需要明确哪些参与者、能力或制度变化使阶段真正不同。

- Textual confidence: high
- Empirical confidence: medium
- Failure condition: 用一个总体标签抹平事件的独立结构。

## H1-13-02 — Early recognition is not equivalent to system-level execution capacity

最先发现、表达或解释问题的群体，不一定拥有完成任务所需的规模、资源和组织能力。

- Textual confidence: high
- Empirical confidence: medium
- Modern mapping: sensor/analyst role != actuator/operating system

## H1-13-03 — Role claims should be tested by observable relation and action

口头身份不足以证明实际角色；至少要检查持续行为以及该行为与目标群体/任务的真实关系。

- Textual confidence: high
- Empirical confidence: medium
- Boundary: 行为检验所依据的目标与价值标准也必须接受审计。

## H1-13-04 — Historical narratives used for action require a variant and causal audit

当历史解释直接控制当前行动时，应分开审计事件序列、阶段分类、因果归因和编辑版本；不能把后期修订后的更完整模型静默回填到早期决策点。

- Textual confidence: high for the observed variant
- Empirical confidence: high as a research-control rule
