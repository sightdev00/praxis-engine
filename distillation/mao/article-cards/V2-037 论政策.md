# Pass 0 — Historical frame

本文同时处理两个问题：一是纠正把土地革命时期做法直接复制到抗战时期的政策惯性；二是纠正组织在“全联合”与“全斗争”之间摆动。它明确承认一批早期政策不只是不合当前阶段，而是在当时也属错误。

```text
historical failure review
-> distinguish invariant from stage-specific policy
-> define strategic corridor
-> instantiate by domain
-> correct gradually while monitoring backlash
```

这是一份比口号更接近 operating policy 的材料，也同时暴露了权利与安全分类仍依赖“反共/反动”等宽标签。

# Pass 1 — Source / argument reconstruction

## 1.1 区分长期不变量与阶段性政策

文章坚持抗战时期统一战线总方针不变，同时要求许多土地革命政策不能简单沿用。

```text
invariant: broad anti-Japanese coalition
stage variables: property, labor, governance, military, organization
```

这不是“原则永远不变、执行随意变化”，而是要求每个具体域重新匹配当前任务、联盟和生产条件。

## 1.2 对过去错误作跨域明确承认

文中列举：消灭资产阶级/富农、肉体消灭地主、打击知识分子、肃反极左、党员完全独占政权、共产主义国民教育、进攻大城市/否定游击战、白区盲动、党内打击政策等，并说这些“就是在过去也是错误的”。

```text
observed historical loss
-> reject prior policy bundle
-> do not protect it as merely stage-expired
```

这是 revision evidence，而不是后来研究者根据结果推测作者改变了判断。

## 1.3 用两个历史极端构造策略走廊

第一次大革命后期被总结为一切联合、否认斗争；土地革命后期则是一切斗争、否认联合；两者都造成重大损失。

```text
failure mode A: cooperation without autonomy/resistance
failure mode B: conflict without coalition
-> coupled policy corridor
```

这不是求中间值，而是在不同 actor/aspect 上同时允许联合与斗争。

## 1.4 actor 被拆成多轴状态而非单一身份

同一个顽固派可在抗日、反共、合作破裂意愿等方面呈现不同状态；亲日者中也区分坚决与动摇；帝国主义按当下侵略行为、联盟关系、政府/人民和政策时期分开。

```text
actor
-> issue vector + time
-> aspect-specific policy
```

这比固定身份分类更高分辨率，但结构阶级判断仍常预设未来行为。

## 1.5 外援与自主被放进组合约束

文章反对把日本之外国家都当朋友，也反对拒绝援助；主张独立战争、自力更生前提下尽量利用外援。

```text
internal capability floor
+ diversified external support
-> avoid dependency / avoid isolation
```

V2-019 的永久利益一致已被后续现实反驳，本文的条件化表达明显更稳。

## 1.6 政权政策扩大参与但仍设政治资格门

三三制再次被规定，部分地区党员可少于三分之一，民意机关甚至可容许少数右派；同时参加者被限定为“不积极反共/不反共”。

这展示 representation range 可适配，却仍未解决和平反对执政党是否受保护。

## 1.7 劳动、土地和税收采用双边约束

劳动政策同时改善生活、保留企业利润和生产；土地政策同时减租减息、保留所有权与借贷可用；税收按收入并广泛负担、最贫者免征，禁止靠抓人罚款筹军饷。

```text
protect vulnerable actor
+ preserve production / credit / fiscal capacity
-> bounded reform
```

这些是 trade-off policies；具体边界主要由政治判断给出，缺真实收入、生产、租息和分配结果数据。

## 1.8 司法安全政策加入多项程序约束

正文要求少杀、不牵连无辜、胁从/动摇者宽大、废止肉刑、重证据不轻信口供、限制逮捕权于政府司法/治安机关，并对大多数俘虏释放或争取。

```text
security objective
-> evidence + authority + restraint + reintegration
```

这是高后果 actuator 前较明确的防错设计；例外中的群众痛恶、非杀不可和上级批准仍不是独立司法程序。

## 1.9 权利被写为普遍规则但带政治前提

不反对抗日者不分阶级享有人身、财产、选举、言论、集会、结社、思想和信仰自由；政府只干涉组织破坏/暴动者。

若“只干涉组织破坏/暴动”严格执行，边界相对行为化；但开头“不反对抗日”可被扩张解释，需要公开证据与司法复核。

## 1.10 经济自给被设计为多所有制组合

发展农业、工业与商品流通，吸引外来资本、奖励民营，政府企业只占一部分，并要求关税货币服务发展目标。

```text
public enterprise + private enterprise + market circulation
-> regional self-sufficiency
```

这与 V2-026 当前阶段的混合经济一致；“自给自足”仍需要定义是基本生存、财政稳定还是完全封闭。

## 1.11 人才吸纳采用“先接入、后观察”

对文化教育技术人才主张大胆吸收任用，不因少量反动者可能混入而停止；在学习工作中再识别处理。

```text
broad intake
-> limited role / observed work
-> update trust
```

它与 V2-035 对地下领导机关“稍有嫌疑即排除”形成对照，说明风险容忍应随权限和 failure cost 变化。

## 1.12 军事领域保留更高控制集中

军队不实行三三制，领导权必须由党掌握，但技术/军事部门大量吸收同情者，且党员数量垄断应改变。

```text
high-risk core control centralized
peripheral/technical participation broadened
```

这是一种 tiered access architecture；权力集中是否必要及如何外部监督，本文未证明。

## 1.13 纠错本身要求分阶段

文章最后要求纠正错误要有步骤，避免干部不满、群众怀疑、地主反攻等二阶效果。

```text
identify wrong policy
-> sequence correction
-> monitor transition effects
-> continue / adjust
```

错误明确不等于可无成本瞬间切换，correction plan 也需要风险控制。

# Pass 3 — Reasoning reconstruction

主要推理操作：

1. **invariant/parameter separation**：总方针与阶段政策分开；
2. **explicit error-bundle revision**：承认早期多域政策错误；
3. **failure-bounded corridor**：用两端历史失败限制当前策略；
4. **actor-vector modeling**：同一 actor 按问题/时期拆分；
5. **capability/dependency balance**：自力基础上使用外援；
6. **two-sided policy constraints**：改革与生产/联盟条件并行；
7. **high-consequence due process**：证据、权限、少杀、宽大与再融入；
8. **mixed-system design**：公共/民营与多阶级利益组合；
9. **tiered trust/access**：开放吸纳与核心控制按风险分层；
10. **staged correction**：修错同时管理切换副作用。

# Pass 4 — Adversarial reading

## 4.1 过去错误的因果证据仍未展开

明确承认很重要，但每项政策造成何种损失、通过什么机制、有哪些反例并未在本文展示。error list 不是完成的 after-action review。

## 4.2 “无论何种情况总方针不变”可能免疫核心假设

若环境变化到共同目标、参与安全或联盟结构消失，总方针也应可重审。invariant 必须有适用边界和撤销条件。

## 4.3 左右标签可能替代事实诊断

“过左/过右”是相对于当前路线的位置，不直接说明事实错误、价值冲突或结果机制。应具体标注错误层级。

## 4.4 actor 向量仍受阶级先验支配

细分虽提高分辨率，但“阶级关系决定政策”容易忽略个体组织、地区、制度和新行为证据。每个轴需可更新。

## 4.5 劳资/地租边界缺权力不对称审计

“资本家有利可图”“农民交租交息”强调生产连续性，却可能把工人农民的低议价权当自然约束；真实成本与替代制度未比较。

## 4.6 税收广覆盖可能把战争成本转给低收入多数

最贫免税不等于其余家庭可负担。需要收入定义、税率、征收成本和申诉，不可用“国家赋税”抽象合法化。

## 4.7 司法保护仍保留群众情绪死刑门

“群众痛恶、非杀不可、上级批准”不等于证据充分、独立审判和比例性。群众情绪是风险信号，不是定罪器。

## 4.8 权利前提可吞噬权利本身

若批评政策被解释为反抗日/反共，思想、言论、结社自由就由被批评者决定。必须保护和平反对与组织竞争。

## 4.9 “洗刷”缺程序与恢复机制

先吸收后观察比全拒绝更能扩容，但被认定“反动”后的调查、权限限制、申诉与恢复未规定。

## 4.10 军事领导不可动摇与联合治理存在长期张力

关键强制能力完全由一个党控制，可能使政权三三制的多数意见在冲突时失去实际执行力。formal/effective control 必须联审。

## 4.11 渐进纠错也可能保护既得错误

有步骤可降低副作用，也可能成为拖延停止伤害的理由。对持续侵权/不可逆损害应立即止损，对复杂迁移才分阶段。

# Pass 5 — Article-local candidate mechanisms

## H1-37-01 — Historical policies require explicit error-type revision

不要把失败全部解释为环境变化；区分当时就错、后来失配、执行失败和证据不足，并为每项保留机制与结果证据。

- Textual confidence: high
- Empirical confidence: high

## H1-37-02 — Stable objectives need revisable domain policies

跨阶段可保留高层目标，但劳动、土地、税收、组织、安全等政策必须按当前约束重算，且高层目标本身也需撤销边界。

- Textual confidence: high
- Empirical confidence: high

## H1-37-03 — Map actors as issue-specific, time-versioned vectors

一个 actor 可同时合作、竞争、动摇或造成危害；policy 针对具体维度而不是整体身份，并随新行为更新。

- Textual confidence: high
- Empirical confidence: high

## H1-37-04 — Trust and screening should be permission-tiered

低后果学习/技术岗位可宽入口、在工作中更新；高风险核心权限需强审查，但任何层级都要证据、复核、申诉与恢复路径。

- Textual confidence: high across V2-035/037 contrast
- Empirical confidence: high

## H1-37-05 — Correction urgency should track continuing harm

修正复杂系统时需管理切换副作用；正在造成不可逆侵害的措施先停，结构迁移再分阶段，不能统一“慢改”。

- Textual confidence: high for staged correction, medium for harm exception
- Empirical confidence: high

## H1-37-06 — High-consequence classification needs independent due process

证据优先于口供、禁止刑讯、限制逮捕权和宽大恢复是基础；仍需独立裁决、辩护、记录、申诉和比例性。

- Textual confidence: high
- Empirical confidence: high with added controls
