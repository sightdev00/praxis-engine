# Pass 0 — Historical frame

欧洲战争已爆发，中国抗战被判断基本进入战略相持；日本的占领区治理、政治诱降、经济掠夺和敌后扫荡重要性上升，国内统一战线摩擦加剧。

本文的功能是把快速变化的形势判断固定为全党当前任务，同时为“突然事变”保留组织韧性准备。

# Pass 1 — Source / argument reconstruction

## 1.1 国际判断延续此前阵营模型

文章把欧洲战争归因于帝国主义国家试图摆脱经济/政治危机，把德、英法两方都定性为掠夺战争；同时继续把苏联进兵波兰解释为制止德国东进、巩固和平和解放少数民族。

这部分压缩了 V2-017/019 的结论，也继承其秘密协议缺失和证据标准不对称。

## 1.2 日本目标不变，当前手段重新配置

日本被判断为专力解决中国问题，以便未来扩大国际行动。具体区分：

- 占领区：扫荡根据地、经济开发、建立伪政权、消解民族精神；
- 中国后方：政治进攻为主、军事进攻为辅；
- 大规模战略进攻概率下降，但战役进攻仍可能。

```text
stable higher objective
-> capability/environment changes
-> operating-mode portfolio changes
```

## 1.3 相持阶段是条件性、可逆的

正文说相持“基本”到来，但列出使其被破坏的路径：

- 占领区被敌人巩固经营；
- 政治进攻未被打退；
- 抗战、团结、进步未坚持；
- 反攻能力未积累；
- 国民党政府主动投降。

```text
stage entered
+ maintenance conditions
-> stage persists

maintenance failure
-> prior large-offensive state may return
```

阶段转换不是吸收态。

## 1.4 当前最大危险按内部失效路径定义

投降、分裂、倒退仍被称为当前最大危险，反共和倒退被解释为投降准备步骤。根本外敌仍是日本，但当前行动优先针对使抗战系统内部失效的链条。

## 1.5 任务按战场/后方接口分解

为准备反攻：

- 敌后：游击、反扫荡、破坏占领、政治经济改革；
- 正面：支持防御、打退战役进攻；
- 后方：结束一党专政、召开民意大会、制定宪法、实行宪政；
- 组织内部：巩固党、军队和政权，应对突然事变。

这是从阶段维护条件反推能力工作包。

## 1.6 “突然事变”转化为韧性目标

文章不预测突发事件具体形式，而要求从思想、政治、组织上巩固党及其军政能力，以避免意外损失。

```text
unidentified shock class
-> preserve core organization/capability
-> reduce surprise loss
```

但“巩固”仍需可观察的 readiness 指标。

# Pass 3 — Reasoning reconstruction

主要推理操作：

1. **policy synthesis**：把多篇分析压成组织决议；
2. **objective/mode separation**：目标保持，行动组合改变；
3. **conditional stage recognition**：用“基本”而非绝对状态描述转换；
4. **reversible-state modeling**：明确维护失败可使系统回退；
5. **failure-path prioritization**：按内部失效链定义当前危险；
6. **maintenance-to-task derivation**：从阶段支撑条件反推工作包；
7. **unknown-shock resilience**：不知具体冲击时保护核心组织能力。

# Pass 4 — Adversarial reading

## 4.1 世界大战和苏联波兰行动继续沿用单阵营解释

经济危机被设为战争爆发原因之一，但具体外交、军事和秘密协议被压缩；苏联行动仍免于同等领土/安全交易审计。

## 4.2 敌人行动模式的相对变化缺少分母

正面大战略进攻“可能不大”、政治进攻“为主”都需要兵力、预算、行动频次和效果的相对数据，而非仅有预测类别。

## 4.3 可逆阶段模型合理，但条件集合可能不可证伪

如果任何新进攻都可解释为局部战役，任何阶段回退又可归因于维护失败，阶段判断需要预先定义转换阈值。

## 4.4 国内反共—投降链仍混合结果和动机

反共/摩擦可能削弱抗战并增加分裂风险；并非每个行为者都因此具有投降目的。

## 4.5 “任何相反方针绝对错误”关闭了政策实验空间

抗战、团结、进步是高层目标，但具体宪政时间、改革方式和军事部署仍有不确定性；不能借目标正确性给全部手段继承绝对置信。

# Pass 5 — Article-local candidate mechanisms

## H1-21-01 — Stage transitions require maintenance conditions

系统进入新阶段后仍需持续满足若干条件；应同时记录进入阈值、维持条件和回退路径。

- Textual confidence: high
- Empirical confidence: high as a state-model rule

## H1-21-02 — Derive current work from failure paths, not only desired future state

除了描述未来反攻/目标，还应列出哪些机制会破坏当前阶段，并为每条路径配置检测和能力工作。

- Textual confidence: high
- Empirical confidence: medium-high

## H1-21-03 — Unknown-shock readiness should protect minimal viable capability

无法预测突发事件形式时，优先保护信息、组织协调、关键人员、执行能力和恢复路径；“提高警觉”本身不是验收标准。

- Textual confidence: high
- Empirical confidence: medium-high

## H1-21-04 — Strategic directives must preserve uncertainty below the objective level

高层目标可明确承诺，但具体因果、参数和手段仍应允许证据更新；“目标正确”不能使全部实现方案绝对化。

- Textual confidence: high that the directive closes alternatives
- Empirical confidence: high as a decision-control boundary
