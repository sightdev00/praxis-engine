# Pass 0 — Historical frame

这篇演讲处于国民政府宣布筹备国民大会、共产党推动宪政运动的阶段。它既在界定一种不同于欧美资产阶级议会制和苏联无产阶级专政的过渡政治形式，也在把“宪政”从政府承诺改造成群众施压工具。

文章的核心难题是：

```text
formal constitution may exist without democracy
but democratic facts do not yet exist nationally
therefore:
research + mobilization + pressure
-> change actual power relations
-> constitutional form can recognize them
```

它区分制度形式与运行事实，但对谁定义合法参与者、如何约束新的权力联盟仍不充分。

# Pass 1 — Source / argument reconstruction

## 1.1 把当前问题压缩为独立与民主的联合缺口

文章说中国缺少许多东西，但主要缺独立与民主；相应存在帝国主义和封建主义两种压迫。

```text
desired conditions: independence + democracy
blocking conditions: imperial oppression + feudal oppression
```

这是一种双重 constraint topology，不是单一瓶颈。但“主要”仍来自理论诊断，本文未用比较指标证明其他约束可被暂缓。

## 1.2 建设与破坏被定义为同一转换过程

文章反对“只要建设不要破坏”，认为旧的压迫结构若不移除，新制度无法运行。

```text
remove blocking structure
+ build replacement capability
-> system transition
```

它正确指出旧控制可以吞噬新接口；但“破坏”从制度废除到对 actor 的强制处理，范围差异很大，需要安全与权利边界。

## 1.3 用阶段/条件选择制度，不直接复制理想终态

正文拒绝在当时中国直接采用旧式资产阶级民主或苏联式社会主义民主，主张按当前条件建立多个革命阶级联合的新民主主义宪政，未来条件成熟后再转向社会主义民主。

```text
terminal preference
!= current institutional form

current structure
-> select transitional governance form
```

这延续 V2-026 的当前制度与终局目标分离；风险是“暂时”没有期限、权利底线和可验证的阶段转换门。

## 1.4 用共享传统建立跨组织合法性接口

文章援引孙中山关于民权为一般平民共有的表述，将其解释为多阶级联合、反对一党一派一阶级包办。

```text
counterpart/shared constitutional commitment
-> reinterpret as common governance criterion
-> pressure current controller
```

这再次说明共同文本可作为联盟问责基线；也存在解释垄断和选择性引用风险。

## 1.5 “促进会”兼具研究与推动功能

文章明确给宪政促进会两个任务：研究宪政道理，并通过会议、文章、演说、电报和多地组织推动实际改变。

```text
research
-> answer objections / clarify model
-> coordinated public action
-> aggregate distributed pressure
```

认识与行动相连但不等同；问题在于研究是否允许反证既定路线，还是只为更有效动员服务。

## 1.6 分布式小行动被建模为系统级压力

各界、各地促进会被比作小流汇成大河，通过扩散使对方不能忽视。

```text
many local actions
-> visibility + participation + pressure
-> national institutional change
```

这是 local-to-system aggregation；正文提供机制想象，但没有传播、阈值、反作用或失败案例。

## 1.7 法律形式被放在权力事实之后

文章比较各国宪政，提出宪法通常是在革命成功和民主事实出现后，用根本法确认它；中国尚无全国民主事实，即使颁布好宪法也会被现有势力阻碍。

```text
actual power / participation structure
-> constitutional text recognizes and stabilizes it

text without supporting structure
-> symbolic compliance / implementation failure
```

这是全文最强的制度机制之一：formal interface 不能自行生成运行事实。不过历史概括过于绝对，宪法也可能反过来塑造组织、权利主张和裁判实践。

## 1.8 用行为一致性审计宪政承诺

文章拒绝以国民大会、命令、宪法或总统选举本身作为验收，要求观察是否真实给予民主自由。

```text
declaration / formal artifact
vs
observable rights + constraints + participation
```

这是一种 claim-behavior audit，与 V2-024 对友谊/帮助的可观察行为标准相通。

## 1.9 承认高摩擦实施，但又转向历史必然

文章先警告开会、通电、写文章不会立即带来宪政，强调长期努力和群众动员；随后又断言顽固派必败、倒退行为无一例外地反噬、历史巨轮不可逆。

```text
implementation realism
+ inevitability narrative
```

两者并存：前者为计划留出摩擦，后者可能使反例被解释为暂时现象，降低预测可证伪性。

# Pass 3 — Reasoning reconstruction

主要推理操作：

1. **constraint pairing**：用独立/民主与帝国/封建压迫构造双重问题；
2. **remove-and-build transition**：同时拆除阻碍与建设新结构；
3. **stage-fit design**：按当前条件选择过渡制度；
4. **shared-commitment reuse**：借对方传统建立问责接口；
5. **research-action coupling**：研究为公共推动提供理由；
6. **distributed aggregation**：多地小行动形成系统压力；
7. **formal/operational separation**：区分宪法文本与民主事实；
8. **behavioral validation**：用实际自由/参与检验承诺；
9. **historical inevitability framing**：以方向必然维持长期动员。

# Pass 4 — Adversarial reading

## 4.1 “多数作主”缺多数如何形成的制度

谁能组织、提名、投票、监督、更替和保护少数，正文未规定。多数原则若没有程序与基本权利，仍可能由声称代表多数的一方代理。

## 4.2 多阶级联合与“专政”之间的分类器风险

反对一党包办与排除汉奸反动派同时存在。若参与资格由同一执政联盟定义且无法申诉，反对者可被先分类、后排除，联合政治失去外部边界。

## 4.3 对旧民主和社会主义民主的判断过度类型化

欧美制度被整体归为资产阶级专政/反动，苏联制度被设为更高未来形态，缺少内部差异、权利表现和失败比较。制度标签替代了 mechanism audit。

## 4.4 宪法不仅承认事实，也可能改变事实

正文的 `facts -> law` 方向很重要但不完整。可执行的权利文本、司法/行政接口和社会组织也能改变行动成本与权力关系，存在双向反馈。

## 4.5 研究可能退化为动员工具

文章说研究是为了答复“为什么促”的问题。这给研究预设了方向；若结论不能反过来修改目标和手段，就不是开放证据过程。

## 4.6 “人民推动”缺效果归因

多开会、写文章、发电报可能提高可见度，也可能被封锁、仪式化或引发镇压。局部行动如何聚合需要传播网络、阈值和对照，不是自然汇流。

## 4.7 行为审计只用于对手，没有同等自审

文章要求用实际自由检验国民党宪政，却没有给新民主主义政权自身同样具体的言论、组织、监督和更替测试。方法若只审对手，就会形成单向证伪。

## 4.8 “古今中外没有例外”是不可接受的全称

损人者常可能短中期获益，制度倒退也可能长期稳定。把最终失败设为历史必然，会通过延长时间范围吸收任何反例。

## 4.9 方向确定与精确时间含混并存

正文称需要几年“大概差不多”，但目标是运动扩大、民主事实形成、新民主主义国家还是宪法颁布并不清楚。预测必须拆项评分。

## 4.10 修正一个错误数字不证明其他历史例证可靠

“三天皇帝”改为“几个月”显示编辑纠错，但张伯伦、各国宪政和历史人物的因果总结仍须逐项核验，不能因局部修正推定全文已校准。

# Pass 5 — Article-local candidate mechanisms

## H1-32-01 — Formal institutions require operational facts

政策、宪法和权限声明若没有实际组织、激励、执行和申诉支撑，会成为形式合规；验收必须观察运行事实。

- Textual confidence: high
- Empirical confidence: high

## H1-32-02 — Institutional interfaces can also reshape operational facts

`power facts -> formal rule` 不是单向；可执行规则也会改变行为成本、协调与权利主张。应建模为双向反馈而非先后教条。

- Textual confidence: medium-low; mainly adversarial extension
- Empirical confidence: high

## H1-32-03 — Research and mobilization need a correction boundary

研究可以服务行动，但必须允许证据改变问题定义、联盟对象和手段；否则研究只是既定结论的说服优化。

- Textual confidence: high that text couples them
- Empirical confidence: high for added boundary

## H1-32-04 — Shared governance requires classifier and appeal design

“多数/联合”只有在参与资格、排除标准、证据门、申诉、更替和少数权利可审计时才是运行结构，而不只是代表性声明。

- Textual confidence: high that gap exists
- Empirical confidence: high

## H1-32-05 — Validate institutions by behavior, not artifacts

会议、命令、宪法、头衔和选举名称不能单独证明民主；需要权利可用性、权力约束、竞争/参与和纠错结果。

- Textual confidence: high
- Empirical confidence: high
