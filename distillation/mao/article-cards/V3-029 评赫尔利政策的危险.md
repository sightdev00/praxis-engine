# V3-029 评赫尔利政策的危险

> 状态：依现行协议完成首轮蒸馏
> 日期：1945-07-12
> 文类：新华社评论／外交政策／内战风险

## A. 识别

- 原文：https://www.marxists.org/chinese/maozedong/marxist.org-chinese-mao-19450712.htm
- 写作身份：毛泽东为新华社撰写的评论

# Pass 0 — 历史情境

抗日战争尚未结束，国共武装与政权竞争已重新加剧。评论围绕赫尔利1945年4月2日声明、美国对华政策和国民党“反共第一”的军事重心，判断外部支持正在把中国推向内战危机。

# Pass 1 — 原文／论证重构

赫尔利由支持联合政府转为只同蒋介石合作 → 美国政策助长国民党反共与军事进攻 → 中国共产党及广大人民被排斥 → 抗战、战后和平和美国自身利益同时受损 → 美国人民应要求改变赫尔利式政策。

# Pass 2 — 证据审计

见 ../evidence/v3-029/evidence-ledger.md。原文直接提供政策转变叙述和风险判断；“必然趋势”、人民规模和美国利益受损是预测性归因。后续重庆谈判、赫尔利辞职和全面内战可检验方向，但不能证明美国政策是唯一原因。

# Pass 3 — 推理重构

1. 把外交代表的声明与国家政策、执行资源分层；
2. 观察援助、军队整编、谈判席位和公开承诺如何共同改变冲突激励；
3. 将抗战目标、国内和平与美国声誉作为不同结果指标；
4. 为“政策改变”设定可观察的时间和行动门槛。

# Pass 4 — 对抗性阅读

文章把赫尔利式政策概括为美国政府一群人的意见，但内部异议、援助条件和中国行动者的自主选择没有展开。把国民党自1927年以来的内战传统与1945年的具体军事配置连接起来，有历史解释力，却不能替代逐项因果证据。“人民不可阻止的势力”是动员性判断，不是规模测量。

# Pass 5 — 本篇候选机制

## H1-3-29-01 — 外部支持的排斥性会放大国内冲突

记录外部声明、武器／运输／顾问支持、国内整编和谈判变化，检验支持是否提高一方压制另一方的能力与预期收益。

- 文本置信度：高
- 实证置信度：中

## H1-3-29-02 — 政策风险评估必须同时计入目标冲突

把抗战胜利、国内和平、人民权利、美国利益和世界和平分别验收，不能以单一“反共成功”覆盖其余损失。

- 文本置信度：高
- 实证置信度：高（作为审计框架）

# Pass 6 — 跨篇更新

V3-028将最低民主改革从程序日期中拆出；本篇进一步把外部外交背书纳入风险模型。新增约束是：外部调停者必须披露对象、资源和退出条件，并接受被排斥政治力量的结果审计。

## 工作判断

本篇最可迁移的是把外交政策当作会改变国内激励结构的行动，而非中立话语。最危险的误读是把后来的内战与赫尔利个人或美国单一政策简单等同，忽略国共双方、战后权力真空和国际格局的共同作用。
