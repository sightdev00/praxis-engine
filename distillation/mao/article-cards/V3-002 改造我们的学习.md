# Pass 0 — Historical frame

V3-001 把调查方法与过期结论分开；本文把同一问题提升到组织规模：一个拥有大量行动权限的政党，怎样持续形成关于现状、历史和理论的共同知识，并把知识转化为政策。

```text
fragmented current information
+ unorganized history
+ decontextualized imported theory
-> weak local explanation
-> impression becomes policy

proposed response:
organized collection
+ division of labor
+ analytic synthesis
+ problem-centered education
-> policy-relevant knowledge
```

这不是已经验证的 learning loop。文章主要给出问题诊断和制度提议，没有提供改革后的验收结果。

# Pass 1 — Source / argument reconstruction

## 1.1 把学习问题定义为组织制度问题

开头主张同时改造“学习方法”和“学习制度”。失败不是只由个体懒惰造成，而与材料生产、研究组织、课程中心和评价方式有关。

```text
individual study behavior
embedded in
institutional research and education system
```

因此治理单位从“一个人读什么”转为“组织如何取得、比较、保存、教授和使用知识”。

## 1.2 用二十年叙事建立进步基线

文章把建党二十年描述为一般理论与中国具体实践日益结合、认识逐步深化的过程，并把抗战以来的研究视为进一步发展。

这为改革提供连续性：不是否定全部旧学习，而是说已有进步仍不足。但它同时是组织对自身历史的总体自评，缺少失败率、反例和替代解释。

## 1.3 将缺陷分为三个知识输入端

文章诊断三类断裂：

1. 对国内外政治、军事、经济、文化现状材料收集零碎，研究不系统；
2. 中国近百年与更早历史缺少有组织研究；
3. 国际革命经验和一般理论被当作孤立词句学习，不能用于中国问题。

```text
current state     -> fragmented / unsystematic
historical path   -> organizationally absent
general theory    -> memorized without local application
```

三者分别回答“现在是什么”“怎样走到现在”“可用什么概念解释和行动”；缺一都会削弱问题表征。

## 1.4 把局部知识不足连接到政策错误

文中批评不了解国内外、省县区具体情况却凭一知半解发号施令，及实际工作者把感想当政策。

```text
thin evidence
-> unmarked inference
-> directive / policy
-> high-consequence error
```

这延续 V3-001 的 authority/evidence coupling：离 actuator 越近，不能只靠热情与印象。

## 1.5 用 local-explanation test 检验教育迁移

在延安学习到富县不能应用、经济学教师不能解释边币和法币，被用作课程失败例子。

```text
course knowledge
-> can it explain a nearby live phenomenon?
-> can it guide a concrete task?
```

这比背诵测验更接近 transfer evaluation；但单个解释失败不能独自判定整个理论或教师无效，还需任务集、预测和行动结果。

## 1.6 对照两种态度来压缩诊断

“主观主义”被定义为不研究环境、割断历史、无目的地学理论；相反态度是以理论方法研究现实和历史、从材料中求规律并服务行动。

```text
environment + history + theory
-> analysis / synthesis
-> inferred relations
-> action guide
```

对照能形成清楚 classifier，却把多种失败捆成道德化二分，容易漏掉“认真调查但方法错”“联系实际但因果错”等中间状态。

## 1.7 “实事求是”被操作化为材料到结论的链条

文章将“实事”解释为客观事物，“是”为内部联系/规律，“求”为研究；要求详细占有材料，在一般原理指导下分析综合，而非罗列现象。

```text
facts
-> organized material
-> analysis across forms/relations
-> synthesis
-> provisional conclusion
-> action guide
```

强点是区分材料罗列与关系解释；弱点是没有规定竞争解释、反事实、误差、复核和结论撤销程序。

## 1.8 把领导基本任务拆为认识与改造

第四节明确把领导机关基本任务概括为了解情况与掌握政策：前者认识世界，后者改造世界。

```text
sense / know
-> policy / act
```

这是认识—行动接口，但中间仍需 evidence audit、commit boundary、权限和结果验收；否则“了解”可被领导机关自行宣布完成。

## 1.9 为现状研究设计组织化管线

提议对敌友我各方的经济、财政、政治、军事、文化、党务动态作系统调查，再引出结论；任何部门先了解情况后处理。

这是多 actor、多维、持续状态建模。文章强调系统性，却未说明资料所有权、冲突材料裁决、负面报告保护和更新频率。

## 1.10 为历史研究设计分工—综合结构

近百年中国史应聚集人才、分工合作；先按经济、政治、军事、文化分析，再综合。

```text
domain decomposition
-> specialized inquiry
-> cross-domain synthesis
```

这是一种可扩展研究架构；综合者如何保存来源分歧、避免中央叙事覆盖专业结论，本文未规定。

## 1.11 将干部教育改成问题中心制

教育以中国革命实际问题为中心，以一般原则为指导，废止静止孤立学习。理论在这里是工具/方法来源，不应成为脱离任务的收藏品。

```text
live problem as center
+ general principles as guide
+ historical case as comparison
-> task-grounded curriculum
```

这一结构可迁移；但文中同时指定一部苏联党史为全世界唯一“完全典型”，重新引入了单一权威范本。

## 1.12 以错误为学习前导，但没有给出纠错协议

结尾说走过许多弯路，错误常是正确的先导。这承认失败的认识价值，却没有规定如何记录预测、识别责任层、阻止重复、验证修正。

V1/V2 已发展出的 revision/prediction ledger 正好补充这一缺口；不能把“犯错有益”理解为对可避免错误的免责。

# Pass 3 — Reasoning reconstruction

主要推理操作：

1. **institutionalize learning**：把学习从个人行为升级为组织系统；
2. **three-horizon knowledge model**：连接现状、历史路径与一般理论；
3. **authority/evidence coupling**：禁止薄证据直接变政策；
4. **local transfer test**：用解释真实附近问题检验学习；
5. **material-to-relation synthesis**：区分材料罗列与规律推断；
6. **sense-policy separation**：把认识情况与制定政策分阶段；
7. **actor-by-domain observation**：持续跟踪敌友我多维动态；
8. **specialize then synthesize**：专业分工后跨域综合；
9. **problem-centered curriculum**：实际问题为中心、理论为指导；
10. **failure-as-input**：把弯路作为后续正确的可能材料。

# Pass 4 — Adversarial reading

## 4.1 自称科学不等于通过科学检验

把一种理论定义为“最好的真理”、把与之统一定义为科学/党性，会让反对结论被解释为态度问题，而不是可检验竞争模型。

## 4.2 三类诊断的 prevalence 没有证据基线

“许多”“相当地多”“二十年来一般没有”是领导观察，没有研究清单、样本、成果基线或失败分布。

## 4.3 反教条论证内部保留唯一教科书

批评“万古不变的教条”后，又把一部苏联党史称唯一完全典型。案例可教方法，但单范本会制造选择偏差、路径依赖和新的背诵对象。

## 4.4 本土化可能滑向外部知识排斥

“言必称希腊”批评的是不翻译到本地问题，不应推导为外国史/理论无用。需要结构可比性审计，而非来源国别 classifier。

## 4.5 问题中心制也可能锁定权力中心的问题

谁定义“中国革命实际问题”、谁控制研究议程，会决定哪些伤害和异议不可见。还需 bottom-up question intake 与受影响者申诉。

## 4.6 “事实”进入系统前已经被选择和编码

材料不是无中介现实。V3-001 已显示样本、纲目、访谈权力和记录者会塑造数据；这里的分工系统会放大同一风险。

## 4.7 从材料“引出规律”存在 underdetermination

同一材料可兼容不同因果模型。应保存替代解释、预测差异、置信度与能推翻结论的证据。

## 4.8 道德化标签可能造成 epistemic chilling

把错误方法等同党性不纯、大敌，并使用人格讽刺，可能提高服从、降低公开未知和反例报告。V3-001 的谦逊访谈姿态与此处惩罚性环境存在张力。

## 4.9 local explanation 不等于 intervention success

能解释边币/法币是比背诵更好的测试，但解释正确、预测准确、政策有效和副作用可接受是四个不同验收层。

## 4.10 分工会创造接口损失

经济/政治/军事/文化各自分析后，变量定义、时间尺度和证据等级可能不兼容；“综合”不能只做总叙事，需要 schema、provenance 和 disagreement preservation。

## 4.11 “错误是正确先导”需受失败成本门约束

有些错误能生成知识，有些会造成不可逆损害。M-03 要求先判断可逆性、权限和暴露范围，不能用未来学习价值合理化高代价试错。

# Pass 5 — Article-local candidate mechanisms

## H1-3-02-01 — Organizational learning needs three connected horizons

对实时状态、历史路径和外部/一般模型分别取得证据，并在具体问题上连接；任一输入不能替代其余两个。

- Textual confidence: high
- Empirical confidence: high

## H1-3-02-02 — Evaluate learning by local transfer, not recall

评价学习者能否解释附近真实状态、提出可区分预测并改善任务结果；把解释、预测、干预和副作用分层验收。

- Textual confidence: high for explanation/application test
- Empirical confidence: high for expanded validation ladder

## H1-3-02-03 — Scale research through specialization with provenance-preserving synthesis

按领域分工获取深度，再用共同 schema、来源链、分歧记录和跨域复核综合，避免综合层覆盖不一致证据。

- Textual confidence: high for division/synthesis, medium for modern controls
- Empirical confidence: high

## H1-3-02-04 — Put live problems at the center and theories in the tool layer

课程以待解决问题为中心，理论负责生成问题、比较和解释；理论本身也必须能被任务结果和反例修改。

- Textual confidence: high for problem-centered study
- Empirical confidence: high with falsifiability boundary

## H1-3-02-05 — Keep sensing, inference, commitment and validation distinct

了解情况不直接等于掌握政策。材料、解释、决定、执行和结果分别留痕，并在接口设置审计门。

- Textual confidence: high for situation/policy distinction
- Empirical confidence: high for expanded pipeline

## H1-3-02-06 — A learning system needs protected contradiction channels

组织化研究若缺少异议、反例和负面结果保护，会把系统性误差规模化；知识生产制度必须同时设计 challenge path。

- Textual confidence: low as source attribution; inferred from source's coercive rhetoric gap
- Empirical confidence: high

# Pass 6 — Cross-article update

### Scales V3-001 from field method to research architecture

V3-001 规定如何做小组调查并按维度迁移经验；本文增加材料生产、领域分工、综合和教育接口。两篇共同支持 P2：学习基础设施必须同时管理观察方法与组织传播。

### Strengthens but bounds the praxis loop

V1-007/013/017 的材料—判断—行动链，在这里变成组织级“了解情况—掌握政策”。保持 P2；本文没有执行、反馈和撤销设计，不能据此升级成完整闭环。

### Adds a learning-evaluation ladder

“延安所学到富县不能用”提供 transfer failure。以后应区分：recall → local explanation → discriminating prediction → safe intervention → durable outcome，而不是把“联系实际”当二元标签。

### Creates a new internal contradiction for later rectification texts

文章反对死教条，却指定唯一完全典型并把科学态度绑定党性。V3-006/007/018 应检验整风是否建立可纠错讨论制度，还是主要强化统一解释权。

### No prediction/revision ledger entry

“改革一定有好结果”没有时间、指标和可观察边界，不能登记为可评分预测；本文也未给出足够具体的新 policy reversal chain。
