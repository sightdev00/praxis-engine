# Pass 0 — Historical frame

这篇讲话既解释“五四为什么成为青年节”，也试图用五十年革命史给全国青年规定当前方向。其直接决策压力包括：

- 抗战能否从长期失败史转向胜利；
- 青年运动如何统一；
- 知识青年怎样与更大规模的社会力量连接；
- 延安经验能否成为全国范型。

它比 V2-013 更完整地展开了阶段、目标、力量、成败标准和组织方法，但也把若干政治判断表述成高度确定的历史规律。

# Pass 1 — Source / argument reconstruction

## 1.1 纪念日被解释为阶段转换信号，但不是已经完成的转换

文章把“五四”被定为青年节解释为革命接近从反复失败转向胜利的转变点，随后立即区分：

```text
directional sign / mobilizing commitment
!=
transition already achieved
```

它明确说转变尚未到来，胜利仍需通过抗战争取。

## 1.2 当前行动先由目标对象和阶段边界限定

文章依次回答：

- 反对什么；
- 谁来行动；
- 哪些力量构成动力；
- 当前革命的性质；
- 当前阶段不做什么；
- 要建立什么制度。

尤其把当前民主革命和未来社会主义区分开，借此限制当下行动对象和财产政策。

```text
long-run direction
-> current stage
-> current target + non-target
-> current policy boundary
```

## 1.3 历史成败按任务完成度而不是局部成果判断

辛亥革命赶走皇帝被承认为胜利，但因反帝反封建的总体任务没有完成，又被判为未取得“永久的全国胜利”。

这构成分层验收：

```text
local output achieved? yes
system objective achieved? no
-> partial victory, incomplete mission
```

## 1.4 失败模型先多维展开，再收敛到主要原因

文章把长期失败解释为敌强我弱；“我弱”又包含军事、政治、经济、文化多个方面，但进一步把主要原因归为占人口绝大多数的工农群众尚未充分动员和组织。

```text
outcome gap
-> external capability + internal capability
-> internal multi-domain weaknesses
-> proposed principal enabling condition: mass mobilization
```

这比纯单因素解释多一层结构，但“主要原因”的证据仍需单独审计。

## 1.5 先锋、方面军、主力军和主体不是同一角色

青年/知识分子被肯定为先锋和重要方面军，却被明确判定不是完成任务的主力；工农大众被定义为主力和骨干，全国人民则是行动主体。

文章的角色表征近似：

| Role | Function in the text |
|---|---|
| 先锋 | 较早觉悟、带头、走在队伍前面 |
| 方面军 | 构成重要但有限的行动部分 |
| 主力/骨干 | 提供决定性规模和持续能力 |
| 主体 | 承担整个革命行动的人民集合 |

因此“先行”不自动等于“主力”或“主体”。

## 1.6 身份分类采用动态行为标准

文章重复 V2-013 的标准，并进一步指出：今天结合工农可算革命，明天不结合或压迫民众则分类随行为变化。

```text
classification(t)
<- current/recent behavior and relation
```

这比永久身份标签更动态，但正文又把它称作“唯一标准”，产生过度收缩风险。

## 1.7 延安被当成“正确方向”的实例

文章用延安青年的团结、跨地区汇集、理论学习、生产劳动和同工农结合，证明延安青年运动是全国模范。

推理结构是：

```text
desired criteria
-> observe local case satisfying criteria
-> designate local case as national model
```

但从“符合自己的标准”到“对全国可复制且能产生结果”之间，仍缺独立比较。

## 1.8 结尾把历史学习变成行动闭环

最终要求研究五十年经验、发扬有效部分、去掉错误，再把青年和人民发动、组织、团结起来。

这使历史研究不是纪念性描述，而服务于下一轮组织行动。

# Pass 3 — Reasoning reconstruction

主要推理操作：

1. **goal decomposition**：从长期方向限定当前阶段目标和非目标；
2. **multi-level evaluation**：区分局部胜利与系统任务完成；
3. **force/capability diagnosis**：用敌我强弱和内部能力解释失败；
4. **principal-factor selection**：从多维弱项中选出群众未组织这一主要原因；
5. **role decomposition**：区分先锋、方面军、主力和主体；
6. **dynamic behavioral classification**：按当前实际关系更新身份判断；
7. **reference-case construction**：把延安当地实践指定为全国模范；
8. **experience-to-action update**：从过去成败抽取下一阶段组织动作。

# Pass 4 — Adversarial reading

## 4.1 “转变点接近”主要是方向判断和动员语言

纪念日的制度化不能独立证明力量状态已接近转折。文章承认尚未胜利，但仍从青年觉悟等迹象推出高确定性的胜利方向。

## 4.2 失败原因可能被过度集中到群众未动员

文章先列军事、政治、经济、文化多维弱项，最终却把主要原因归于工农未充分组织。这个收敛可能低估国家能力、国际结构、制度设计、领导判断和组织技术的独立约束。

## 4.3 “唯一标准”把复杂角色判断压成一个指标

同工农关系是重要行为信号，但诚信、能力、具体后果、是否准确代表民众等都可能影响判断。单一标准也可能被表演性满足。

## 4.4 延安模范论存在选择和自我验证偏差

正文以延安符合自身价值标准证明其方向正确，没有与其它地区做结果对照，也没有审计来到延安者的自选择。

## 4.5 人口比例不等于可用组织能力

“占人口百分之九十”说明潜在规模，却不能直接推出可动员性、协调成本、信息质量或实际战斗/治理能力。

## 4.6 长期制度预测被写成无条件定律

“全世界最终都不要资本家并跟随苏联道路”没有给出时间范围、转换机制和可失败条件，应进入 prediction ledger，而不是作为阶段模型的已证前提。

# Pass 5 — Article-local candidate mechanisms

## H1-14-01 — Evaluate progress at multiple objective levels

局部输出可以真实成功，同时更高层系统目标仍未完成；验收应明确所用目标层级。

- Textual confidence: high
- Empirical confidence: high as an evaluation-control hypothesis

## H1-14-02 — Decompose operating roles before assigning authority or expectation

最先识别问题、负责局部行动、提供规模能力和承担系统责任可能是不同主体，不能用“先锋/领导”一词覆盖全部角色。

- Textual confidence: high
- Empirical confidence: medium-high

## H1-14-03 — Static scale is only potential capability

人数或资源规模只有经过发动、组织、协调和反馈，才可能成为实际能力。

- Textual confidence: high
- Empirical confidence: medium
- Failure condition: 把人口/成员数直接当作有效力量。

## H1-14-04 — Behavioral classifications should remain dynamic and multi-signal

实际行为应能更新身份判断，但任何“唯一标准”都需要检查是否遗漏能力、后果和可被操纵性。

- Textual confidence: high for dynamic update; high for the text's single-standard claim
- Empirical confidence: medium for dynamic update; low for single-standard sufficiency

## H1-14-05 — A model case needs external outcome and transfer validation

一个局部实践符合预设标准，只能证明其是候选参考案例；要升级为可迁移模范，还需结果、对照、选择偏差和目标环境差异审计。

- Textual confidence: high that the article uses Yanan as a model
- Empirical confidence: high as an adversarial research rule

```text
raw scale
-> conversion mechanism
-> stress-tested capability
```
