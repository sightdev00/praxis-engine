# Pass 1 — Source / argument reconstruction

## 1.1 用新事件重置威胁排序

德国进攻苏联被解释为不仅针对苏联，也威胁各民族自由独立；因此当前阶段要求集中力量反法西斯。

```text
new high-impact attack
-> broaden affected objective set
-> raise anti-fascist task weight
```

这里的“集中”是阶段优先级更新，不证明其他风险或约束已经消失。

## 1.2 把直接防卫解释为跨群体公共利益

苏联抵抗被定义为同时保护苏联和所有反法西斯民族解放斗争。

```text
local defender action
-> shared adversary constraint
-> positive externality for other actors
```

这为联盟建立共同目标；但“保卫所有民族”是利益一致性/效果判断，不能仅由行动者身份确认。

## 1.3 从共同敌人推导行为型联盟边界

国际统一战线的纳入条件，是反对德意日法西斯统治者；在中国外交上因此可同英美及其他相符力量联合。

```text
actor regime/ideology differs
but behavior on focal threat aligns
-> bounded cooperation interface
```

这修正了按永久阶级/制度身份决定一切关系的模型；合作范围仍应只覆盖共同任务。

## 1.4 将全球目标翻译成中国的三条任务

1. 维持抗日统一战线和国共合作、驱逐日本，以此援助苏联；
2. 反抗国内反苏反共活动；
3. 外交联合英美等反法西斯力量。

```text
global objective
-> domestic coalition continuity
+ internal threat constraint
+ external diplomatic expansion
```

任务覆盖国内协作、防御和国际接口，但没有负责人、顺序、资源或验收指标。

## 1.5 把本地行动放入跨战场互助链

中国继续抗日被解释为援助苏联，不要求直接转移到苏德战场。

```text
hold shared adversary in local theater
-> reduce adversary freedom elsewhere
-> indirect allied contribution
```

这是联盟中的 comparative-position contribution；实际边际效果需军事资源与替代部署数据验证。

## 1.6 对合作与反抗采用双轨，而非全体和解

扩大同英美等合作的同时，对国内反苏反共活动坚决反抗。

```text
cooperate on shared external objective
while
constrain incompatible harmful behavior
```

这延续统一战线的 issue-vector actor model；“反动分子/任何活动”仍缺行为阈值与程序。

# Pass 3 — Reasoning reconstruction

主要推理操作：

1. **event-triggered reprioritization**：重大事件刷新威胁权重；
2. **shared-threat externality**：本地防卫被映射为共同利益；
3. **behavior-based coalition boundary**：按当前共同任务而非永久身份合作；
4. **global-to-local task translation**：把战略目标拆成国内/外交任务；
5. **distributed theater contribution**：本地牵制转化为联盟援助；
6. **cooperation/constraint dual track**：共同目标合作，冲突行为另行约束。

# Pass 4 — Adversarial reading

## 4.1 重大事件更新不证明唯一优先级

“一切力量”集中反法西斯是动员表达；组织仍需维持生存、治理、生产和权利保护。优先事项可获最高权重，不等于支撑系统清零。

## 4.2 公共利益叙事可能把一方目标普遍化

苏联存亡与其他反法西斯力量高度相关，但具体政策仍可能有利益冲突；共享敌人不使所有目标、手段和后果一致。

## 4.3 一个行为轴不能重写 actor 全部风险

英美反对轴心国支持有限合作，不自动消除殖民、对华政策或战后秩序冲突。合作需要 scope、sunset 和独立底线。

## 4.4 “反动分子”是高后果 classifier

若标签直接触发“坚决反抗”，必须把可观察行为、证据阈值、权限和申诉分开；制度/阶级身份不能替代行为。

## 4.5 三项任务缺 execution contract

没有 owner、资源、依赖、完成定义、异常升级和反馈，所以是政策方向而非可执行计划。

## 4.6 间接援助的边际效果未测量

中国抗战客观牵制日军，但“即用此援助苏联”的具体机制取决于日本战略、兵力替代和苏日关系，不能由共同敌人自动验收。

## 4.7 对 V3-003 的模型更新没有显式结算

从怀疑英美妥协到联合英美可能完全由德国入侵解释，但应说明 PRED-024 哪些前提被撤销、哪些风险仍保留，否则旧模型可以无限并存。

# Pass 5 — Article-local candidate mechanisms

## H1-3-04-01 — Major events should trigger explicit priority recomputation

出现改变 actor 能力/目标/约束的事件时，重算威胁与任务权重，并记录旧判断哪些前提失效；不是只在旧计划上加一条任务。

- Textual confidence: high
- Empirical confidence: high

## H1-3-04-02 — Build coalitions on scoped behavioral alignment

以可观察共同目标建立有限接口；身份差异保留为其他轴风险，不自动阻止合作，也不因合作自动消失。

- Textual confidence: high
- Empirical confidence: high

## H1-3-04-03 — Translate global goals into local contribution paths

明确本地任务怎样改变共同 adversary 的资源/选择，再测量边际贡献；避免“支持大目标”只有口号连接。

- Textual confidence: high for theater-link claim
- Empirical confidence: medium-high

## H1-3-04-04 — Coalition updates need scope and exit conditions

新合作须规定共同任务、不可共享领域、底线、复评触发器和结束条件，防止单轴合作变成 actor 全面认证。

- Textual confidence: low as source attribution; inferred control gap
- Empirical confidence: high
