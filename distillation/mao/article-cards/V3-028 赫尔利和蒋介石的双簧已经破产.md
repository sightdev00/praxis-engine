# V3-028 赫尔利和蒋介石的双簧已经破产

> 状态：依现行协议完成首轮蒸馏
> 日期：1945-07-10
> 文类：新华社评论／民主改革／统一战线

## A. 识别

- 原文：https://www.marxists.org/chinese/maozedong/marxist.org-chinese-mao-19450710.htm
- 写作身份：毛泽东为新华社撰写的评论

# Pass 0 — 历史情境

抗日战争尚未结束，国民党准备召开国民大会并维持一党统治；美国驻华大使赫尔利先后对蒋介石方案提供支持，1945年4月2日又公开表示不与中国共产党合作。7月7日四届国民参政会开幕，参政员实际出席仅180/290，成为评论的直接触发点。

# Pass 1 — 原文／论证重构

赫尔利支持蒋介石的一党制与军队整编方案 → 蒋介石以“还政于民”和国民大会包装权力集中 → 各党派及社会反对 → 参政会出席不足、方案出现退缩 → 必须把“是否开会”和“是否立即民主改革”拆开，要求释放政治犯、取消特务、给予自由和党派合法地位。

# Pass 2 — 证据审计

见 ../evidence/v3-028/evidence-ledger.md。参政会出席数字、蒋介石演说和赫尔利4月2日声明是原文直接陈述；“双簧破产”是作者对政治效果的解释。后续赫尔利11月辞职、国共谈判及内战只能检验方向、风险与时限，不能证明本篇评论单独造成转向。

# Pass 3 — 推理重构

1. 识别外部支持者与国内权力方案的耦合；
2. 用出席率、公开承诺和实际改革区分合法性表演与真实授权；
3. 将公共批评作为提高欺骗成本的威慑工具；
4. 设定最低民主改革清单，而不是把选举日期当作改革本身；
5. 保留“暂停或改变方案”与“真正让渡权力”之间的差距。

# Pass 4 — 对抗性阅读

参政会缺席和蒋介石措辞变化可以显示政治成本上升，却不能推出赫尔利—蒋介石合作已经制度性终结。作者把“人民反对”作为总体事实，仍需区分各党派、社会群体和被压制者的可观察意见。把对手称为“欺骗者”有动员作用，但若没有可核验改革指标，也可能把政治标签替代因果证据。

# Pass 5 — 本篇候选机制

## H1-3-28-01 — 最低改革清单优先于程序日期

分别记录政治犯释放、特务机构撤销、言论结社自由、党派合法地位和选举程序；只有前四项出现可验证执行，才把“还政于民”记为实质改革。

- 文本置信度：高
- 实证置信度：高（作为审计框架）

## H1-3-28-02 — 公共揭露提高方案成本但不独自产生转向

将公开批评、国内外反应、对手让步和其他谈判／军事因素按时间记录，避免把同步变化归因于一篇评论。

- 文本置信度：高
- 实证置信度：中

# Pass 6 — 跨篇更新

V3-014已显示公开质问可与私下交涉、自卫准备组成威慑链；本篇把威慑对象从军事进攻扩展到制度性欺骗。V3-016关于宪政承诺的审计提醒：会议文本、实际行动和长期内战结果必须分层保存。新增约束是：程序合法性、基本权利和权力可问责性不可互相替代。

## 工作判断

本篇最可迁移的是“把承诺拆成最低可验行动，并以公开反馈提高失信成本”。最危险的误读是把参政会冷场或后续让步直接等同于民主转型，更不能把美国代表的立场、蒋介石的策略和中国人民的利益压缩成单一主体意志。
