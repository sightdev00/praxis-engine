# Pass 1 — Source / argument reconstruction

## 1.1 用历史类比压缩一个外交风险模型

“远东慕尼黑”把可能的日美妥协解释为：大国用中国利益交换安排，并形成反共反苏局面。

```text
source analogy: Munich accommodation
mapped target:
US-Japan compromise
-> sacrifice China
-> anti-communist / anti-Soviet alignment
```

类比迅速表达 actor、交易结构和受害方，却把多个必须独立验证的步骤封装成一个强标签。

## 1.2 从军事阶段切换预测政治诱降

文章判断以迫蒋投降为目的的军事进攻告一段落，继之“必然”是诱降活动，并以日本惯用的打一拉政策解释。

```text
military pressure phase closes
-> persuasion / bargain phase necessarily rises
```

这是可检验的 channel-switch forecast；“老政策重演”提供 prior，但不能把概率直接提升到必然。

## 1.3 把谣言看作联盟分裂工具

列出的信息攻击集中在合作、扩张、外部联系和另立政府四个指控。文章把它们解释为挑拨国共关系、服务诱降。

```text
claims about ally disloyalty
-> lower inter-ally trust
-> weaken cooperation
-> increase bargaining/capitulation space
```

这识别了 information operation 的可能效果；每项指控真假和传播路径仍需分别核验。

## 1.4 用媒体内容重合推断协调或动机

国民党中央社/报纸照抄散布与日本反共宣传呼应，被称用意可疑。

```text
message similarity / relay
-> suspected alignment or coordination
```

重合是调查触发器，不足以单独证明共同指挥：可能有共同信息源、独立利益、引用链或事实争议。

## 1.5 以己方行动记录回应忠诚指控

文章列举新四军被定为叛变、八路军无饷弹仍作战、晋南战役主动配合和华北多线出击，以反驳“不合作”。

```text
accusation
-> retrieve observable behavior
-> publish counterevidence
```

这是比动机宣称更强的反驳形式；但战果、时序、协同效果仍主要来自本方报告，后期注释不能回填为当时独立证据。

## 1.6 把所有污蔑归于同一终极目的

文中说一切对共产党的污蔑都为了使抗战失败、便利投降。

这是动员性统一解释。它可能识别真实 incentive，也会消除批评中包含事实、误解、派系竞争或其他目标的可能性。

## 1.7 只给出沟通目标，没有交付架构

每条都以“揭穿、反对”收束，最后要求发扬战绩；没有写明受众、证据包、负责人、渠道、频率、纠错和效果指标。

```text
message objective
without delivery specification
-> execution and validation gap
```

V2-029/030 已说明传播接口属于行动模型；这里仍停留在任务口号层。

# Pass 3 — Reasoning reconstruction

主要推理操作：

1. **historical-analogy compression**：用慕尼黑映射秘密交易风险；
2. **channel-switch forecast**：从军事进攻预测政治诱降；
3. **information-operation model**：将忠诚指控连接到联盟分裂；
4. **message-similarity suspicion**：由内容呼应触发协调调查；
5. **behavioral rebuttal**：用可观察行动反驳身份/动机指控；
6. **single-purpose attribution**：把全部污蔑统一到投降目标；
7. **counter-messaging directive**：要求揭穿、反对并传播战绩。

# Pass 4 — Adversarial reading

## 4.1 “慕尼黑”类比可能把风险情景伪装成已证事实

谈判存在不等于达成牺牲中国的协议，更不等于日、美、蒋三方共同反苏反共。每条因果边必须单列证据和置信度。

## 4.2 与 V2-040 的 contingency/base-case 区分发生张力

六天前要求不要把最坏准备当唯一未来，本文却以“正在酝酿”“必然”表述高风险路径，未保留竞争分支。

## 4.3 历史惯例只提供 prior

敌人过去使用打一拉，能提高本次诱降假设先验；当前能力、目标、谈判对象和国际约束仍可能变化。

## 4.4 媒体呼应不等于秘密协调

文本复制可建立传播图，不能只从相似性推断指挥关系。需时间戳、原始来源、编辑链、通信或共同任务证据。

## 4.5 “谣言”也要逐项 fact-check

把不利主张先归为敌方操作会免除事实核验。应分别标记 false、misleading、unverified、mixed，保留能改善己方行为的真实部分。

## 4.6 己方战绩证据可能有选择性

局部出击能反驳“完全不配合”，不能自动证明所有协同争议均为虚假，也不能验证“中流砥柱”的相对贡献判断。

## 4.7 单一目的模型不可证伪

若任何批评都定义为促成失败/投降，批评者行为无法再更新模型。需区分内容真实性、传播者意图、网络协调和实际效果。

## 4.8 反宣传也需要错误更正通道

传播己方战绩若缺独立核验、版本和撤回规则，会复制所批评的信息操纵。

# Pass 5 — Article-local candidate mechanisms

## H1-3-03-01 — Decompose threat analogies into auditable causal links

历史标签只能生成情景；把 actor、交易、受害方、行动序列和结果逐边验证，任何断边都必须降低整体置信。

- Textual confidence: high that article uses a compressed analogy
- Empirical confidence: high for the corrective rule

## H1-3-03-02 — Model adversary channel switching without assuming necessity

一个行动渠道成本上升后，对手可能转向谈判、诱导、信息或代理行动；把它列为竞争分支并设置可观察信号。

- Textual confidence: high
- Empirical confidence: medium-high

## H1-3-03-03 — Use provenance graphs before inferring information coordination

内容相似先触发 source/provenance tracing；共同指挥需传播时序、通信、任务和资源等附加证据。

- Textual confidence: high for similarity suspicion, low for provenance control
- Empirical confidence: high

## H1-3-03-04 — Rebut identity claims with behavior while keeping scope narrow

用时间戳、任务、投入和结果反驳全称指控；局部反例只推翻相应全称，不自动认证所有行为。

- Textual confidence: high
- Empirical confidence: high

## H1-3-03-05 — Separate claim truth, sender intent, coordination and effect

信息审计至少有四轴：内容是否真实、发送者想做什么、是否协同行动、实际造成什么；不能用一轴替代其余三轴。

- Textual confidence: high that source collapses these axes
- Empirical confidence: high
