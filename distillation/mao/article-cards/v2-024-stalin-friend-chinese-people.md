# Pass 0 — Historical frame

中国抗战需要空军、物资、信贷和国际支持；苏联此前提供了实际军事援助，英美法政府当时仍未直接参加对日战争。文章在这一时点把外部参与者分成“口称同情的帝国主义者”和“真正援助的苏联/斯大林”。

它的任务主要是政治动员和盟友合法化，不是平衡的外交比较报告。

# Pass 1 — Source / argument reconstruction

## 1.1 先把人物支持与完整事业绑定

庆祝斯大林被定义为同时拥护：

- 斯大林本人；
- 其事业；
- 社会主义胜利；
- 他指示的全人类方向；
- 苏联对中国的友谊。

```text
support person
= support system
= support historical direction
= support own ally
```

这些命题被捆绑，读者不能只认可某项援助而保留对人物、制度或历史方向的独立判断。

## 1.2 用可观察行为区分朋友

正文提供三组比较：

1. 苏联废除在华特权；
2. 第一次大革命时期苏联援助；
3. 抗战中苏联提供空军和物资援助。

这是比口头同情更强的行为证据：

```text
declared sympathy
< costly concession / material aid / operational support
```

## 1.3 从有限时期的差异升级为阵营全称命题

文章由“截至 1939 年苏联提供了重要援助”跳到：

> 只有社会主义国家、领袖、人民和思想家等才能真正援助中国解放。

并进一步说没有这种援助，中国事业不能取得最后胜利。

```text
observed past support from actor A
-> only class A can truly support
-> class A support is necessary for final success
```

第一跳排除了未来变化和其它国家的真实行动；第二跳是难识别的反事实必要性判断。

## 1.4 友谊被归于领袖，而证据多是国家行为

废除特权、提供飞机与物资是国家/组织行为；正文将其统一归为斯大林个人忠诚友谊。

```text
state outcome
-> leader attribution
```

没有拆分官僚机构、军队、苏联人民、国家安全利益与领袖个人决定的贡献。

# Pass 3 — Reasoning reconstruction

主要推理操作：

1. **behavior-over-rhetoric test**：用有成本行动而非自我声明评价伙伴；
2. **comparative ally classification**：比较不同来源的实际贡献；
3. **bundle construction**：把人物、制度、方向和盟友关系绑定；
4. **sample-to-universal jump**：从截至当时的支持记录推阵营全称；
5. **counterfactual necessity claim**：把社会主义援助判为胜利不可缺；
6. **leader attribution**：把国家行为归于单一领袖。

# Pass 4 — Adversarial reading

## 4.1 “真正援助”可能成为不可证伪定义

若非社会主义国家提供物资、军队、信贷和运输仍可被定义为“不真正”，命题就不再由援助结果检验，而由政治标签预先决定。

## 4.2 截至当时的领先支持不能证明未来垄断

时间切片适合说明谁已经履约，不足以说明其它 actor 永远不能改变政策。1941 年后美国援华即构成明确反例。

## 4.3 援助行为不证明全部利益一致

伙伴可以在抗日目标上提供高价值援助，同时在领土、安全、盟友选择和战后秩序上与中国利益冲突。V2-019/PRED-012 已有反证。

## 4.4 国家成果归于领袖制造单点神化

这会隐藏组织过程、集体行动和制度约束，也会让对一项政策的支持扩张成对领导人的全面服从。

## 4.5 “无此援助不能胜利”难由观察历史识别

实际历史只有一条路径；援助有贡献不等于其为不可替代必要条件。需要替代来源、边际作用和无援助反事实模型。

## 4.6 友敌二分删除了条件性伙伴类别

V2-019 自己曾保留“部分、暂时援助”；本文的纪念文体把它压成口蜜腹剑/真正朋友两类，降低了此前更细的可靠度模型。

# Pass 5 — Article-local candidate mechanisms

## H1-24-01 — Evaluate support through costly observable behavior

声明、同情和身份标签的权重应低于可核验的让利、资源、风险承担和持续履约。

- Textual confidence: high
- Empirical confidence: high
- Boundary: 行为必须按时间、对象、条件和副作用分别评分。

## H1-24-02 — Support evidence should not be bundled into total actor endorsement

某项援助只更新该行为与相关可靠度，不自动证明领导人、制度、全部利益和历史方向均正确。

- Textual confidence: high that the article bundles them
- Empirical confidence: high as a corrective rule

## H1-24-03 — Ally categories must remain open to new entrants and defections

伙伴分类需要可观察升级/降级规则；当前未援助者可能后来援助，当前盟友也可能因其它利益改变行为。

- Textual confidence: high that the article closes the category
- Empirical confidence: high from later counterexamples
