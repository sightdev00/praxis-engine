# Pass 0 — Historical frame

西安事变和平解决后，国共关系由直接武装对抗向可能合作过渡，日本全面侵华风险继续上升。本文面对的不是“是否统一战线”这一抽象问题，而是：

```text
旧阶段的中心任务已部分完成
-> 新阶段当前最关键任务是什么？
-> 哪些旧政策必须调整？
-> 调整到什么程度才不会破坏长期目标与独立能力？
```

# Pass 1 — Source / argument reconstruction

## 1.1 “主要矛盾”被用作政治权重而非存在/不存在开关

正文写：中日矛盾成为主要矛盾，国内矛盾降为次要和服从地位。

但随即明确：

```text
国内阶级矛盾和政治集团矛盾
仍然存在
并没有减少或消失
```

因此本文中的 principal/secondary relation 更接近：

```text
relative decision weight in current stage
```

而非：

```text
principal exists / all others irrelevant
```

## 1.2 外部主矛盾变化会重排国内和国际关系

日本侵略改变：

- 其它帝国主义国家与中国/日本的关系；
- 中国资产阶级、军阀的政治态度；
- 群众与共产党的政策；
- 国内军阀内战结构。

所以“主要矛盾”不是一句优先级口号，而是解释多个 actor relation 重新配置的上层变量。

## 1.3 阶段不是按日期分，而由任务是否获得必要条件决定

文章把 1935-12 到 1937-02 定义为第一阶段，核心任务是争取和平；认为这项任务基本实现，构成统一战线的第一个必要条件。

随后第二阶段中心转为争取民主，因为民主被视为进一步巩固和平和动员抗战的必要条件。

结构：

```text
Stage A objective
-> objective reaches sufficient state
-> unlocks Stage B objective
```

这比简单“时间过去了所以进入新阶段”更接近 gate-based stage transition。

## 1.4 政策变化被记录为连续步骤，而非一次翻转

文章列出从 1935 到 1937 的多次政策调整：

- 宣言；
- 停止“反蒋”口号；
- 致国民党书；
- 民主共和国决议；
- 西安事变和平解决；
- 对国民党三中全会电。

这说明 actor/coalition policy 是逐步更新的。

## 1.5 让步被定义为“有原则有条件”，并显式规定边界

共产党提出：

- 政权/军队名称和关系调整；
- 停止武力推翻国民党；
- 停止没收地主土地等。

但同时规定：

- 保持自身组织领导；
- 保持独立性和批评自由。

因此 negotiation/concession 结构是：

```text
shared higher-priority objective
-> exchange concessions
-> preserve non-negotiable core boundaries
```

## 1.6 某些国内冲突不是“消灭”，而是调整其表达方式

正文区分：

```text
停止不利于当前团结抗日的冲突形式
vs
保留有利于团结抗日的批评、独立和利益改善
```

即冲突管理不是简单 suppress all disagreement。

## 1.7 环境变化要求工作方式/组织方式重学

和平合作成立后，旧的：

- 武装方式；
- 非法方式；

要转为：

- 和平方式；
- 合法方式。

正文明确说这种转变不容易，干部“重新学习、重新训练”成为主要一环。

说明能力迁移不是自动发生：目标改变后，旧成功技能甚至可能失配。

## 1.8 领导被拆成若干条件，而非只由身份宣称

文章自己给出的领导条件包括：

- 提出适合历史阶段的具体政治目标；
- 在行动中承担/示范；
- 保持与同盟者适当关系；
- 自身组织发展、思想统一、纪律。

即使这些结论服务于特定政治领导主张，至少文本把“领导”部分操作化了。

# Pass 4 — Adversarial reading

## A1 — “主要矛盾”识别仍是理论判断

它具有强解释力，但也可能把其它重大问题过度降权。可靠应用必须问：

- 哪些损失因降权而被忽视？
- 次要矛盾是否存在不可越过的硬约束？
- 多个高优先风险是否能被一个中心矛盾代表？

## A2 — 阶段划分有后见性

1937 年回看 1935-37 事件容易构造清晰阶段；实时判断时边界远没有这么整齐。

## A3 — “无产阶级/共产党领导必然必要”的论证具有政治自我授权成分

历史失败与成功不能单独证明某组织领导是唯一充分必要条件。

## A4 — “有原则的让步”边界由自身定义，仍可能与伙伴认知冲突

联盟必须有双方可理解和可执行的协议，而非单方内部定义。

## A5 — 为中心目标调整国内矛盾可能压制正当利益

正文保留批评和利益改善作为边界，这恰恰说明不能以中心目标为名取消所有内部权利。

## First-pass takeaway

V1-015 提供了一个比“抓主要矛盾”更精确的决策结构：

```text
识别当前最改变系统关系的矛盾
-> 提高其决策权重
-> 同时保留其它仍存在矛盾和硬边界
-> 判断当前阶段所缺的关键条件
-> 完成后切换下一阶段中心任务
-> 通过一系列条件化政策调整推动 actor map
-> 让步时明确不可丢失的能力/权利边界
-> 环境改变时重新训练旧工作方式
```

这使我们更有理由拒绝把“主要矛盾”翻译成粗糙的 `find one bottleneck and ignore the rest`。
