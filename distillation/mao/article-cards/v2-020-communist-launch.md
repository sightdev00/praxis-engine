# Pass 0 — Historical frame

1939年党已从较小区域性组织扩大为全国性大党，同时统一战线、抗战和内部组织复杂度显著上升。本文一方面解释为什么需要一个专门党内刊物，另一方面尝试用十八年历史压缩出建设党的“基本问题”。

因此它同时包含：

```text
A. scale transition -> new internal infrastructure
B. retrospective history -> compact strategic doctrine
```

后者尤其需要防止胜利者叙事和选择性压缩。

# Pass 1 — Source / argument reconstruction

## 1.1 系统规模和环境变化产生新的内部信息基础设施需求

文章说党内刊物早有计划，但“当前时机”使其必要性更强：

- 党已成为全国性大党；
- 新党员和新组织大量出现；
- 外部有投降、分裂、倒退及突然事变风险；
- 旧组织也需要提高水平。

于是：

```text
scale + environmental complexity + quality variance
-> specialized internal knowledge/control channel
```

这比“办刊物宣传思想”更接近其实际架构意义。

## 1.2 数量扩张和组织成熟被明确区分

正文直接说：大批新党员形成了许多新组织，但这些组织还不能因此被认为已经群众化、巩固、成熟。

```text
membership growth
!=
organizational maturity
```

这与 V1-004 的压力下党员组织崩溃案例形成很强跨时支持。

## 1.3 外部任务结构应反向决定内部建设重点

统一战线、武装斗争和全国性扩张不是“业务在外、党建在内”两个独立问题；文章认为内部建设必须围绕组织实际面对的外部关系和主要斗争形式发展。

其结构是：

```text
external task topology
<->
internal organization/capability design
```

而不是先设计理想组织，再把任务塞进去。

## 1.4 十八年历史被压缩成三个“基本问题/法宝”

文章把：

1. 统一战线；
2. 武装斗争；
3. 党的建设

定义为三个基本问题，并说正确理解其相互关系“等于正确领导全部中国革命”。

这是一个非常强的 dimensionality reduction：把复杂历史压成三个变量及其关系。

它可以是高价值模型，也可能是过拟合后的胜利者摘要。不能因为文章说“十八年证明了”就把它直接升级成 G3。

## 1.5 三个问题不是平行清单，而是互相反馈

正文明确写：

```text
how party handles united front / armed struggle
-> affects party development and consolidation

party becomes more capable
-> can handle united front / armed struggle better
```

也就是说组织能力既是结果，也是下一轮行动的条件。

这是一个 feedback structure。

## 1.6 统一战线的内容随阶段和 actor relationship 改变

文章将统一战线分成三个历史阶段，并总结资产阶级的双重性：在特定条件下可合作，同时又可能限制、分裂或转向。

这继续支持：

```text
actor role = conditional
coalition policy = stage-dependent
```

## 1.7 外部关系可能成为内部组织的训练环境

文章认为共产党是在“联合又斗争”以及武装斗争中发展和锻炼出来的。

中性表达是：

> 组织能力不是只靠内部培训生成；真实高压外部关系会暴露并塑造内部能力。

这需要和 V1-013 的“从战争学习战争”一起继续验证。

# Pass 4 — Adversarial reading

## 4.1 “三大法宝”可能是强 retrospective compression

十八年历史包含经济、财政、土地、干部、国际环境、制度合法性、群众组织等许多变量。把结果压到三个基本问题，可能是高效抽象，也可能遗漏关键变量。

检验方式不应是再找文章重复“三大法宝”，而应检查：

- 是否能解释失败案例；
- 有没有重要失败无法由这三个维度解释；
- 三者是否只是高层容器，任何变量都能被事后塞进去。

## 4.2 历史成败与“路线正确”存在循环解释风险

文中多处结构近似：

```text
correct handling -> success
failure -> incorrect handling
```

若“正确”最终由成功定义，这个模型不可证伪。

## 4.3 专门内部刊物是否真的解决规模质量问题尚未证明

“需要一个信息基础设施”合理，但该媒介是否有效、覆盖谁、如何形成反馈闭环，本文只是设计意图。

## 4.4 高压实践既能训练组织，也能选择性淘汰并强化错误

“在斗争中锻炼”不保证学到正确规律；没有独立复盘/反证，高压经验也可能固化错误经验。

# Pass 5 — Article-local candidate mechanisms

## H1-20-01 — Scale transition creates new knowledge/control infrastructure requirements

小规模系统可依赖非正式沟通；规模、异质性和环境风险增加后，通常需要专门的信息、培训、反馈和规范载体。

- Textual confidence: high
- Empirical confidence: high as an organizational hypothesis

## H1-20-02 — Growth and maturity are independent state dimensions

```text
size ↑
does not imply
quality / cohesion / resilience / shared model ↑
```

- Textual confidence: high
- Empirical confidence: high

## H1-20-03 — Internal architecture should be coupled to external task topology

内部组织建设应由真正反复面对的外部任务、接口和失败模式塑造，而不是脱离任务单独优化。

- Textual confidence: high
- Empirical confidence: medium-high

## H1-20-04 — Historical compression needs residual analysis

把多年经验压成几个“核心变量”后，必须主动寻找：

```text
unexplained successes/failures
omitted variables
cases the model can only explain retrospectively
```

- Textual confidence: n/a (adversarial meta inference)
- Empirical confidence: high as research discipline

## H1-20-05 — Operational capability and organizational learning can form a feedback loop

实际任务暴露内部缺陷，组织修正后又提高下一轮任务能力。

- Textual confidence: high
- Empirical confidence: medium-high
- Boundary: requires explicit correction mechanism; experience alone does not guarantee learning.
