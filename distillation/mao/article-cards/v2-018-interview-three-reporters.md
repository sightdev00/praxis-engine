# Pass 0 — Historical frame

距离 V2-017 仅半个月。本文最重要的价值不是提出全新战略，而是**澄清前一判断的边界**：什么叫“相持阶段到来”，什么并没有因此结束，准备反攻与立即反攻有什么区别。

它是研究“如何防止战略概念被过度解释”的好样本。

# Pass 1 — Source / argument reconstruction

## 1.1 阶段判断被明确写成“有条件地到来”

文章不说相持阶段绝对、全面、同步到来，而强调其成立依赖国际环境、日本困难、中国不妥协等条件。

这是一种带 assumptions 的状态判断。

## 1.2 全局阶段变化不取消局部相反动作

即使大规模战略进攻/退却基本停止，仍可能发生：

- 敌方较大战役进攻；
- 我方战役反攻；
- 局部退却。

因此：

```text
strategic state
!=
every local event has same direction
```

这对复杂系统阶段识别非常重要。

## 1.3 “准备反攻”与“立即反攻”被严格区分

文章把准备反攻拆成：

- 敌后游击；
- 正面防御；
- 后方政治改革；
- 军事力量准备。

所以阶段目标不是一句口号，而是若干能力-building workstreams。

## 1.4 一个旧制度模型可以由其提出者自己因情势修改

关于“军政—训政—宪政”三阶段，文章调用孙中山后来的《北上宣言》，说明其本人已因现实变化修改原先的固定次序。

这里的可迁移结构是：

```text
founder / canonical plan
!=
permanent constraint
if environment changes and source itself revised it
```

权威来源也有时态。

## 1.5 自力更生并不等于只强调内部意志，而被连接到制度能力

文章把“民主政治”视为提高政治抵抗力和自力更生能力的条件。

无论是否接受其具体制度结论，结构上是：

> 自主能力需要相应的信息、参与和组织制度支撑，而不是只靠“下决心”。

## 1.6 对联盟摩擦提出“严格自卫”边界

文章反对主动消耗友方力量，同时允许在遭受攻击时回应，并明确要求不得超过自卫原则。

现代迁移不能复制政治/军事动作，但它展示一种 bounded response：

```text
no unprovoked escalation
if boundary violated -> respond
response <= defined defensive purpose
```

## 1.7 长期合作需要政治保证，而不只是双方说愿意合作

文章指出“团结和分裂两种可能性都有”，长期合作能否持续取决于制度/政治条件和双方行为。

所以 alliance stability 被视为条件性结果，而不是承诺后的常量。

# Pass 4 — Adversarial reading

## 4.1 “有条件地到来”可能降低阶段判断的可证伪性

如果任何反例都能被解释成“只是局部战役”，阶段模型就会变得过度弹性。因此必须记录可观察的战略层指标。

## 4.2 民主政治 -> 自力更生/抗战能力的因果链需要独立比较

本文给出理论和华北案例，但没有系统排除其它变量。

## 4.3 “凡是敌人反对的我们拥护”是一条危险启发式

正文在特定联盟语境中使用这一政治逻辑，但作为一般决策规则它明显无效：敌人的偏好不能替代独立目标函数和事实判断。

## 4.4 自卫原则仍需要事实判定者和升级边界

“谁先犯谁”“什么算过界”在对抗环境中本身可能争议巨大。若没有证据和仲裁机制，双方都可自称自卫。

# Pass 5 — Article-local candidate mechanisms

## H1-18-01 — Stage judgments should carry explicit conditions and scale

记录阶段时同时写：

```text
scope
trigger conditions
what changed
what has not changed
exit/transition conditions
```

- Textual confidence: high
- Empirical confidence: high as an analytical discipline

## H1-18-02 — Preparation state is distinct from execution state

“正在为 X 建能力”不等于“已经具备执行 X 的条件”。

- Textual confidence: high
- Empirical confidence: high

## H1-18-03 — Canonical plans and authority sources are time-indexed

原制定者自己都可能因情势改变计划，因此引用权威时必须检查版本、时间和当前条件，而不是把旧方案永久冻结。

- Textual confidence: high
- Empirical confidence: high as a source-control principle

## H1-18-04 — Defensive response needs an explicit escalation boundary

- Textual confidence: high
- Empirical confidence: medium-high
- Modern safety boundary: must add evidence, authorization and proportionality controls.
