# Pass 0 — Historical frame

文章需要澄清前文在快速变化的国际/国内环境中可能引起的误读：相持阶段是否真的到来、准备反攻是否等于立即反攻、统一战线摩擦是否会导致国共分裂。

同时，国民党《限制异党活动办法》已引起多地摩擦；中共在 7—8 月间向蒋介石和国民政府提出抗议但未获答复。因采访者来自国民党及中间报纸，正文既说明冲突证据，也继续公开主张合作和申诉。

# Pass 1 — Source / argument reconstruction

## 1.1 相持阶段被重新写成有条件、分层级的状态

文章首先说相持阶段“有条件地到来”，并明确排除三种误读：

- 不等于敌人所有进攻停止；
- 不等于中国所有退却停止；
- 不等于战略大反攻立即开始。

```text
strategic large-scale pattern basically changes
while
campaign-level advances, retreats and counterattacks continue
```

阶段标签描述主导关系，不是抹去所有反向局部事件。

## 1.2 “准备反攻”被定义为能力建设集合

正文按空间和任务拆分：

- 敌后：坚持游击、反扫荡、破坏经济侵略；
- 正面：巩固防御、打退战役进攻；
- 大后方：主要改革政治。

因此：

```text
future strategic action
<- multiple region-specific capability programs now
```

不是等待时机自动成熟。

## 1.3 响应类型与对方主要进攻类型匹配

文章判断敌人当前主要转向政治进攻，所以大后方需要加强政治抵抗；民主政治又被定义为自力更生的主要内容。

```text
dominant threat mode
-> corresponding resistance capability
```

但把民主政治设为自力更生“主要内容”是强优先级判断，经济、工业、军事和财政能力并未因此消失。

## 1.4 既有阶段方案可以由其提出者自己根据情势修改

面对“军政—训政—宪政”三阶段论，文章不把孙中山早期说法当永久权威，而引用其晚年立即召开国民会议的主张，说明原提出者也会按情势改变方案。

```text
authoritative prior plan
+ later environment
+ author's later action/text
-> update implementation sequence
```

## 1.5 “人民无知识不能民主”用局部实践反驳

文章以华北已有民选区、乡、保甲和部分县长，以及青年当选为例，反驳人民不具备民主能力。

这提供了可观察反例，但证明“可以选举”不等于已经证明治理质量、代表性或长期稳定。

## 1.6 先使用名义治理接口并记录其响应

文章说中共已由周恩来致信蒋介石，延安各界又电告蒋介石和国民政府，要求取消相关办法；政府没有答复。

```text
formal complaint
-> documented channel
-> no response
-> interface failure becomes evidence
```

这与 V2-016 原刊的申诉路径一致。

## 1.7 党派关系按当前共同目标而非固有名称分类

共同抗日的党派被称为友党；汪精卫组织因与抗日目标无共同点被称为异党。分类依据从组织名称转向当前目标关系。

但正文又把它压缩成“敌人反对的就拥护、敌人拥护的就反对”，从 relational evidence 滑向简单反向真值规则。

## 1.8 自卫边界把避免摩擦和回应侵犯同时保留

文章反对抗日党派之间相互抵消力量，却说在受压迫时必须严正回应，并明确“不许超过自卫原则”。

```text
default: avoid internal capability destruction
trigger: material infringement
response: self-defense
cap: do not exceed self-defense
```

触发和比例如何判定仍未操作化。

## 1.9 联盟分裂被表示为条件性双路径

对国共会不会分裂，文章不说绝无可能，而承认团结、分裂两种路径都存在，取决于两党尤其全国人民的态度；长期合作需要政治保证，即坚持抗战和实行民主。

这比道德必然论更接近：

```text
coalition outcome
<- participant behavior
+ institutional guarantees
+ wider constituency pressure
```

# Pass 3 — Reasoning reconstruction

主要推理操作：

1. **scope/stage qualification**：为阶段标签补上条件、尺度和残余事件；
2. **goal-to-capability decomposition**：把未来反攻分解成当前各区域能力任务；
3. **threat/response matching**：按主要攻击形态选择抵抗能力；
4. **authority self-revision audit**：用提出者后期变化限制早期权威规则；
5. **counterexample use**：以华北实践攻击“人民不能民主”的全称判断；
6. **interface-response tracking**：记录申诉、渠道、等待和未答复；
7. **relational classification**：按当前共同目标定义友/异；
8. **bounded defensive response**：设定回应触发和不超过自卫的上限；
9. **conditional coalition branching**：保留团结/分裂竞争路径及影响变量。

# Pass 4 — Adversarial reading

## 4.1 “有条件到来”仍缺可测阶段指标

限定语减少了全称误读，但何种正面攻势规模、领土变化、兵力分配和持续时间足以说明战略退却“基本停止”，仍未操作化。

## 4.2 政治民主可能重要，但未证明是自力更生的主要内容

作者用敌人政治进攻推出政治抵抗优先，逻辑上可理解；但自力更生还依赖工业、财政、后勤、军事训练和社会组织，本文未比较其相对约束。

## 4.3 华北选举案例只能推翻“不可能”，不能证明全面成功

局部存在民选实践是对全称否定的反例，但不能单独估计代表性、治理绩效、胁迫、参与率或全国迁移成本。

## 4.4 “敌人反对什么就拥护什么”是无效的一般真值规则

对手可能：

- 反对本来就有害的东西；
- 支持对双方都有利的东西；
- 故意表达相反偏好操纵响应；
- 内部存在多个冲突目标。

敌人态度是 actor evidence，不是命题真假的替代品。

## 4.5 自卫原则仍需独立事实认定

双方都可能把自己的先发动作称作自卫。没有共享证据、时间序列、比例和第三方仲裁，自卫边界可能无法约束升级。

## 4.6 正文继续把蒋介石当申诉和合作接口，后期注释却强化其责任

这延续 V2-015/016 的时间层冲突。正文提供的命令材料据称已交蒋，但未公开；后期注释不能替代当时的证据链。

# Pass 5 — Article-local candidate mechanisms

## H1-18-01 — Stage labels describe dominant relations, not elimination of counter-events

进入新阶段不等于所有旧阶段事件归零；必须说明尺度、条件、残余事件和哪些动作仍合法。

- Textual confidence: high
- Empirical confidence: high as an analytical-control rule

## H1-18-02 — Future commitments need present capability programs

“准备某行动”只有被分解为当前不同位置、责任主体和能力缺口的工作时，才不是口号或等待。

- Textual confidence: high
- Empirical confidence: medium-high

## H1-18-03 — A counterexample refutes impossibility, not proves general sufficiency

一个成功存在例可以推翻“绝不可能”，但不能自动证明大规模、长期或跨环境都有效。

- Textual confidence: high that the text uses a local counterexample
- Empirical confidence: high as an inference rule

## H1-18-04 — Adversary preference is evidence, not a truth function

对手支持/反对某行动可以更新其意图模型，却不能替代对行动本身的目标、后果和证据审计。

- Textual confidence: high that the article states the inverse heuristic
- Empirical confidence: high that universal use is unsafe

## H1-18-05 — Defensive escalation needs shared incident and proportionality criteria

“不主动侵犯、受侵则回应、不超过自卫”需要把先后顺序、损害、证据和比例标准写清，否则双方都可自称防御。

- Textual confidence: high
- Empirical confidence: medium-high
