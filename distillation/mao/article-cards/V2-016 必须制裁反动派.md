# Pass 0 — Historical frame

1939 年 6 月 12 日，新四军平江通讯处人员被国民党军队杀害。到 8 月 1 日，文章所称的法律和政府机关仍未作出有效追责。

本文面对三个直接问题：

1. 抗战联盟为何在后方杀害自身的抗日人员；
2. 名义上的法律和统一为什么没有阻止或纠正这种结果；
3. 应通过什么公开、法律和政治渠道施压。

原刊把国民政府和蒋介石作为申诉/追责对象；第二版注释则把蒋介石写为密令发出者。这个 actor-model 变化必须保留时间层。

# Pass 1 — Source / argument reconstruction

## 1.1 文章从系统输出反转开始

在抗战目标下，预期被打击的对象应是侵略者和汉奸；实际被杀的却是抗日人员，而且发生在抗战后方。

```text
declared system objective
-> protect/resupply anti-invasion capability
-> constrain enemy/collaborator

observed output
-> anti-invasion personnel killed
-> perpetrators not sanctioned

=> objective/output inversion
```

这使平江惨案被当作系统性失配的诊断事件，而不只是孤立伤亡。

## 1.2 责任追踪先沿命令链上溯，随后发生因果跳跃

文章依次追问：谁杀人、军队为何杀、谁指使军队。这一部分体现从执行者追到命令者的责任链。

但随后直接推断国内反动派接受日本和汪精卫命令、以杀害抗日者准备投降。正文没有提供通信、命令文本或证人来完成这一步识别。

```text
observed executor
-> inferred domestic commander
-> inferred foreign/collaborationist principal
```

前一跳与后一跳的证据强度不同。

## 1.3 制度存在和制度实际响应被分开

文章指出中国名义上有法律和法官，但惨案近两个月无人过问；原刊更明确追问法律是否“死了”、是否在纵容凶犯，并提出抗日者的生命保护权。

```text
formal rule/institution exists
!=
triggered investigation
!=
enforcement
!=
protected outcome
```

## 1.4 “统一”被重新定义为目标和奖惩的一致

文章拒绝把统一理解为单一服从，转而用三个目标定义：

- 统一于抗战；
- 统一于团结；
- 统一于进步。

再用奖惩是否支持这些目标检验统一是否真实存在。

```text
declared unity
-> inspect who is protected/rewarded
-> inspect who is harmed/unpunished
-> infer actual system alignment
```

## 1.5 单个事件被升级为压力测试

平江惨案涉及人数和地点有限，但文章认为如果同类机制不受约束，个案可以重复扩大，最终摧毁抗战能力。它又声称此前已有几十或数百名相关人员被暗杀，以说明并非完全孤立。

这是从：

```text
concrete anomaly
-> repeated-pattern claim
-> unchecked scaling path
-> system-level risk
```

的推理。

## 1.6 公开纪念被转化为制度升级动作

原刊提出开会、写信、发电报、向全国传播、要求国民政府办案；如果法律仍不执行，则全国人民继续要求。

所以纪念活动同时承担：

- 保存事件；
- 扩大可见性；
- 保护未来潜在受害者；
- 迫使名义治理接口响应。

## 1.7 用目标审计政策标签

文章反转《限制/防制异党活动办法》的分类：不按“异党”标签本身，而按谁破坏抗战、团结、进步判断真正应受限制者。

```text
policy label
-> compare with shared objective
-> inspect actual protected and constrained actors
-> detect goal inversion
```

## 1.8 版本链改变了责任和申诉接口

原刊标题和主体论证强调“国法”，并直接要求蒋介石、国民政府执行法律；第二版保留部分法律论证，但删去生命保护权、持续诉诸法律和直接要求蒋介石等内容。第二版注释又以回顾口吻直接说惨案根据蒋介石密令实施。

因此至少存在三个时间层：

```text
1939 public claim: petition government/Chiang for enforcement
later selected text: reduce explicit petition framing
later editorial note: identify Chiang as hidden commander
```

# Pass 3 — Reasoning reconstruction

主要推理操作：

1. **objective/output comparison**：用实际受保护/受打击对象审计宣称目标；
2. **command-chain tracing**：从执行者向指挥者和潜在委托者上溯；
3. **institution/enforcement separation**：区分规则存在与实际触发、执行、保护；
4. **incentive-alignment audit**：用奖惩方向判断统一是否真实；
5. **incident-to-system escalation**：把个案作为可重复机制和系统风险的探针；
6. **public escalation path**：从纪念、传播、申诉到持续政治压力；
7. **policy-label inversion test**：检查政策名义对象与实际作用对象是否相反。

# Pass 4 — Adversarial reading

## 4.1 责任链的最高层归因缺少篇内证据

军队执行命令支持继续上溯，但不能单凭行动后果证明国内指使者直接接受日本/汪精卫命令。

## 4.2 从单个惨案到“中国不统一”可能过度一般化

重大个案可以揭示制度故障，但需区分局部越权、地区性政策、中央命令和全国制度常态。作者用其它暗杀数量补强，却未给来源。

## 4.3 奖惩一致不等于正当程序

文章强调法律和法官，却在政治标签层面预先规定哪些类别应罚。现代迁移必须加入证据标准、独立调查、申辩和比例性，不能把目标一致直接替代 due process。

## 4.4 “进步”由谁定义仍未解决

抗战、团结较容易观察，进步则更强烈依赖政治判断；把三者共用一个奖惩系统可能引入不可审计的价值标签。

## 4.5 后期注释可能把后来 actor model 回填为当时事实

第二版注释指认蒋介石密令，与原刊向蒋介石请求执法存在明显张力。在获得独立命令/档案证据前，只能记录为后期 O7 证据。

## 4.6 公开升级也可能提高冲突和报复风险

扩大事件可见性可迫使机构响应，也可能触发更强压制；文章未讨论受害者保护、证据保全和升级阈值。

# Pass 5 — Article-local candidate mechanisms

## H1-16-01 — Audit declared objectives through actual protection and sanction patterns

制度真正优化什么，往往比口号更清楚地体现在：谁被保护、谁被处罚、谁伤害他人而不受追责。

- Textual confidence: high
- Empirical confidence: medium-high

## H1-16-02 — Formal governance requires an enforcement trace

规则或机构存在不足以证明治理有效；应检查事件是否触发记录、调查、裁决、执行和结果保护。

- Textual confidence: high
- Empirical confidence: high as a governance-audit hypothesis

## H1-16-03 — Command-chain investigation must preserve evidence strength at each hop

从执行动作上溯责任是必要的，但每一层“执行者—命令者—最终委托者”都需要独立证据，不能让合理的第一跳替后续跳跃借用置信度。

- Textual confidence: high that the text traces and then jumps
- Empirical confidence: high as an investigation-control rule

## H1-16-04 — A severe anomaly can be a system probe, not automatic system proof

重大个案足以触发系统审计；只有识别重复机制、控制范围和其它样本后，才能把它升级为全国/全系统结论。

- Textual confidence: high
- Empirical confidence: high

## H1-16-05 — Escalation paths need protection and evidence gates

当名义接口长期不响应时，可以逐级提高可见性和外部压力，但应同时保护受影响者、保全证据并评估不可逆冲突成本。

- Textual confidence: high for escalation path
- Empirical confidence: medium-high with added modern safety boundary
