# Pass 0 — Historical frame

本文不是一般政策论文，而是一份跨组织的 escalation/negotiation artifact。它一方面承认并调用国民政府与蒋介石的抗战权威，另一方面用十项要求约束其内部治理、军队资源、特务机构和党派政策。

决策问题是：

> 如何在仍承认共同政府/领导接口的条件下，把“继续抗战”从口号转成可观察的政治、军事和社会条件？

# Pass 1 — Source / argument reconstruction

## 1.1 交付对象本身就是论证结构

原始上款列出：国民政府、蒋介石、各院部会、国民党中央、参政会、社会团体、出版社、报社、学校、军队、地方政府和全国民众。

```text
formal authority
+ political organizations
+ public communication network
+ executing units
+ affected public
```

这使文本同时具备 petition、public commitment pressure、coalition signaling 和 distributed mobilization 功能。删除收件人会损失实际执行架构。

## 1.2 原文采用“承认接口 + 施压改革”

原题“讨汪拥蒋”，正文拥护蒋抗战到底、称“我国民政府”，并引用政府/蒋已下令实行三民主义；同时要求开放党禁、停止军事限共、改组特务、惩治腐败和保障自由。

```text
recognize counterpart's current legitimate role
+ hold it to shared commitments
+ demand observable changes
```

选集删除前一层，使后人更容易把文本读成对国民党的单向对抗，而不是 1940 的 conditional support/pressure posture。

## 1.3 十点要求覆盖一条系统性失败链

十项可重组为：

| Failure domain | Demand |
|---|---|
| 外部/内部敌对网络 | 全国讨汪 |
| 联盟结构 | 加紧团结 |
| 政治授权与公开反馈 | 宪政、开放党禁、舆论 |
| 内部暴力 | 制止磨擦、处罚惨案制造者 |
| 人才与思想空间 | 保护青年、取消集中营 |
| 作战资源 | 接济前线、保护军队声誉 |
| 安全机关 mission drift | 取缔/改组特务，转向敌人与汉奸 |
| 资源掠夺与信任 | 取缔贪官污吏 |
| 大众参与 | 实行孙中山遗嘱、唤起民众 |
| 公共纲领履约 | 实行三民主义 |

它不只列症状，而是把联盟失败连接到权利、资源、情报、腐败、参与和承诺履行。

## 1.4 用对方自己的公开承诺建立审计基线

文章反复引用：

- 孙中山遗嘱；
- 三民主义；
- 《抗战建国纲领》；
- 政府和蒋介石已有的公开命令。

```text
counterpart's stated commitment
-> observable implementation gap
-> demand for compliance
```

这是 shared-contract accountability；但谁拥有“真三民主义”的解释权仍有争议。

## 1.5 把抽象统一拆成底层条件

延续 V2-028，统一必须基于团结，团结必须基于进步；具体落实为平等对待地方抗日力量、信任/接济/奖励、停止取消盟友组织。

```text
unity label
-> resource parity
-> organizational survival
-> political inclusion
-> common resistance output
```

## 1.6 把宪政诚意转为前置可观察条件

文章认为在言论不自由、党禁未开放时制宪只是形式；所以把开放党禁、扶植舆论当作诚意信号。

```text
future constitutional promise
requires
present costly enabling action
```

比只评估讲话更强，但还缺选举法、司法、权利救济和执行期限。

## 1.7 把安全机构问题定义为 mission drift

特务机关被批评把能力用于内部政治控制而非敌人/汉奸，方案是取缔并改组，重新确定任务。

```text
security capability
-> diverted toward internal control
-> public fear + coalition damage
-> mission reset
```

仅改 mission statement 可能不足；人员、档案、权限、监督和问责都未规定。

## 1.8 每点都有 owner 方向，但缺验收规格

多项以“宜由政府下令”结束，说明知道需要正式 authority；然而大多使用“彻底取缔”“充分接济”“严禁”“从重治罪”等词，没有：

- 时限；
- 预算/数量；
- 证据标准；
- 执行机构；
- 独立验收；
- 申诉/纠错。

因此是 requirements list，还不是 implementable specification。

# Pass 3 — Reasoning reconstruction

主要推理操作：

1. **recipient-architecture design**：把权力、执行、传播和公众同时纳入交付对象；
2. **recognition-plus-pressure**：承认共同接口并要求其兑现约束；
3. **systemic requirement decomposition**：把危机拆成十个治理/能力域；
4. **shared-contract audit**：以对方公开纲领建立实施差距；
5. **costly-signal test**：以当前开放权利判断未来宪政诚意；
6. **mission-drift diagnosis**：识别安全机构从外部任务转向内部控制；
7. **authority mapping**：多项要求指向政府正式命令；
8. **rhetorical requirement specification**：给出方向但缺指标/程序。

# Pass 4 — Adversarial reading

## 4.1 “暗藏汪精卫”把治理失败重分类为叛国身份

贪腐、反共磨擦、政策错误可以客观帮助敌人，但不自动证明属于汪精卫网络。把所有问题收入隐藏敌人类别会绕过正常治理和证据程序。

## 4.2 保障信仰/思想自由与严厉思想标签并存

第五点说思想不能靠武力压制，文本其它部分又要求惩治不奉行者、取缔所谓汉奸言论/组织。必须明确保护的是何种表达、何种行为越界、谁裁决。

## 4.3 调用共同纲领可能发生解释垄断

以对方承诺审计很有力，但三民主义、统一和进步的含义由各方争夺；需把抽象词转成双方可观测指标，而不是宣布己方为唯一真释。

## 4.4 “政府下令”可能复制命令主义

许多问题本就来自政府/秘密机关；让同一权力体系下令自我纠正而无外部监督、举报保护和利益调整，执行可信度不足。

## 4.5 改组特务机关不等于消除滥权

mission reset 若不伴随权限最小化、记录、司法审查、人员责任和受害者救济，旧能力可换名继续。

## 4.6 反腐要求缺制度机制

“彻底取缔”不说明资产申报、采购审计、预算公开、独立调查、定罪标准与追赃，容易变为选择性政治打击。

## 4.7 资源要求缺分配基线

“充分接济前线有功军队”需要共同定义贡献、需求、边际作战效果和其它战区机会成本，否则本方自报贡献会控制资源分配。

## 4.8 重罚与奖励没有 due process

第九、十点以背叛孙中山/违反三民主义从重处罚，政治纲领解释被直接连接刑罚，高后果 actuator 缺法定性、证据和上诉。

## 4.9 原始合法性姿态被定本删除

删除拥蒋、上款、下款和“我国政府”，使 later selected persona 看起来从未采取 tactical recognition。版本变化不是润色，直接改变 actor/interface model。

# Pass 5 — Article-local candidate mechanisms

## H1-29-01 — Delivery metadata is part of the action model

收件人、署名、标题、公开范围和渠道决定文本能触发哪些责任、联盟信号和执行路径；source audit 不能只比较正文。

- Textual confidence: high via variant
- Empirical confidence: high

## H1-29-02 — Use shared commitments as observable accountability contracts

引用对方已承诺的目标可降低价值争论，但需把抽象承诺转成共同指标、时限和可独立审计的行为。

- Textual confidence: high
- Empirical confidence: high with specification boundary

## H1-29-03 — Reform packages should cover coupled failure domains

联盟危机可能同时由权利、暴力、资源、安全机关、腐败、人才和参与构成；单点修复会被其它通道抵消。

- Textual confidence: high
- Empirical confidence: medium-high

## H1-29-04 — Requirements need owner, metric, deadline, evidence and appeal

方向性十点若要进入 actuator，至少需：责任人、量化/行为标准、截止时间、证据来源、独立验收和纠错渠道。

- Textual confidence: high that the source lacks most fields
- Empirical confidence: high as an execution principle

## H1-29-05 — Recognition and pressure can coexist in coalition governance

承认伙伴的当前接口不等于无条件信任；可以在共同目标下要求其履约，同时保留退出/防御边界。

- Textual confidence: high in original version
- Empirical confidence: medium-high
