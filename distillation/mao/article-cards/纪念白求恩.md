# Pass 0 — Historical frame

本文不是对白求恩全部生平、医疗绩效或死亡事件的完整调查，而是从一个已被高度评价的个案中选取行为，建立组织角色榜样。

它回答三个不同问题：

1. 为谁工作：跨国协作与目标范围；
2. 怎样工作：责任、热忱和承担；
3. 能否把工作做好：专业技术和持续精进。

选集定本较早期版本删除/缓和了羞辱性语言、绝对技能排名和作者个人歉疚，值得单独看作 moral framing 的版本变化。

# Pass 1 — Source / argument reconstruction

## 1.1 从跨国行动推国际主义

正文以白求恩离开加拿大、赴中国前线、把中国解放事业视为自己的事业，推断其行为体现国际主义。

```text
distant actor
+ no direct national membership
+ accepts high cost/risk
+ serves another population's objective
-> cross-boundary commitment
```

这一推断至少基于有成本行动，不只基于自我声明。

## 1.2 把抽象价值拆成工作行为

“毫不利己专门利人”随后被操作化为：

- 对工作高度负责；
- 对同事和受助者热忱；
- 不逃避重担；
- 不用少量贡献进行自我宣传。

```text
value label
-> responsibility
-> burden choice
-> interpersonal behavior
-> credit-seeking behavior
```

这比只重复道德词更可观察，但“毫无利己动机”仍是无法由外部行为完全识别的内心全称。

## 1.3 用多来源接触者反应证明榜样影响

文本称前线归来者、受治疗者和亲眼见其工作者都佩服/感动。其结构是：

```text
direct observers across roles
-> convergent reputation
-> exemplar credibility
```

但使用“没有一个”“无不”而没有样本、反向证言或观察记录，证据仍是汇总性声誉报告。

## 1.4 道德承担与专业能力并列

第三段单独强调医术和精益求精，并批评鄙视技术工作、频繁换方向的倾向。

这使榜样不是只有动机：

```text
prosocial orientation
+ responsibility
+ technical competence
+ sustained craft improvement
```

任何一个维度都不能替代其它维度。

## 1.5 从单个榜样生成普遍最低价值判断

末段承认能力有大小，但认为无私方向足以使人成为有益于人民的人。这里把能力差异与价值/方向拆开，有反精英主义意义；但若按字面理解，也可能低估低能力、高权限者造成的伤害。

```text
good intent / orientation
does not require equal talent
but
good intent alone does not ensure safe outcomes
```

## 1.6 早期文本到定本的道德强度被下调

主要变化包括：

- “对着白求恩应该愧死”被删除；
- “医术是最高明的”改为“很高明”；
- 删除“五十多岁干此一门并未想改换”的绝对职业叙述；
- 作者“很歉疚”改为“很悲痛”。

```text
shame / absolute rank / personal guilt
-> example / high competence / grief
```

定本仍强道德化，但减少了部分不可证实和羞辱驱动的表达。

# Pass 3 — Reasoning reconstruction

主要推理操作：

1. **costly-action inference**：由高成本跨边界行动更新动机可信度；
2. **value operationalization**：把抽象精神映射到工作行为；
3. **multi-dimensional exemplar**：把目标、责任、关系和技术并列；
4. **observer-reputation aggregation**：以接触者一致声誉增强可信度；
5. **contrastive teaching**：用反面行为突出榜样字段；
6. **ability/value separation**：承认能力差异而维持最低伦理方向；
7. **editorial intensity calibration**：定本降低羞辱、绝对排名和个人内疚。

# Pass 4 — Adversarial reading

## 4.1 高成本行动提高动机可信度，但不能证明“毫无”自利

声望、身份、理想一致、职业挑战等可能与利他并存；可靠评价无需宣称动机纯度为零。

## 4.2 单一英雄个案存在选择偏差

榜样被选中正因为表现突出。个案能说明某种组合可能存在，不能估计这种培养方式的一般成功率、组织成本或失败副作用。

## 4.3 “所有人都感动”是无反向样本的声誉证据

组织纪念语境会选择正向证言；需要原始信件、医疗记录、同事评价和可能的冲突记录区分事实与圣化。

## 4.4 羞耻驱动可能压制真实能力/负荷信号

早期“应该愧死”等语言可迫使成员表演奉献、隐瞒疲劳或承担不安全负荷。定本删除它是重要缓和，但仍保留纯粹/不纯粹的身份评判。

## 4.5 自我牺牲不能成为系统可靠性的替代品

白求恩死于手术感染。纪念牺牲不应阻止对防护、器械、排班、感染控制和组织支持的审计；否则系统会把可预防风险转写成道德美德。

## 4.6 好动机不能弥补能力或权限失配

“能力有大小”可以保护不同贡献者的尊严，但高后果岗位仍须设置技术门槛、监督和作用范围。

## 4.7 稳定专业投入不等于永不换方向

持续精进有价值；若环境、能力匹配或需求变化，合理转岗也是学习。早期文本将不改换职业当优点，定本删除后边界更稳。

# Pass 5 — Article-local candidate mechanisms

## H1-25-01 — Exemplars are stronger when values map to observable work behavior

抽象价值若能拆成承担、责任、关系行为、技能质量和持续改进，就更可教、可评、可反驳。

- Textual confidence: high
- Empirical confidence: high as a training design principle

## H1-25-02 — Prosocial orientation and technical competence are independent requirements

动机、责任和专业能力应分别验收；不能用善意替代质量，也不能用技术能力免除对受影响者的责任。

- Textual confidence: high
- Empirical confidence: high

## H1-25-03 — Costly action is evidence of commitment, not proof of pure motive

愿意承担距离、风险和机会成本可提高承诺置信度，但仍须保留多重动机和行动效果审计。

- Textual confidence: high
- Empirical confidence: high

## H1-25-04 — Heroic sacrifice should trigger system-safety review

个体牺牲既可表达价值，也可能暴露防护、资源或工作设计缺陷；纪念与事故审计必须并行。

- Textual confidence: low as authorial mechanism; this is an adversarial extension
- Empirical confidence: high as a modern safety principle
