# Pass 0 — Historical frame

五四二十周年纪念讲话。与前一篇相比，本文从历史性质转向更直接的问题：青年运动在当前阶段究竟应该把自身放在什么位置，怎样判断“正确方向”。

# Pass 1 — Source / argument reconstruction

## 1.1 “转变点”被提出，但明确区分“接近转折”与“已经胜利”

文章说革命正在接近从长期失败向胜利转变的节点，同时又明确说转变尚未到来、尚未胜利。

```text
trend judgment
!=
state completion
```

这延续 V2-002 的“进入阶段 != 能力完成”。

## 1.2 历史任务和当前阶段被区分

文章把当前任务限制在反帝反封建的民主革命范围内，并明确说不能因为远期目标存在，就把当前阶段直接当作后续阶段执行。

```text
future target
!=
current admissible program
```

## 1.3 对几十年失败的解释集中到“敌强我弱 + 群众未充分组织”

本文将失败原因简化为：

- 敌方能力强；
- 自身军事、政治、经济、文化能力弱；
- 其中关键是广大工农群众未充分动员组织。

这是一个强 causal compression，需要保留但不能直接当历史定论。

## 1.4 青年先锋角色再次与主力角色严格区分

青年、学生可起带头作用，但文章明确说仅靠这支力量不够，工农大众才是主力。

```text
vanguard = discovery / initiation / propagation role
main force = sustained mass capability
```

这是 V2-013 的直接重复，因此至少形成 related-context P1 强支持。

## 1.5 判定一个人的方向，强调行动关系而非口头信仰

本文极强地反对只看“三民主义/马克思主义”等口头身份，转而看其是否真正和工农群众结合、是否在行为上站在哪一边。

值得抽取的是：

> 判断角色时优先使用持续行为与依赖关系，而不是 self-description。

但原文把“与工农结合”设为唯一标准，这一点现代迁移必须降级。

## 1.6 方向正确被进一步拆成两个方面

延安青年被作为“模范”时，正文实际上给出两个判据：

- 政治方向；
- 工作方法。

这说明“目标正确”仍不能推出“执行方式正确”。

# Pass 4 — Adversarial reading

1. “工农未充分动员是几十年失败的主要原因”过于单因化，可能忽略国家能力、国际结构、军事技术、组织质量等变量。
2. “与工农结合”被设为唯一人格/政治标准，明显超出可一般化范围。
3. 延安青年作为全国模范是内部案例选择，存在 selection bias。
4. “正向胜利转变”的判断必须进入 prediction ledger，不能由后见历史自动验证。

# Pass 5 — Article-local candidate mechanisms

## H1-14-01 — Trend estimate and state completion must be separate fields

看到趋势改善不等于目标已经达到；计划需要分别记录方向判断和当前状态。

- Textual confidence: high
- Empirical confidence: high as a planning discipline

## H1-14-02 — Vanguard and main-force functions should not be conflated

最早发现、最积极发声、最能传播的一群人，可能并不是系统长期执行能力的主要来源。

- Textual confidence: high
- Empirical confidence: medium-high

## H1-14-03 — Behavioral evidence outranks ideological self-description for role assessment

- Textual confidence: high
- Empirical confidence: high as a general audit heuristic
- Boundary: 具体行为指标必须由目标系统重新定义，不能照搬原文单一政治标准。

## H1-14-04 — Correct direction and correct work method are independent validation dimensions

- Textual confidence: medium-high
- Empirical confidence: high as a process distinction
