# Pass 0 — Historical frame

1935 年末，日本侵略由东北进一步向华北扩展；中共经历第五次反“围剿”失败与长征，到达陕北。原有“土地革命时期”的敌友与组织边界面对新的民族危机发生变化。

本文核心问题是：

```text
external threat structure changed
-> have actor interests and alignments changed?
-> should the previous coalition boundary change?
-> how wide can the alliance become without repeating 1927 dependence failure?
```

# Pass 1 — Source / argument reconstruction

## 1.1 从环境变化推导任务变化

文章开头直接规定：

```text
形势发生重大变化
-> 党的任务随之变化
```

新形势被定义为日本从局部占领向吞并全中国推进。

## 1.2 行动者立场不是类别常数

文章逐类重新估计：

- 工人、农民；
- 小资产阶级；
- 民族资产阶级；
- 地主买办阶级内部不同部分；
- 国民党内部不同军事政治力量。

尤其民族资产阶级被明确视为可能因外部威胁改变立场、内部继续分化的群体。

其依据不是“类别名称变了”，而是：

```text
threat changes expected losses
+ previous alliance outcomes
+ economic ties differ within group
-> stance distribution can shift
```

## 1.3 用历史反例攻击“永远固定”的 actor model

文章列举：

- 十九路军从反红军到抗日并与红军妥协；
- 冯玉祥的不同阶段；
- 二十六路军宁都起义；
- 马占山抗日；

用来反驳“整个地主资产阶级营垒任何情况下都固定不变”的判断。

这是明确的 historical counterexample reasoning。

## 1.4 同一个行动者可同时具有合作价值和背叛风险

文章对民族资产阶级不是从“敌人”翻转成“可靠盟友”，而是保留：

```text
可以参加/中立
+
动摇、不彻底、可能欺骗
```

因此策略不是二值分类，而是：

```text
cooperate where interests overlap
while
retain evaluation, leadership and independent capability
```

## 1.5 选择当前主要敌人，避免把资源打在次要对象/潜在盟友上

统一战线论证中最强的资源配置表述是：

```text
identify current central enemy
-> pull movable actors away from that enemy
-> avoid spending force on secondary enemies or possible allies
-> isolate the central opponent
```

其比喻是“择敌”和“浪费弹药”。

## 1.6 当前力量评估必须同时容纳两个看似矛盾的事实

文章明确同时承认：

- 革命力量相比过去增长、环境出现新高潮；
- 当前反革命力量仍暂时大于革命力量、发展仍不平衡。

于是：

```text
trend improving
!=
current balance already favorable
```

这导致两条同时成立的策略约束：

- 不能悲观关门；
- 不能急于决战。

## 1.7 局部失败和总体任务完成需分维度评价

关于长征，文章先承认：

```text
丢失原有根据地 -> 一个方面的失败
```

但又认为：

```text
完成战略转移/摆脱围堵 -> 另一个方面的成功
```

其方法价值是：评价复杂行动不能用单一结果维度吞掉其它目标。

## 1.8 扩大联盟不能替代自身核心能力

文章以 1927 年失败解释：若只依赖暂时盟友、没有扩大自身组织和武装能力，联盟一旦破裂便会失去抵抗能力。

所以新统一战线采取：

```text
broad alliance
+
strong independent core
```

而不是二选一。

## 1.9 长期阶段转换要等条件成熟

从民主革命到社会主义革命的转换，被明确规定不能按日历或愿望提前，而要看政治经济条件是否具备、是否有利于全国多数。

这延续 V1-006 “方向与时间不可机械绑定”的思路，并更明确地引入 condition-gated transition。

# Pass 4 — Adversarial reading

## A1 — 行动者分析使用高度政治化标签

“卖国贼”“走狗”等是政治动员语言，不是中性行为变量。现代迁移只能保留利益/能力/移动条件的结构。

## A2 — 历史案例选择可能具有确认偏误

列举从敌对转向合作的案例，可以反驳“永不变化”，但不能证明当前所有候选对象都有显著转向概率。

## A3 — 对未来“必然分化/必然加入”的语言过强

外部威胁增加合作可能性，不保证具体 actor 一定移动。

## A4 — 长征“成功/失败”的多维评价可能被用来重定义失败

多目标评价是必要的，但必须在行动前明确目标权重，避免事后选择最有利维度。

## A5 — “自身核心能力”与“联盟领导权”可能转化为控制欲

现代合作系统中，独立能力有韧性价值，但不能据此推导一方应支配所有合作伙伴。

## A6 — “当前主要敌人”框架容易过度压缩多风险系统

若多个威胁不可忽略或彼此耦合，单一中心目标可能产生盲区。需先判断风险结构。

## First-pass takeaway

本文的可迁移核心不是某个具体统一战线结论，而是一个动态联盟算法：

```text
外部结构发生变化
-> 重算所有行动者的利益与风险暴露
-> 用历史行为反例攻击固定标签
-> 区分合作价值与可靠性
-> 识别当前最优先对手
-> 通过争取/中立其它力量减少同时对手
-> 同时建设不可外包的核心能力
-> 将当前力量与变化趋势分开
-> 只有条件成熟时才转换更高阶段
```

它进一步验证了 Praxis Engine 的一个原则：**行动者分类必须有时态；没有时态的 stakeholder map 很快会变成错误的历史快照。**
