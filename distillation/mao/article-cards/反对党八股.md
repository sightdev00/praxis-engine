# Pass 0 — Historical frame

本文不是孤立的写作指南，而是组织认识错误如何通过传播接口规模化的分析。

```text
bad problem model / sectarian relation
-> stereotyped representation
-> publication / speech / meeting
-> audience belief and action
-> organization-wide propagation
```

因此文风是 upstream reasoning 与 downstream actuator 之间的界面；修辞改进不能替代事实和模型审计。

# Pass 1 — Source / argument reconstruction

## 1.1 将传播半径连接到错误成本

自写自看影响有限，给第二人、贴墙、油印、登报、出书会逐级扩大影响；所以公开输出必须接受更强审查。

```text
reach increases
-> affected decisions increase
-> error externality increases
-> review duty increases
```

这是全文最可迁移的 risk-scaling 结构。

## 1.2 把表达形式视为上游问题的隐藏层

党八股被说成主观主义和宗派主义的工具/表现形式；仅修内容而不改传播习惯，旧问题仍有藏身处。

```text
upstream epistemic / social failure
-> encoded in output pattern
-> normalized by repeated use
```

但反方向也可能成立：强制统一格式会反过来塑造可想/可说的问题。

## 1.3 以历史反转解释改革如何僵化

五四反旧教条的积极运动后来产生新教条；原本解放性的形式若失去批判和环境连接，会转成其反面。

```text
successful reform
-> copied as fixed form
-> context changes / rationale forgotten
-> new orthodoxy
```

这是 protocol 自身必须防止的 fate：六阶段也可能变成新八股。

## 1.4 第一罪：区分长度与信息密度

文章反对又长又空，但明确不认为所有内容都应短；要按情境、任务和内容选择长度。

```text
quality != brevity
quality ~= necessary content / audience cost / task context
```

这防止“简洁”成为无内容的机械指标。

## 1.5 第二罪：恐吓不能替代可批判证据

装腔恐吓被解释为害怕反驳；对偶然犯错的同志应使用批评与自我批评，不用对敌手段。

```text
weak evidence
-> status/threat display
-> suppress challenge
-> false appearance of victory
```

它保护同伴纠错，却保留“敌人/坏人”例外；分类错误会使残酷手段误作用于普通异议者。

## 1.6 第三罪：传播前必须研究受众

内容、字体、语言和论证若不匹配受众，就等于拒绝让对方理解；问题在发送者，不归咎听众。

```text
audience goals + language + knowledge + context
-> message design
```

这是 delivery-metadata 的 audience-model 层。研究受众应服务清楚沟通，不应成为脆弱性操纵。

## 1.7 第四罪：语言从多来源按适用性吸收

建议向群众、外国语言和古代语言学习活的、有用成分，拒绝硬搬和死语汇。

```text
local living language
+ useful external innovation
+ still-living historical resources
-> task-fit vocabulary
```

这是一种 dimension-wise selective transfer，不是本土/外国二选一。

## 1.8 第五罪：清单结构不能代替因果结构

“开中药铺”指按外部标志列很多分类，却不提出、分析、解决问题。文章给出替代链：初步调查发现问题，周密调查暴露内部联系，分析后综合并提出办法。

```text
surface taxonomy / list
!= problem model

initial inquiry -> problem discovery
detailed inquiry -> relation analysis
analysis -> synthesis -> solution
```

这直接警告本项目：Pass 0–6 若只被填满而没有 argument/causal relation，也会成为研究八股。

## 1.9 第六罪：传播物需要 preflight review

写作/演说会影响他人思想行动，所以发布前要调查、准备、复看和删改；拿不出的不要公开。

```text
draft
-> evidence/task check
-> audience check
-> reread / remove unnecessary material
-> publish or withhold
```

审查强度应按 reach、authority、reversibility 和 action proximity 调整，不能变成无限 polish。

## 1.10 将会议流程也视为可僵化接口

固定“开会—报告—讨论—结论—散会”和不顾需要的长报告，被视为同一种形式主义。

```text
procedure copied independent of task
-> time cost + performative participation
```

流程应由 decision need、information state 和 participant role 选择，而不是以存在流程自证严谨。

## 1.11 反对口号总化，要求先做最小实例

提倡民族化/科学化/大众化的人若连少许都做不到，全面口号就是眼高手低；应先实际学群众语言。

```text
large abstraction / transformation claim
-> implement a small observable instance
-> test with real user
-> then expand
```

这是从 slogan 到 pilot 的强转换规则。

## 1.12 用熟悉现场者共同创作

列宁传单例强调同熟悉工厂情况的参与者商量，根据具体事实和工人要求写作。

```text
domain communicator
+ situated participant
-> evidence-grounded message
```

这延续 V3-006 的互补知识；例子效果由苏联党史叙事提供，仍属被选定权威案例。

## 1.13 目标漏斗包含理解、相信与行动

引文要求普通工人都懂、相信号召并决定跟随。

```text
comprehension -> belief -> action
```

作为传播验收它很清楚；现代适用必须加入 claim truth、uncertainty、voluntary choice 和 harm，不得只优化转化率。

## 1.14 文本以其所批评的羞辱性风格纠错

“大喝一声你有病”、罪状、丑化比喻和阶级污名被用于刺激改革；这可能打破惯性，也可能制造 V3-006 所需的 epistemic chilling。

```text
shame shock
-> compliance / attention
but possibly
-> concealment / defensive conformity
```

文章对恐吓的批评没有完全应用到自身修辞。

# Pass 3 — Reasoning reconstruction

主要推理操作：

1. **reach-scaled consequence**：传播范围扩大错误外部性；
2. **interface manifestation**：上游模型/关系错误编码进输出；
3. **reform-to-orthodoxy reversal**：成功形式脱离理由后僵化；
4. **content-density/context fit**：长度按任务和信息量决定；
5. **status/evidence separation**：威吓不构成论证；
6. **audience modeling**：发送前研究接收者；
7. **selective language transfer**：多源吸收适用成分；
8. **relation over enumeration**：内部联系优于表面清单；
9. **preflight review**：发布前调查、复看、删改；
10. **task-shaped procedure**：会议形式随任务而变；
11. **small-instance validation**：宏大口号先做可观察实例；
12. **comprehension-belief-action funnel**：传播结果分阶段。

# Pass 4 — Adversarial reading

## 4.1 文风不是主观主义的可靠 classifier

短、活泼、群众语言也可传播虚假；长、技术、结构化文本可能准确必要。先验风格不能替代 claim audit。

## 4.2 reach 大不自动意味着应禁止发布

大范围沟通也可能带来巨大公共价值。正确控制是按风险提高验证、标注不确定性、纠错和撤回能力。

## 4.3 “科学不怕批评”与预认证真理冲突

若马克思主义已被定义为最正确科学，批评可能只被允许用于应用层而非核心模型；M-04 protected-layer audit 继续触发。

## 4.4 敌人/同志二分决定极端不同待遇

文章反对对同志无情打击，却允许对敌人；若 classifier 由同一权力掌握且不可申诉，温和纠错保护极易失效。

## 4.5 audience fit 可以用于操纵

理解目标、情绪和语言既能提高可达性，也能利用认知弱点。必须把准确性、透明意图和自主选择设为上位约束。

## 4.6 群众语言不等于群众知识或授权

模仿词汇可能制造亲近感，却不代表共同决定或利益一致；应让受众参与问题、证据和验收。

## 4.7 问题—分析—解决链可能强迫二元站队

“赞成一方面、反对另一方面”不适合所有探索、测量、设计和多目标权衡；有些任务需要先保留未知或组合方案。

## 4.8 preflight 可演变成审查瓶颈

重要文本多次复看有价值；低风险内部沟通若同样要求十多遍会延迟反馈。审计强度必须 risk-tiered。

## 4.9 固定流程不是天然坏事

清单和会议模板可减少遗漏、提高比较性；问题是形式与任务脱钩。需要 escape hatch，而非消灭结构。

## 4.10 “先办少许”仍需代表性与停止条件

一个成功小例不能证明全面 rollout；pilot 需预先指标、失败/副作用和迁移边界。

## 4.11 理解—相信—行动不是充分成功标准

高转化可由不透明说服产生。还要问内容是否真、选择是否自由、行动是否带来预期/可接受结果。

## 4.12 羞辱式治疗可能降低真实反馈

强刺激能引起注意，却会鼓励表态合规、隐藏错误和相互指控；与“不装腔恐吓”原则不一致。

# Pass 5 — Article-local candidate mechanisms

## H1-3-07-01 — Scale communication review to reach and action consequence

受众越大、发送者权限越高、内容越接近行动，越需来源、反例、理解测试、版本、撤回和影响监测。

- Textual confidence: high
- Empirical confidence: high

## H1-3-07-02 — Diagnose output patterns as interfaces, not root causes

风格异常可提示上游模型、激励或关系问题；修表达时仍追溯内容生成与权力结构，避免只换皮。

- Textual confidence: high
- Empirical confidence: high

## H1-3-07-03 — Preserve task-shaped structure with an escape hatch

清单、模板和会议流程用于防遗漏与比较，但允许按任务删改，并要求每项服务真实问题/关系/决定。

- Textual confidence: high that dead form is rejected
- Empirical confidence: high for bounded corrective rule

## H1-3-07-04 — Validate communication across truth, comprehension, agency and outcome

分别测内容准确、受众理解、选择自主、行动和后果；不以阅读量、认同或转化单轴验收。

- Textual confidence: high for comprehension-belief-action funnel
- Empirical confidence: high for expanded controls

## H1-3-07-05 — Test abstractions with a bounded real instance before scaling

宏大“化”先落成小实例，设置代表性、指标、停止/修订条件，再决定扩展。

- Textual confidence: high
- Empirical confidence: high

## H1-3-07-06 — Keep hostile-actor classification outside the communication author

当分类决定是否可用残酷手段或失去发言保护时，需要独立证据、审查和申诉，不能由争论中的发送者即时决定。

- Textual confidence: high that source creates treatment tiers
- Empirical confidence: high for corrective control
