# Pass 0 — Historical frame

本文处于抗战进入长期化、敌后游击战争已展开的阶段。它既回看党从1921年以来对武装与战略的认识变化，也解释为什么在1938年的具体条件下，组织工作重心要继续向战区和敌后移动。

因此本文特别适合研究：

> 一个组织怎样根据历史失败重设“核心能力”，又怎样在新环境中对已经形成的能力进行反向转换？

# Pass 1 — Source / argument reconstruction

## 1.1 普遍原则和具体执行形式被明确区分

开头先提出一个普遍政治原则，随后立即强调：不同国家的制度、民族压迫、合法组织空间等条件不同，执行形式也不同。

文章通过中国与资本主义国家的对比说明：

```text
general political claim
+
institutional environment
-> dominant action form
```

所以不是从普遍理论直接推出固定组织模式。

## 1.2 中国的制度结构被用于决定组织工作重心

文中认为当时中国缺乏合法议会/工人合法斗争空间，又处在半殖民地、半封建和武装冲突环境中，因此战争和军队被置于中心位置。

无论是否接受其政治结论，方法结构是：

```text
what institutions actually exist?
what channels are actually available?
where is coercive/decisive capability located?
-> organization priority
```

## 1.3 历史失败被解释为核心能力识别不足

文章回顾1921—1927年，认为党长期不够重视军事准备、军队和战略研究；在北伐时片面重视民众运动，国民党反动后民众运动随之受挫。

这是一个强 retrospective causal claim：

```text
misidentified decisive capability
-> underinvestment
-> vulnerability when environment changes
```

但因果不能只依本文自证。

## 1.4 能力学习不是一次完成，而经历阶段性修正

文章列出：

- 早期认识不足；
- 1927失败后大幅转向；
- 1931以后仍未全党转变；
- 1933后又发生原则性错误；
- 遵义会议再修正。

这不是线性“越来越正确”的简单故事，而至少承认：

```text
learn capability importance
!=
know how to use capability correctly
```

## 1.5 组织重心应服从当前决定性任务

本文把“主要工作方面在战区和敌后”作为当前阶段方针，并要求党员学习军事、准备前线。

这延续 V1-008 的结构：

```text
current central task
-> supporting organizational work reprioritized
```

不是说其它组织/群众工作消失，而是要求与主要任务建立直接或间接关系。

## 1.6 最重要的内容之一：同一能力形态要反复切换

文章把军事战略变化概括为三次转变：

1. 国内游击 -> 国内正规；
2. 国内正规 -> 抗日游击；
3. 未来抗日游击 -> 抗日正规。

这非常关键，因为能力成熟并不是单向“从低级到高级”。1937年反而要求已经正规化的部队重新分散执行游击任务。

```text
capability maturity
!=
permanent operating mode
```

## 1.7 转型失败存在两个相反方向

第一次转型时：

- 一种错误是停留在旧游击性，不愿按新任务正规化；
- 另一种错误是过度正规化、机械搬外国经验，脱离现实能力和敌情。

所以转型问题不是“旧 vs 新”，而是：

```text
under-adaptation
vs
over-adaptation
```

两侧都可能失败。

## 1.8 第二次转型显示“看似退步”的形式可能是更高层适配

1937年从正规运动战转向分散游击，在表面形式上像倒退，但文章认为它与新敌人、新盟友、新战场和敌后任务更匹配。

因此：

> 不能按形式的“高级/低级”判断策略升级，应该按任务适配度判断。

## 1.9 正规战与游击战的主辅关系随分析尺度变化

全文总体上正规战争为主、游击为辅；但战略相持阶段，游击战争又可能成为该阶段主要形态。

这再次支持：

```text
principal status depends on scope + stage
```

而不是绝对属性。

## 1.10 能力会产生二阶组织资产

文章不仅把军队视为作战工具，还声称它能够产生干部、学校、文化、群众组织和政治影响。

即使这段政治表达很强，它提示了一个结构问题：

```text
core operational capability
-> creates adjacent capabilities/assets
```

这种能力外溢需要在后文继续验证，而不是立即一般化。

# Pass 3 — Reasoning reconstruction

主要推理：

1. **institutional comparison**：相同原则在不同制度环境中实现方式不同；
2. **capability prioritization**：根据决定性任务确定核心能力投资；
3. **historical error reconstruction**：用失败解释能力缺口；
4. **stage-dependent mode switching**：同一组织在不同阶段切换集中/分散、正规/游击；
5. **two-sided transition control**：防止转型不足与转型过度；
6. **scope-sensitive principal relation**：整体主辅与阶段主辅可不同。

# Pass 4 — Adversarial reading

## 4.1 文章可能过度军事化解释组织历史

把大量政治、组织和群众工作的价值最终归于战争，可能低估制度、经济、合法组织等独立因果作用。

## 4.2 历史失败容易被单一关键能力重新解释

1927失败、第五次反“围剿”等事件存在多重原因；“没有正确认识战争中心地位”并不能单独证明因果。

## 4.3 “正确指导”具有自我验证风险

第二次战略转型成功被归因于干部接受中央正确指导并灵活观察情况，但“正确”部分可能由结果倒推。

## 4.4 未来正规化预测需要 prediction ledger 跟踪

文章预测战略反攻阶段将大幅正规化并装备新式武器。不能因为后见历史大方向相近就忽略时间、条件和具体机制误差。

## 4.5 “核心能力外溢”可能把相关性当因果

军队扩张与干部、文化、群众组织发展同时发生，并不自动证明所有邻接资产由军事能力单向产生。

# Pass 5 — Article-local candidate mechanisms

## H1-12-01 — Abstract principles require institutional instantiation

在迁移一个原则前，必须重新识别目标环境的制度、合法接口、能力结构和约束；不能从一般原则直接复制行动形式。

- Textual confidence: high
- Empirical confidence: high as a broad transfer hypothesis

## H1-12-02 — Learning that a capability matters is different from learning how to control it

组织可能先发现某能力不可缺少，随后仍在该能力的使用方式上反复犯错。

- Textual confidence: high
- Empirical confidence: medium

## H1-12-03 — Operating mode should be reversible across stages

能力成熟后仍可能因环境变化重新采用看似更分散、更轻量或更临时的模式。

- Textual confidence: high
- Empirical confidence: medium-high as a systems hypothesis

## H1-12-04 — Transitions require two-sided error checks

```text
changed environment
-> need transition
-> risk A: stay in old mode too long
-> risk B: over-transition beyond real conditions/capability
```

- Textual confidence: high
- Empirical confidence: medium

## H1-12-05 — “Primary” is scope- and stage-indexed

同一子系统可以在全局上是辅助，在某阶段成为主要形态。

- Textual confidence: high
- Empirical confidence: medium-high as an analytical rule
