# Pass 1 — Source / argument reconstruction

## 1.1 源文先用可观察行为而非自我声明判断合作价值

文章区分“口头称为朋友”和“实际提供援助”，列举的判断材料包括：

- 是否废除在华特权；
- 过去革命时期是否援助；
- 抗战时期是否提供空军和物资援助。

方法结构可还原为：

```text
self-description
<
observable costly behavior
```

## 1.2 随后出现从具体行为到制度类型的强推广

源文由苏联过去的具体援助进一步推出“只有社会主义国家等才能真正援助中国”的广泛判断。

从推理结构看，这是：

```text
selected historical cases
-> universal statement about actor class
```

列举的正例本身不足以排除其它类型主体可能提供实质援助，因此推广强度超过了文内证据。

## 1.3 领导人、国家、制度类型、政策和具体行动在叙事中高度绑定

源文把斯大林、苏联、社会主义制度及具体援助行动连接成统一的“朋友”判断。研究时应把这些层级重新拆开：

```text
leader
institution/state
regime/system type
policy
specific action
```

不同层级需要各自证据。

## 1.4 高成本支持是当前一致性的较强信号，但不是永久保证

废除特权、提供军事物资等事实如果成立，比低成本口头表达更能支持“当前存在合作价值”。

可迁移部分应限制在：

```text
costly + verifiable support
-> stronger evidence for current alignment
```

不能自动升级为永久身份判断。

## 1.5 与 V2-019 一起出现证据标准不对称风险

对被视为潜在对手的主体，文本倾向要求从利益和隐含动机审视；对被视为盟友的主体，则更容易由制度身份和过去行为推出长期可靠性。

因此本篇继续为 `evidence symmetry check` 提供历史案例。

# Pass 4 — Adversarial reading

## 4.1 全称判断需要研究反例空间

从若干苏联援助案例不能逻辑上推出“其它制度主体不可能提供真正援助”。要支持这种全称命题，必须主动研究非该类别主体的反例。

## 4.2 过去一致不证明长期永久一致

合作方的领导、利益、能力、制度和国际环境都会变化。可靠性判断需要时间范围和重新验证条件。

## 4.3 强人物/制度标签可能降低后续修正能力

一旦把某个主体编码成“忠实朋友”或相反的固定身份，后续相反证据容易被弱化。可靠模型应继续允许行为证据修改主体判断。

## 4.4 样本选择需要对称审计

应同时检查：

- 支持该主体可靠的事实；
- 与己方利益可能冲突的事实；
- 其它主体的实质帮助案例；
- 时间窗口是否被选择性截取。
