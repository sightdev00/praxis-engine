# Pass 0 — Historical frame

The article comes roughly one month after V2-001, after the conflict has visibly moved into nationwide armed resistance.

This makes it useful for testing a key distinction:

```text
stage transition has happened
!=
capabilities required by the new stage are already complete
```

The text is also explicitly a propaganda/mobilization outline, not a neutral analytical report. Its imperative and deterministic language therefore needs stronger adversarial control.

---

# Pass 1 — Source / argument reconstruction

## 1.1 The article declares a stage transition

The text says the situation has moved from:

```text
停止内战、准备抗战
```

to:

```text
实行抗战
```

This is not merely chronological. The transition is supported by:

- Japanese large-scale attack;
- actual Chinese military resistance;
- broader public struggle;
- changes in sections of the bourgeoisie;
- prior united-front efforts;
- partial Nationalist policy change.

## 1.2 Stage attainment does not imply stage consolidation

Immediately after acknowledging progress, the article lists major elements that remain unchanged or insufficient:

- mass mobilization remains restricted;
- political institutions have not fundamentally changed;
- people's livelihood policy remains inadequate;
- CCP-KMT cooperation is not yet sincere enough.

Thus:

```text
new stage entered
+
old institutional residue persists
-> transition remains incomplete
```

## 1.3 The new central task is reformulated

The text defines:

```text
今后的任务 = 动员一切力量争取抗战胜利
```

and identifies a key requirement:

```text
国民党政策的全部的和彻底的转变
```

This is a strong prioritization claim, but the rest of the article shows that `彻底转变` itself is a multi-component program rather than one scalar intervention.

## 1.4 `Government-only resistance` is rejected as an insufficient capability model

The article explicitly argues:

```text
单纯政府抗战
-> can obtain some local victories
-> cannot achieve complete victory
```

and contrasts it with:

```text
全面民族抗战
```

This is an important architecture claim: formally entering a war is not the same as mobilizing the full system required for the desired outcome.

## 1.5 The Ten-Point Program is a capability decomposition

The ten points span:

1. war objective;
2. total military mobilization;
3. mass mobilization;
4. political-institutional reform;
5. foreign policy;
6. wartime finance/economy;
7. livelihood;
8. education;
9. rear-area security;
10. national unity.

For our research, the important source structure is:

```text
one strategic objective
-> decomposed into multiple military, institutional, economic, social and organizational capabilities
```

This is another counterexample to treating `中心任务` as a single implementation lever.

## 1.6 Policy coherence is again central

The article requires all domains to be brought into alignment with the new war objective.

This strengthens V2-001's distinction:

```text
new declared objective
+
old institutions/policies
= incomplete strategic transition
```

## 1.7 The article makes a strong conditional forecast

It says that if the program is completely, sincerely and firmly implemented, victory can be achieved.

This gives a falsifiable-looking condition, but the set is so broad that attribution remains difficult: nearly every major subsystem is included.

# Pass 3 — Reasoning reconstruction

## R1. Stage-transition diagnosis

```text
external shock
+ observed policy/behavior changes
-> classify new stage
```

## R2. Transition-completeness audit

```text
new stage label
-> inspect whether institutions/capabilities actually transformed
-> distinguish nominal transition from completed transition
```

## R3. Objective-to-capability decomposition

```text
strategic objective
-> derive required capability domains
-> identify missing/old subsystems
```

## R4. Whole-system mobilization logic

The causal thesis is that partial mobilization cannot achieve a system-level objective whose demands exceed the state apparatus alone.

## R5. Cross-domain consistency test

Military, political, economic, educational and organizational arrangements should not optimize against the declared strategic objective.

# Pass 4 — Adversarial reading

1. The text is a mobilization program; rhetorical completeness can be mistaken for causal completeness.
2. The ten-point bundle is not experimentally decomposed into necessary vs helpful vs ideological components.
3. `Only X can win` and `if all ten points then victory is certain` are much stronger than the evidence supplied.
4. Some subsystem reforms may matter through political legitimacy rather than directly through military effectiveness; the causal paths are not separated.
5. The article may conflate `desirable political program` with `necessary operational conditions`.
6. Strongly integrated programs can make falsification difficult: failure can always be attributed to incomplete execution of one point.
7. Stage-transition claims may be correct at the strategic level while local institutions remain in older regimes; stage classification must allow mixed-state systems.

# Pass 6 — Cross-volume update

## P2 strengthened — stage as mixed transition state

Volume I already showed that stages correspond to state/force changes. V2-002 adds a useful refinement:

> A system can cross a stage boundary while retaining substantial institutions and practices from the prior stage.

Therefore stage representation should support:

```text
entered / consolidating / mixed / regressing
```

rather than a clean categorical flip.

## P2 strengthened — central objective + multi-capability architecture

The article's `中心任务` does not reduce the strategy to one lever. It expands into ten policy/capability domains.

This reinforces Volume-I correction to naive `principal contradiction = one bottleneck` thinking.

## P2 strengthened — strategy-method consistency

V2-001/V2-002 together form a tight sequence:

```text
policy declaration
-> implementation bundle
-> institutional consistency audit
-> future scenario
```

Future texts should test whether this becomes institutional control/reporting rather than rhetorical prescription.

# First-pass takeaway

The most reusable structure is:

```text
when a system enters a new stage:
1. do not assume the transition is complete;
2. derive what capabilities/institutions the new stage requires;
3. identify residual mechanisms from the old stage;
4. prioritize changes by their effect on the new objective;
5. validate progress through behavior/capability, not the stage label itself.
```

The historical ten-point program is not itself transferable, and its necessity/sufficiency claims remain underdetermined.
