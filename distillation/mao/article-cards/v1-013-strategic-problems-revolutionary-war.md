# Pass 1 — Source / argument reconstruction

## 1.1 一般规律必须经过特殊条件重写

第一章开篇构造三个层级：

```text
general war
-> revolutionary war
-> Chinese revolutionary war
```

每一层都有前一层不能完全覆盖的特殊条件。

文章分别反对机械复制：

- 外国一般军事条令；
- 苏联内战经验；
- 北伐战争旧经验。

核心不是拒绝已有知识，而是：

```text
learn prior experience
+
identify what remains valid here
+
add local-specific mechanisms
```

## 1.2 规律和方法随时间、地域、性质、规模和能力发展

文章明确说战争指导规律有：

- 时间差异；
- 地域差异；
- 性质差异；
- 兵团规模差异；
- 技术/战术/战略发展阶段差异。

因此经验不能冻结成固定模板。

## 1.3 战略的对象是“全局中决定性的关系”

文章区分：

- 战略：关照全局和各阶段；
- 战役/战术：局部规律。

但同时说全局不能脱离局部。

关键不是“战略比局部高贵”，而是：

```text
which local event or relation is decision-relevant to the whole?
```

某些局部失败可以不伤全局；某一个决定性失败却可能改变全盘。

而“决定性”必须按具体情况规定，不能抽象预置。

## 1.4 从材料到计划的认识链第一次被完整写出

正文给出：

```text
必要而周到的侦察
-> 收集敌情材料
-> 去粗取精
-> 去伪存真
-> 由此及彼
-> 由表及里
-> 加入己方情况
-> 比较敌我关系
-> 判断
-> 决心
-> 计划
```

这比前文“调查后再下结论”更进一步：**证据并不直接生成决策，中间需要筛选、关系化和综合。**

## 1.5 计划开始执行后，认识过程重新开始

正文明确说：计划建立之前有一次认识过程，计划执行以后又是一个认识情况的过程。

```text
plan
-> action
-> new observations
-> check whether prior model fits reality
-> new judgment
-> new decision
-> partially or wholly revise plan
```

并说部分修改“差不多每一作战都是有的”，全部修改也会发生。

这是此前实践—纠错机制最清楚的显式理论化。

## 1.6 从自己经验验证外部理论

文章主张：

```text
learn past theory/experience
-> test it against own experience
-> keep useful parts
-> reject unusable parts
-> add own specific findings
```

并提出“从战争学习战争”。

这不是拒绝学习，而是把使用本身视为更重要的学习阶段。

## 1.7 主观能动性受客观边界约束

正文同时写：

```text
物质条件限定可行空间
but
在该空间内，指导能力显著影响结果
```

因此既反对“意志万能”，也反对“条件决定一切所以无须决策”。

## 1.8 战略退却是为了改变条件集合，而非被动等待

退却目的被定义为保存力量、准备反攻，并列出转入反攻所需的候选条件：

- 人民支持；
- 有利地形；
- 主力集中；
- 发现敌弱点；
- 使敌疲劳；
- 使敌出错。

并明确说不必全部满足，只需依据具体情形争取若干必要条件。

这是一种主动塑造条件配置的策略。

## 1.9 集中不是“所有资源永远集中”，而是在决定点形成局部优势

文章反对多方向平均用力，强调在同一时刻有一个主要使用方向。

但同时保留：

- 次要方向钳制力量；
- 游击力量；
- 某些场景局部劣势；

其真正结构是：

```text
strategic total may be weaker
-> choose local target
-> create local superiority at decisive point/time
```

## 1.10 同一个“游击性”被拆成应淘汰和应保留的两部分

随着组织成熟：

应减少：

- 不集中；
- 不统一；
- 纪律差；
- 工作简单。

当前仍需保留：

- 运动战；
- 流动性；
- 灵活计划；
- 不过早正规化。

因此阶段升级不是“旧模式全错、新模式全对”，而是：

```text
old bundle
-> split by function
-> retire harmful legacy
-> retain still-adaptive mechanisms
-> prepare for next capability stage
```

## 1.11 计划时间尺度受环境稳定性限制

流动作战和根据地流动导致多年固定建设计划“不可能设想”，计划频繁改变成为常态。

这与 V1-010 的“控制分辨率匹配系统结构”相呼应：

```text
high environmental volatility
-> shorter reliable planning horizon
```

## 1.12 速决与持久并非逻辑矛盾

战略总体可能持久，而具体战役要争取速决；“速决”也必须由条件支撑，而不是愿望。

这继续证明：不同层级可以采用表面相反的原则。

# Pass 3 — Reasoning reconstruction

## R1 — Hierarchical transfer: general -> special -> more special

迁移已有规律时逐层加入环境特殊性。

## R2 — Generalize only after identifying invariant vs context-dependent parts

经验包不是整体复制或整体丢弃。

## R3 — Search the global structure for decisive relationships

关注能改变全局的局部，而不是平均处理所有局部。

## R4 — Evidence requires synthesis before decision

原始材料需经过真实性、相关性、关系和敌我对比处理。

## R5 — Action is another observation phase

执行不是认识结束，而是新的模型检验。

## R6 — Diagnose mismatch as model/plan vs current reality divergence

失败的核心解释框架是主观指导和客观情况“不对头”。

## R7 — Learn by controlled retention and rejection of inherited rules

既尊重别人流血经验，也尊重自己流血经验。

## R8 — Act within constraints while shaping them

不能超出客观条件，但可以通过退却、集中、诱导等改变局部条件结构。

## R9 — Create local advantage when global advantage is unavailable

全局弱势和局部优势可以同时成立。

## R10 — Mature systems by decomposing legacy features

不要把“正规化/现代化”当作整体开关。

# Pass 4 — Adversarial reading

## A1 — 文本具有明显后见与路线胜负背景

1936 年已知遵义会议后的权威变化和第五次反“围剿”结果。作者对旧路线的因果解释可能受胜者视角影响。

## A2 — “客观规律”可能把作者模型自然化

声称规律是客观实际反映，并不证明当前总结已经准确获得该规律。

可靠迁移必须保留：

```text
claimed law
!=
validated invariant
```

## A3 — 多个军事反事实不可验证

如某时若转向某方向“必能”改变第五次反“围剿”结果，属于强 counterfactual，无法由实际历史直接证实。

## A4 — 成功案例集中支持自身主张

集中兵力、诱敌深入等案例选择可能忽略失败的相同策略或其它共同条件。

## A5 — “全局决定性”可能成为集中权力的辩护

正确识别系统级变量很重要，但上级并不天然比局部更了解什么是决定性的。V1-004 已提供远程判断失败反例。

因此全局判断必须有高质量下行/上行信息网络。

## A6 — 军事领域的损失函数和现代组织差异巨大

集中资源、诱导对手、歼灭等具体军事做法不可直接迁移到商业、管理或人际系统。

## A7 — “边做边学”不适用于不可逆高风险试错

有些行动不能用失败换经验。现代 Skill 必须加入 failure cost / reversibility gate。

## First-pass takeaway

这篇第一次把过去十篇零散形成的 Praxis 模式写成近乎完整的认识—行动闭环：

```text
学习一般经验
-> 分析当前领域和本地特殊条件
-> 识别对全局真正决定性的关系
-> 侦察并审计原始材料
-> 将材料综合成敌我/系统关系模型
-> 判断
-> 承诺并制定计划
-> 执行
-> 把执行结果当作新证据
-> 比较现实与模型
-> 部分或全部修改计划
-> 把新经验重新总结为更好的规则
```

但 Praxis Engine 必须比原文再加一层约束：**行动只有在错误成本可接受、可逆或已有必要安全控制时，才适合作为学习手段。**
