# Pass 0 — Historical frame

The united front is formally in force, but the border region reports attempts to reverse existing land/debt arrangements, disrupt organizations, collect intelligence and provoke internal conflict.

This short document is useful because it shows how high-level coalition strategy becomes a local **security and jurisdiction rule**.

---

# Pass 1 — Source / argument reconstruction

## 1.1 Coalition does not eliminate internal security boundaries

The proclamation begins by affirming national anti-Japanese unity, then identifies actions inside the border region that it treats as incompatible with that unity.

Thus:

```text
shared high-level coalition
!=
unrestricted local access / intervention
```

## 1.2 Previously granted rights are treated as state that should not be silently rolled back

It explicitly protects:

- already distributed land/houses;
- previously abolished debts;
- existing military, political, economic, cultural and mass organizations developed under united-front principles.

This is a **state-preservation / non-regression** rule during coalition transition.

## 1.3 External participation requires authorization

The proclamation welcomes good-faith assistance but requires outsiders entering the region for activity to obtain approval/documentation.

The structure is:

```text
cooperation open
+
identity/authorization gate
```

## 1.4 Enforcement is evidence-based in wording but coercive in mechanism

It permits reporting and arrest when evidence is `确实`, followed by punishment after verification.

The important analytical distinction is:

```text
security allegation
-> evidence threshold
-> coercive action
```

but the source does not specify modern due-process standards, independent adjudication, or rights protections.

# Pass 3 — Reasoning reconstruction

## R1. Coalition/security boundary

```text
shared external objective
-> define internal non-negotiable rights/capabilities
-> permit cooperation only inside those boundaries
```

## R2. Non-regression protection

A new coalition stage should not automatically undo previously created local state/capability unless explicitly renegotiated.

## R3. Admission/authorization control

Open cooperation is combined with identity and scope verification.

---

# Pass 4 — Adversarial reading

1. The issuing authority is also the judge of what counts as `破坏`; political disagreement can be securitized.
2. `证据确实` is not an operational due-process specification.
3. Restricting outside actors can protect system integrity but also block legitimate oversight, dissent or coordination.
4. Protection of acquired rights is politically specific; modern transfer should focus on explicit state-change/rollback governance, not historical property policy.
5. The editorial note's attribution of all activity to Chiang's conspiracy is retrospective partisan framing.

new shared interface

# First-pass takeaway

Even a short proclamation adds a distinct control principle:

> Coalition expands interaction, but does not remove the need to specify protected state, authorization boundaries and change-control rules.

The source's punitive political enforcement is not transferable as such.
