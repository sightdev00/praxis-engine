# Pass 0 — Historical frame

本文是一部课本，而不是针对单一即时问题的短文。其功能是构建一套从“中国是什么”到“当前应做什么”的完整解释链。

# Pass 1 — Source / argument reconstruction

## 1.1 全文最核心的架构是一条层层推导链

文章明确写：只有认清中国社会性质，才能认清革命的对象、任务、动力、性质、前途和转变。

可以还原为：

```text
system / environment model
-> principal contradictions
-> object / obstacle model
-> task definition
-> actor-force map
-> current-stage nature
-> future transition
-> organizational requirement
```

这是一套高度结构化的问题表征框架。

## 1.2 对一个系统先做“结构画像”，再下战略结论

第一章尝试从：

- 地理；
- 人口/民族；
- 历史制度；
- 经济关系；
- 外部资本/帝国主义关系；
- 政治结构；
- 区域不平衡

等层面定义中国社会。

其方法优势是先建立 context model；风险是这些宏大类别一旦被固定，后续所有策略都被它们锁定。

## 1.3 “主要矛盾”再次表现为优先关系，而非唯一关系

第一章明确列出不止一组矛盾，又说帝国主义与中华民族矛盾是当前“最主要”。

这继续支持：

```text
principal = highest current strategic weight
not = only existing relation
```

但其因果排序仍需外部历史证据，而不能因理论一致性自证。

## 1.4 从系统性质推导敌人/对象，形成强 dependency chain

第二章说：

```text
social nature
-> main obstacles/enemies
-> long duration and harshness
-> dominant struggle form
-> need for base areas
```

这是一种结构化推导，而不是逐个策略独立提出。

方法价值在于依赖关系清楚；方法风险在于上游假设错误会级联到整个下游。

## 1.5 “主要形式”没有消灭辅助形式

即使把武装斗争和农村根据地设为主要形式，文章立即强调：

- 不能放弃其它斗争形式；
- 不能放弃城市工作；
- 农村根据地若与城市/其它地区隔离仍会失败。

因此再次出现：

```text
primary channel
requires
supporting channels
```

而不是 top-1 strategy 独占资源。

## 1.6 同一行动模式按环境选择不同可见度/风险姿态

对于敌人长期控制的地区，文章反对冒险暴露，提出：

```text
concealed / lean organization
accumulate capability
use legal/public space where possible
move step by step
wait for state change
```

这与公开根据地的运行方式明显不同，进一步支持 context-dependent operating mode。

## 1.7 Actor 分类同时保留“阶级位置”与“阶段移动”

第二章大量从经济位置推断阶级政治倾向，但也承认：

- 同一资产阶级集团在不同国际矛盾下可能暂时加入联盟；
- 民族资产阶级具有双重性；
- 开明中小地主在抗战中可以团结；
- 知识分子有先锋/桥梁作用但并非自动可靠。

所以其实际模型比静态阶级表复杂，但仍高度依赖 material-position ontology。

## 1.8 先锋、基本动力、领导、同盟等角色被进一步分层

特别是知识分子被称为先锋和桥梁，但并非长期主力；无产阶级又被描述为领导力量但单独不能胜利，需要组织广泛联盟。

角色不是单一 ranking，而更像多种函数：

```text
initiation / bridge
mass capability
leadership / coordination
conditional ally
```

## 1.9 阶段转换被建成“必要准备 + 未来转变”，而非一步完成

最后区分：

```text
democratic-revolution stage
-> complete current tasks
-> build necessary conditions
-> later socialist stage
```

并同时反对：

- 只看当前阶段、忘记未来方向；
- 把未来阶段任务提前当作当前任务。

这强烈支持第一卷形成的 `long-term direction != current admissible action`。

# Pass 4 — Adversarial reading

## 4.1 上游 ontology 错误会造成整条推理级联错误

全文优点是结构清楚，但这也放大一个风险：如果“社会性质”分类过粗、错误或遗漏，后续对象、任务、动力、性质、前途都可能在同一错误表征上保持逻辑一致。

## 4.2 经济/阶级位置被赋予过高解释权

V1-004 已看到宗族、地域等变量可穿透阶级分析。本文虽加入更多条件，但仍反复从经济地位推出政治立场，需要持续寻找反例。

## 4.3 长历史被目的论式整合

把数千年农民起义、近代事件等压成统一历史动力，可能忽略事件性质、目标和结果的巨大差异。

## 4.4 “没有某领导就必然失败”等反事实断言难以识别

这类必然性命题往往缺乏可比较 counterfactual。

## 4.5 Authorship attribution 不能因收录在《毛选》而被抹平

第一章虽经毛修改，但不是独立起草。最终 Skill 若用第一章的具体 schema 作为“毛的稳定方法”，必须降低 textual-attribution confidence 或寻找第二章/其它独立 Mao 文本重复。
