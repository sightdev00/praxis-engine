# V3-024 两个中国之命运

> 状态：依现行协议完成首轮蒸馏
> 日期：1945-04-23
> 文类：中共七大开幕词／战后制度选择／政治动员

## A. 识别

- 原文：https://www.marxists.org/chinese/maozedong/marxist.org-chinese-mao-19450423.htm
- 场合：中国共产党第七次全国代表大会开幕。

# Pass 0 — 历史情境

日本尚未投降，战后秩序尚未定型。文本把即时军事任务与战后国家制度放在同一决策框架中：抗战胜利并不自动决定中国将走向何种政治和经济道路。

# Pass 1 — 原文／论证重构

抗战未结束、战后制度未定，因而两种中国前途并存。文本要求放手发动群众、壮大人民力量、团结一切可能力量，打败侵略者并建设独立、自由、民主、统一、富强的新中国。

文本把“光明中国”定义为新中国，把“黑暗中国”定义为半殖民地半封建、分裂贫弱的旧中国，并将七大、全党和全国人民的任务统一为争取前者。

# Pass 2 — 证据审计

见 ../evidence/v3-024/evidence-ledger.md。正文直接证明当时的政治框架、任务排序和制度愿景；不能单独证明群众授权、政策可行性或战后制度必然沿着二分法发展。

# Pass 3 — 推理重构

1. 将战争胜利与战后制度选择分开审计；
2. 把政治目标转化为组织、联盟和群众动员能力；
3. 用独立、自由、民主、统一、富强作为结果指标，而非口号；
4. 把“两个前途”视为竞争情景，不把对手自动等同于所有黑暗结果。

# Pass 4 — 对抗性阅读

二分框架有很强的动员清晰度，却压缩了第三种制度组合和内部异议的空间。“人民”由组织代表，不能把动员规模直接当作授权。1945 年后的内战、政权建立和制度实践可以检验部分结果，却不能把后见结果倒写成开幕词当时已经证明的必然性。

# Pass 5 — 本篇候选机制

## H1-3-24-01 — 将制度愿景转成可审计指标

分别记录政治参与、权利保障、统一程度、经济能力和分配结果，并允许不同群体报告代价与异议。

- 文本置信度：高
- 实证置信度：中

## H1-3-24-02 — 将战争动员与战后授权分开

抗战时期的紧急动员不能自动延长为战后无限授权；在胜利或转型节点设置代表性、权利和政策复核。

- 文本置信度：中
- 实证置信度：高

# Pass 6 — 跨篇更新

V3-016、V3-020 已把政治承诺与可观察行动连接。本篇增加长期情景边界：军事胜利、政治授权和制度绩效必须分别验证，不能用“光明／黑暗”的标签替代结果账。

## 工作判断

本篇提醒决策者：战争结束不等于制度选择结束。其风险在于二分动员框架可能把组织目标、群众授权和最终结果压缩成同一件事。
