# Pass 0 — Historical frame

此前文本不断讨论投降、反共、统一战线破裂和时局好转的竞争方向。本文不再主要建立长期制度蓝图，而是把不确定局势转换为当下的风险控制、联盟扩展和公开动员计划。

决策问题是：

> 如何既不被局部恶化吓倒，也不因害怕联盟破裂而放弃抵抗；同时怎样利用仍存在的有利条件改变全国路径？

# Pass 1 — Source / argument reconstruction

## 1.1 同一现实保留两条可达路径

文章认为投降/倒退与抗战/进步两个方向同时存在，两种前途都有可能。

```text
current state
-> capitulation / fragmentation path
or
-> resistance / unity / progress path
```

它没有把“主要危险”写成唯一必然结果，而是把行动定义为改变路径概率。

## 1.2 局部严重信号既不能孤立，也不能全局化

对各地投降、反共、倒退现象，文本要求：

- 不孤立看待，要连接共同趋势；
- 承认其严重性并抵抗；
- 不被其威力压倒，不直接推断全国已不可挽回。

```text
local event
-> cluster/trend audit
-> severity assessment
but not
-> automatic total-system conclusion
```

## 1.3 风险还要结合抑制条件

正文列出使全国投降/全面反共战争较难发生的国际和国内条件，包括日方强硬、列强矛盾、苏援、共产党/军队抵抗、中间阶层态度、国民党内部派别数量等。

这相当于：

```text
hazard pressure
- inhibiting constraints
= conditional risk
```

但“数量少”不等于权力小；约束强度和持续时间均未量化。

## 1.4 采用双轨策略，不在合作与抵抗之间二选一

总任务一方面反抗军事/政治进攻，另一方面扩展党政军民学各界统一战线并发展根据地、武装、政权和党组织。

```text
defend against harmful action
+ widen cooperative coalition
+ build independent capability
```

这比只抗议或只求和都多一层结构：抵抗防止被压缩，扩展改变力量关系，能力建设保护持续行动。

## 1.5 警觉程度按风险范围校准

文章要求准备突然事变，但明确“目前”更可能是局部、地方性事变，而不是立刻把全国内战当成基线。

```text
high vigilance
with
bounded incident scope
```

这是 alert severity 与 event scale 的分离。

## 1.6 新事件同时产生正反二阶效应

汪精卫协定公开、蒋介石声明之后，文章预测：

- 和平/妥协空气受打击，抗战势力可能增长；
- 限共政策仍会继续，地方事件仍可能发生；
- “统一对外”甚至可能被用作攻击共产党的话语。

单一事件不是单方向更新：

```text
event
-> weakens one risk channel
and
-> strengthens/reframes another
```

## 1.7 把政治判断转为分层行动包

文件把总方针展开为：

- 全国统一口号；
- 地方按情势增加口号；
- 文章、宣言、传单、演说、小册子等多渠道；
- 联合各界和国民党抗日派；
- 指定二月上中旬的大会窗口。

```text
strategic frame
-> standardized public claims
-> local adaptation
-> channel portfolio
-> dated mobilization
```

这形成从判断到执行的完整下传。

# Pass 3 — Reasoning reconstruction

主要推理操作：

1. **competing-path model**：保持两种前途同时可达；
2. **local-to-system calibration**：聚合局部信号而不自动全局化；
3. **hazard/inhibitor decomposition**：风险压力与抑制条件分别建模；
4. **dual-track response**：抵抗攻击、扩大合作、建设能力并行；
5. **alert-scope calibration**：提高警觉但限定当前事件尺度；
6. **multi-effect event update**：同一事件产生正负二阶影响；
7. **strategy-to-campaign decomposition**：总方针转成口号、渠道、伙伴和日期；
8. **central/local interface**：统一核心信息，允许地方增加适配内容。

# Pass 4 — Adversarial reading

## 4.1 “历次估计正确”没有逐项列出失败预测

它会强化确认偏差。正确的评分对象应是具体预测、时间、条件和结果，而不是中央整体判断的信誉。

## 4.2 阶级方向模型仍过于固定

把大地主大资产阶级和其它阶层各自归入两条方向，弱化了同类内部差异、组织利益和行为变化；V2-023 的 1940 分类修订已经证明 taxonomy 需更新。

## 4.3 抑制条件是存在性列举，不是强度模型

列强矛盾、中间阶层态度和派别数量都可能限制投降，但需要权力、资源、协调和持续时间。少数掌权者可压倒数量多数。

## 4.4 “暗藏汪派汉奸”是高误伤分类

反共行为可能支持敌方分裂目标，但从行为相似跳到秘密身份/指挥关系，需要独立证据。该标签靠近宣传、排斥甚至处罚 actuator，门槛应提高。

## 4.5 大规模宣传可能把分析压成单一口径

统一动员有协调价值，但也可能抑制对蒋声明、地方冲突和统一战线内部真实差异的公开讨论。中央口号与地方事实不符时需要反馈渠道。

## 4.6 双轨行动存在升级风险

抵抗军事进攻与扩展自身武装/政权可能被对方解释为竞争升级。需要区分防御、扩张、威慑和报复，并设比例与停火接口。

## 4.7 风险模型缺少触发阈值

何时从局部事件判断为全国趋势、何时从宣传升级为军事准备、何时调整联盟策略，正文没有定义可观察阈值。

# Pass 5 — Article-local candidate mechanisms

## H1-27-01 — Severe local events require aggregation without automatic globalization

局部信号应进入共同模式和系统影响审计，但范围、基率和反向样本必须保留，避免孤立化与灾难化两种错误。

- Textual confidence: high
- Empirical confidence: high

## H1-27-02 — Risk equals pressure constrained by inhibitors and response capacity

```text
risk = hazard pressure - inhibiting constraints - response capacity
```

条件清单需进一步加入强度、持续时间、相关性和失效模式。

- Textual confidence: high
- Empirical confidence: high with added quantification boundary

## H1-27-03 — Coalition defense should combine resistance, expansion and capability building

只退让会被逐步压缩，只对抗会失去可争取伙伴；可并行保护边界、扩大共同域和提高独立承载能力。

- Textual confidence: high
- Empirical confidence: medium-high

## H1-27-04 — Alerts need both severity and scope

可以对高后果事件保持高警觉，同时把当前最可能范围设为局部；这有助于准备而不把最坏情形当成已发生事实。

- Textual confidence: high
- Empirical confidence: high

## H1-27-05 — Central messages need local adaptation and upward correction

统一核心目标可减少碎片化，地方增加情境内容可提高适配；还必须允许地方证据反向修改中央判断。

- Textual confidence: high for downward adaptation
- Empirical confidence: high for added upward-feedback boundary
