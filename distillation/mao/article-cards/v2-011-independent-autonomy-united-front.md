# Pass 0 — Historical frame

本文是六届六中全会结论的一部分，直接处理统一战线内部的行动边界。前一篇已经提出“统一 + 相对独立”；本文进一步回答：

> 在合作方权力不对等、缺少真正共同决策机构的情况下，哪些事项应共同决定，哪些事项应自主行动，怎样让步而不自我取消？

# Pass 1 — Source / argument reconstruction

## 1.1 让步的价值由其在整体策略中的功能决定

文章把改编红军、改制区域、停止某些旧政策解释为为了形成全国抗战所做的让步。

其结构不是：

```text
concession = loss
```

而是：

```text
local concession
-> removes obstacle / buys cooperation
-> enables higher-level objective
```

但文章同时区分“积极让步”和放弃自身核心能力的投降式让步。

## 1.2 长期合作需要互惠，不是单向服从

文中用党派、工农、地主农民等关系说明互助互让应该具有双向性。其源文本政治立场很强，但方法结构明确：

```text
one-sided compliance
!=
stable cooperation
```

## 1.3 独立性被视为合作的构成条件，而非合作的反面

民族斗争在当前阶段占据更高权重，但原有阶级和组织差异没有被宣布消失，而是被限制在“不破坏合作”的边界内。

因此：

```text
shared objective
+
bounded independent agency
-> coalition
```

而不是把所有参与者合并成一个主体。

## 1.4 “一切经过统一战线”被拒绝，理由是实际治理接口并不存在

文章特别指出：中国当时没有平等的统一战线共同组织，所谓“一切经过”如果实际上等于所有事项取得国民党批准，就变成单方面受控。

这是本文极重要的一层：

> 一个治理口号是否成立，取决于现实中是否真的存在它假设的共同决策机构和对等接口。

## 1.5 不同动作使用不同授权路径

正文按当时政治情境区分：

- 有些先取得同意；
- 有些行动后报告；
- 有些暂不报告；
- 有些因为会破坏大局而不做。

现代分析不能照搬这些具体政治动作，但可以看到一种 action classification：

```text
action
-> impact on shared objective
-> dependence on counterpart approval
-> reversibility / externality
-> choose coordination route
```

本文本身并未给出这套抽象字段，这是我们的 I 层重构。

## 1.6 统一性与独立性不是固定比例

文章说独立性应服从统一战线总目标，但又不能被抹杀。也就是说边界由当前总目标和现实权力结构决定，而不是固定制度常数。

# Pass 3 — Reasoning reconstruction

主要推理：

1. **local-to-global evaluation**：局部损失按其对更高目标的作用评价；
2. **interface realism**：先检查现实中是否存在名义制度所假设的决策接口；
3. **bounded autonomy**：共同目标下保留参与者的最低独立能力；
4. **action classification**：不同事项不使用单一审批流程；
5. **coalition stability reasoning**：合作不能等于单向服从。

# Pass 4 — Adversarial reading

## 4.1 “先行动后报告”高度依赖政治冲突语境

把它直接迁移到企业、软件 Agent 或治理系统会非常危险。现代系统必须重新考虑授权、法律、责任、不可逆后果和安全边界。

## 4.2 谁定义“妨碍大局”仍然是核心权力问题

如果参与者各自都以“大局”为理由绕过共同流程，联盟会崩溃。本文没有提供中立仲裁机制。

## 4.3 独立性可能服务合作，也可能服务联盟内竞争

正文倾向强调保持自身力量的必要性；这一机制在其它合作关系中是否提高长期总收益，不能由本文证明。

## 4.4 后期编者说明存在明显后见强化

第二版注释用1947年以后结果评价1938年路线，这些后见证据不能回填为1938年决策时已知信息。

# Pass 5 — Article-local candidate mechanisms

## H1-11-01 — Evaluate concessions by system-level function, not immediate sign

一次局部后退可能扩大总体可行空间；一次表面坚持也可能破坏高层目标。

- Textual confidence: high
- Empirical confidence: medium-low
- Boundary: 不能用“长远利益”给任意牺牲事后合理化。

## H1-11-02 — Collaboration protocols must match real governance interfaces

如果不存在真正共同、平等、可执行的决策接口，就不能假设一个“所有事情都走共同审批”的流程已经存在。

- Textual confidence: high
- Empirical confidence: medium
- Modern mapping: governance/interface audit

## H1-11-03 — Shared objective does not imply zero local agency

稳定合作可能要求每个参与者保留完成自身职责、维护核心边界和适应局部状态的能力。

- Textual confidence: high
- Empirical confidence: medium

## H1-11-04 — Coordination route should depend on action class

高外部性、不可逆、改变共同接口的动作，与低外部性、可逆、局部动作，不应自动使用同一授权级别。

- Textual confidence: medium（抽象为我们的 I/G 映射）
- Empirical confidence: medium as an engineering hypothesis
- Safety: modern use must default to explicit authorization for high-impact actions.
