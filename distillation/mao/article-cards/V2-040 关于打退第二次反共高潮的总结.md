# Pass 1 — Source / argument reconstruction

## 1.1 先确认 episode 关闭并刷新环境状态

文章确认反共高潮已经过去，进入继续抗战的新环境，并列出国际战争、革命运动、苏日条约、国内力量地位和日本新攻势准备等新因素。

```text
close prior episode
-> refresh state variables
-> retain continuing objective
-> extract lessons for next episode
```

这是一个合理的复盘顺序；但“高潮被打退”和力量地位变化仍主要由本方评价。

## 1.2 用主要矛盾解释为何没有复现 1927

文章说中日民族矛盾依然基本，国内阶级矛盾从属；外敌深入国土的事实“决定一切”，因此即使大地主大资产阶级全部投降也不能造成 1927 局面。

```text
dominant external conflict
-> constrains domestic actors / coalition break
-> historical analogy boundary
```

前两步提供有用边界：相似暴力事件不等于相同系统状态；“决定一切”和极端 counterfactual 则过度绝对。

## 1.3 明确指出类比判断被客观事实否定

文中称前后两次反共高潮都有人估计为马日/四一二重演，而事实证明错误，原因是忘记主要民族矛盾。

这构成显式 error diagnosis：不是风险事件不存在，而是把局部冲突映射到错误历史阶段。

## 1.4 保留 actor 的双面结构

英美派大地主大资产阶级既对日又反共，在抗日和反共内部又各有两面，因而政策仍是“以打对打、以拉对拉”。

```text
actor issue-vector
-> mirror cooperation on cooperation
-> constrain attack on attack
```

这延续 V2-037 的多轴 actor 模型；“镜像”原则仍须受比例、权利和独立目标约束。

## 1.5 把项英失败作为反面执行案例

文章再次把项英的机会主义失败当全党警戒，认为不针锋相对就会被消灭，同时重申有理、有利、有节。

这是具体失败反馈，但仍主要采用单因果归责；指令可达性、撤退命令、路线、资源和中央自身预测/部署责任未展开。

## 1.6 用 actor 行为变化支持分类分辨率

阎锡山由上次强反共转为此次中间，桂系由中间转向反共但仍与蒋系有矛盾，被用于证明不能把地主/资产阶级整体化。

```text
same structural category
-> different behavior across episodes
-> update policy category
```

这是对 taxonomy 的一次真正 temporal test；但个案选择是否完整、分类是否只按对中共态度，仍需审计。

## 1.7 最坏准备与基线预测被明确分离

文章说准备国民党可能破裂完全必要，但不能因此抛弃好的可能；准备最坏恰是争取好转并使之成为现实的条件。

```text
probability model: multiple live branches

contingency plan for worst branch
!= assign probability 1 to worst branch

protect against downside
+ act to improve preferred branch
```

这是全文最强、最可迁移的认识—行动边界。

## 1.8 又把准备直接归因为威慑成功

文章进一步说充分准备使国民党不敢轻易破裂。

```text
readiness
-> deterrence
-> non-event
```

这是可能机制，但 non-event 不能单独证明 deterrence；对方目标有限、国际约束、内部矛盾也可解释。

## 1.9 将统一战线与阶级政策视为同一多面策略

文章反对把两种教育/政策分开，认为对还抗日的上中层既联合又按其妥协、动摇、反共程度斗争；对多数伪军/汉奸也保留转变通道。

这继续削弱永久身份分类，但“绝对坚决不愿悔改”仍缺判定程序。

## 1.10 用代表+领导定义新民主主义社会

文章把人民代表参与和共产党领导作为判断新民主主义社会的主要原则，并称根据地政治经济文化已具该性质，可作为全国模型。

```text
formal representation
+ party leadership
-> regime/social-type classification
```

该定义忽略 effective control、权利可用性、政策结果和可更替性，容易让组织自我认证制度性质。

# Pass 3 — Reasoning reconstruction

主要推理操作：

1. **episode closure / state refresh**：结束上一轮并更新环境；
2. **historical-analogy boundary**：用关键结构差异拒绝表面类比；
3. **explicit error diagnosis**：指出错在遗漏主要约束；
4. **time-versioned actor classification**：用跨事件行为更新类别；
5. **contingency/base-case separation**：准备最坏不等于预测最坏；
6. **branch shaping**：防下行同时争取较好路径；
7. **deterrence inference from non-event**：把未破裂归因准备；
8. **multi-aspect coalition policy**：联合与斗争针对 actor 不同方面；
9. **prototype-to-system inference**：根据地模式被定义为全国原型。

# Pass 4 — Adversarial reading

## 4.1 “决定一切”重新把主要矛盾变成唯一解释

V1-015/018 已显示 principal ≠ only；国内武装、组织、外援、领导与民意都可能改变结果。外敌约束很强，不等于即使国内主导力量全部投降也无法复现灾难。

## 4.2 历史类比错误不只属于下级

V2-038 中央公开谈话自己说全国性事变开端、全面破裂决心和十五步计划。复盘若只纠正“一些同志”，会遗漏上游信号对执行认知的贡献。

## 4.3 客观事实证明结论错，不证明指定原因唯一

没有复现 1927 可因民族战争、组织实力、地域控制、国际约束和双方利益共同造成；不能只验证“主要矛盾”一个解释。

## 4.4 镜像应对可能复制对方不当行为

“以其人之道”若没有独立规范，会把对方升级作为己方升级许可。合法目标、比例和不可越界权利必须先于 reciprocity。

## 4.5 项英归责仍是 hindsight simplification

未执行部分准备可能增加风险，但灾难的完整因果链和中央/地方责任没有由本文证明。

## 4.6 中间派个案可能被成功叙事选择

阎/桂变化能反驳固定类别，但不能证明现有分类规则预测准确。应把所有事前分类和事后行为放入 confusion matrix。

## 4.7 non-event 不能自动验证威慑

“准备后没有破裂”同时兼容多种解释。需要对方决策记录、感知信号、成本变化或比较案例。

## 4.8 最坏准备也会改变行为与成本

contingency 可能威慑，也可能刺激对方、消耗资源或使组织把正常信号都解释为攻击。方案需成本预算和 activation gate。

## 4.9 “仍在抗日”不能无限延长合作边界

一个 actor 在共同任务上贡献，不应免除其对严重侵害的责任；联合接口和权利/安全底线必须并存。

## 4.10 社会性质不能由领导者身份自证

代表参与若无信息、否决、组织和更替权，可能只是形式；共产党领导作为定义条件又使任何非本党领导的相同机制被排除，形成身份本体化。

# Pass 5 — Article-local candidate mechanisms

## H1-40-01 — Contingency preparation is not a probability assignment

为高损失分支准备不意味着它最可能，更不意味着其他分支关闭；prediction、preparedness level 与 activation trigger 必须分字段。

- Textual confidence: high
- Empirical confidence: high

## H1-40-02 — Prepare for downside while actively shaping the preferred branch

安全容量和积极塑造可同时进行；应分别评估准备成本、威慑/刺激效应和偏好路径行动的效果。

- Textual confidence: high
- Empirical confidence: high

## H1-40-03 — Historical analogies require structural state comparison

相似事件名称/暴力不足以证明同一阶段；需比较主导约束、actor 能力、组织韧性、外部环境和转换条件。

- Textual confidence: high
- Empirical confidence: high

## H1-40-04 — Actor classifiers should be scored on time-versioned behavior

保存每次分类时的特征与预测，用下一 episode 的行为构建 confusion matrix；不能只挑移动正确的 actor 讲故事。

- Textual confidence: high for observed changes
- Empirical confidence: high for validation rule

## H1-40-05 — Institutional type needs operational, rights and outcome axes

代表比例与领导结构只是制度特征；还需 effective control、权利可用、申诉、竞争/更替和结果，才能判断运行性质。

- Textual confidence: high that article uses a narrow classifier
- Empirical confidence: high as corrective rule
