# Pass 0 — Historical frame

这是为干部教育编写的课本，不是一次开放式调查报告。它试图从中国社会结构推导：

```text
国情 / 社会性质
-> 主要矛盾
-> 革命对象
-> 任务
-> 动力 / 联盟
-> 主要形式与空间路径
-> 当前阶段性质
-> 后续阶段
-> 组织能力要求
```

它写于抗战相持和第一次反共高潮前后；因此既是历史解释，也是为当时统一战线、农村根据地、武装斗争与党建提供一致化依据的行动模型。

# Pass 1 — Source / argument reconstruction

## 1.1 从环境描述进入决策模型

第一章先描述地理、人口、历史制度、近代资本与外国势力进入后的结构变化，再把中国定性为殖民地、半殖民地、半封建社会。

文本的推导链不是从目标倒推，而是宣称从当前结构推出目标：

```text
system diagnosis
-> adversary/constraint selection
-> coalition design
-> operating form
-> transition program
```

## 1.2 外部介入被建模为同时促进与阻碍

外国资本进入一方面分解自然经济并创造商品/劳动力市场，另一方面又与封建力量结合，压迫民族资本发展并取得军事、政治、金融、交通和文化控制。

因此同一变量不是单一正负效应：

```text
external capital
-> decomposition / new factors
and
-> dependency / extraction / blocked autonomy
```

## 1.3 “主要矛盾”依然是优先级，不是唯一变量

文本列出帝国主义—中华民族、封建主义—人民大众等主要矛盾，同时承认资产阶级—无产阶级和统治集团内部矛盾；在当时把帝国主义—中华民族置于最高优先级。

这再次支持：

```text
principal = highest decision weight in a stage
principal != only active relation
```

## 1.4 由敌方配置推导行动形式，但保留配套形式

敌方控制中心城市、军队和政治空间，加上地域广大、经济政治不平衡、敌营不统一及农民基础，被用来推导长期农村根据地与武装斗争。

但正文立即设边界：

- 主要形式是武装斗争，不等于放弃其它斗争；
- 着重农村，不等于放弃城市和其它农村；
- 根据地要同时具备军事、政治、经济、文化功能；
- 隐蔽区工作按有理、有利、有节逐步积蓄力量。

```text
primary operating mode
+ complementary modes
+ enabling bases
+ final-target interfaces
```

## 1.5 两个任务相互区别又相互依赖

民族任务与民主任务不是同一件事，但各自解决对方的支撑条件：外部支配支持内部地主结构；改变内部土地/群众结构又为抵抗外部支配创造力量。

因此它们不是两条独立队列，也不是简单合并：

```text
Task A removes support for Task B's obstacle
Task B builds capability for Task A
```

## 1.6 联盟分类由结构位置推导，但后来按行为重新细分

正文尝试按社会经济位置判断各阶级的行动倾向，并据此划分敌、可靠同盟、条件同盟和领导力量。

但版本史显示 1939 模型不够细：1940 年以后补充分离大/中小地主、亲日/非亲日大资产阶级、民族资产阶级与开明绅士。这表明：

```text
structural class
is a prior
not a sufficient real-time behavior classifier
```

## 1.7 规模、领导与联盟被拆开

农民被认作数量和实际斗争的主力；无产阶级被认作领导力量；知识分子具有先锋/桥梁功能；民族资产阶级是条件性同盟。

这与 V2-014 的角色分解一致：

```text
largest force != first mover != integrator != decision leader
```

## 1.8 当前阶段是有边界的过渡系统

文本拒绝把民主革命直接等同社会主义革命；当前阶段允许一般私人资本和富农经济存在，同时建设国营、合作和政治组织等后续转变条件。

```text
current-stage objective
+ protected non-targets
+ next-stage enabling conditions
+ transition gate
```

但“必要条件具备”没有操作化，阶段转移仍高度依赖领导者判断。

## 1.9 组织能力被放在长链末端，却是全链条的承载条件

结尾提出全国性、群众性、思想政治组织上巩固的党是完成两阶段任务的条件。原计划第三章党建未完成，因此文本提供了 capability requirement，却没有提供完整的 capability construction mechanism。

# Pass 3 — Reasoning reconstruction

主要推理操作：

1. **diagnosis-to-strategy chain**：从社会结构逐层推导对象、任务、联盟和形式；
2. **dual-effect decomposition**：同一外部变量同时产生解体与支配效应；
3. **priority among coexisting relations**：在多矛盾中设阶段优先级；
4. **environment-form fit**：按敌方控制、空间与经济结构选择行动形式；
5. **primary/complementary separation**：主要形式不排除配套形式；
6. **interdependent task design**：两个不同任务互相改变成功条件；
7. **role-decomposed coalition**：区分规模、先锋、桥梁、领导和条件同盟；
8. **stage boundary design**：规定当前目标、非目标和后续方向；
9. **model revision from new behavior**：1940 年新观察触发分类细化；
10. **capability prerequisite inference**：战略链条反推组织承载能力。

# Pass 4 — Adversarial reading

## 4.1 宏观定性可能把复杂历史压进单一理论框架

“三千年封建社会”“农民战争是历史发展真正动力”等强命题把制度、区域、商业化、国家能力、技术和跨国变化压缩过度，需现代史学独立复核。

## 4.2 从经济位置直接推行为仍是高风险 ontology

正文说政治态度“全依”社会经济地位决定，但自身的 1940 修订已经显示同一大类内部因地域、资本联系、战争行为和政治选择而分化。V1-004 暴露的宗族、地域、组织和恐惧等变量仍未被吸收。

## 4.3 “领导不可缺”主要由选择性历史解释支持

辛亥失败、大革命成败、抗战动员均为多因结果；把差异主要归于某阶级/政党领导，可能把参与、领导、资源、国际环境和敌方错误混在一起。

## 4.4 统一战线政权的实际权力分配没有被审计

“各阶级联合”与“无产阶级领导”同时存在，但谁定议程、谁否决、如何问责、何时退出并未规定。名义参与不等于实质共同治理。

## 4.5 当前阶段的保护边界不等于可信承诺

保存一般私人资本和富农经济的表述，与最终社会主义方向并存。若转移门槛和财产权保障不明确，条件同盟者会按未来征收风险而非当前口号行动。

## 4.6 世界趋势判断把方向确信借给了具体路径

“社会主义上升、资本主义下降”与中国必然走向社会主义的论证，混合了价值目标、国际预测和国内机制；后来中国制度方向不能验证全部全球因果链。

## 4.7 文化机构一律归为侵略工具是功能归因过度

传教、医院、学校、报纸和留学可能同时服务软实力、宗教、知识传播、医疗和地方行动者利益；需要组织级证据，不能仅凭外部来源判定统一目的。

## 4.8 “游民”分类带有污名和高误伤风险

将失业、乞讨、犯罪、性工作和宗教职业合并，容易从生计状态推导道德/组织风险；一旦连接准入或处罚，必须拆类并用行为证据。

# Pass 5 — Article-local candidate mechanisms

## H1-23-01 — Strategy should be derived through an auditable representation chain

```text
environment -> structure -> constraints -> actors -> tasks -> operating form -> capabilities
```

每一跳都应保留证据、替代解释和可修订接口，不能把开头的宏观标签当作后续结论的证明。

- Textual confidence: high
- Empirical confidence: high as an audit architecture; low-to-medium for this article's specific chain

## H1-23-02 — A primary operating form requires complementary interfaces

主要形式集中资源，但其它形式可能是其成功条件、情报接口或最终转移路径；“主要”不能授权删除补充系统。

- Textual confidence: high
- Empirical confidence: high

## H1-23-03 — Structural identity is a prior that must be updated by behavior

结构位置可形成初始倾向，但实时联盟/风险分类必须吸收行为、环境、组织关系和新证据。

- Textual confidence: high via the 1940 revision record
- Empirical confidence: high

## H1-23-04 — Stage programs need protected non-targets and transition gates

一个阶段不仅定义要改变什么，也要定义暂不改变什么、为下一阶段建设什么、哪些可观察条件授权转移。

- Textual confidence: high for targets/non-targets/direction; low for operational gate
- Empirical confidence: high as a planning requirement

## H1-23-05 — Multi-role coalitions should separate mass, expertise, initiation and authority

参与规模、专业/桥梁功能、主力行动和最终领导不是同一指标，不应由单一身份自动兼得。

- Textual confidence: high
- Empirical confidence: medium-high
