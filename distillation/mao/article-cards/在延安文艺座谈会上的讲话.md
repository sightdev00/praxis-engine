## B. Version identity warning

当前《毛选》正文不是未经编辑的 1942 年现场记录。现有版本史至少区分：1942 年速记/七七社本、1943 年《解放日报》及解放社本、1953 年《毛选》定本、1991 年注释修订本。1943 年文本加入过与“抢救运动”相连的“特务文艺”措辞；1953 年定本又删除全部相关文字，并有大量逻辑、书面化和政治术语修订。

因此本文必须同时保存三个对象：

```text
1942 forum event
!= 1943 public policy text
!= 1953/1991 Selected Works text
```

本卡以标准第二版为 corpus 对象，但凡涉及 1942 年信息状态、现场自由度或原始措辞，均不把后期定稿倒灌为同期事实。

# Pass 1 — Source / argument reconstruction

## 1.1 从“交换意见”进入方向性结论

引言把会议定义为交换意见，结论称数十名党内外人士发言使问题展开和具体化；但最终输出不是分歧记录，而是由讲话者确定“为什么人”“如何为”、批评标准和整风方向。

```text
participant input
-> issue elaboration
-> central synthesis
-> binding direction
```

这是一种 consultation-to-policy 结构。它能汇集现场知识，却没有说明异议如何保留、少数意见如何进入最终文本、综合者怎样被复核。

## 1.2 把文艺定位为战争与组织的行动组件

文艺被置于文化战线，目标包括团结、教育、打击敌人和帮助民族解放；后来又用“齿轮和螺丝钉”说明党的文艺工作服从一定时期的革命任务。

```text
artistic production
-> belief / emotion / coordination
-> collective action
-> political-military objective
```

文本同时承认文艺反过来影响政治，但优先级和目标由政治层确定。

## 1.3 以 actor class 决定表达态度

敌人、统一战线同盟者和人民内部被分配不同的歌颂、批评、反对和教育方式。对同盟者再按抗战、民主和艺术方法逐项形成不同范围的团结。

```text
actor classification + issue
-> permitted attitude / criticism intensity
```

这是 differentiated treatment，不是所有对象使用同一传播策略；高风险在于分类权与表达处分权集中于同一组织。

## 1.4 同时重定义受众、描写对象和知识来源

根据地的主要接受者被定义为工农兵及干部。文艺工作者不熟悉这些人、语言和生活，所以“了解人、熟悉人”被置于第一位；人民生活又被定义为创作的唯一源泉。

```text
audience / represented people / source community
-> field contact
-> observation + language learning
-> creation
-> audience use
```

文本把 production 与真实使用环境连接起来，这是相对上海小圈层生产模型的重大切换。

## 1.5 以长期共同生活改造生产者模型

作者以自己对知识分子、工农衣物“干净/不干净”判断的变化为例，认为只有长期甚至痛苦的磨练，知识分子才能改变感情并被群众接受。

这不仅是增加数据，而是改变 producer identity、默认受众和价值排序。问题是“改造完成”没有外部判据，可能由政治符合性代替真实理解和互信。

## 1.6 宣称从事实出发，但事实选择已受理论约束

结论反对从抽象定义出发，列出战争、统一战线、根据地环境、文艺运动和争论等现实，再从中找方针。但引言已经预设无产阶级/党的立场、存在决定意识和阶级化的爱、自由、真理、人性。

```text
selected facts
+ protected theoretical categories
-> policy inference
```

因此“从事实出发”不等于无前提归纳；真正需要审计的是哪些事实未被选入，以及何种证据能重新打开理论分类。

## 1.7 先确定服务对象，再定义质量问题

文本认为“为什么人”是根本原则，“如何为”随后才可解决。普及和提高都不能脱离工农兵的需要、接受能力和前进方向。

```text
intended beneficiary
-> need / access baseline
-> product level and form
-> improvement path
```

这避免了用生产者内部标准自证质量，但“工农兵需要什么、向哪里前进”仍主要由组织和文艺工作者解释。

## 1.8 把普及与提高设计成双向反馈环

文本拒绝“只普及”或“只提高”：普及提供提高的基础，提高反过来指导普及；一地经验可帮助另一地少走弯路，干部所需的高级作品也被视为间接服务群众。

```text
accessible form -> broad use -> audience capability rises
        ^                         |
        |                         v
advanced work <- specialist learning / synthesis
```

这是本文最强的 process architecture，但跨地区迁移仍需检查基础条件和效果差异。

## 1.9 区分生活源泉与历史作品借鉴

人民生活被定义为唯一“源”，古代和外国作品是由过去生活形成的“流”；优秀遗产可批判吸收，却不能替代此时此地的创造。

```text
current social life -> raw material
historical / foreign works -> reference and technique
creative labor -> new work
```

它反对机械模仿，保留选择性迁移；“唯一源泉”则是过强本体论断言，忽略想象、形式实验、个体记忆和非社会环境的不同作用。

## 1.10 把专门家放入中介与学习双重角色

专门家既帮助普及工作者，也向其学习群众材料；高级作品可先服务干部，再经干部教育群众。专业性被保留，但只有联系、表现并代表群众才获得正当性。

该结构允许 specialization，却形成一个代表链：

```text
masses -> popular worker -> specialist -> cadre -> masses
```

链条每增加一层都可能发生选择、失真和利益替换，文本未给出代表性审计。

## 1.11 以“最广、最远”处理功利冲突

文本不否认功利，而以占人口百分之九十以上群众的当前和未来利益统一，反对少数人的短期功利。

这是 beneficiary breadth 与 time horizon 的双维目标；但没有给出：人口估算来源、不同群众利益如何聚合、当前牺牲的上限、谁代表未来人。

## 1.12 将群众意见集中—提炼—返回作为政治接口

政治家被描述为把群众政治家的意见集中、提炼，再返回群众接受和实践，而不是闭门决定。文艺政治性与真实性的统一依赖此链。

```text
distributed experience
-> centralized synthesis
-> returned policy/message
-> acceptance and practice
```

这与后来的领导方法构成前序机制。当前文本没有提供拒收、竞争性综合或综合失败后的问责渠道。

## 1.13 统一战线按问题分层，而非按人永久归队

抗日、民主、艺术方法三个问题产生逐层缩小的团结范围；同一关系中可同时存在团结、斗争和批评。

这是 issue-specific coalition，避免把一个维度的一致外推为全面一致，也避免一次分歧自动变成全面敌对。

## 1.14 用动机—效果与政治—艺术两个轴评价作品

主观声明不能证明好心，作品在社会大众中的效果用于检验动机；艺术性不能被正确政治口号替代，政治性也不能被艺术性免除。

```text
intent + observed effect
x
political criterion + artistic criterion
-> criticism
```

文本反对单轴评价，却又规定政治标准第一；一旦政治判断支配“社会效果”的定义，两个轴可能在执行中重新塌缩为一个。

## 1.15 批评机制受敌我 classifier 控制

人民缺点应以保护、教育和内部批评处理，敌人则可被暴露、打击；讽刺不是取消，而是按敌人、同盟者、自己人改变方式。文本还宣称根据地给革命文艺家充分民主自由，仅不给反革命者自由。

自由边界因此是：

```text
freedom if classified revolutionary
no freedom if classified counterrevolutionary
```

若分类缺少独立审查和申诉，这不是稳定权利，而是可撤销许可。

## 1.16 马克思主义被限制为观察框架，又被用来清除情绪

文本说马克思主义不能替代现实主义创作，不应写成哲学讲义；同时又主张彻底破坏封建、资产阶级、小资产阶级、自由主义、个人主义等创作情绪。

这保留了 craft autonomy，却不保留目的、世界观和情感自主。方法层不替代，不等于治理层不控制。

## 1.17 座谈结论转为思想与组织整顿

结尾不只要求提高作品，而要求展开无产阶级对非无产阶级的思想斗争，使队伍在思想上、组织上统一巩固。问题的 actuator 从创作反馈升级为组织性整风。

## 1.18 以“新阶段”收束成可跟踪预测

文本相信整风和长期学习会改造作者及作品，创造许多受人民热烈欢迎的优秀作品，并把根据地和全国文艺运动推进光辉新阶段。这是方向预测，不是已经发生的结果。

# Pass 3 — Reasoning reconstruction

主要推理操作：

1. **mission decomposition**：政治任务下分文化/文艺战线；
2. **actor-conditioned treatment**：按敌人、同盟者、人民内部和具体议题选择态度；
3. **audience/source coupling**：接受者也是描写对象和知识来源；
4. **producer transformation**：长期共同实践改变生产者的语言、感情和模型；
5. **beneficiary-first design**：先定服务对象，再定普及/提高标准；
6. **two-level feedback**：普及提供提高基础，提高指导下一轮普及；
7. **source/reference separation**：现实生活与历史/外国作品承担不同角色；
8. **specialist-mediator loop**：专业者、一线传播者、干部与群众互联；
9. **breadth-horizon utility**：用覆盖面和时间尺度反对狭隘功利；
10. **centralize-refine-return**：分布意见经中心综合后回到实践；
11. **issue-specific coalition**：联盟范围按议题变化；
12. **intent-effect audit**：声明由实际后果检验；
13. **dual-axis evaluation**：政治与艺术、内容与形式都需达标；
14. **organizational enforcement**：创作争论最终接入思想和组织整顿。

# Pass 4 — Adversarial reading

## 4.1 群众同时是源泉和对象，却不是最终决策者

文本要求向群众学习，但无产阶级方向、政治标准和未来利益由党及其文艺系统解释。participation in data collection 不等于 participation in objective setting、评价或否决。

## 4.2 “受欢迎/有益效果”可能被组织环境共同制造

传播渠道、批评权限和组织纪律会影响哪些作品可见、哪些反馈可说。若效果数据来自受同一治理系统控制的环境，就不能独立验证动机与政策正确性。

## 4.3 “从事实出发”保留了不可重开的理论层

阶级分类、党的立场和文艺服从政治先于事实清单被确定。若反例只能被解释为作者尚未改造，理论层便免于证伪，继续触发 M-04 protected-layer audit。

## 4.4 生活是重要来源，不是可证成的唯一来源

社会经验、语言和关系确实给作品提供材料；但形式发现、想象、梦、个体记忆、自然经验和抽象实验不宜被强行还原成一个单一源。更稳健的命题是“现实使用环境是不可替代的校验来源”。

## 4.5 普及—提高环需要可迁移性门槛

一地经验不因成功就能指导另一地；受众语言、识字率、媒介、风险和偏好不同。需要迁移前比较状态变量，而不是以先进地区替落后地区规定路径。

## 4.6 干部/专门家中介链可能替代群众意见

多层代表链能放大能力，也能把群众需要转换成干部教育目标。需记录每层输入、删改、异议和返回后的理解/拒绝，不能以“代表群众”自证。

## 4.7 “最广、最远”不能自动解决权利与分配

多数长期利益可能被用来压倒少数当前伤害；未来利益也无法直接观测。应分开覆盖率、利益/伤害分布、不可逆损失、异议权和代际折现。

## 4.8 政治标准优先会吞并艺术与真实性标准

文本承认艺术规律和反对口号化，却让政治标准处于第一位。若政治不合格直接排除作品，艺术轴只在预筛后的集合中有效；若“真实性”又由政治集中机制保证，独立纠错空间进一步缩小。

## 4.9 敌我分类使民主自由承诺不稳定

同期王实味由批评者被转成反党/托派负面典型，说明“革命文艺家有充分自由、反革命者没有”的边界能在冲突中移动。无独立证据、申诉和恢复机制时，classifier 本身是最关键的权力接口。

## 4.10 对人民只教育、不“暴露”会削弱向上问责

保护性批评可避免敌意污名；但若制度缺陷、干部利益或群众内部伤害都被定义成不宜公开的“人民缺点”，公共批评会被内部教育替代，决策者较难受到可见约束。

## 4.11 思想改造可能混淆学习与服从

与使用者共同生活能修正知识分子偏见；但“彻底破坏”一组情绪、思想和身份，且最终以组织统一验收，会把认知更新、道德自省与政治服从混为一体。

## 4.12 版本修订暴露后见性与政治性编辑

1943 年加入“特务文艺”，1953 年删除，并有数百处修改。后版可能更清晰、也可能把特定政治失误从经典文本移除。版本控制必须记录 added/removed claim、当时 actuator 和现实后果，而不能只保留定稿。

## 4.13 后来文艺发展不能总体验证治理机制

群众形式、下乡实践、劳动英雄叙事和新作品的发展支持“进入生活—改变题材/形式”的部分机制；它不证明政治标准优先、公开异议受限或每一种思想改造都是必要条件。结果必须按机制拆分归因。

# Pass 5 — Article-local candidate mechanisms

## H1-3-08-01 — Couple producer research to real users and represented subjects

让生产者进入真实使用/生活环境，分别记录使用者、被描写者和受影响者的语言、任务、约束与反馈；不以代表声明代替共同验收。

- Textual confidence: high
- Empirical confidence: high for field contact; medium for identity transformation as a requirement

## H1-3-08-02 — Run accessibility and capability growth as a coupled loop

可达产品形成使用与能力基础，较高级产品再指导下一轮普及；两条轨道共享反馈，但不允许任何一方永久垄断资源。

- Textual confidence: high
- Empirical confidence: high with audience measurement and migration controls

## H1-3-08-03 — Separate primary environment evidence from inherited solution forms

当前环境、用户行为和结果是不可替代的校验来源；历史/外部方案作为结构、技巧和反例库，不直接替代本地问题定义和创造。

- Textual confidence: high
- Empirical confidence: high after weakening the source's “唯一源泉” claim

## H1-3-08-04 — Preserve specialists inside a two-way field interface

专门家既向一线参与者提供高阶工具，也持续从其取得材料与失败反馈；以任务结果、理解和可纠错性验收，不以身份服从验收。

- Textual confidence: high
- Empirical confidence: high

## H1-3-08-05 — Evaluate intent through disaggregated, independently observable effects

不以自我声明证明动机；同时把理解、使用、利益、伤害、分布、持续性和表达自由分开测量，并检查反馈是否受评价者控制。

- Textual confidence: high for intent/effect link
- Empirical confidence: high for expanded control

## H1-3-08-06 — Build coalitions per issue rather than per permanent identity

分别记录各方在目标、治理、方法和具体行动上的同意/分歧；一个维度的合作不自动升级为全面信任，一个维度的冲突也不自动升级为全面敌对。

- Textual confidence: high
- Empirical confidence: high

## H1-3-08-07 — Keep high-consequence actor classification independent and appealable

当分类决定表达权、批评方式或惩罚强度时，分类者不得同时作为争议当事人和终审者；保留证据、申诉、期限、复核和恢复。

- Textual confidence: high that the source creates classification-dependent rights
- Empirical confidence: high for the corrective control

## H1-3-08-08 — Version policy texts as decision artifacts, not timeless transcripts

对每次公开版本记录时间、受众、增加/删除的判断、触发环境和 actuator；后版不得无痕覆盖早期高后果主张。

- Textual confidence: high from variant history
- Empirical confidence: high

## Working judgment

本文最可复用的不是“文艺必须服从政治”，而是一个 producer—environment—audience feedback architecture：生产者进入真实生活，区分现实来源与历史借鉴，让普及和提高循环，让专门家与一线参与者互学，并用效果而非自我声明检查工作。它最大的系统风险也来自同一架构的治理层：党组织预先确定目标、分类对象、解释群众利益并控制批评边界。现代迁移必须保留现场学习和双向反馈，同时拆除不可申诉的敌我 classifier、单一政治预筛和以组织统一替代真实效果的验收方式。
