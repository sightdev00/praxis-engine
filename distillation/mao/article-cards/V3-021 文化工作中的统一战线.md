# V3-021 文化工作中的统一战线

# Pass 0 — 历史情境

战时、低识字率且联通不足的地区面临文化、医疗和教育供给短缺。文件提出先使用既有机构与从业者，而不等待全新的专业体系成熟。

# Pass 1 — 原文／论证重构

```text
覆盖不足 + 既存做法 + 战时稀缺
→ 使用正规与非正规学校、旧新文艺、旧新医药
→ 先团结，再批评、教育、改革

改革需要群众参与
→ 真实需要 + 知情自愿
→ 避免代替群众和形式主义运动
```

文本把文化视为战争和生产的条件，指出文盲、迷信和有害医疗实践是障碍，并主张动员、逐步改变旧机构与旧从业者，而非简单废弃。

# Pass 2 — 证据审计

见 `../evidence/v3-021/evidence-ledger.md`。识字率、医生与人口数字是决策当时的主张；讲话直接证明既定政策，却不证明每个地区的改革都出于自愿或有益。

# Pass 3 — 推理重构

1. **能力桥梁**：一面使用不完善的既有供给，一面建设新能力；
2. **双重错误控制**：反对无标准吸收，也反对在没有替代服务时排斥；
3. **有序改变**：关系和参与先于可持续的改革；
4. **需要与同意闸门**：不能把规划者偏好变成群众的需要。

# Pass 4 — 对抗性阅读

“为人民”和“改革”仍由权威定义。等待多数同意可能保护自主，也可能在权力或错误信息压制声音时延迟紧急保护；反过来，若没有异议、退出、专业独立和补救，“教育”会变成强制。健康与迷信的主张应有结果、伤害和可及性指标，不能只是文明等级标签。

# Pass 5 — 本篇候选机制

## H1-3-21-01 — 在不神化旧体系的前提下建设过渡能力

绘制既有从业者、可及性和风险；在透明质量标准下合作；培训并扩展替代方案；保留独立申诉和安全退出。

- 文本置信度：高
- 实证置信度：中

## H1-3-21-02 — 以需要、同意和可逆性约束参与式改革

扩大前检验受影响群体表达的需要、理解与自愿采用；另行提供紧急保护，并记录拒绝而不施惩罚。

- 文本置信度：高
- 实证置信度：中

# Pass 6 — 跨篇更新

V3-013 的反馈循环和 V3-017 的自愿合作边界在本篇重现。新的结论是：仅有参与还不够，改革者必须公开其标准、保留拒绝权，并测量不均等的收益与伤害。

## 工作判断

可迁移机制是在真实需求和自愿采用约束下，从既有能力逐步过渡到改进服务。其失败形态是家长式“改革”：保留统一语言，却否认平等发声和独立核验。
