# Pass 0 — 历史情境

蒋介石发言人把拒绝“原地待命”称为违抗命令，并称人民军队为“人民公敌”。日本投降尚未完成，受降和城市控制已成为国共冲突的直接接口。

# Pass 1 — 原文／论证重构

把继续抗日称为违令 → 以“人民公敌”等标签压制异议 → 公开发出全面内战信号 → 共产党坚持反对内战、壮大民主力量、解放敌占城市并采取自卫反击 → 联合政府是制止内战的制度方案。

# Pass 2 — 证据审计

见 ../evidence/v4-004/evidence-ledger.md。发言人原话和历史命令是直接证据；“内战信号”“人民公敌标签愚蠢”以及自卫力量足以制止内战是作者的政治判断，需与后续战事分开。

# Pass 3 — 推理重构

1. 将身份标签视为冲突升级信号；2. 用历史行为反驳宣传词；3. 把反内战原则与武装自卫并列；4. 以力量平衡而非单纯呼吁和平阻止进攻。

# Pass 4 — 对抗性阅读

标签确有动员和去合法化作用，但作者也以同样强烈的“人民公敌”反标签回应，可能形成互相升级。历史类比能揭露叙事矛盾，却不自动证明当前行动者的全部动机。自卫与进攻的边界必须依照时间、地点和行动证据判断。
