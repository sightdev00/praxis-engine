# V3-023 游击区也能够进行生产

> 状态：依现行协议完成首轮蒸馏  
> 日期：1945-01-31  
> 文类：《解放日报》社论／游击区生产政策

## A. 识别

- 原文：[《游击区也能够进行生产》](https://www.marxists.org/chinese/maozedong/marxist.org-chinese-mao-19450131.htm)，1945 年 1 月 31 日《解放日报》社论。
- 直接证据基础：社论主要援引 1 月 28 日关于晋察冀张平凯部队 1944 年生产的报道。因此，它直接证明该政策主张和一则被报道的个案；并不独立验证该个案的全部数据。

# Pass 0 — 历史情境

决策难题是：在据点、封锁沟墙、反复进攻与频繁转移下，部队和村民能否实际维持生产。文本反对“只有巩固根据地才能生产”的看法，并将一则被报道的成功个案转化为 1945 年广泛动员的信号。

# Pass 1 — 原文／论证重构

```text
游击式机动 + 敌方控制 + 物资紧缺
→ 不能照搬定居地区的常规生产

据称的地方适应 + 警戒与生产协同
→ 部分粮食、衣物和作坊供给
→ 减轻物资压力并改善军民关系
→ 推动 1945 年更大范围生产
```

社论列举小块分散、夜间耕种、利用敌人工事改变的地形、帮助缺劳力农户、适应转移的作物选择和小型作坊，并主张把战斗任务与生产结合。它还声称无偿帮助民耕改善了给养和关系，并把战争界定为军事、政治、经济三方面的竞赛。

# Pass 2 — 证据审计

见 `../evidence/v3-023/evidence-ledger.md`。原文提供了一套细密的操作办法和若干产出、战果数字；但成功个案由正主张扩大化的同一报纸挑选，缺乏总体样本、失败案例、安全记录和独立账目。

# Pass 3 — 推理重构

1. **先验可行性而非类推照搬**：检验最低限度生产能否经受扰动，而非整体移植巩固区模式；
2. **适应性组合**：把耕作、修复和作坊分散到多个小机会中，避免单一暴露点；
3. **任务耦合**：共同安排警戒、转移、粮食和民间劳力需要；
4. **互惠主张**：将帮助民耕作为军队供给关系的一部分，而不只是汲取；
5. **扩大化推断**：把个案当作学习和试验的理由，不能当作普遍推广已经成功的证明。

# Pass 4 — 对抗性阅读

社论既不能证明所列数字，也不能证明生产导致了战斗效能。一个突出单位可能不具代表性；报道没有记录失败地块、作物损失、伤害、农户拒绝、土地权利、机会成本，或“无偿帮助”是否出于自愿。“能够”只建立可能性，结尾的普遍运动号召却可能在没有同等地形、安全与权利条件时滑向“必须”。在敌据点附近生产还可能把风险转嫁给平民。

# Pass 5 — 本篇候选机制

## H1-3-23-01 — 把受扰地区生产作为有保护的能力试验

开展由当地选择的小规模试点，明确安全阈值、参与者同意、伤害／损失报告、家庭分配记录和立即停止规则。扩大前须把成功案例与中止或造成伤害的尝试一并比较。

- 文本置信度：高（针对探索可行性的逻辑）
- 实证置信度：低至中；原文仅提供一个被挑选的个案

## H1-3-23-02 — 将后勤韧性与对平民的互惠收益合并评估

把军队供给与平民劳力负担、作物损失、补偿、食物分配和申诉渠道一并评估。若单位把未记录的危险或无偿劳动转给家庭，便不能称其为自给。

- 文本置信度：中
- 实证置信度：未决

# Pass 6 — 跨篇更新

V3-015 与 V3-022 已把生产和组织耐力相连，V3-021 则要求真实需要与自愿参与。本篇加入高扰动边界：地方适应可能使机动条件下的生产成为可能，但一则宣传性成功报道不能授权普遍生产义务。安全压力越使拒绝失去实质，V3-017 对强制合作的警戒就越重要。

## 工作判断

可迁移的经验是在扰动下试验有韧性的地方供给方法，并保存失败和平民成本的记录。文本富有操作想象力，但当它把一个内部报道的成功个案视为普遍运动的充分依据时，结论便明显变弱。
