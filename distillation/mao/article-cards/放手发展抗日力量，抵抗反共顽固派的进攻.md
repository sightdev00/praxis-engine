# Pass 0 — Historical frame

本文不是抽象统一战线论文，而是一次总部对区域执行偏差的纠正。中央认为东南局把本地特殊性当作不发展、不准备的理由，要求在敌后扩大军政经教能力，同时在国民党区域采用完全不同的隐蔽积蓄策略。

```text
central strategic invariant
-> classify operating environment
-> choose environment-specific posture
-> assign rollout owner/deadline/report
```

选集后来的结果注释提供了重要事故线索，却也可能把复杂失败压成“未服从正确中央路线”的单因果故事。

# Pass 1 — Source / argument reconstruction

## 1.1 “强调同一性”只在明确 scope 内成立

文章说华北、华中、华南，不同地形和不同部队在敌后/战争区域都面对敌人、都在抗战，所以都有发展可能和必要。

```text
shared mission + shared adversarial condition
-> common strategic invariant: build capability
```

它不是否定地理、组织和环境差异，而是反对用差异否定共同能力目标。

## 1.2 “发展”被拆成完整地方系统

发展不只是扩军，还包括根据地、群众动员、政权、财政、税收、经济、农工商业、学校和干部。

```text
military
+ governance
+ finance
+ economy
+ education/cadres
+ public organization
-> durable autonomous base
```

这是 capability portfolio，不是单点增长；同时也意味着对区域的实际控制、征税与组织扩张，不能仅以“抗日”目标免于合法性/民众成本审计。

## 1.3 目标被数字化并绑定时间

中央此前要求一年内在江浙敌后扩大到十万人枪并迅速建政，本文追问具体部署。

```text
strategic direction
-> numeric/time commitment
-> request implementation plan
```

这是目标/命令，不是对现实将自动发生的预测。是否合理需用起点、资源、补给、招募质量和风险评估，不能因后来增长而自动验证。

## 1.4 对等反制把抽象“斗争”映射到具体接口

对于调动、募兵、宣传、法律与军事压力，文件主张分别提出针锋相对的反要求或行动。

```text
specific restriction channel
-> matched countermeasure in same/related channel
```

它提高响应的可操作性，但“针锋相对”不自动保证事实归因、比例或最低损害。

## 1.5 下级被授权提出强硬异议

文件明确说有理之事不只中央可提，部队任何部分也可向上级提出强硬抗议，并举下级对上级的例子。

```text
local evidence / harm
-> local voice and escalation
-> challenge higher authority
```

这为实时信息下沉处置和向上反馈提供接口；但同时“坚决执行中央方针”仍限制对中央判断本身的挑战。

## 1.6 强硬策略同时承担内部心理/组织功能

文件认为斗争能振奋精神、团结干部、扩大力量并使组织为突发事变准备。

```text
external stance
-> internal confidence/readiness
```

这种二阶效果可能真实，也可能奖励升级姿态、压制风险报告，把谨慎误作软弱。

## 1.7 局部冲突被解释为战略侦察而非系统转换

文章把当前冲突判断为局部、对方战略侦察和投降准备步骤，尚非全国剿共或立即投降。

```text
severe local probe
!= system-level transition
```

这与 PRED-017 一致；风险是将对方行动目的解释得过于确定，且“侦察”标签可能低估局部灾难成本。

## 1.8 局部发展被视为跨区威慑

江北胜利/发展被认为会降低顾祝同在江南进攻意愿；全国各区发展则增加避免投降和争取好转概率。

```text
capability in region A
-> adversary cost/risk update
-> protection in region B
```

这是 cross-theater deterrence 假设，需要观察对方决策；皖南事变后来至少表明威慑并未消除重大攻击风险。

## 1.9 运行环境变化会翻转策略参数

敌后/战争区域强调公开发展；国民党统治区与日占城市则强调隐蔽精干、长期埋伏、积蓄力量、利用合法空间和保护干部。

```text
same high-level objective
+ different control/surveillance environment
-> opposite operational visibility and tempo
```

因此全文不能被抽象为“放手扩大”通则；适用策略依赖 authority、exposure 和 repression risk。

## 1.10 安全审查采用近乎零容忍门槛

国民党区域组织人员从书记到伙夫逐一严审，稍有嫌疑者不得留在领导机关；暴露干部应转移。

这是对真实捕杀风险的安全响应，但“稍有嫌疑”缺证据等级、复核和申诉，容易产生误排、恐惧与内部清洗。

## 1.11 指令有 owner、deadline 和 result report

文件指定皖南/苏南传达者，要求一个月内完成讨论传达，并由项英统筹工作、报告结果。

```text
decision
-> named owner
-> deadline
-> dissemination
-> execution
-> result report
```

相比 V2-029/031 的要求清单，这是一条更完整的交付链；仍缺共同验收指标和异常升级渠道。

# Pass 3 — Reasoning reconstruction

主要推理操作：

1. **scoped invariant extraction**：在同一工作域寻找共享战略约束；
2. **capability portfolio design**：军政经教组织共同建设；
3. **target-to-plan conversion**：量化目标并追问部署；
4. **channel-matched countermeasure**：按限制渠道设计反制；
5. **upward challenge authorization**：允许地方对更高权威抗议；
6. **local/system transition separation**：不把局部冲突自动视为全国转折；
7. **cross-region deterrence model**：以一地能力影响另一地风险；
8. **environment-specific posture**：公开发展或隐蔽积蓄随环境切换；
9. **security screening**：降低渗透与捕杀风险；
10. **owner/deadline/report rollout**：把指示连接到责任链。

# Pass 4 — Adversarial reading

## 4.1 同一性可能压平关键地方条件

共享敌人与任务不证明各区具有相同群众基础、补给、交通、敌我密度或政治许可。共同目标不等于共同可行性函数。

## 4.2 “不靠上级”与中央精确命令有张力

地方被要求自给、自主，却由中央规定规模、区域、节奏和政治路线。责任下放与决策权下放并不一致。

## 4.3 十万人枪目标可能制造指标替代

人员/武器数量易测，但训练、补给、纪律、群众成本、指挥跨度和长期能力更关键。硬期限可能诱发低质量扩张或虚报。

## 4.4 对等反制可能形成升级镜像

每一限制都以更强要求回应，双方都可称自卫。没有共同事实和损害门，针锋相对可能把局部争议连接成多渠道升级。

## 4.5 强硬带来的内部士气不能证明外部正确

团结干部和振奋勇气是组织效果，不是 actor model、军事行动或因果判断正确性的证据。

## 4.6 “战略侦察”是高置信意图推断

同一行动可用于试探、压迫、区域争夺、组织控制或更大战役准备。应保留竞争解释并定义可区分证据。

## 4.7 跨区威慑没有考虑反向刺激

本方发展可能提高对方攻击成本，也可能提高其阻止扩张的紧迫感。V2-035 自己拒绝“我发展使彼投降”的相反模型，却没有实证比较两条路径。

## 4.8 “稍有嫌疑”审查门损害反馈系统

极低证据门会使成员隐藏不确定性、关系或错误，安全系统可能因此更难看到真实风险。高敏感度必须配合复核、分级权限和恢复机制。

## 4.9 秘密打入组织涉及现代不可迁移边界

在历史地下斗争语境中的渗透策略不能直接迁移到现代 Agent 行为；它涉及欺骗、隐私、授权和法律风险，必须排除为一般技能规则。

## 4.10 后来灾难不能证明中央方案全对

“未执行 A 后发生 B”不等于“A 能防止 B”。编者注需要反事实、其他原因和中央决策责任审计；否则失败被用作事后服从性证明。

# Pass 5 — Article-local candidate mechanisms

## H1-35-01 — Transfer invariants only within an explicit scope

先声明共享任务、约束和环境，再迁移战略原则；地理/组织差异可改变参数甚至翻转可见度与节奏。

- Textual confidence: high
- Empirical confidence: high

## H1-35-02 — Quantitative targets need quality and downside guardrails

规模/期限可迫使计划具体化，但必须同时记录能力质量、资源、系统负荷、负外部性和停止条件，防止指标替代。

- Textual confidence: high that text uses a target
- Empirical confidence: high for added controls

## H1-35-03 — Local actors need an upward evidence challenge path

靠近实时风险的执行者应能用证据挑战上级限制；同样也应能挑战中央假设，而不只强化中央路线。

- Textual confidence: high for local protest authorization
- Empirical confidence: high with symmetric extension

## H1-35-04 — Security screening requires tiered access and appeal

高风险组织需要审查与保护暴露人员；“任何嫌疑即排除”应改为证据等级、权限分层、独立复核、申诉和定期重评。

- Textual confidence: high that strict screening is used
- Empirical confidence: high for modern controls

## H1-35-05 — Directives need owner, deadline, report and exception route

执行链至少要明确责任人、期限、传达范围和结果报告；另需异常、资源不足和反证向上升级机制。

- Textual confidence: high
- Empirical confidence: high

# Pass 6 — Cross-article update

### Refines the centralize-invariants/localize-actions pattern

V2-008/033 已支持全局约束集中、局部参数适配；本文显示环境分类可让策略参数翻转。现代 Agent 先判定 control/exposure context，再套用不变量，不能从一句“强调同一性”推出跨域复制。

### Tests but does not validate V2-034 bounded conflict

本文复述有理、有利、有节，并给具体反制；同一策略链的重复不是独立证据。反而“针锋相对”和零容忍审查暴露了比例、归因和权利门仍不足。

### Preserves PRED-017 without duplicate counting

“局部侦察、非立即全国内战”与 V2-027/031 同源。皖南事变将检验严重局部事件与系统不转移是否能同时成立，不新建重复预测。

### Adds target/forecast separation

“一年十万人枪”是有 owner 的控制目标，不是中立预测。最终账本应分别记录：forecast（认为会发生）、target（要促成）、commitment（承诺交付）和 outcome，避免用行动后果反证/证实错误对象。

### Adds hindsight attribution control

编者注将皖南损失主要连接到项英未执行。本研究保留该解释为后来 O7 hypothesis，不把它合并进 1940 年的证据集，也不把灾难当作中央方针“绝对正确”的自动验证。
