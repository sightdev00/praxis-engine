# Pass 1 — Source / argument reconstruction

## 1.1 从外部形势到当前任务采用分层映射

结构非常紧凑：

```text
international state
-> Japan's current operating mode
-> China's war stage
-> internal coalition risks
-> region-specific tasks
-> party resilience preparation
```

不是直接从“国际新形势”跳到一个统一动作。

## 1.2 相持阶段被明确视为可逆状态

文章说相持局面“基本上已经到来”，但如果：

- 敌占区经营成功；
- 政治进攻成功；
- 中国不能坚持团结进步；
- 国民党政府投降；

敌方仍可能恢复大规模进攻。

因此：

```text
state entered
!=
state locked
```

阶段具有维持条件和失效条件。

## 1.3 同一阶段在不同空间生成不同任务

- 敌后：游击、反“扫荡”、破坏敌占区经营、改革；
- 正面：支持防御、打退战役进攻；
- 后方：政治改革；
- 党自身：思想、政治、组织巩固，准备突然事变。

这是一个 context-to-task routing，而非 one-policy-for-all。

## 1.4 “突然事变”被当作组织设计输入

文章要求组织在没有具体知道事件内容前，就通过巩固党、军队、政权减少意外损失。

中性结构：

```text
known uncertainty / shock risk
-> build generic resilience before exact event is known
```

这与预测具体事件不同。

## 1.5 前文国际模型被几乎原样继承，缺少重新打开

苏联进波兰、英法/日本动机等判断被直接写入正式决定。这说明一个重要风险：

```text
analysis narrative
-> organizational decision
```

一旦跨过 commitment boundary，未经充分挑战的上游模型会进入执行层。

V2-019 已发现其中至少有重大隐藏变量，因此本文是“错误/不完整模型传播到组织承诺”的可定位案例。

# Pass 4 — Adversarial reading

## 4.1 上游判断的错误会被制度放大

V2-019 的波兰解释在本文再次出现，但重复进入正式决定并不增加其真实性，只增加了组织采纳程度。

## 4.2 “最大危险”仍可能过度锁定候选空间

把投降、分裂、倒退设为最大危险有行动价值，也可能使其它战略风险被低估。需要 risk register，而不是只保存 top-1 risk。

## 4.3 Resilience 指令过于抽象

“思想上、政治上、组织上巩固”若没有可观察指标，可能变成不可验收的口号。

# Pass 5 — Article-local candidate mechanisms

## H1-21-01 — State models need maintenance and invalidation conditions

进入某阶段后仍应记录：

```text
what keeps this state true?
what observations would invalidate it?
what fallback state follows?
```

- Textual confidence: high
- Empirical confidence: high

## H1-21-02 — Global strategy should route to context-specific workstreams

- Textual confidence: high
- Empirical confidence: high as an organizational design principle

## H1-21-03 — Known uncertainty can justify resilience investment without pretending to predict the exact shock

- Textual confidence: high
- Empirical confidence: high

## H1-21-04 — Repetition after commitment is not independent evidence

这是研究控制：分析进入正式决定后再次出现，只能证明 adoption，不应自动提高 empirical confidence。
