# Pass 1 — Source / argument reconstruction

## 1.1 先保护总路线，再开放作风问题

文章明确说总路线正确、没有问题、工作有成绩，随后才承认思想作风问题相当严重。

```text
freeze strategic/top-level model
-> diagnose method and execution layers
-> correct within protected objective
```

这能避免改革被理解为路线崩溃，也会产生 correction scope lock：若上层模型错误，证据只能被吸收到下层作风解释。

## 1.2 将三个可见问题映射到不同生成层

```text
subjectivism -> study/thought method
sectarianism -> organizational relations
stereotyped writing -> communication form
```

文章进一步说后两者是主观主义的组织/表达表现，形成从认识方法到组织与输出的因果链。

## 1.3 用“非主导但持续作怪”校准问题规模

主观主义、宗派主义和党八股被称已非统治地位，却仍反复袭击、需要研究分析和抵制。

```text
not dominant
!= absent
-> retain monitoring and correction
```

这种残余风险表达比全盘危机更校准；没有 prevalence、episode 或 severity 数据。

## 1.4 把理论产出定义为实践材料的抽象

理论不足不是读书少，而是没有把中国经济、政治、军事、文化实践考察并提升到科学、周密的理论。

```text
rich practice
-> detailed inquiry
-> abstraction / explanation
-> theory
```

理论不是权威文本库存，而是对当前问题的可解释模型。

## 1.5 用 application depth 评价理论学习

党校应按学习者能否看清中国问题、能解释多少、多普遍、多深刻来评价优劣。

```text
learning assessment
!= recall
= application breadth + depth + explanatory power
```

它延续 V3-002 的 local transfer test；“正确/看清”由谁判、如何防止路线一致性替代证据准确性，未规定。

## 1.6 把书本知识与亲历知识都视为片面

只读书缺实际证明；只凭工作经验则偏感性、局部，容易把局部经验当普遍真理。

```text
book/general model without local contact -> dogmatism
local experience without abstraction/comparison -> empiricism

combine
-> more complete knowledge
```

这是重要的对称纠偏：并非只尊崇基层经验或只尊崇理论。

## 1.7 用互补角色设计知识生产团队

有书本知识者向实际发展；有经验者学习理论并把经验系统化。工农干部还需文化基础以获得理论工具。

```text
formal/model skill
+ situated/operational skill
+ enabling literacy
-> joint theory-practice capability
```

这比要求每个人立即全能更接近团队能力设计，但文章仍主要期待个人互相转化。

## 1.8 构造理论的验证循环

以马克思为例，详细调查研究、概括成结论，再拿到实际斗争中证明。

```text
observe
-> abstract
-> apply/test
-> evidence of fit
```

这是 Praxis loop 的强文本基础；“实际证明”需区分预测、干预、结果、替代解释和失败成本。

## 1.9 同时建立封闭知识 ontology

文章说知识只有生产斗争与阶级斗争两门，自然/社会科学是其结晶，此外没有知识；又说马克思列宁主义是最正确最科学真理。

```text
preferred ontology/model
-> declared exhaustive and already verified
```

这与“从实际发展理论”发生张力：异常若落在预设两类之外，可能被重新编码而非扩展 schema。

## 1.10 将参加实际工作称为书本型知识者转化的唯一办法

这强调 embodied practice，但“唯一”忽略观察、模拟、案例、协作、复现和安全试验；更忽略某些高风险实践不能为学习直接暴露。

M-03 reversibility gate 必须优先于 action-as-learning。

## 1.11 以全局/局部关系支持集中统一

宗派主义的第一类被定义为局部利益凌驾全党，要求少数服从多数、下级服从上级、局部服从全体、全党服从中央。

```text
coordination failure / local capture
-> central priority and common objective
```

它解决局部寻租和执行碎片化，也会把上行坏消息、地方差异和对中央错误的挑战误分类为“闹独立性”。

## 1.12 把关系冲突的主要责任放到高权力方

外来/本地、军队/地方、老/新干部发生关系失败时，文章多次说通常应由负领导责任、掌权或资深一方承担主要责任。

```text
asymmetric authority
-> greater duty to understand / include / repair
```

这是明确的 responsibility gradient，能约束“双方各打五十大板”；仍需具体事件因果，不能按身份自动定责。

## 1.13 按互补优势设计多组关系

外来干部有跨地经验，本地干部熟悉情况和群众；老干部有经验，新干部对新事物敏感、热情；军队与地方各有任务信息。

```text
different situated advantages
-> mutual learning
+ promote underrepresented local/new members
-> organizational continuity and local fit
```

这把 diversity 的价值从名额提升到互补信息和 succession。

## 1.14 识别部门本位与资源负外部性

只顾本部门、拒调干部或以劣质人员支援，被定义为以邻为壑。

```text
local metric optimization
-> shift cost to other unit
-> damage system objective
```

这是组织级 local/global optimization 问题；中央统一并非唯一解，还可用共享指标、转移价格、接口承诺和跨部门验收。

## 1.15 把成员—非成员合作设为必要条件

党员永远是少数，若不同党外人员联合便不能胜利，因此对愿意/可能合作者只有合作义务、没有排斥权利。

这延续 V3-005 的 scoped invariant；“可能合作”仍由组织一方判断，外部 actor 的独立目标和退出权未展开。

## 1.16 以完全统一作为组织结果

整风目标多次表述为队伍整齐、步调一致、清除无原则派别斗争和达到完全团结统一。

```text
shared goal / coordinated action
```

可提高执行可靠性；若把 epistemic disagreement 也清除，会破坏 V1-005 的认识阶段多意见和 V3-005 的外部反证通道。

# Pass 3 — Reasoning reconstruction

主要推理操作：

1. **correction scope lock**：先冻结总路线，再修方法/组织/表达；
2. **root-to-manifestation mapping**：认识偏差生成组织与传播偏差；
3. **residual-risk monitoring**：非主导问题仍需持续控制；
4. **practice-to-theory abstraction**：从材料形成解释模型；
5. **transfer-based evaluation**：按真实问题解释能力评学；
6. **symmetric incompleteness**：教条主义与经验主义是两极片面；
7. **complementary-role integration**：形式知识与在地经验结合；
8. **theory validation loop**：抽象后回到实践检验；
9. **global/local optimization**：压制局部利益损害整体；
10. **authority-responsibility gradient**：高权力方承担更多关系责任；
11. **situated-advantage pairing**：外来/本地、军地、老新互补；
12. **unity as execution mechanism**：共同目标与集中提高协调。

# Pass 4 — Adversarial reading

## 4.1 被保护的总路线使纠错可能只向下归因

若结果不好，原因只能落在干部思想、组织或表达，中央目标与策略无法成为 competing hypothesis。V2-040 已出现相同结构：中央高警报不审，只纠正干部误读。

## 4.2 “正确解释”可能退化为路线一致性评分

应用测试比背诵好；若教师/中央预先拥有正确答案，学生对现实的独立发现仍可能因不合路线被判错。

## 4.3 知识二分法造成 ontology lock-in

把所有知识归入生产/阶级斗争会压缩照护、生态、心理、文化、伦理等独立机制；即使可强行归类，也会失去有用分辨率。

## 4.4 理论循环缺竞争模型与失败登记

“在实践中证明”容易只保存成功案例。需事前预测、替代解释、失败边界和撤销规则。

## 4.5 直接实践不是唯一且可能不安全

对高代价行动，应先读已有失败、模拟、shadow、pilot；经验生成不能为不可逆伤害授权。

## 4.6 教条主义被定为更危险缺比较证据

它可能确实在当时权力结构中更能伪装，但文章没有给出 dogmatism/empiricism 的事件频率、损失或纠错成本比较。

## 4.7 中央化可能放大全局错误

局部最优化会伤害系统，中央错误也可同步扩散到全体。集中需要上行证据、异议保护、有限自治和可逆 rollout。

## 4.8 将异议与私利/不老实绑定会压低坏消息

人格化批评可能惩罚真实寻租，也会使善意 dissent 不敢表达。应审行为和证据，不以立场不同推断道德。

## 4.9 高权力责任不能替代事件因果

领导者负更多程序/修复义务合理；具体事故责任仍需命令、信息、资源和可预见性链，不能身份自动归责。

## 4.10 “完全团结统一”混淆认识与行动

行动 commitment 后可统一执行；commit 前需要多模型竞争。整风若追求思想结论完全一致，会摧毁 epistemic deliberation。

## 4.11 组织成就和全民族示范是 self-validation

“作风正派后全国跟学、任何敌人可打倒”既无指标也无反事实；组织凝聚不是胜利的充分条件。

## 4.12 外来/本地和老/新仍是粗分类

身份组内能力差异大；互补优势应由任务证据验证，不应成为固定本质。

# Pass 5 — Article-local candidate mechanisms

## H1-3-06-01 — Audit the protected layer of every correction process

每次复盘明确哪些目标、模型、角色或制度被预先宣布不可质疑；要求为每个 protected layer 提供退出条件或独立审查。

- Textual confidence: high that source protects the general line
- Empirical confidence: high for the corrective audit

## H1-3-06-02 — Pair abstract models with situated experience

一般知识缺现场约束，局部经验缺比较和抽象；以互补团队、共同任务和双向学习连接，保留各自证据来源。

- Textual confidence: high
- Empirical confidence: high

## H1-3-06-03 — Evaluate theory by discriminating application, not conformity

用未见案例的解释、预测和安全干预结果评价模型；评分者不得把与既有路线一致当作正确代理。

- Textual confidence: high for application, low for anti-conformity boundary
- Empirical confidence: high

## H1-3-06-04 — Assign greater relationship duty to greater power

高权力/资历/控制资源者承担更多倾听、信息获取、纳入、修复义务；具体过错仍按事件证据分配。

- Textual confidence: high
- Empirical confidence: high

## H1-3-06-05 — Prevent local optimization with shared outcome interfaces

除共同目标外，记录跨部门资源请求、拒绝成本、下游影响和共同验收，避免把成本转给邻接单元。

- Textual confidence: high for problem
- Empirical confidence: high for control

## H1-3-06-06 — Separate epistemic diversity from committed execution

决策前保护竞争模型和异议；承诺后在安全边界内协调行动；新证据触发重新开放，而非追求永久思想一致。

- Textual confidence: high that source seeks unity, low that it preserves this boundary
- Empirical confidence: high

## H1-3-06-07 — Treat theory and ontology as versioned hypotheses

任何自称完备的知识分类或最正确理论都必须保留异常、竞争 schema、版本和撤销条件。

- Textual confidence: high that source closes theory/ontology
- Empirical confidence: high for corrective rule

# Pass 6 — Cross-article update

### Adds a protected-layer audit to the active protocol

V2-040 将中央公开警报排除在错误归因外；本文先宣布总路线无问题，再把 correction 限定到干部作风。两个不同任务触发同一风险，研究协议正式增加：任何自我纠错框架都要列出 protected layer 和 challenge path。
