# Pass 0 — Historical frame

文章处于第一次反共高潮之后、第二次高潮之前。它既要阻止党员因冲突而把国民党整体敌对化，也要阻止“团结”变成接受限制或攻击，因此用“坚决者/非坚决者”和“行为停止后恢复友好”维持可重新进入的联盟边界。

```text
shared national objective
-> broad default inclusion
-> narrow exclusion / defensive response
-> reclassify coerced or temporary-error actors
-> restore cooperation after harmful behavior stops
```

这提供了错误可恢复与关系重置的机制线索，但“反共”参与门把批评、竞争与攻击混在一起，会侵蚀所宣称的多党政治。

# Pass 1 — Source / argument reconstruction

## 1.1 共享责任不取消组织差异责任

民族存亡被称为全国共同责任，共产党同时认为自身责任更大，要求党员做抗战和团结的模范。

```text
shared outcome responsibility
+ role/capability-specific responsibility
```

这种不对称责任可由能力、承诺和影响力解释；若只来自自我指定领导身份，则可能变成更大权力的正当化。

## 1.2 抗战与团结被构造成相互依赖

文章说只有抗战到底才能团结到底，也只有团结到底才能抗战到底。

```text
resistance sustains coalition
coalition sustains resistance
```

这是反馈环，不是独立因果证明；需要同时追踪冲突是否由共同任务缓解，以及联盟是否实际提高战争能力。

## 1.3 用一个地方样本支持“强硬者是少数”

作者称调查某地方政府 1300 人，其中坚决反共者 40–50 人，不足 4%，随后支持“任何地方都只占少数”的判断。

```text
one local administrative sample
-> universal prevalence claim
```

这是非常清楚的外部效度错误：样本选择、分类标准、地区差异和隐藏态度均未知。

## 1.4 把敌对行为细分为不同可恢复状态

除坚决投降/反共者外，文章区分两面、被迫、一时错误，并要求争取其继续抗日。

```text
observed deviation
-> persistent hostile commitment?
-> coerced behavior?
-> temporary error?
-> ambiguous/double behavior?
-> differentiated response
```

这比错误即永久身份更可更新；但“坚决”如何判定、两面派如何证伪，仍缺程序。

## 1.5 用双边界控制左右偏差

无原则接受限制/攻击被标为右倾；不团结一切尚能抗日者被标为左倾。

```text
lower boundary: preserve autonomy / resist attack
upper boundary: maximize viable coalition
```

这是 policy corridor，而非中点折衷；但边界仍由党内路线定义，不能自动证明具体分类正确。

## 1.6 三三制在公共文本中被再次承诺

文章公开反对国民党及共产党一党专政，主张党员只占政权/民意机关三分之一，其他抗日民主党派和无党派占三分之二。

相比 V2-033 的内部指示，这是一项 public commitment，可作为后续运行审计基线。

## 1.7 多党权利带有“不得反共”前置条件

个人和党派只要不投降、不反共，就可参加政权或享有存在活动权。

```text
plural rights
subject to loyalty / non-opposition gate
```

若“反共”包括反对政策、组织竞争或批评领导，它与多党代表和民主自由直接冲突；必须窄化为可证实的暴力/破坏行为才有边界。

## 1.8 行为停止后关系应恢复

对未制造军事磨擦的友军保持友好；即使曾发生磨擦，只要停止，也恢复友好。

```text
harmful behavior stops
-> terminate punitive state
-> restore cooperation interface
```

这使冲突处理不是永久身份惩罚，与 V2-034 的休战原则相互支持。

## 1.9 统一战线政策被扩展到多资源域

财政、经济、文化、教育、锄奸等均要求调节阶级利益，同时防止两端偏差。

这说明联盟不是单一组织协议，而是资源分配、知识权与安全权的复合治理；尤其“锄奸”属于高后果分类器，不能只用一般平衡语言控制。

## 1.10 对下一年提出可评分的风险排序

文章预测世界战争扩大、许多国家革命爆发、日本南进并加紧对华进攻、投降危险空前加重，并称抗战第四年将是最困难的一年。

这是多组件预测：全球革命、日军方向、国内 actor 反应、年度困难峰值应分开评分，不能因其中一项命中就验证整套世界模型。

# Pass 3 — Reasoning reconstruction

主要推理操作：

1. **differential responsibility**：共同任务中按角色承担不同责任；
2. **mutual-dependence modeling**：抗战与团结构成反馈；
3. **sample-to-population inference**：由局部政府样本推全国；
4. **recoverable actor states**：坚决、被迫、暂错、两面分别处理；
5. **policy corridor**：用左右边界限制策略漂移；
6. **public institutional commitment**：公开三三制与多党参与；
7. **behavioral reset**：停止冲突后恢复友好；
8. **multi-domain interest adjustment**：联盟规则进入资源/文化/安全领域；
9. **component forecast bundle**：把国际、军事、政治与时间风险打包预测。

# Pass 4 — Adversarial reading

## 4.1 更大责任可能被用来主张更大控制权

责任、能力、风险承担和决策权应分别记录。自称责任最大不能自动赋予不可挑战的领导或信息垄断。

## 4.2 单地 4% 没有代表性

该政府可能本就经过筛选；坚决反共的分类可能依赖自报或作者判断；未观察到的态度不等于希望团结。不能外推“任何地方”。

## 4.3 坚决/非坚决阈值可能随政治需要移动

没有行为次数、严重度、时间和复核规则，原本可争取者可在冲突时被迅速升级为永久敌人。

## 4.4 “反共”不是可接受的宽泛权利限制

一个民主联合政权必须允许反对执政党的政策、组织竞争和和平更替。只有明确违法暴力、协敌或破坏行为可进入相应程序，而且仍需证据与申诉。

## 4.5 关系恢复不能跳过受害修复

停止磨擦后恢复合作有助降级，但严重伤亡、财产和信任损失还需调查、责任、赔偿、保证和监控；reset 不等于 erase history。

## 4.6 调节利益缺最低权利与不可交易项

财政经济利益可谈判，言论、身体安全和程序权利不能只按联盟稳定权重交换。

## 4.7 锄奸不能与普通政策共用模糊中道

安全分类直接连接拘捕/惩罚，需要远高于财政文化政策的证据、权限和复核标准。

## 4.8 全球革命“必然爆发”复用历史方向先验

战争危机确会增加部分政治动员，但各国出现改革、威权巩固、殖民变化或革命的条件不同，不能由危机直接推出同一路径。

## 4.9 “最困难一年”没有共同量尺

伤亡、领土、物资、组织生存、联盟裂痕和国际支持可能给出不同排序。superlative forecast 必须先定义 metric 和 comparison set。

# Pass 5 — Article-local candidate mechanisms

## H1-36-01 — Treat actor error states as updateable, not permanent identities

区分持续恶意、强迫行为、暂时错误和歧义可以保留恢复路径；分类必须基于行为、证据、期限与复核，而非不可证伪标签。

- Textual confidence: high
- Empirical confidence: high

## H1-36-02 — Ended harmful behavior should reopen cooperation with repair controls

停止事件应触发退出对抗状态，但严重事件还需事实确认、修复、保证和监控；恢复接口不等于删除责任。

- Textual confidence: high
- Empirical confidence: high with added controls

## H1-36-03 — Public commitments create future audit baselines

内部制度设计在公共文本中重申后，应作为外部可引用的承诺，后来运行需按席位、权利和行为数据审计。

- Textual confidence: high
- Empirical confidence: high

## H1-36-04 — Never generalize prevalence from an unqualified convenience sample

局部样本需要 sampling frame、分类可靠性、缺失与地区异质性审计；强全称不能由一个样本支持。

- Textual confidence: high that article commits this error
- Empirical confidence: high as corrective rule

## H1-36-05 — Superlative forecasts require a metric and comparison window

“最大、最难、空前”必须拆成指标、单位、时间、比较集和阈值，否则结果无法证实或反驳。

- Textual confidence: high
- Empirical confidence: high
