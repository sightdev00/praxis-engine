# Pass 0 — Historical frame

V1-015 刚刚提出“和平已经取得，下一阶段中心任务是争取民主”。会议中有人用新的不利信号反驳这一阶段判断：日本表面后退、南京动摇、国内矛盾上升，以及苏州审判、压制罢工、东北军东调等事件。

所以本文实际面对的是一个典型的在线更新问题：

```text
previous stage judgment
+ new adverse observations
-> should the model revert to the old stage?
-> or does the old stage remain achieved but not consolidated?
```

# Pass 1 — Source / argument reconstruction

## 1.1 “取得”与“巩固”是两个不同状态

文章首先反驳一种二值理解：

```text
和平已经取得
!=
和平已经巩固
```

它明确允许：

- 波折；
- 暂时倒退；
- 旧政策残余；
- 对方破坏企图继续存在。

因此状态模型至少有：

```text
not achieved
-> achieved but unstable
-> consolidated
```

而不是 `false / true`。

## 1.2 新的不利信号不自动把系统重置到旧阶段

文章主张：西安事变后和平局面由多方力量共同促成，不能由某一个行动者轻易单独推翻。因此局部反复应和形成新状态的结构性条件一起评估。

这形成：

```text
new local adverse evidence
+
structural conditions supporting current state
-> reassess persistence probability
not
-> automatically revert state label
```

这是我们的结构化重写。

## 1.3 但这里存在一个重要版本差异

### Selected Works wording

选集版把反对意见的方法问题写成：

> 不从“根本之点”出发，而从许多局部和一时现象出发。

### Earlier/unedited wording

较早版本则写成：

> 他们“不但从根本之点（日本后退、南京更动摇，民族矛盾下降，国内矛盾上升）出发，而且也从许多局部与一时的现象出发，并把二者联贯起来”。

这不是无关紧要的文字润色。两版的 epistemic critique 不同：

```text
Later selected version:
local/temporary phenomena substitute for a deeper structural view

Earlier version:
a wrong high-level structural assessment + local observations are combined into a pessimistic model
```

因此 Praxis Engine **不能**从选集版单独抽象出“只看局部、不看根本”的永恒方法而忽略版本层变化。更稳妥的共同结构是：

> 不利观察必须放入一个可审计的总体模型；局部证据不能孤立一般化，但“总体/根本模型”本身也可能是错误假设。

## 1.4 方向与残余风险可以同时存在

文章同时坚持：

```text
总体方向：和平 -> 民主 -> 抗战
```

和：

```text
旧内战/独裁/不抵抗结构仍有残余
+ 可能波折/回头
```

因此：

```text
trend direction
!=
absence of adverse residuals
```

## 1.5 对手的目标/风险可能不变，但实现方式发生变化

文章说国民党/资产阶级中破坏共产党的倾向仍存在，但方式从：

- 战争/屠杀；
- 硬政策；
- 军事政策

转向：

- 改良/欺骗；
- 软政策；
- 政治政策。

这提示：

```text
actor objective/risk may persist
while
interaction mode changes
-> countermeasure must change
```

## 1.6 阶段中心任务是有依赖关系的序列

文章继续解释：

```text
和平是此前抗日的必要条件
-> 和平取得
-> 民主成为当前抗日的关键条件
-> 民主又支持抗战
```

和平、民主、抗战被描述为相互条件化，但不同阶段中心项不同。

因此不是简单 task list，而是：

```text
same long objective
+ changing binding condition by stage
-> changing current center
```

## 1.7 长期目标不能跳过当前必要阶段

“上篇做好，才能做好下篇”的比喻再次区分：

```text
long-term direction
and
current phase requirements
```

支持未来目标，并不允许跳过当前民主革命阶段。

## 1.8 组织能力必须与任务规模匹配

面对全国规模任务，文章反对依靠狭窄小团体，强调发现和培养大量干部、领导者。

这里的结构是：

```text
mission scale increases
-> coordination / local problem-solving demand increases
-> leadership/cadre capacity must scale
```

但“干部决定一切”这类强表述不能被现代迁移为个人英雄主义模型；系统、制度和工具同样决定可扩展性。

## 1.9 组织控制方式本身随阶段改变

文章说：

```text
反动/内战时期 -> 集中制表现较多
新时期 -> 集中制应更密切联系民主制
```

也就是说，不仅对外策略随阶段变，**内部 governance mode 也随环境和任务变化**。

## 1.10 会议不同意见 -> 解释/讨论 -> 形成一致

本文本身就是一次异议处理记录：报告后出现不同意见，结论先逐项回应。

但“最后一致”不能被当作正确性的证据；它只能说明组织完成了一次 deliberation-to-commitment 转换。

## 1.11 “正确方针”到真实群众行为之间存在长的转化链

结尾明确说，把党的方针变成群众的方针，需要：

- 长期；
- 坚持；
- 耐心；
- 宣传；
- 鼓动；
- 组织。

所以：

```text
policy statement
!=
behavioral adoption
```

中间有一个长期 translation / distribution / organization layer。

# Pass 4 — Adversarial reading

## A1 — “历史总规律”可能免疫局部反证

如果一切坏消息都被解释为“暂时、局部、旧毒残余”，总体趋势就很难被推翻。

可靠版本必须补充：

```text
What magnitude/duration/pattern of adverse evidence would force us to downgrade or reverse the stage judgment?
```

## A2 — 选集版本身改变了方法论表述

较早版不是简单“只看局部”，而是承认反对者也有自己的“根本估计”，再把局部事实和这个高层模型连接。

所以不能把后期编辑版当作唯一窗口来重构 1937 年即时推理。

## A3 — 把对手软化手段解释为“欺骗”可能预设恶意

行为方式变化是真实可观察对象，动机标签仍需独立证据。

## A4 — “民主在任何情况下都适用”之类断言过强

作为政治价值主张可以成立，但作为“当前中心任务”的因果判断仍需环境证据。

## A5 — 干部规模论可能过度个人化组织能力

人员能力重要，但规模任务还需要制度、信息系统、分工、工具和反馈架构。

## A6 — 会议达成一致可能包含权力结构效应

不能由最终一致反推最初异议已被真正证伪。

# Pass 6 — Cross-article update summary

## Strong refinement — current state vs stable state

V1-014 introduced provisional actor update; V1-016 now gives a general state distinction:

```text
signal / initial transition
-> achieved state
-> consolidation
```

This is useful for avoiding binary completion labels.

## P2 strengthened — mode transitions require method transitions

V1-015: armed/illegal -> peaceful/legal work requires retraining.  
V1-016: opponent's hard/military methods -> soft/political methods require new countermeasures; internal democratic/central balance also changes by stage.

## P2 strengthened — long-term direction vs local evidence

V1-006 warned against local-to-global extrapolation. V1-016 repeats the issue, but its variant difference forces a stronger formulation:

> neither local observations nor a preferred high-level model should be privileged without an auditable relation between them.

## Important source-criticism lesson

The V1-016 variant demonstrates that **edition history can change the apparent reasoning method itself**, not just rhetoric. Methodologically important texts therefore need variant audit before G2/G3 promotion.

## First-pass takeaway

本文给 Praxis Engine 增加的不是“坚持正确方向”这一口号，而是更可审计的状态控制：

```text
区分状态开始、取得、巩固
-> 对新坏消息同时检查局部性与结构性
-> 方向判断允许波折，但必须预设可失败条件
-> 对手的目标与手段分开跟踪
-> 当前中心任务由阶段依赖关系决定
-> 任务规模变化要求组织能力和治理模式变化
-> 组织一致只说明进入共同承诺，不证明认识必然正确
-> 方针到真实行为之间必须经过长期翻译、组织和反馈
```

同时，版本差异提醒我们：**文本本身也是证据对象；编辑后的“方法论清晰度”不能反投射为原始决策现场中已经存在的清晰度。**
