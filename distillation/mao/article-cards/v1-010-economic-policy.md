# Pass 0 — Historical frame

V1-008 之后约五个月，中央根据地经济建设已有更多结果数据。当前仍处战争和封锁环境，但经济工作从“必须开始重视”进入更完整的政策架构阶段。

核心问题：

```text
在封锁、战争、资源有限、小农与分散手工业占主导的条件下
-> 哪些经济部门优先？
-> 哪些可以计划到什么程度？
-> 国家、合作社、私人经济怎样并存？
-> 财政金融如何不透支真实经济基础？
```

# Pass 1 — Source / argument reconstruction

## 1.1 延续“可能且必须”原则

经济政策开头再次限定：

```text
一切可能的和必须的经济建设
```

并同时服务：

- 战争供给；
- 群众生活；
- 工农联合；
- 国营/合作社长期发展。

这不是无限建设清单，而是阶段内的选择框架。

## 1.2 经济建设内部也要排序

正文把农业置于当前第一位，理由是农业同时决定：

- 粮食；
- 棉麻等日用品原料；
- 糖、纸等生产原料；
- 畜产、林业等基础供给。

不是因为农业抽象地更“重要”，而是它在当前经济结构中具有更高基础依赖度。

## 1.3 把农业问题拆成具体约束

文章列出：

```text
劳动力
耕牛
肥料
种子
水利
```

并根据不同约束配置不同组织手段：

- 劳动互助社/耕田队；
- 妇女参加生产；
- 犁牛合作社；
- 水利建设；
- 试验场、农业学校、展览所。

这比“提高农业生产”更接近 constraint-specific intervention。

## 1.4 用历史前后状态支持制度—激励解释

正文描述：

```text
根据地建立初期生产往往下降
-> 地权未定、秩序未稳

土地分配后 + 鼓励生产
-> 劳动积极性提高
-> 生产恢复甚至超过此前水平
```

这是一个因果解释，但需要对天气、战争、低基数等共同变量保持审计。

## 1.5 控制/计划精度随对象结构变化

工业部分有一句非常值得保留：

```text
散漫手工业基础上 -> 全部精密计划不可能

主要国营/合作社事业 -> 相当精密生产计划完全必要
```

而精密计划具体要求：

- 原料生产；
- 敌区/本区市场；
- 生产与销售匹配。

这实际上在做：

```text
system observability + controllability
-> feasible planning resolution
```

现代映射必须标为我们的分析语言。

## 1.6 当前经济形态允许多种所有制并存

正文同时提出：

- 国营事业只限可能且必要部分；
- 私人经济只要在法律范围内，应鼓励和奖励；
- 私人经济当前占绝对优势并将在相当长时期保持优势；
- 合作社和国营经济长期发展。

这是明显的阶段性政策：长期方向和当前可行结构并不要求立刻一致。

## 1.7 贸易政策也是约束驱动，而非全面接管

敌方封锁导致出口困难，但正文利用内部市场，并选择若干必要商品由国家直接经营，而不是全部商品国家垄断。

这延续 V1-008 的选择性介入逻辑。

## 1.8 财政金融被绑定到真实经济基础

正文规定：

```text
财政收入 -> 主要从国民经济发展增加
```

并特别说纸币发行应基本根据国民经济发展需要，单纯财政需要只能居次。

也就是说，不允许把金融工具当作脱离真实产出约束的无限资源。

## 1.9 生产改善不只靠宏观制度，还增加实验和知识基础设施

文章提出：

- 小范围农业试验场；
- 农业研究学校；
- 农产品展览所。

说明在大规模推广之外，还需要实验、技术知识和示范机制。

# Pass 3 — Reasoning reconstruction

## R1 — Prioritize by dependency structure

农业当前第一位，因为多个关键供给依赖它。

## R2 — Decompose broad shortage into actionable constraint classes

劳动力、耕牛、水利等分别处理，而非统一称为“农业困难”。

## R3 — Match intervention to the specific constraint

不同问题使用不同组织与技术工具。

## R4 — Match planning resolution to system structure

分散且难观测系统不能假装可精确控制；集中、可核算部分可以更精密计划。

## R5 — Separate long-term direction from current feasible institutional mix

长期方向不等于当前立即替换现有结构。

## R6 — Use real-economy anchors to constrain financial expansion

货币/财政必须受真实生产与经济发展约束。

## R7 — Add experimentation/knowledge generation before or alongside scale

试验场、研究学校、展览所提供学习基础设施。

# Pass 4 — Adversarial reading

## A1 — 产量恢复的因果归因仍不充分

土地分配和生产组织可能重要，但天气、战争强度、低基数、人口流动等变量未被控制。

## A2 — “农业第一位”是特定结构判断，不是通用产业顺序

现代迁移只能保留 dependency analysis，不能保留行业排名。

## A3 — 计划精度判断需要可观测性证据

文章正确承认分散手工业不能全面精密计划，但并没有明确测量计划误差、信息延迟或执行成本。

## A4 — 多种经济形态并存仍服务于既定政治长期目标

这是历史政策选择，不等同于一般经济最优理论。

## A5 — 货币发行绑定经济需要的原则合理，但“经济需要”本身仍可能被政治机构误判

约束的存在不等于约束测量正确。

## A6 — 试验场/研究学校是学习机制，但不能由提出机构自动推断其实际成效

后续若有运行数据才能评价。

## First-pass takeaway

V1-010 将 V1-008 的阶段经济原则推进为更细的运行模型：

```text
识别当前结构性优先项
-> 将大问题拆成具体约束
-> 为不同约束选择不同工具
-> 按系统可观测/可控制程度决定计划精度
-> 区分长期方向与当前可行组合
-> 用真实生产能力约束财政金融
-> 在知识不足处建立实验与学习设施
```

对 Praxis Engine 的新约束是：**控制越精细，不代表越先进；超过系统可观测性和执行能力的精细计划，本身就是一种虚假的确定性。**
