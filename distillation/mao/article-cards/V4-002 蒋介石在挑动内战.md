# Pass 0 — 历史情境

日本尚未完成事实投降。朱德命令解放区抗日军队依据波茨坦公告促使敌伪投降；国民党则要求解放区军队原地待命，同时命令其嫡系推进。受降权和战后地盘控制因此重叠。

# Pass 1 — 原文／论证重构

依据盟国公告进攻并受降 → 扩大解放区、缴获武器 → 与“驻防待命、不得擅自行动”形成冲突 → 后一命令客观上保护敌伪、限制抗日力量 → 蒋介石正在借受降问题挑动内战；共产党应拒绝不利于民族利益的命令，同时准备民主联合政府。

# Pass 2 — 证据审计

见 ../evidence/v4-002/evidence-ledger.md。命令文本、波茨坦公告和日期是强一手证据；“有利敌人”“勾结敌伪”“挑动内战”是作者的动机与因果判断。后续冲突可验证风险方向，不能证明每一项命令的单一意图。

# Pass 3 — 推理重构

1. 以“是否仍在抵抗”界定受降时点；2. 对照同一领导者给不同军队的命令；3. 用受降、武器、交通线和地盘控制识别内战准备；4. 将拒绝命令与继续抗日包装为同一民族利益框架。

# Pass 4 — 对抗性阅读

两套命令确实存在张力，但军事通信、地方治安和盟军受降安排也可能影响行动。作者把地下军概括为伪军和特务，属于高强度身份归类，需保留具体名单和证据。拒令是否扩大内战风险，必须与其他行动者和后续谈判同时评估。

# Pass 5 — 本篇候选机制

并列记录命令对象、允许行动、受降权限、资源和实际执行；若规则只约束一方，就形成内战预警。

把敌军停止抵抗、缴械、受降代表到场和领土控制分别记账，避免口头投降导致误判或被动放弃行动。

- 文本置信度：高
- 实证置信度：中

# Pass 6 — 跨篇更新

V4-001提出和平谈判与防御准备双轨；本篇把双轨具体化为“继续对日作战”和“防止受降权转为内战工具”。新增约束是：任何停火或待命命令都要写清敌方事实状态、适用对象和撤销条件。

## 工作判断

本篇最可迁移的是用可比命令和事实受降标准识别隐藏的权力转向。最大风险是把政治归因当作已证实动机，并把拒令的民族正当性自动等同于所有后续军事行动的正当性。
