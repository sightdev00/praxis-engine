# Pass 0 — Historical frame

西安事变刚刚和平解决。蒋介石接受若干停止内战、转向抗日的条件并恢复自由，但公开声明仍含糊。问题从 V1-012 的“某些力量可能转向”进入现实验证阶段：

```text
potential alignment change
-> initial signal appears
-> should trust/status be upgraded now?
```

# Pass 1 — Source / argument reconstruction

## 1.1 先承认行为变化，但只称“开始”

撤离陕甘内战军队被视作转变的开始，而不是完成。

## 1.2 区分声明内容与可验证行动

文章评价公开文字不足以证明诚意，真正判断标准被转到后续行动：

```text
是否撤兵
是否释放政治犯
是否停止“剿共”
是否联合抗日
是否保障权利
...
```

并明确说将在今后行动中考察。

## 1.3 合作承诺本身也是条件化的

共产党表示：若蒋介石/国民党实际改变政策、采取抗日步骤，则给予支持。

因此双方关系不是一次永久身份变更，而是：

```text
observable behavior
-> provisional trust/update
-> conditional reciprocal commitment
```

## 1.4 外部压力改变行动者可选路径

文章认为蒋介石不仅受“信义”约束，也受到日本、国民党内部派别、全国民意等现实力量结构约束。

所以 actor behavior 不是只用道德品质解释，而是受外部约束和激励共同影响。

# Pass 4 — Adversarial reading

## A1 — 验证条件仍带有一方政治目标

这些不是中性指标，而是该统一战线策略希望对方做到的行为。

## A2 — 单次撤兵也可能是战术行为

不能仅由一个初始动作推出长期立场改变；文章本身其实保留了这个警惕。

## A3 — 对蒋介石动机和外部派别压力的解释仍是推断

可观察行为比心理归因更可靠。

## A4 — “言必信行必果”式道德语言不应替代制度验证

现代迁移应优先里程碑、可观测行为和退出条件，而非人格信誉标签。
