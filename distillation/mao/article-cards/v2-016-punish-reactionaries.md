## A. Identification

# Pass 0 — Historical frame

本文针对平江惨案作追悼演说。核心问题不是抽象“团结”，而是：

> 一个名义上共享抗战目标的联盟，如果内部出现伤害共同目标参与者的行为，而正式法律/治理机制长期不处理，这种联盟是否还具有实际一致性？

# Pass 1 — Source / argument reconstruction

## 1.1 单个严重事件被用作系统一致性的检验样本

文章从平江惨案出发，不把它只当局部刑事事件，而把它视为全国抗战联盟内部规则失效的证据。

```text
shared declared objective
vs
actual treatment of actors serving that objective
-> test whether system is truly aligned
```

## 1.2 “统一”被重新定义为共同目标上的行为一致，而非形式服从

正文拒绝把统一理解为取消差异或单方控制，而把它具体化为：

- 抗战；
- 团结；
- 进步；
- 对支持这些目标的行为奖赏；
- 对破坏这些目标的行为制裁。

因此名义结构与实际 incentives/enforcement 被连接起来。

## 1.3 共同规则没有执行者，就不构成有效约束

文章特别追问：事件发生后“法律和法官”为什么长期没有处理。

这指出一个治理结构：

```text
rule / shared norm
without
credible enforcement / adjudication
-> weak operational constraint
```

## 1.4 奖惩系统必须与声明目标方向一致

文中反复使用：

```text
support shared objective -> should be protected/rewarded
sabotage shared objective -> should be sanctioned
```

如果实际结果反过来，则被视为“没有统一”的证据。

## 1.5 内部破坏被视为联盟可靠性风险

继 V2-015 后，本文把风险进一步从“可能投降/分裂”落到真实暴力事件和制度不处理。

因此 actor reliability 不只看声明，也看：

- 对共同参与者的实际行为；
- 是否尊重共同规则；
- 是否接受共同问责。

# Pass 2 — Evidence audit

详见 `../evidence/v2-016/evidence-ledger.md`。

平江惨案本身是具体事件；但本文把事件直接解释成某些参与者“准备投降”的步骤，这部分动机因果需要独立证据，不能与事件事实混为一体。

# Pass 3 — Reasoning reconstruction

- incident-as-system-test;
- declared-goal vs incentive/enforcement consistency;
- governance gap analysis;
- coalition reliability assessment;
- motive attribution from harmful behavior.

# Pass 4 — Adversarial reading

1. 从单一严重事件推断整个联盟结构可能过度外推，需要同类事件频率和制度响应数据。
2. “杀害抗日人员 -> 准备投降”的因果链比“破坏联盟”更强，正文未充分证明中间机制。
3. 强调制裁若缺乏独立证据标准、程序和申诉机制，可能转化为以“共同目标”为名的政治惩罚。
4. 奖惩一致性虽重要，但系统目标本身也可能错误，不能只检查执行是否一致。

# Pass 5 — Article-local candidate mechanisms

## H1-16-01 — Declared alignment should be tested against enforcement behavior

组织/联盟说什么不够，要看实际规则保护谁、惩罚谁、忽略谁。

- Textual confidence: high
- Empirical confidence: high as a governance audit heuristic

## H1-16-02 — Rules without credible adjudication are weak operational constraints

只有规定而没有调查、裁决、执行和责任链，规则很可能停留在名义层。

- Textual confidence: high
- Empirical confidence: high

## H1-16-03 — Incentive and sanction direction should match the shared objective

如果系统持续奖励破坏目标的行为、惩罚实现目标的行为，目标声明本身没有治理意义。

- Textual confidence: high
- Empirical confidence: high

## H1-16-04 — Sanction mechanisms require evidence and procedural safeguards

这是 Praxis 的现代补丁，不是原文结论：高影响制裁必须有证据门槛、责任主体和复核机制，否则“目标一致性”会成为任意惩罚的授权。

- Textual confidence: n/a (A-layer safety mapping)
- Empirical confidence: high as a modern governance requirement
