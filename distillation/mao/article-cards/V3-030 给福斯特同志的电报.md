# Pass 0 — 历史情境

美国共产主义政治协会特别会议决定放弃白劳德的修正主义、投降主义路线并重新成立美国共产党。毛泽东以贺电把美国共产党内部路线变化与中国面临的内战危机连接起来。

# Pass 1 — 原文／论证重构

美国共产党恢复马克思主义领导 → 美国工人阶级运动能力增强 → 可反对美国反动资本集团对中国国民党反动政策的支持 → 有利于中美人民的抗日战争、战后和平与民主建设。

# Pass 2 — 证据审计

见 ../evidence/v3-030/evidence-ledger.md。电报直接证明祝贺、路线评价和国际联结方式；“重大贡献”和美国资本集团影响中国的判断属于政治预测与归因，须与美国政策和中国内战结果分开验证。

# Pass 3 — 推理重构

1. 以政党路线选择作为国际联盟信号；
2. 把美国国内工人运动与对华外交压力连接；
3. 将反法西斯战争、战后和平、民主建设拆成不同结果；
4. 通过跨国组织协调扩大政策反对力量。

# Pass 4 — 对抗性阅读

电报把美国共产党路线争论解释为阶级力量对外政策的反映，但美国政府、工会和社会舆论并非单一行动者。路线纠正可能提升组织独立性，却不自动转化为外交政策改变；国际声援也不能替代中国国内谈判与军事能力。
