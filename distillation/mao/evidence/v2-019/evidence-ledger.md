## Evidence judgment

### High-confidence methodological positives

- composite actor decomposition;
- trade/aid/participation semantic separation;
- dependency sources should be classified by reliability.

### High-confidence methodological negative case

V2-019 是目前语料中最清楚的一个例子：

```text
strong ideological prior
+ incomplete observable information
+ asymmetric evidence standards
-> coherent but materially incomplete causal explanation
```

这不是轻微措辞问题，应保留为后续 Skill 的**反例资产**。
