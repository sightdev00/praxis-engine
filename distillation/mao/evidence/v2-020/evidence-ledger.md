## Adversarial checkpoints

1. “三大法宝”之外有哪些失败/成功残差？
2. 三个变量是否过宽到能够事后容纳几乎一切？
3. 专门内部刊物是否产生可观察的质量/一致性改善？
4. 高压实际任务在什么条件下促进学习，在什么条件下固化错误？
5. 后续整风、报告制度、党委制是否提供更明确的学习控制机制？

## Research-control consequence

遇到历史经验的低维压缩时增加 `residual analysis`：

```text
compressed model
-> predicted/explained cases
-> unexplained residuals
-> alternative dimensions
-> whether model remains useful after residual audit
```
