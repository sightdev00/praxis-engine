## Evidence architecture

### What is strongly supported textually

1. 本文确实采用 `表现 -> 来源 -> 纠正办法` 的重复诊断格式；
2. 纠正手段跨教育、制度、组织、成员构成、物质条件和信息流；
3. 调查和证据被明确纳入分析/批评规则；
4. 上下级信息流和讨论—执行阶段被明确设计。

### What is weak empirically

1. 每种错误思想被归因于特定阶级/社会来源；
2. 某项纠正方法单独造成了后来的组织改善；
3. “正确路线”本身的外部有效性。

## Key audit conclusion

本文对 **control architecture** 的文本证据很强，对 **specific causal diagnosis** 的实证证据较弱。因此后续抽象应优先研究：

```text
how errors are surfaced
how evidence flows
how decisions are discussed
how commitment is enforced
how interventions span multiple layers
```

而不是直接继承其八类思想标签及社会来源解释。
