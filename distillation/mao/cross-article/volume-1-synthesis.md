# Volume I Synthesis — 毛泽东选集第一卷

> Scope: V1-001 through V1-018  
> Status: first-pass within-volume synthesis  
> Confidence ceiling: mostly `P2`; **no `G3` skill rules** are promoted from one volume alone  
> Methodological caution: V1-001/V1-002 were written under the legacy protocol and require current-protocol re-audit. V1-017/V1-018 are later philosophical syntheses and must not retroactively overwrite the operational evidence that precedes them.

---

# 1. What Volume I actually contains

Volume I is not one homogeneous theory text. For this project it contains at least six materially different problem families:

```text
1. social / actor analysis
2. field investigation and mobilization
3. base-area survival and governance
4. organizational correction
5. economic work and support systems
6. military strategy and stage transition
7. united-front / actor reconfiguration
8. explicit epistemology and dialectical philosophy
```

This diversity is precisely why within-volume repetition is more useful than reading only `实践论` and `矛盾论`.

The strongest patterns are those that appear before 1937 in operational texts and are later made explicit in philosophical texts.

---

# 2. The core epistemic loop reconstructed from the volume

Across V1-002, V1-004, V1-005, V1-006, V1-007, V1-013 and V1-017, the most persistent structure is not a slogan but a control loop:

```text
reality / task state
-> investigate / observe
-> audit and synthesize evidence
-> construct judgment/model
-> choose objective and action
-> execute
-> compare result with expectation / new state
-> locate error or changed condition
-> revise model / parameter / policy / organization / plan
-> re-enter reality
```

## 2.1 This is not equivalent to `practice automatically produces truth`

Volume I itself already shows why:

- V1-004: rapid organizational growth produced misleading success signals;
- V1-006: direction could be broadly correct while a time parameter was wrong;
- V1-007: investigation itself can be incorrect;
- V1-013: raw reconnaissance requires filtering and synthesis;
- V1-016: high-level framing can condition how local facts are interpreted;
- V1-017: theory must return to practice, but successful outcome alone cannot uniquely identify causality.

Therefore the modern reconstruction must contain explicit epistemic controls.

# 3. P2-01 — Problem representation precedes solution

The corpus repeatedly changes the outcome by changing what the problem is taken to be.

Examples:

- V1-001: the practical question is not abstract class taxonomy but which forces can be united, contested or expected to move;
- V1-002: `农民运动糟不糟` is decomposed into concrete actors, behaviors, power shifts, results and side effects;
- V1-003: `红色政权能否存在` is reframed from an assumed impossibility into a conditional configuration question;
- V1-005: organizational symptoms are decomposed into manifestations, causes and correction methods;
- V1-008/V1-010: `economic work vs war` is reframed as central task plus supporting capability rather than a binary choice;
- V1-018: different qualitative structures require different methods.

Working principle:

> Do not optimize inside the user's or agent's first framing until the decision-relevant structure has been reconstructed.

This remains `P2`, not a final universal rule.

---

# 4. P2-02 — Reality contact is necessary, but the observation ontology is revisable

V1-002 and V1-007 make field investigation unusually explicit.

But Volume I also supplies an important correction to naive empiricism:

```text
field access
!=
correct representation
```

Why:

- V1-004 shows kinship, native/outsider identity and local history interacting with class categories;
- V1-007's investigation schema privileges class relations and therefore itself embodies an ontology;
- V1-009 turns class concepts into execution categories, raising the cost of misclassification;
- V1-013 requires evidence synthesis rather than mere collection;
- V1-017 explicitly rejects remaining at the sensory/fragmentary stage.

Modern reconstruction:

```text
collect evidence
+
question the schema used to collect/classify evidence
+
retain competing representations when decision-relevant
```

---

# 5. P2-03 — Raw evidence, interpretation and decision are separate layers

This pattern becomes increasingly explicit over the volume.

V1-013 provides the clearest operational chain:

```text
reconnaissance material
-> filtering
-> authenticity check
-> relational synthesis
-> judgment
-> decision
-> plan
```

V1-017 generalizes it philosophically as sensory -> rational -> practice.

Praxis Engine must preserve at least:

```text
Observation
Interpretation
Belief/Judgment
Commitment
Action
Validation
```

Collapsing these layers creates several failure modes:

- inference reported as fact;
- plausible interpretation upgraded to commitment;
- action success used to self-validate the same theory;
- later editorial framing treated as contemporaneous evidence.

---

# 6. P2-04 — Judgment formation and action commitment require different control modes

V1-005 is especially important here.

Before commitment:

```text
facts
+ lower-level information
+ competing opinions
+ discussion
-> judgment
```

After a decision is actually adopted:

```text
coordinated execution
-> common action
```

Then reality may reopen the judgment.

This yields a useful control boundary:

```text
OPEN EPISTEMIC PHASE
    ↓
COMMITMENT GATE
    ↓
COORDINATED EXECUTION
    ↓
VALIDATION GATE
    ↓
REOPEN IF NEEDED
```

This maps closely to Agent systems but should remain an independent historical finding until cross-volume validation.

---

# 7. P2-05 — Stage is a state transition, not a calendar label

Repeated support:

- V1-002: organization / public action / revolutionary stages correspond to changes in organization and force;
- V1-003/V1-004: tactics effective during one enemy configuration fail after the political state changes;
- V1-006: local events should not automatically redefine the whole trend;
- V1-012: external invasion reconfigures actor relations and alliance strategy;
- V1-015/V1-016: peace attained vs consolidated; principal political contradiction shifts without other contradictions disappearing;
- V1-018: stages arise as tensions intensify, weaken, emerge or change form.

Working model:

```text
stage = f(force structure, active relations, capability, task, risk, transition conditions)
```

not:

```text
stage = date interval
```

---

# 8. P2-06 — Actor maps are dynamic, conditional and intervention-sensitive

The actor model matures across the volume.

Early form:

```text
material position
-> predicted stance
```

Later form:

```text
position
+ trajectory
+ pressure
+ organization
+ force balance
+ success expectation
+ identity/history
+ our own intervention
-> current behavior + movement conditions
```

Evidence:

- V1-001/V1-002: internal segmentation and movement under changing strength;
- V1-004: policy itself pushes middle actors across coalition boundaries;
- V1-012: external invasion changes prior enemy/ally configuration;
- V1-014: declared stance change is not treated as sufficient—later action is used for validation;
- V1-015/V1-016: alliance structure changes with political stage.

Important constraint:

> `can cooperate` is not the same as `can rely on`.

Actor mapping therefore requires reliability and movement triggers, not only current labels.

---

# 9. P2-07 — Effective capability is structural, not a raw-count metric

Volume I repeatedly rejects naive quantity measures.

Examples:

- industrial workers: concentration and production position matter beyond number;
- peasants: organization changes effective capacity;
- regular force, local force, party structure, logistics and mass support are different capabilities;
- membership count can rise while resilience falls;
- globally weaker forces can create local superiority at a decisive point.

Working rule:

```text
nominal quantity
!=
usable capability
```

Do not preserve the early pseudo-formula multiplying every variable; actual dimensions are task-dependent.

---

# 10. P2-08 — Infer constraint topology before selecting a prioritization rule

This is one of the most important corrections generated by our own research process.

Volume I contains several different structures:

## A. Dependency/enabling sequence

V1-002 can be read as one constraint opening later work.

## B. Conjunctive configuration

V1-003 explains viability through multiple conditions that jointly matter.

## C. Core objective + support subsystems

V1-008/V1-010: war is central, economic work is necessary support.

## D. Local decisive point inside a larger system

V1-013: global weakness can coexist with local concentrated superiority.

## E. Principal strategic relation

V1-015 and V1-018 explicitly use a principal-contradiction structure.

Therefore Praxis Engine should not begin with `find the principal contradiction`.

It should begin with:

```text
What topology does the problem actually have?

- bottleneck?
- dependency chain?
- multiple necessary conditions?
- threshold?
- compensatory trade-off?
- core objective + support systems?
- network / feedback system?
- unknown?
```

Then ask whether one relation currently deserves principal decision weight.

---

# 11. P2-09 — Principal does not mean only

This is the key narrowing of `主要矛盾` supported by the operational corpus.

V1-015 explicitly says that when the Sino-Japanese relation becomes politically principal, domestic contradictions continue to exist.

V1-018 distinguishes principal from secondary relations rather than erasing the secondary ones.

Modern reconstruction:

```text
principal = highest current system-wide strategic weight
not
principal = only active variable
```

Furthermore, a secondary constraint can still be safety-critical or execution-blocking.

So prioritization must preserve guardrails.

---

# 12. P2-10 — Different objects and levels can legitimately require opposite rules

Repeated examples:

- regular force concentration vs local-force dispersion;
- strategic defense vs local tactical attack;
- global weakness vs local superiority;
- current mobility vs future regularization;
- rough planning for highly dispersed activity vs precise planning for concentrated enterprises;
- current democratic-stage work vs long-term socialist objective.

Therefore a rule should carry metadata:

```text
object
level
stage
objective
conditions
failure boundary
```

A rule stripped of those fields becomes a slogan.

---

# 13. P2-11 — Planning precision should match uncertainty and controllability

Volume I does not support arbitrary precision.

Evidence:

- V1-006: broad trend retained while a one-year deadline is explicitly withdrawn;
- V1-010: planning precision differs across economic forms;
- V1-013: mobile environment makes long-range concrete plans unstable and frequent revision normal.

Working principle:

> Use only the planning resolution the environment, evidence and control capability can support.

This is stronger than generic `be flexible`.

---

# 14. P2-12 — Execution method changes the system; it is not a neutral transport layer

Examples:

- coercive mobilization can create nominal compliance and long-term distrust;
- attention to concrete participant constraints changes mobilization outcomes;
- over-left policy changes the coalition itself;
- organizational control roles that appear redundant may carry hidden functions;
- execution after plan formation produces new knowledge.

Therefore:

```text
same objective
+
different execution mechanism
-> different state trajectory
```

This means implementation architecture belongs inside reasoning, not after it.

---

# 15. P2-13 — Growth metrics must be stress-tested

The strongest case is V1-004:

```text
membership rapidly grows
-> hostile pressure arrives
-> large part collapses
-> re-registration / stricter structure
-> smaller nominal organization, greater reported resilience
```

The lesson is not `smaller is better`.

It is:

> Evaluate a system under the conditions it is supposed to survive.

Volume II organizational/governance texts should test this further.

---

# 16. P2-14 — Long-term direction and current admissible action are different objects

Volume I repeatedly separates:

```text
long-horizon objective
current stage objective
current executable task
```

Examples:

- V1-006: direction retained, calendar forecast removed;
- V1-008/V1-010: future economic direction does not erase current wartime constraints;
- V1-012/V1-016: stage transition depends on conditions rather than wish or calendar;
- V1-017: theory should guide current practice but remain revisable.

This separation is central to avoiding both short-termism and premature future-state implementation.

---

# 17. P2-15 — Correction must identify *which layer* failed

The revision ledger now reveals different error classes:

```text
factual error
representation / ontology error
causal-model error
stage error
actor-model error
parameter error
policy design error
organizational design error
metric error
execution error
argument insufficiency
scope / boundary error
environment change
```

Volume I strongly suggests that `the result was bad -> change strategy` is too coarse.

A reliable learning loop asks:

> Which layer of the stack is contradicted by the evidence?

This is a major candidate for future Agent integration.

---

# 18. P2-16 — Philosophy appears to formalize earlier practice, but also overstates some operational heuristics

## `实践论`

Strongly aligns with prior operational evidence on:

- reality contact;
- sensory evidence -> synthesis;
- theory -> action;
- action -> correction;
- knowledge as historically scoped.

But its final upward spiral overstates the reliability of self-correction unless additional controls exist.

## `矛盾论`

Strongly aligns with prior evidence on:

- specificity;
- stage change;
- non-uniform priority;
- dynamic dominance;
- different methods for different structures.

But its strongest universal claim—one principal contradiction in every complex process, grasping which makes all problems readily resolvable—is too strong for the operational corpus itself.

This is a crucial research finding:

> The philosophical synthesis should be tested by the practice record, not granted automatic authority over it.

# 19. Major unresolved tensions after Volume I

## T1 — Principal contradiction vs multiple-necessary-condition systems

Can `主要矛盾` be rigorously distinguished from:

- bottleneck;
- dominant dependency;
- objective function;
- most salient conflict;
- highest-value intervention point?

Volume II must test this.

## T2 — Practice as truth criterion vs causal ambiguity

How does the framework distinguish:

- theory failure;
- implementation failure;
- luck/noise;
- omitted variable;
- adversarial adaptation;
- bad measurement?

`实践论` does not fully specify this.

## T3 — Investigation vs ontology lock-in

How does an investigator discover variables that the initial classification schema does not contain?

This is especially important after V1-004/V1-007/V1-009.

## T4 — Deliberation vs organizational obedience

V1-005 combines broad discussion before resolution with disciplined execution after resolution.

But what mechanism reopens a wrong committed decision when hierarchy resists correction?

Volume II/III leadership and organization texts may answer this.

## T5 — Mass participation vs manipulation/coercion

Several texts value mobilization, organization and participant agency, while others operate in coercive revolutionary conditions.

Modern transfer requires strict ethical/legal separation; participation must not be romanticized from historical mobilization alone.

## T6 — Dynamic actor model vs ideologically fixed classifications

Operational texts sometimes treat actors dynamically; philosophical/political classifications can also make strong structural predictions.

We need later cases where actors violate expected class/structural behavior.

# 20. Philosophy-layer reflection

After Volume I, the most defensible philosophical position for Praxis Engine is provisional realism:

```text
Reality exists independently of our model.
Our access to it is mediated by evidence, categories and action.
Models are historically and operationally bounded.
Action can reveal mismatch but does not automatically identify the correct explanation.
Knowledge remains revisable.
```

This is **our synthesis**, not a claim that Volume I formulates modern scientific realism in these terms.

This should **not** yet become the final Skill schema. Volume II must try to break it.

# 22. Methodology-layer reflection

Our own research protocol improved materially during Volume I:

1. from instant abstraction to source reconstruction first;
2. from `G1/G2/G3` to `H1/P1/P2/G2/G3`;
3. from undifferentiated facts to evidence typing;
4. from success-only cases to revision/failure ledger;
5. from one confidence axis to textual vs empirical confidence;
6. from single-bottleneck bias to constraint-topology inference;
7. from `practice = learning` to reversibility/failure-cost gating;
8. from canonical text only to variant-sensitive source criticism;
9. from article summary to object-loop + meta-learning-loop.

The important meta-result is that methodology changed because the corpus contradicted our framework, not because we wanted more process.

# Volume-I first-pass takeaway

The strongest distilled structure is not a list of aphorisms.

It is a provisional way of controlling action under changing reality:

```text
start from the concrete state
-> reconstruct the actual problem
-> gather decision-relevant evidence
-> audit and synthesize it
-> map actors / relations / capabilities / constraints
-> infer stage and constraint topology
-> choose priority without erasing guardrails
-> separate judgment from commitment
-> act at a risk-appropriate scale
-> observe what actually changed
-> localize the error when reality disagrees
-> revise the correct layer
-> repeat
```

Volume II should be treated as a hostile test of this reconstruction, not as additional material to confirm it.
